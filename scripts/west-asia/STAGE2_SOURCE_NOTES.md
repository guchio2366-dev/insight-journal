農産品の生産値と製材品の生産・輸入・輸出は現行 main の保存済み FAOSTAT 資料を維持。製材品の統計は食料自給率には転用しない。農産品の輸入相手国・輸出先・国内仕向け、カロリー基準食料自給率は、対応する同年・同品目の貿易行列と食品需給表が保存されていないため、数値・円グラフを作らない。FAOSTAT の QCL bulk 配布先は 2026-10-09 と 2026-10-11 に接続拒否を確認済みで、同じ経路の再試行はしない。既存の世界生産比の出典と欠測の扱いは維持する。

2026-10-11 に代替の公的経路も調査。FAO は [新API開発者ポータル](https://www.fao.org/statistics/highlights-archive/highlights-detail/faostat-launches-a-new-api-developer-portal-to-make-data-access-easier/en) を案内するが、API利用には登録とキーが必要で、本実行環境にその認証はない。[FAO詳細貿易行列のカタログ](https://data.fao.org/catalog/dataset/955a7b61-ce56-4a04-adf5-61a3012eec84) と [食料需給表のカタログ](https://data.fao.org/catalog/iso/2f264bb6-1238-459a-bf8b-0e2d0a16804a) は資料の存在を確認できる一方、個別データ行はこの環境から取得できなかった。別の集計・時点やHS品目をFAOSTAT QCLの品目と接ぎ合わせて需給・カロリー自給率を算出しない。取得可能な公式行が揃えば、品目・国・年・単位・再輸出と欠測を照合して追加する。

水資源面は地下水を含む地層の広域分類であり、補給速度・年間利用可能量・現存貯留量を直接表さない。水の点は自然水源面と異なる供給工程の事例として重ねる。地形名称と主要都市は位置を読む補助であり、地形の法的境界や都市行政界ではない。民族・宗教の既存掲載域は GeoEPR/EPR-ED の抽出例で、最多属性の地図でも全住民の網羅分布でもないため、資料の範囲を保つ。

## 2023年の食料需給・貿易行列の追加

上の「保存されていない」は第二段初稿時点の状態。2026-10-11 に分析済みの公式 FAOSTAT 抽出パケットが渡され、小麦、ナツメヤシ、オリーブ油の一部について同年の FBS と詳細貿易行列を追加した。原 CSV ZIP はこの実行環境に存在せず、元の CSV 名・SHA256 と返却値合計は `src/data/atlas/west-asia-wheat-2023.json`、`src/data/atlas/west-asia-mediterranean-food-2023.json` に記録。原 CSV との照合はパケット提供元が別途実施した。公開画面の値は分析パケットにある返却値に限定する。

FBS の小麦・小麦製品（S2511）、ナツメヤシ（S2619）、オリーブ油（S2580）はそれぞれ対象20中19の国内供給・食用供給を示す。パレスチナの行は未収録であり 0 としない。生産、用途、在庫の収録国数は要素ごとに異なるので、19対象に完全な収支帯を作らない。食用供給は実際の摂取量でも、国内産由来の熱量でもない。カロリーベース食料自給率は引き続き未算出。

詳細貿易行列の原穀小麦（CPC 0111）とオリーブ油（CPC 2167）の円は、20対象のうち返却行のある報告国から域内取引を除いた相手先別量。上位5と「その他」は、その域外返却量を分母にする。再輸出を含む。FBS と TM、オリーブ果実と保存食用オリーブとオリーブ油は定義・単位が異なり、相互に加減算しない。既存のオリーブ地図は果実の QCL 国別生産量で、油の円は別品目の地域供給網として添える。

追加の照合済みパケット `src/data/atlas/west-asia-olives-dates-2023-missing.json` で、オリーブ保存品込み（FBS S2563）13数量要素157セル、TM 原料オリーブ（01450）・保存オリーブ（F0262）・ナツメヤシ（01314）の域外1272行を接続した。FBS オリーブの国内供給4,053千tと食用供給1,139千tは同じ19対象。品目全体が食用向けではない。加工2,195千tは10対象、損失298千tは13対象、飼料・種子の原表0は各ヨルダン1対象だけ。欠測を0にせず、異なる収録国集合の用途を積み上げて100%にしない。在庫増減−21千tと残差139千tの符号も保持する。

TMの保存オリーブ域外輸出141,198.64t（12報告国）をオリーブ画面の主円とし、原料オリーブ416.57t（5報告国）とオリーブ油145,176.58t（14報告国）は別系列の詳細に置く。ナツメヤシの域外輸出302,881.72t（13報告国）は同品目の別円にする。いずれも輸出先上位5と返却された他の域外相手のみが円の分母で、未報告国や最終消費地を示さない。各CSVのレコード範囲は候補範囲であり、保存した全フィルターを適用して初めて対象行となる。
