# メキシコ農林業・追加需給と輸出先参考

2026-10-16に確認した公式公開資料の地域専用抽出。主目的の全品目・同期間三列は未完成。

- `gain-MX2026-0018-tables.txt`：USDA FAS公式公開PDFのp.12とp.21の表をwebツールの行番号付きテキストから保存した抜粋。原PDFファイルはこの環境ではダウンロードしていない。2024/2025の最初の `USDA Official` 列だけを採用し、隣接 `New Post` や2025/26・2026/27列を混ぜない。
- `wits-*.txt`：World Bank WITS / UN Comtrade公式公開表で観測した数量・分類の記録。コーヒーと針葉樹製材は行番号付き抜粋、とうもろこしと綿は観測した数値の転記。原HTMLとは呼ばない。
- `wits-*.csv`：同じ公開表のReporter=Mexico、Export、2024、H0、Worldと掲載相手の数量転記。輸出額は本実装の分母に使用しない。製品コードの先頭0を保存する。
- 綿花と精米の需給原行は既存の `scripts/data/wasde0926.txt` を参照する。別地域用の共通生成物は更新しない。

再生成：`python scripts/prepare-mexico-agro-statistics.py`。入力SHA-256と年・報告国・品目・単位・重複・収支・相手合計を検証し、`src/data/atlas/mexico/agro-statistics-20261016.json` のみ生成する。取得や外部通信は行わない。

国内利用は公表Total Consumption / Domestic。輸入・期首在庫を含む供給からの仕向けで、国産生産を国内と輸出へ直接分割した量ではない。飼料・残差とFSIは国内利用の内数。精米と籾、繰綿と種付き綿、子実と青刈り、原木と製材を換算・合算しない。

2024暦年HS輸出先表は全て `balanceCompatible=false` の閉じた別資料。比率の分母は掲載された全相手の数量合計、World行は別の公表総輸出として表示する。相手合計との差（とうもろこし+0.043 t、綿+0.002 t、コーヒー−0.030 t、製材0 m³）を保持し、残差国や消費を捏造しない。0.1 t（製材0.5 m³）の監査許容幅は生成時の不一致検出用で、欠測相手の存在や真の丸め誤差を証明するものではない。

メキシコ全国の国境外への輸出で、国内取引を含まない。米国・カナダも国外相手に含める。北米地域全体の域外輸出へ再利用する際は、その地域内相手の除外を別途行う必要がある。総輸出から再輸出や輸入原料を分離できず、相手国は最終消費地とは限らない。

丸太・製材・木材パルプの同年FO需給は未取得。HS440710の針葉樹製材m³は、全樹種の製材・松限定生産・2022年INEGI松材取得の代理ではない。取得の障害と必要な公式書出しは `docs/atlas-mexico-agro-statistics-20261016.md` に記載。
