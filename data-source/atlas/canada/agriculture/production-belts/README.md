# カナダの主要生産帯（2021年）

地図で読む対象は、行政地域ごとの最大品目ではなく、品目ごとの特徴的な集積の広がりです。`src/data/atlas/canada/agriculture-production-belts.json` に、公式分布図と保持した個別CCS公表値を照合して汎化した独立の輪郭を保存しています。作物と畜産の帯は重なります。帯の面積・濃さ・線幅に数量を割り当てません。

## 採用した根拠と方法

- Statistics Canada の2021年Census of AgricultureのCD別ドット分布図。原図の点は各CDの農業エクメーネ内へランダム配置されており、農場座標ではありません。ドット位置を農場として転記せず、まとまった集積を緩い輪郭として読みます。
- 作物・肉用母牛・乳牛と飼料・土地利用には、既存の1,757 CCSポリゴンと保持した原表の値・品質・成分を照合します。帯の輪郭をCCS境界へスナップせず、各CCS内の最大品目で塗りません。
- レンズ豆は、保持した2021年のCCS別レンズ豆面積を根拠にサスカチュワン南西部を汎化しています。干草・放牧地の3帯は補助品目で、選択時に表示します。
- 豚と養鶏の地理は2021年の公式CD図のみを根拠とします。既存の州値をCCSへ配分しません。原図の丸められたドット数から頭数を復元しません。
- 養鶏図は肉用・採卵用の合計です。地図の名称は「養鶏（肉・卵）」とし、既存の鶏肉生産者数や鶏肉の現金収入を別の指標として保ちます。broiler専用のAAFC CCS GISは2011年、StatCan CD図は2015年のため、2021年の地図へ混ぜていません。

`ccs-production-support.json` は帯内に表示アンカーが入る既存CCSの照合用台帳です。上位3例のDGUID・公表セル・品質・元成分をそのまま保存します。地域件数は照合例の件数であり、農場数ではありません。合計値、帯の面積、生産量、州値の再配分を作りません。再生成は `node scripts/prepare-canada-agriculture-belt-support.mjs`。

## 採用範囲

初期表示は10品目・32帯、補助3帯を含めて35帯です。カノーラ・小麦・レンズ豆と肉牛のプレーリー、Peace、BC内陸、とうもろこし・大豆の南部ON/QCとMB、ジャガイモのAB/MB/ON/QC/NB/PEI、酪農のON/QC/Fraser/AB中央/Saguenay、養豚のMB/ON/QC、養鶏のFraser/ON/QC/Annapolisを採用しています。

次点はAB南部の乳牛、Saguenayのジャガイモ、ABの養豚、AB・MBの養鶏、小規模な他州の作物・畜産集積です。全国の全農場や全産地の網羅図ではありません。原図と原表を根拠に追加できます。2021年の肉用鶏だけの地域別機械可読データと豚のCCS値は未取得です。

## 取得・実見の記録

`source-manifest.json` に元URL、年次、対象、取得結果、原bytesのSHA-256、実見の状態を記録します。元図は既存の安全なCIジョブで通常HTTPS取得し、元bytesのSHAを照合して確認用環境へ持ち帰りました。デザイン上の描画には原画像を埋め込まず、出典付きの独自汎化輪郭を使います。

直接取得時のエラーは `URLError: Tunnel connection failed: 403 Forbidden` でした。安全設定・証明書・権限を変更せず、既存CIの通常HTTPS取得で代替しました。ユーザーLibraryの2参照画像は正規取得と許可された再試行が `download failed` のため、未実見のままです。公式原図の実見とは別に記録します。
