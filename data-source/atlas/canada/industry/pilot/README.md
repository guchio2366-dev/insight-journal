# カナダ主要産業パイロット：資料と表示の契約

基点は公開main `e81854398cea55525242a1ed24ad8d10a03917e0`（欧州PR314）。カナダの主要産業画面だけを改修する。主要産業の大タブ内で、資源・エネルギー／製造業／サービス業の3分類を切り替える。これは学習用分類であり、統計上の第2次・第3次産業の分割ではない。

## 地図に採用した対象

10産業、45件の位置レコード。資源21件、製造19件、サービス15件（分類間で重複するため、これらを足して施設数とはしない）。同じ施設群のID・座標・資料を共有し、説明だけが分類の目的に従う。

- 石油・天然ガス：アサバスカ、モントニー、ニューファンドランド東方沖。東岸沖を代表都市の位置に置換しない。
- 石油精製：エドモントン〜レッドウォーターの複数施設、BC・オンタリオ・ケベック・NBの加工拠点。CERの稼働施設記述を採用。
- ニッケル：サドベリーの採掘・選鉱・精錬、トンプソンの採掘・選鉱、ヴォイジーズ・ベイの採掘・選鉱、ロングハーバーの湿式精錬。Vale Base Metalsの操業資料。
- アルミ：サグネ・ラックサンジャンとキティマット。Rio Tintoの地域操業資料。カナダ国内のボーキサイト採掘を示さない。
- 水力：ピース・コロンビア・ラグランド・ロメーヌと、製錬に結び付くケマノ・サグネ水系。CERと操業者資料。
- 自動車・バス：オンタリオ南部の4集積に、ウィニペグとモントリオール近郊の大型車を加える。ISEDの2024年乗用車・2025年大型車の表。終了・計画状態の工場を現在稼働中に読み替えない。
- 航空機・部品：ミラベル、ミシサガ、フォートエリー。Airbus・MHIの製造拠点を採用。本社やサービスオフィスを生産拠点に数えない。
- 金融・保険：トロントとモントリオール。市・地域産業機関の資料。
- 情報技術：トロント、ウォータールー、オタワ、モントリオール、バンクーバー、カルガリー。Invest in Canadaの技術集積説明。
- 物流：太平洋・プレーリー・中央・大西洋回廊の7拠点。Transport Canada 2024。

URL、確認日、資料の範囲は `src/data/atlas/canada/industry-pilot.json` の `sources` に一元化し、ページに表示する。資料の図・写真は転載しない。自作の説明と位置案内だけを配信する。

## 位置・集積と線

基図は既存の公式州境、Natural Earthの国土・水系、NOAA ETOPO地形線。既存Web Mercatorの座標契約を使用する。産業の座標はWGS84の編集上の**概略地域案内位置**。存在する地域・工程を一次資料で確認しており、施設の測量座標、鉱床境界、統計的密度、実測の集積範囲ではない。例えば「エドモントン〜レッドウォーター」は複数施設をまとめる。全工場・全鉱山の網羅図とはしない。主な集積の全国的な広がりを同時に読む初版。

円・四角は一定サイズの位置記号。数量でサイズを変えない。加工・精製・精錬は四角、採取・発電・サービスは円。複数産業が同じ都市圏にある場合は案内位置を共有して記号を横に並べ、産業名・色を併記する。ラベル引出線は位置案内で、輸送・取引ではない。

地図の破線矢印は**ヴォイジーズ・ベイ→ロングハーバーの精鉱輸送**だけ。操業者が明記した実流通関係だが、曲線は海路の模式表現で、正確な航路・量ではない。サドベリーの精錬→航空宇宙等は一般的用途として本文に書き、特定の機体工場への販売線を描かない。精製拠点どうしも、近接だけで結ばない。

## 統計

既存の2021年GDP・雇用抽出と、2024年原油輸出（420万b/d・米国向け93%・アルバータ由来91%）を保持。原油説明の原典版・分母も保持する。

保持済み原CSVからNAICS 324（石油・石炭製品製造）、48–49（運輸・倉庫）を追加抽出した。2021年・当年価格・基本価格・百万CAD、各13州・準州で26行。全国GDPは州・準州の公表値合計。運輸・倉庫の雇用は同じ保持済みLFS原CSVの全国値986.7千人。精製の細分類雇用は未取得（null）。抽出CSVと入力SHA256は本ディレクトリに保存。

鉱業・一次金属／金属製品・電力等の既存統計は、ニッケルだけ、アルミだけ、水力だけの値にしない。情報技術の一致する都市別統計は未取得。地図の学習分類は重複するので合計しない。従来の全国構成は原NAICSの既存分類で保ち、表示分類へ再配分しない。

地図下の3列は①対象を明記したGDP・雇用、②同じ統計区分の州別GDP、③原油輸出／港湾貨物量／原料工程。港湾貨物量はTransport Canada 2024のバンクーバー158百万t、プリンスルパート23.5百万t。地図記号にGDP・重量・雇用の共通丸尺度を使わない。

## 次点と不足

NRCanの鉱物facts（新旧URL）に403・取得不可が生じ、鉱物全国生産量は追加していない。カリ肥料・ウラン・鉄鉱石・銅・金の面的分布と数量は次点。Saskatchewanの公式操業地図は参照入口が確認できたが、動的レイヤー本体を取得できず、州の代表都市1点で代用しない。食品・木材・機械・電子機器等の製造、医療・教育・観光・行政は未整備。航空宇宙のウィニペグ等を含む全国完全台帳、全拠点の座標資料、操業時点のそろった地域別雇用・品目生産量、最終需要者の実取引資料が不足する。

## PC検証

主確認は1920×1080 CSS viewport、ブラウザ100%、DPR1。1440×900は補助。実ブラウザのviewport・visualViewport.scale・DPR・地図枠・統計列・Git SHAを `verification.json` に記録する。3分類の初期・産業選択・地点選択・単独表示・解除・切替・履歴・再読込と、精製／ニッケル／アルミの重複表示を実画面で検証する。

ローカルChromiumはsandbox付き起動で `setuid_sandbox_host.cc:166 ... The SUID sandbox helper binary was found, but is not configured correctly ... /usr/lib/chromium/chrome-sandbox ... mode 4755` と停止。安全設定・証明書・権限を変更しない。既存の `industry-regional-review.yml` の同じreviewジョブにこのPCキャプチャを追加し、新しいCIジョブや有料ブラウザを追加しない。画像が取得・目視確認されるまで合格としない。
