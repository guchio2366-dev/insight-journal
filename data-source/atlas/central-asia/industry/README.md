## 石油

採用理由：最大級の外貨収入とロシア側搬出路への集中を示す。天然ガスとは産地・販売先・輸送条件が異なる。

確信度：高。

地図で読ませること：カザフスタン西部のテンギスと北カスピ海のカシャガンに大型油田が分布し、産地から黒海へ延びる管路が輸出を支えます。

集積理由：堆積盆地の資源、処理設備、輸出路の接続が生産と販売を支えます。カスピ海パイプライン・コンソーシアム（CPC）はカザフスタン輸出石油の3分の2超を扱うため、搬出路への集中も重要です。

工程：油田で採掘 → 処理 → 原油の輸送・販売。CPCの総積出量にはロシア産も含まれます。

範囲の注意：世界比較の石油は原油以外も含みます。油田の案内点は生産量の円や敷地境界ではありません。

## 天然ガス

採用理由：中国への供給と顧客集中を示す。油ガス一括では中国の管路輸入への寄与が消える。

確信度：高（規模の金額換算は未確認）。

地図で読ませること：トルクメニスタン南東部のガルキニシュでは天然ガスを採取・処理し、ウズベキスタンとカザフスタンを通る幹線で中国市場へ接続します。

集積理由：大型ガス鉱床と処理施設、長距離管路が結び付きます。2024年の中国向けはトルクメニスタンの管路輸出の約73%で、販売先の変更は輸送能力・契約にも制約されます。

工程：ガス田 → 処理 → パイプライン輸送。処理能力と実際の生産、商業化生産と総生産は別です。

範囲の注意：確認したガス田の位置例を示します。中央アジア全ガス田の一覧と最新のガス単独GDP・輸出金額は未収録です。

## ウラン採掘・回収

採用理由：一次採掘の供給集中、日本企業の契約調達、燃料供給網の工程差を示す。銅・金の総称へまとめない。

確信度：高。

地図で読ませること：カザフスタン南部のシュウ・サリス盆地とウズベキスタンのウチクドゥク・ザファラバード・ヌラバード地区にウラン採掘・回収が分布します。

集積理由：透水性のある砂岩層は、地中の鉱石を溶液で回収する採掘法に適します。採掘の世界シェアと、転換・濃縮・燃料加工の供給網は別です。

工程：砂岩型鉱床 → 溶液による回収 → 酸化ウラン。tUはウラン金属含有量、U₃O₈は酸化物重量で、そのまま加算しません。

範囲の注意：企業権益比例の20%をカザフスタン全体の39%と混同しません。日本企業との契約は最終燃料消費地を意味しません。

## 銅鉱業・製錬

採用理由：輸出規模と電化素材、採掘・選鉱・製錬の違いを示す。企業の鉱山別実績を国全体の量と分ける。

確信度：高。

地図で読ませること：銅の採掘・選鉱はボズシャコルとアクトガイ、製錬はジェズカズガン・バルハシに分布し、ウズベキスタンのアルマリクでは採掘と加工が近接します。

集積理由：大規模鉱床が採掘地を定め、鉱石・精鉱の処理設備と電力・輸送が加工拠点を支えます。銅は送電・電化の素材で、採掘の比率と精製の比率は異なります。

工程：鉱石 → 選鉱で精鉱 → 製錬・精製で金属銅。工程別の生産量を足すと同じ金属を重ねて数えます。

範囲の注意：輸出金額は別品目の合計ですが付加価値ではありません。国際エネルギー機関（IEA）の2035年供給差25%は将来推計で、現在の不足率ではありません。

## 金鉱業

採用理由：輸出と企業収益への寄与、価格による稼ぎの変化を示す。電化素材の銅とは用途と収益構造が異なる。

確信度：高。

## 水力発電

採用理由：世界規模より国内電源依存と季節的な電力輸出を重視する。山地上流の発電と下流の灌漑を別用途として扱う。

確信度：高（発電構成は2023年）。

地図で読ませること：キルギスのナリン川のトクトグル、タジキスタンのヴァフシュ川のヌレークとログンに水力施設が連なり、山地の落差と季節的な水を利用します。

集積理由：山地の落差、融雪水、貯水と送電網が立地を支えます。上流の発電と下流の灌漑は水の季節的な配分で関わり、タジキスタンの電力輸出は増水期に集中します。

工程：河川水・貯水 → 発電 → 送電。設備容量MW、年間発電GWh、商業電力輸出は別の指標です。

範囲の注意：ログンは一部稼働・建設中。完成後の出力・輸出計画や未完成送電事業を現在の実績として描きません。

## クロム鉱石・フェロクロム

採用理由：クロム鉱石の世界優位とステンレス鋼向け合金加工の稼ぎを示す。鉱石とフェロクロムの段階を分ける。

確信度：高（製品別実績は2024年）。

地図で読ませること：クロム鉱石の採掘・選鉱はカザフスタン西部のフロムタウに集まり、アクトベとアクスの製錬が鉱石と電力を組み合わせてステンレス鋼向けフェロクロムを生産します。

集積理由：クロム鉱床と自社原料、電力を使う製錬が結び付きます。製品の炭素量・不純物の仕様と市場への接続が販売を支え、銅や金とは用途が異なります。

工程：クロム鉱石 → 選鉱 → 電気炉でフェロクロム → ステンレス鋼等の原料。シリコン系合金をクロム製品に含めません。

範囲の注意：2024年の製品別企業売上と販売量を使用。2025年の製品別値は未確認。鉱石の世界比率と会社推定の合金市場比率は別です。
