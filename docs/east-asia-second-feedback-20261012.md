## 地域の変更

- 自然・人口・農畜産・林業の海岸線を、Natural Earth v5.1.2 の1:10m原図から地域用に作成。EPSG:3857で1,500m簡略化後、EPSG:4326の小数5桁に戻す。島と穴を保持し、丸め後も各地物の有効性を確認する。隣接国全体の共有境界トポロジーを保証した処理ではない。
- 416,034 bytes / gzip 152,122 bytes。従来の詳細図1,152,280 / 426,624より小さい一方、初期の全世界概略図267,614 / 97,162より大きい。ファイルサイズから速度向上と結論しない。実Chromeの同一アプリで元の概略図と今回の図を各3回読み、起動・東京選択を測る。
- 作物名は既存MapSPAM由来の集積 core の大きい連結部分内へ配置。各作物2点、日本と韓国の米を追加して14点。分布や生産量は変更しない。羊・山羊は元のモンゴルの代表点も常設名の対象にする。
- 林業の初期説明は中国東北・南部、日本・朝鮮半島と乾燥内陸。日本の天然林・人工林の説明は日本選択後。国別の森林・木材統計を保持し、確認した製紙工場3例と清水港の案内点を追加。
- 気候は13観測所を保持し、主要な固有地形名のみ追加。都市を選んでも表示範囲・ラベル順を変えない。
- 河川・地下水の都市は位置点を保持し、名前はホバーとキーボードフォーカスのみ。流域の4水系表示を保持。
- 地形は固有名、原河道の4川、名前付き海域4、気象庁の黒潮・親潮・対馬暖流・北西季節風の解説を追加。海流・風は概説に沿う案内札で、時々刻々の観測流路やベクトルではない。
- 標高図は500mの等高線・段階色を保持。国・地点・旧着目点の選択を解除し、背景クリックを無効化。
- 人口の都市点は一定サイズの選択点として明確化。民族・宗教の選択は同じ地図・名前を残し、輪郭を強調。宗教は最初から資料の文化圏の面を表示し、全国構成は右へ分離。

## 原資料・位置の定義

海岸線のURL、原本SHA、出力SHA、国別面積・島数・実測境界差は `data-source/atlas/east-asia/second-feedback/coast-provenance.json`。自然海域名と農作物 core の出典・SHAは各配信JSONに保持する。島の輪郭は測量精度を意味しない。元の簡略化許容値と実測最大境界差を区別する。

工場3点は日本製紙の公式所在地ページの埋込所在地図の中心。敷地輪郭ではなく、都市中心で代用した点でもない。清水港はNatural Earth港湾原本の `[138.509894,35.014444]`。港の機能は静岡県清水港管理局の富士見埠頭説明にある木材チップと専用荷役機械。埠頭そのものの正確な外形、物量、工場への取引関係は描かない。

- [旭川工場](https://www.nipponpapergroup.com/about/sales/asahikawa/)、[石巻工場](https://www.nipponpapergroup.com/about/sales/ishinomaki/)、[八代工場](https://www.nipponpapergroup.com/about/sales/yatsushiro/)。Web資料で所在地を確認。石巻ページの後続curlはHTTP403で取得停止し、先に確認した内容だけを使用。
- [清水港・富士見埠頭](https://www.portofshimizu.com/overview/%E5%9F%A0%E9%A0%AD/%E5%AF%8C%E5%A3%AB%E8%A6%8B%E5%9F%A0%E9%A0%AD/)。点は港全体の所在、木材チップの説明は埠頭の機能。
- [UPM Specialty Materials](https://www.upmspecialtymaterials.com/about-upm-specialty-materials/) は常熟港近くの工場立地を確認。厳密な工場座標未確認のため地図の工場点を作らず、説明のみ。
- [環境省・中部山岳](https://www.env.go.jp/park/chubu/point/index.html) で北アルプスの名称を確認。国立公園界を山脈の境界に代用しない。台湾の中央山脈は既確認の原住民族委員会の地理説明と対応。
- 海流・風の公式説明は `src/data/atlas/east-asia-review-geography.ts` の各気象庁URL。概念位置、原資料の位置、施設所在地を別の精度として扱う。

## 未達・取得結果

民族の多数派を含む全域の実居住分布は未完成。全国比率、国籍・母語、行政区をぼかした面で補わない。漢族等の網羅分布と朝鮮半島国内の同定義資料、モンゴル多数派の原値確認が残る。

- GeoEPR原本 `https://icr.ethz.ch/data/epr/geoepr/GeoEPR-2021.geojson`：通常curlでHTTP403。同じ呼出を1回再試行し403。以後停止。既存の固定原本から準備済みの分布だけを使用。
- `https://tuv.nso.mn/uploads/users/87/files/Khun_am_toollogo.pdf`：Webでは画像PDF（18頁、抽出文字なし）。スクリーンショット呼出から実画像を受け取れず、通常curlはHTTP403。未確認の民族数値を採用しない。既存の検証済み宗教表を変更しない。
- UNdata `https://data.un.org/Data.aspx?d=POP&f=tableCode%3A26`：Webのデータ系列・国一覧は確認。中国・モンゴルの指定フィルターは取得不能／400 Timeout、通常curlはHTTP403。国別レコードを得ておらず、数値・多数派の輪郭を新造しない。
- 韓国の山脈原図・名称の一次資料はNGII・KNPSの取得不能／400等で未確認。「朝鮮半島」の固有名を保持し、未確認の太白山脈の境界は追加しない。

宗教の面はGeoEPR2021で2020年に有効な集団の居住域とEPR-EDの特徴を対応させた限定文化圏。全住民の信仰比率や東アジアの全宗教文化圏ではない。農畜産3統計、木材の域外相手、民族多数派の実分布、林業の全拠点台帳の従来未達は継続。
