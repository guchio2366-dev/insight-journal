# アジア地図：気候・都市・米の初期実装の確認

確認日：2026-09-25。基準 main：96918bef794fb0c97bf4a6d4759fa7338cbcfa4b。

## 今回の完成範囲

東アジア・東南アジア・南／中央アジアの既存3ページに、気候分類、都市42地点の雨温図、米の収穫面積推計を接続した。国選択30件を維持し、気候と米の比較前の国・都市・選択格子・地図位置をURLで復元する。これは自然環境と農林業の最初の作業単位であり、北米相当の4分野全体の完成ではない。

## 実ブラウザーで確認したこと

WindowsのCodex内ブラウザー、公開用の静的ビルドをローカル配信して確認。実際のMapLibre描画を使用した。

- 3地域の気候画像・国境・都市マーカーを描画。東京などの地点を含む表示色と照会値の整合はデータ試験でも照合。
- 台北の雨温図 → 同じ場所の米 → 比較前へ復帰。都市・国・地図位置を維持。
- シンガポールを国選択から表示し、都市の雨温図へ到達。
- モルディブの広域格子不足を案内し、マレの観測所平年値は独立して表示。都市URLを再読み込みして復元。
- ホジェンドの降水量12か月は未収録として表示。×印・読み上げ説明・年間合計に欠測を反映し、0mmに置き換えない。
- 気候PNGを配信対象から一時的に外す障害試験を実施。案内と再試行を維持し、雨温図および米への切替は利用可能。画像復元後の再試行で回復。
- 390×844、768×1024、844×390、通常のデスクトップ幅で構成を確認。タブレット幅の文書幅753pxに対して内容幅753pxで横はみ出しなし。これは画面幅の検査であり、物理スマートフォンのタッチ操作確認ではない。

MapLibre 6のworkerはViteの `?worker&url` で同梱し、Map作成前にURLを明示する。自動推定のままではGeoJSONの処理待ちとなることを実ブラウザーで再現・修正した。[公式のVite導入説明](https://maplibre.org/maplibre-gl-js/docs/)に従う。北米・欧州のコントローラーは変更していない。

## 自動確認

- 全体のunit suite：最初の統合確認で155件成功、既存の環境依存試験1件省略。追加の画像失敗レース2件も個別確認済み。
- 全体の既存E2E suite：84件成功。HTMLとDOM・代替描画の試験を含み、実WebGL確認は上記の別工程で実施。
- 気候の入力版・生成物ハッシュ・格子とPNGの色・30か国の収録、都市の月順・平年値・欠測、URLと比較復帰、描画障害と再試行を専用試験で確認。
- build、公開物検証、GitHub上の統合時チェックは公開対象の版で再確認する。

## 性能の初回記録と次の上限

ローカルのキャッシュを含む再読み込みで、南・中央アジアの初期化開始→MapLibre loadは210ms、再試行は91ms。回線速度を制限した測定ではなく、本番初回や低速回線の性能値として扱わない。

非圧縮の成果物サイズ：HTMLは東239KB・東南258KB・南／中央272KB。MapLibre本体1.058MB・worker507KB・アジアページCSS103KB。気候PNGは各11〜27KB、選択時の気候格子は469〜834KB。米の画像3件は合計約145KB、照会格子は地域ごと約0.58〜0.78MB。配信圧縮後の通信量は未測定。

次の追加時の目安は、各照会アセット1MB以下、画像200KB以下、最初に未選択の分野の格子を取得しないこと。追加作物・人口の格子は選択時に取得する。ライブラリを含む初回通信は別途本番で計測し、物理端末の確認を残す。

## 残る不足

- 都市平年値は25か国／地域。カンボジア、東ティモール、アフガニスタン、ネパール、ブータンの観測所を未収録。取得状況は都市出典文書を参照。
- モルディブは広域の気候分類画素なし。米はモンゴル・シンガポール等にも入力範囲や推計値の不足があり、ゼロとは区別する。
- 地形・水資源、米以外の農林業、主要産業、人口分布と詳細統計、地域ごとの説明は後続工程。
- MapSPAMの作物格子を国別総量として単純合算しない。国別統計は独立の公式資料から加える。

次の農林業作業は `atlas-asia-agriculture-expansion.md` の小麦と米／小麦の国別統計から進め、人口基礎・自然環境の追加資料を並行して準備する。
