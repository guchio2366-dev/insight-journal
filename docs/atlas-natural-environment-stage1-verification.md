## 実装した動作

| 対象 | 実装内容 |

| 12都市の名前・点 | 既存のNOAA観測所座標を使用。名前と点を同じ選択関数につなぎ、既存の雨温図を開く。名前はボタン化し、全国表示で間引かず、混雑時は位置をずらして地点と引出線で結ぶ。パンで地点が画面外になった場合だけ名前を隠す |

| 更新・状態 | 21個の名前ボタンを再利用し、位置更新はrequestAnimationFrameでまとめる。遅れた分類応答が都市選択や別の表示を上書きしない。既存のカメラ、URL、農業・産業の選択処理を利用 |
| 代替図 | 画像のobject-fit:containの余白を除いてWebメルカトル座標を変換。WebGLを最初から使えない場合と描画停止後の両方で、都市点・名前・気候面の選択を提供 |

雨温図のデータ、12か月・共通目盛りと既存のカード配置を使用する。都市近傍の小型図は第2段階で扱う。標高色・年降水量線・土壌データの追加は行っていない。

## 代替画像の必要な追加

既存の地形代替図には9地形名が焼き込まれており、ボタンを重ねると二重表示になる。そのため第1段階で、公開済みの形状・陰影・投影から名前なしの `landform-interactive.webp` を1枚生成した。新しい地理資料やDEMを取得する処理は含まない。

- 追加画像：231,038 bytes、1800×1091 px。
- 公開自然環境資産：12ファイル、合計3,481,293 bytes（manifest自体を除く）。
- 元の名前付き画像は、JavaScriptなしの表示と「図を拡大」リンクに残す。
- manifestへ追加画像のサイズ・SHA-256と用途を記録し、全資産のハッシュ試験で検証する。
- 再生成コマンド：`python3 scripts/render-nature-fallbacks.py --interactive-landform-only`。既存のPillow／NumPy環境とNoto Sans CJK JPフォントを使用。フォントは `ATLAS_NATURE_FONT` で指定できる。

v2.1ではバイナリ保存確認を第3段階の冒頭としていたが、名前の二重表示を避けるため、この小さな実ファイルを使って第1段階で保存経路を確認した。
