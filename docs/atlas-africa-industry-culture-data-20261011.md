# アフリカ第2弾：産業・文化の原資料と表示契約

## 産業

18品目群と49の資料で挙げられた産地・地域・都市を収録。既存7地点のID、座標、読解、テーマ出典は保持した。品目群は `africaIndustryCommodities`、地図との結合は各地点の `commodityIds`。産業地域を先に一覧・地図で読み、施設単位の説明は補足にする。点数上限による間引きはしていない。

各地点には `countryCodes`、`evidencePeriod`、`status`、`geographicScope` がある。開発計画 `development` と休止 `paused` を生産 `production` へ混ぜない。国単位しか取得できないモザンビークのタンタルは `country` であり、鉱山位置を捏造しない。座標は編集上の丸めた地域代表位置。原資料の施設図・文章・写真を転載していない。

採用理由の数値は全国・企業・鉱山の単位を区別した。USGSは原則2024年、製造業は取得できた2015地域表・2025企業公表等を資料年として明記。資料年の異なる値を統一順位にしていない。数量未取得を各地点・品目群で明記。共通年・単位で全品目を並べる数量表は未取得。

## 宗教：実装できる大陸概観

`africa-religion-overview.ts` は [Pew Research Center Appendix B](https://www.pewresearch.org/wp-content/uploads/sites/20/2025/06/PR_2025.06.09_global-religious-change_appendix-b.pdf) の2020年全世代推計から、アフリカ55地域の最大集団と大きな第2集団だけを抜粋。全201地域の原表を転載しない。`sourcePage` はPDFの1始まりページ。元の7分類を民族や宗派へ変換しない。「その他」は在来宗教だけを指さない。

国面の主色＝最大集団。混在印＝第2集団25%以上、または最大集団50%未満。面は国単位統計であり、個々の宗教居住境界ではない。CIV・MUSは最大集団でも過半数ではなく、BFA・CMR等も第2集団を読めるようにする。

Pewの[利用規約](https://www.pewresearch.org/about/terms-and-conditions/) §1、§13に基づく抜粋・独自分類。copyright attribution、独自解釈の免責、訳文未承認の免責をデータに保持。生データのダウンロードはアカウント要求があり、その経路を使用していない。公開付録表の事実を転記した。

歴史の解説は [Pew 2010](https://www.pewresearch.org/religion/2010/04/15/executive-summary-islam-and-christianity-in-sub-saharan-africa/) 、[UNESCOラリベラ](https://whc.unesco.org/en/list/18/)、[UNESCOトンブクトゥ](https://whc.unesco.org/en/list/119/) を参照。キリスト教・イスラム教すべてを近代植民統治由来としない。中世エチオピアのキリスト教、近代以前のイスラム教、植民地期以後の変化、在来実践との重なりを区別する。

## 言語：適法な補助レイヤー

[Glottolog公式CLDF](https://github.com/glottolog/glottolog-cldf) commit `072ca0d0410039fb8b779be8fc165bac575d2cda`、version5.3（2026）、CC BY4.0。公式blob `774cbd8cb1bbdbc2eab64edf5df552b61252e876` の `languages.csv` を使用。原CSV SHA256、出力SHA256、分類条件、著者をasset manifestに保存。

全Africa・languageレベル・座標ありからBookkeeping、Unattested、手話、地図範囲外を除いた2,222地点。主要7系統とその他を表示群にするが、各点の元の独立系統名を保持。「その他」は単一語族でない。孤立言語と接触言語も源データの分類を保持。元座標を小数5桁へ丸めるのみで、密度・居住面を推定していない。点数・密集＝話者数ではなく、言語＝民族でもない。

オフライン再生成：`python scripts/prepare-africa-language-points.py --languages /path/to/pinned/languages.csv`。入力SHA256が違う場合は停止する。

## 民族：未達と具体的障害

[GeoEPR公式](https://icr.ethz.ch/data/epr/geoepr/)、[GREG公式](https://icr.ethz.ch/data/greg/) は研究上の引用・配布を案内するが、公開webでの派生geometry再配布を明示する許諾を確認できなかった。既存workspaceにAfrican GREG/GeoEPRの公開済assetはない。GeoEPRは政治的関連集団、GREGは1964年Atlas Narodov Mira由来の8969ポリゴンであり、全住民の現在民族割合でもない。権利を確認できないgeometryや原図は追加していない。

この民族居住域の未達は、言語点や注記で解決扱いにしない。実装の選択肢は、公開派生配布許諾が明示される原資料を取得するか、権利者から許諾を取得すること。CIA1996民族言語図の正規カタログも調査したが、LOC APIが403で取得経路を停止。拒否された原資料の別ホストやproxyでの取得はしていない。

親の独立調査で共有された代替案は次のとおり。現代の民族居住分布は引き続き未達であり、目的変更・採用は親とユーザーが判断する。ここでは実装せず、現在のPew国別表示も変更しない。

|案|可能な範囲|不可・採用条件|
|---|---|---|
|歴史資料で大枠を読む|[LOC掲載のCIA1996民族言語図](https://www.loc.gov/item/96680239)は、親がカタログのfree use/reuse表示と主出典Murdock1959を確認。別案として「歴史的・概略的民族言語地図」の広域構成を読む候補になる|1996は図の公表年であり、現在の民族割合・全住民の居住境界を示す資料として使わない。採用前に対象素材の権利表示・出典粒度・年代を記録し、民族と言語の混合分類を明示する。カタログの利用表示を、別の原データやgeometryの再配布許諾へ拡張しない|
|現在統計の確認地域を読む|[Gershman／Riveraの研究資料](https://www.borisgershman.com/research/subdiversity/subdiversity.pdf)は、約400の行政第1階層地域について宗教のcensus/surveyを辿る手がかり。原表を確認できた地域について、その調査年・定義・対象に限る宗教構成図を検討できる|共通の現在年、全アフリカ、民族分布を満たすとは扱わない。replicationデータの再配布許諾は未確認。多様性指数から宗教割合を逆算せず、確認した原表と境界の利用条件を個別に記録する。論文公開を原データの再配布許諾や代行許諾と同一視しない|

Pew PDFのexecutor転送、LOC API、JSE contactの403はその取得経路を停止。一部403経路で既に1回再試行したことは親へ記録済みで、それ以降の迂回はしていない。公式独立資料Glottolog、Pew公開付録、政府・企業の産業一次資料による作業は継続した。
