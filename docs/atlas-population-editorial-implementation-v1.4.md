# 人口：共通編集・UI指針の反映 v1.4

2026-09-16。基準：`atlas-editorial-and-map-guidelines.md`。

## 読者が持ち帰る要点

| タブ | キーセンテンスの軸 | 地図で確かめる対象 |
| --- | --- | --- |
| 人口分布 | 人口を支える仕事は都市によって異なる | 沿岸・五大湖・内陸の都市と郡の平均密度 |
| 人種・民族 | 定住と仕事を求める移動に、住まいの制約が重なる | 南部・五大湖・国境沿いの最大区分 |
| 宗教 | 移住先に築いた共同体が宗教の地域差に関わる | 南部・北東部・ユタ周辺の最多グループ |
| 投票傾向 | 色の面積と票数を分けると選挙地図の読み方が変わる | 都市を含む郡と周辺の得票率差・実票数 |

都市12件、人種・民族8区分、宗教8区分と地域6件にも、選択した内容に対応する要点を置く。特定の分類から個人の信仰、職業、投票を推定しない。地図で見える相関と、資料で裏付ける歴史的背景を分ける。

## 構成と導線

- 右欄は見出し → 強調した一文 → 場所・理由 → 段落直後の関連ボタン → 分類の詳細。
- 都市圏・郊外・郡・人口密度・大移動・adherentsを説明する。表示していない全国円グラフや市街地境界への案内は削除。
- 人種・民族から関連都市、宗教区分から番号付き地域、地域から都市へ進む。本文内の移動には「前の解説へ戻る」を付ける。
- 都市の説明は表示中の地図に合わせる。宗教・人種・投票地図を見ながら「周囲の密度」を読む不整合を解消。
- 地名は既存の都市ラベル・番号に結び付ける。南西部・山岳西部・五大湖など位置を文中にも補足。新しい文化境界は描かない。
- iPad横相当の2列・左の地図追従を維持。狭い画面では地図の後に本文、関連ボタンを全幅・44px以上にする。

## 実装契約

既存のMapLibre一台、分類色、凡例、静的代替画像、データ遅延取得を使用。追加ライブラリ・画像・地理データはない。本文内の選択は同じタブの右欄だけ更新し、地図の再生成・カメラ移動・データ再取得を行わない。既存のURL状態へ選択を反映し、ブラウザの戻るにも対応する。本文内の戻り先スタックはセッション内だけに保持し、タブ変更・直接選択・全国への復帰で解除する。

## 根拠

既存の各都市BLS職種資料、USRC・Pew・NPS・Pluralism Project・Censusの出典を維持する。大移動と住宅差別の説明は[米国国立公文書館](https://www.archives.gov/research/african-americans/migrations/great-migration)、人種区分は[Census](https://www.census.gov/topics/population/race/about.html)、宗教団体が把握する人数は[USRC FAQ](https://www.usreligioncensus.org/faq)、西方移住は[NPS](https://www.nps.gov/mopi/learn/historyculture/index.htm)を確認した。職種割合の更新や新しい因果関係の推定は行っていない。
