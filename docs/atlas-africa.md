# アフリカ：4分野の国別統計地図

## 2026年10月3日：作物・家畜の分布を追加する候補

SPAM 2020 v2r2の作物4種の収穫面積・生産量と、FAO GLW4 2020の家畜3種の推定密度を実装する。詳細な原典、CC BY4.0対象、固定原本SHA、単位・モデル・欠測・加工の区別は [農畜産の記録](atlas-africa-agriculture-20261003.md) にまとめる。後続の10月2日・1日節は当時の範囲を記録したもの。この候補の存在は検査や公開の完了を意味せず、新画像の親目視後に公開する。

## 2026年10月2日：概要と主要な分布を追加

以下は今回の実装範囲。後続の10月1日節は旧版の記録であり、気候・標高・人口格子が未収録という記述は今回の追加後には当てはまらない。

- 概要は54か国と西サハラの55対象に、自然環境・農林業・主要産業・人口社会・制度と地域協力の5つの読み方を収録する。国別値は既存WDIの固定2021年。長期平均降水量を2021年の観測にせず、欠測を他年や他国から埋めない。地域事例は対象国固有の根拠と区別する。制度の説明はAfCFTA設立協定の2018年採択を含む読み方であり、現在の加盟状況や国別政治制度の一覧ではない。
- 自然環境にKöppen–Geigerの1991–2020年気候区分とETOPO 2022の標高を加える。固定気候原本は0.1度で、1km原本とは呼ばない。標高原本は60秒で、表示・照会は陸域を集約した0.1度格子。地形表示は標高区分と等高線による派生表示で、地質図や地形分類原図ではない。
- 河川はNatural Earth 5.1.2の実形状を表示する。流域はCC BY 4.0のBasinATLAS v1.0レベル6を用い、`NEXT_SINK`による流域の集約と表示用の簡略化を分ける。独自の再配布条件があるHydroBASINS原本は公開素材に用いない。河道・集水域は流量や現在利用できる水量を表さない。
- 人口分布はJRC GHS-POP R2023Aの2020年人口推計。元のMollweide等面積1km格子を0.1度へ集約し、有効な元セルの面積で密度を求める。0人と欠測を区別する。国別WDIの年選択で固定2020年の格子を更新したように見せない。
- 民族・宗教タブは資料の読み方と公式原サイトへの案内を提供する。GeoEPR 2021は政治的に関連する掲載集団の居住域、EPR-ED 2021は掲載集団内の帰属資料であり、全民族・地域多数派・住民全体の宗教割合と区別する。公式ページで確認できたのはダウンロード案内と研究利用時の引用指定で、派生図の公開利用許諾を確認した根拠にはならない。このため今回の配信から文化の派生形状を外し、国・地域の位置を示す基底図と資料範囲の説明を残す。全データの不許可を断定していない。原本・過去の生成履歴・216掲載集団と648宗教記録枠の確認記録は保持し、許諾未解決の面を別の分布で代用しない。
- 林業では森林割合の統計と、土地利用・管理を読む説明を組み合わせる。カカオとサヘルの農業代表点を森林分布として残さない。森林割合は木材生産量や保全の良否ではない。
- 国・比較国・年の選択を上段へ置き、主地図は承認済み北米と同じ寸法を基準にする。右欄全体を一つのスクロール範囲とし、詳細・数表・推移・原典は折り畳む。分布を表示してから比較へ進む場合は、元分布・全凡例・比較専用説明・選択状態・対象名付きの戻りを保持する。

固定分布素材は `public/assets/atlas/africa-{physical,population,water}-v1/` に配置し、各manifestに原本・取得版・期間・母集団・加工方法・利用条件・欠測・SHA-256を記録する。`africa-settlements-v1/manifest.json` は配信対象外とした文化資料の案内・利用条件の確認状況だけを記録し、形状ファイルを参照しない。原本と生成物の確認はそれぞれのアフリカ専用生成スクリプトで行い、訪問時に外部の原データAPIへ接続しない。

新しい分布の取得・切替・国選択にはJavaScriptが必要。無効時は静的な基底国図、地域の説明、分野入口、国別一覧・CSVと出典を利用できる。初期の自然環境は気候区分を表示し、既存の明示的な統計・テーマURLは保持する。

残るデータ拡張は、実測・推計に基づく作物別の栽培域、家畜分布、鉱山・工場別生産量、都市圏別人口、連続降水分布・帯水層など。既存の国別統計や代表位置を、これらの完成した面分布と称さない。今回の検証は新しいアフリカ専用試験、固定候補のCI、同寸法の実画面と親の目視、公開commit・Pages・配信素材の一致を別々に記録する。

## 2026年10月1日：4分野の初回版を改善

既存15指標に加え、各分野2件、計8件の地理テーマを収録する。自然環境はナイルの河川水利用と東アフリカ高地、農林業はギニア湾岸の樹木作物とサヘルの農牧複合、主要産業はザンビアの銅鉱業とカサブランカの製造業、人口はナイル沿いの居住と都市への接続を扱う。

- テーマ記号は代表位置の定性表示。数や大きさで生産量・人口・耕作面積を表さない。ナイルの線はFAO AQUASTATのエジプト地図（2015）を参照した本流の近似線で、流量や流域境界ではない。農業の地域説明はFAOの2001年の営農システムを用い、現在の産地面積・順位に読み替えない。
- 右欄の持ち帰る要点を、自然条件、灌漑・加工・電力・物流・技能、市場、用水配分・土地制度・環境管理の関係に沿って読む。自然条件だけで生産や暮らしの成否を決めない。
- 主地図、要点、テーマ選択と比較入口を同じワークスペースへ置き、詳細説明・数表・推移・定義・出典は下部の折畳みにまとめる。全統計凡例と全テーマ記号の凡例は常時表示する。
- 初期表示とリセットは最初の自然テーマ「ナイル」の範囲を表示。全体、地域、国、テーマ範囲を選べる。テーマ範囲は説明用の表示範囲で、産地の境界ではない。
- 比較入口はテーマ記号を残し、背景の国別指標を切り替える。比較専用の説明、現在の指標名・単位・原典、対象名付きの戻りをそろえる。`theme/context` を既存のURL状態に追加し、元の指標・国・比較国・年・拡大を保持する。別テーマ・別分野へ進むと比較を終了する。

この更新は全米の細分類統計や産地ポリゴンの完全複製ではない。気候分類面、最新の作物別面積・販売総額、鉱山別産出量、都市圏別人口は未収録であり、国平均や代表位置で代用したと説明しない。共通ニュース欄・共通ルートの調整は地域専用ファイルの範囲外として親担当へ引き継ぐ。

検証はアフリカ単体7件と、8テーマそれぞれの比較・元記号・両凡例・専用説明・URL復元・対象名付き復帰を確認する回帰試験を追加。PC実画面、exact commitのCI、親の目視、公開commit/Pages/配信asset一致は別の受入条件とする。

`/atlas/africa/` に自然環境・農林業・主要産業・人口を追加。54か国と西サハラを選択し、同じ国・比較国・年を保持して15指標を切り替える。表、推移図、地図、CSVは同じ固定データから生成する。

## 表示と操作

- 自然環境：長期平均降水量、国内の再生可能淡水／人。
- 農林業：耕地割合、森林割合、穀物収量、農林水産業のGDP比。
- 主要産業：製造業・工業・サービス業のGDP比、天然資源レント、一人当たり名目GDP。
- 人口：人口、人口密度、都市人口率、人口増加率。
- 2か国比較、2000〜2024年の時系列と数値表、5地域の絞り込み、全体／地域／国の拡大、リセット、履歴移動とURL復元。
- 分野ごとに3件、計12件の解説。本文内の国名から選択できる。FAOの2001年の営農分類は背景説明に使い、現在の作物分布や生産順位として扱わない。

初期年は全指標を読み比べやすい2021年。年を変えたら分野を切り替えても保持する。「収録国が多い最新年」は当該指標で54か国中40か国以上が収録された最新年（上限2024年）を選ぶ。資源レントは2021年、淡水資源は2022年まで。選択年に欠測なら前後の年で埋めない。降水量は長期平均のため、年選択と推移を無効化し、最新の収録値を表示する。

## データと再生成

取得日2026-09-25。Natural Earth 1:50m countries（public domain）と世界銀行WDI source 2（CC BY 4.0）。WDI応答の更新日は2026-07-13。元組織、原指標定義、URL、取得応答SHA-256を `data-source/atlas/africa/manifest.json` に保存。

```
node scripts/build-africa-data.mjs --cache=/path/to/africa-cache
```

キャッシュ未収録なら公開元を取得する。原本ハッシュが変わった場合は停止し、無断で新しい版に更新しない。既存の固定JSONでサイトのビルドは完結し、訪問時に外部APIへ接続しない。15指標×55地物×25年のCSVは20,625行。空欄は未収録。

国コードは南スーダンをSDS→SSD、西サハラをSAH→ESHに対応。Natural Earthの大陸属性がSeven seasとなるモーリシャス・セーシェルも含める。ソマリアはソマリランド地物とまとめて同じ統計対象とし、ソマリランドを独立したWDI系列として生成しない。西サハラは常に統計未収録で、モロッコから転用しない。

## 地図と統計の意味

国別統計の塗り分けは国平均・国全体の比較であり、国内の人口分布、気候区分、農作物の栽培域、鉱山や工場の境界を表さない。重ねる地理テーマは別の定性的な代表位置・近似河道である。雨温図、作物別収穫面積、鉱物別産出統計、都市別人口はこの版の対象外。国平均で国内の多様性を説明できないことを画面に記載する。

国別の率・密度は固定閾値5色で表示し、欠測は斜線。人口実数は円面積に比例させ、代表座標は国の目印とする。選択国は赤枠、比較国は青い破線。色だけに頼らず表に全数値を置く。年や地域で色の境界は変えない。推移の欠測区間を線で結ばない。名目GDPの推移を実質成長と呼ばず、製造業と工業を足さない。

等距円筒図法（標準緯線0度）、西経27〜東経64度、南緯36〜北緯39度。面積比較用ではない。Natural Earthの概略境界を現在の実効支配線と扱わず、海外領土は選択対象から除外。地物は55件、SVGは1個。国境は拡大に追従し、線幅は画面上で固定。島の目印は量を表さない白丸と明示する。

## 操作・配信設計

Astroで国境・初期統計・出典・一覧を静的出力。専用コントローラーがSVGとDOMを更新し、WebGLや追加ライブラリは使わない。`field/metric/year/place/compare/region/zoom` を許可値で検証してURLに保存。未知値、同一国比較、不正年は安全な既定状態へ戻す。任意のHTMLは挿入しない。

1000px以下では地図の下に比較欄、600px以下では全体を一列に配置。地図の選択と同じ操作をselect・ボタンから実行でき、最小44pxの主要タッチ操作を用意。JavaScript無効時にもナイルの代表位置・降水地図・国別一覧・出典を表示し、全分野CSVを提供。

共通入口の世界地図化は並行作業側が担当するため、この変更は入口ファイルを編集しない。入口の世界地図はPR #100で、アフリカページの存在をビルド時に検出してリンクを有効化する。アフリカの遷移先は `/atlas/africa/`。サイトマップには追加する。
