# アブジャ：表示位置・人口定義・資料年

2026-10-11確認。アブジャの都市名・首都表示は維持できるが、現在の人口順位・人口値を新たに断定できる原表行は未取得。

## 地図ラベルの契約

親が導入したNatural Earthの座標 `[7.489505, 9.05462]` は地名表示の代表位置。`capital:true` は首都表示、`rank:3` は表示優先度であり、人口が第3位という意味ではない。自然地名データの順位属性を人口ランキングへ変換しない。現時点のラベルは「アブジャ」で十分で、人口値や順位の追記はしない。

## 国連の統計範囲と年

[UN DESA・WUP2025ダウンロード](https://population.un.org/wup/downloads) は2025改訂版。国別・国際定義・国内定義が別に提供され、年央の人口推計と将来推計を収録する。[公式FAQ](https://population.un.org/wup/faqs) によると1950〜2025年は推計、2050年までが将来推計。2025版が過去版を更新し、2025年5万人以上の都市を12,000超収録する。2018版の都市収録閾値は30万人だった。2018・2025の数値は版・年・定義をそろえず直結しない。

[WUP2025公式用語集](https://population.un.org/wup/glossary-demographic-terms) では、DEGURBAの都市は人口密度1,500人/km²以上、総人口5万人以上の連続地理領域。都市集積は行政境界によらない都市と周辺の連続開発域である。一方、首都の designation は各国の報告に基づく。首都であることは人口値・順位の根拠ではない。

したがって、アブジャの市行政範囲、連邦首都地域（FCT）全域、国連の都市集積／DEGURBA都市は別の統計対象。単位が違う人口を同じ「アブジャ人口」の系列へまとめない。国連の都市行を採用するときは、改訂版・対象年・都市ID・統計範囲・推計／将来推計・元単位（千人等）を一緒に保存する。

[WUP2018公式Methodology](https://population.un.org/wup/assets/Publications/WUP2018-Methodology.pdf)（2018、ESA/P/WP.252、印刷p.1〜2）は、都市規模を各国の統計定義から取り、国際的に統一定義を課していないと説明する。同資料印刷p.4では都市集積・大都市圏を優先し、一貫した資料がなければ市行政範囲を採用したと説明する。都市規模の将来推計は2035年まで、全国都市化は2050年まで。2018の都市集積・行政・各国定義による値を2025のDEGURBA定義に等置しない。

今回、WUP2025都市別原表のアブジャ行とその都市ID・対象年・数値は未取得。2006年市人口776,298とFCT推計約250万という記述はUNOSSC/South-South Galaxyの検索索引で見つかったが、[掲載先](https://southsouth-galaxy.org/organizations/detail/federal-capital-territory-administration-fcta/) の本文は404だった。「presently estimated」の推計年を確認できず、現人口値・現在順位の根拠に採用しない。FCTA公式プロフィールも本文を取得できなかった。

## 今回の表示案と未取得

「アブジャ（首都）」または通常の「アブジャ」地名ラベル。人口分布ラスターは既存資料の年・推計・欠測の定義のまま表示する。都市名ラベルの追加は、人口値の更新を意味しない。
