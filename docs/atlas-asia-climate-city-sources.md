# アジアの都市別雨温図：出典・再生成・検証

## データの意味

- 月平均気温（℃）と月降水量（mm）の**1991–2020年平年値**を使う。2025年の実測値や2026年の予報ではない。
- `temperatureC` と `precipitationMm` は1〜12月の順。欠測は `null` とし、`missingMonths` に1始まりの月を記録する。欠測をゼロに変換しない。
- 都市名は選択用の名称、`stationName` / `stationId` は観測所そのもの。空港や郊外の観測所は都市全域の平均ではない。地図上の点も都市の中心ではなく観測所の経度・緯度を使う。
- `summary` / `reading` は掲載平年値の季節差から作る解説。年間降水量は12か月すべての値があるときだけ合計する。丸め済みの月値を足すため、提供元の年値と丸め差が生じ得る。
- この雨温図だけからケッペンの気候区分を推定しない。気候区分の面データは別の格子資料と定義に基づく。

## 一次資料と利用条件

### 海外の観測所：気象庁 ClimatView

- [ClimatView](https://www.data.jma.go.jp/tcc/tcc/products/climate/climatview/frame.php)
- [データの説明](https://www.data.jma.go.jp/tcc/tcc/products/climate/climatview/outline.html)
- [気象庁コンテンツ利用条件](https://www.jma.go.jp/jma/kishou/info/coment.html)

ClimatViewの説明は、気温・降水量の平年期間を1991–2020年と明示している。平年値の基礎資料は気象庁が受信したCLIMATとNOAA/NCEIのGHCN。個別観測所のHTML表には実測値と平年値が隣接するため、取得処理は見出しと列構成を確認して **Normal** の気温・降水量だけを抽出する。2024年と2025年の表で同じ月の平年値が一致することも検査する。

気象庁の公開コンテンツは別の権利表記がない限り公共データ利用規約第1.0版に従う。画面では個別の出典URLと「気象庁の資料を加工して作成」の表示を付ける。図やロゴの転用はせず、数値を再構成した独自の雨温図を描く。

### 日本の観測所：気象庁「過去の気象データ検索」

ClimatView自身の案内に従い、日本の気温・降水量には国内の平年値表を優先する。観測所名・位置・標高の補助情報はClimatViewを使い、その点を各レコードの `notes` に残す。

国内の平年値ページでも月別の気温と降水量を抽出する。日最高気温や日最低気温を月平均気温の代わりに使わない。

### 台北：台湾・中央気象署

- [気候月平均の案内・表示ページ](https://www.cwa.gov.tw/V8/C/C/Statistics/monthlymean.html)
- [気温の公式表](https://www.cwa.gov.tw/V8/C/C/Statistics/MonthlyMean/MOD/Taiwan_tx.html)
- [降水量の平均値の公式表](https://www.cwa.gov.tw/V8/C/C/Statistics/MonthlyMean/MOD/Taiwan_precp.html)
- [観測所番号・位置・標高・移転履歴](https://hdps.cwa.gov.tw/static/state.html)
- [中央気象署の利用条件](https://www.cwa.gov.tw/V8/C/information.html)

台北（466920）の気温・降水量とも、表の統計期間が1991–2020年であることを検査して抽出する。中央気象署は降水量の平均と中央値を別に掲載しているが、雨温図には**平均**を使う。観測所位置は25.037658°N、121.514853°E、標高6.3m。平年期間内に一時移転があり、観測所一覧の注記を各レコードにも残す。

中央気象署のウェブサイト利用条件は、出典を明示した無償の複製・編集・再配布を認める。「台湾・中央気象署の資料を加工して作成」と表示する。数値表から独自のグラフを作り、署のロゴや著作物画像を転用しない。特定ファイルの位置が変わることがあるため、閲覧時に取得せず、確認したスナップショットを配信する。

未収録国はカンボジア、東ティモール、アフガニスタン、ネパール、ブータン。今回のClimatView一覧では採用できる地点を確認できず、別の公式平年値を使う補完が必要。国全体の観測データが存在しないと判断したものではない。候補のWMO/NCEI配布先は取得が完了していないため、未検証の値を追加していない。

ハノイ（ハドン）は降水量平年値が欠測だったため、この版の北部ベトナムの地点には両要素がそろうハイフォン（フーリエン）を採用。ジャカルタも気温が欠測の旧観測所から、両要素がそろうスカルノ・ハッタ空港に変更した。これらを同じ観測所のデータとして接ぎ合わせていない。

## 掲載地点の選定

首都だけを集めず、地域内の寒冷・温暖、湿潤・乾燥、沿岸・内陸、高地・低地の季節差を読めるよう選ぶ。日本の札幌・東京・那覇、中国の長春・北京・上海・広州・ウルムチ・ラサ、モンゴル・朝鮮半島を含める。東南アジアは大陸部・島嶼部、南・中央アジアはインドの複数沿岸・内陸と中央アジアを分けて扱う。

都市の追加は、出典の確かさと12か月の定義の統一を確認して行う。近隣国や別の都市の値を、収録できない国の代表値として転用しない。

## 再生成

必要環境はPython 3の標準ライブラリのみ。閲覧時の外部API、APIキー、有料サービスは使わない。

```text
python scripts/atlas-asia-climate-cities.py --discover
python scripts/atlas-asia-climate-cities.py --generate
python scripts/atlas-asia-climate-cities.py --write
```

取得したHTMLと検査前のJSONはリポジトリの隣の `asia-climate-source-cache/` に保存する。既存キャッシュを優先し、同じソースへの反復取得を避ける。更新時は対象HTMLを別名で保管してから再取得し、差分を確認する。TypeScriptには個別URL・取得日・ソースのSHA-256を残す。

`--generate` は取得候補・失敗一覧をキャッシュへ保存する。取得失敗や表の形式変更がある場合、`--write` は公開用データの上書きを拒否する。明示的な `--allow-partial` は確認済みの成功地点のみで初回の画面組立を進める場合に限る。今回の42地点の最終生成では失敗0件で、部分出力は使用していない。

補完データを調査するための `--supplement-sources` は数値を公開用データに自動採用しない。環境の証明書ストアの違いで取得できない場合は、TLS検証を有効にしたシステムのHTTPクライアントで同じ公開URLを取得し、同名のキャッシュに保存してから再実行する。TLS検証を無効化しない。

## 検査項目

- 観測所IDを公式一覧と照合し、同名の別地点を混ぜない。
- 各配列12か月、ID重複なし、経緯度範囲、気温・降水量の異常値、空欄を確認。
- 海外HTMLの平年値を2年分で照合し、実測列の混入を防ぐ。
- 日本国内は1991–2020年の月別平年値表を使用。
- 個別出典URLを取得時に開き、取得できない資料を採用しない。
- 掲載都市一覧・対象国・欠測月・未収録国を最終データと照合する。

## 画面側の必須表示

雨温図には単位・1〜12月・平年期間・観測所名・出典リンクを付ける。選択国に地点がない場合は「雨温図の観測所データは未収録」と表示し、近隣国の雨温図をその国のものとして表示しない。欠測がある線や棒は該当月を空け、値がない理由を読めるようにする。
