# 農業 v7.2：地図横の統合解説と3列統計

作成日：2026-09-14
状態：合意した方向を実装仕様へ整理した設計書。アプリの実装・公開はこの文書の作成には含まない。
確認したmain：`fd4b8f021ae185647cd08ab24d40e4f2984ac903`（産業PR #45の統合後）。

## 1. 目的と採用方針

地図に隣接する説明欄で、選んだ農畜産物の地域条件・性質・用途を読む。その直下で、同じ品目の供給・行き先、輸出先、世界生産を比較する。文章の「米国南部」「中西部」などを、地図と照らし合わせて理解できる配置にする。

| 場所・操作 | 採用する仕様 |
|---|---|
| 初期の右欄 | 現行の「米国の農業」。販売収入と全国の輸出入グラフも保つ |
| 地図下の品目をタップ | 右欄をその品目の既存詳説に置き換え、下の統計も同じ品目へ切り替える |
| 地図下の「分布のつながりを読む」 | 関係の見出しを常時表示する。本文は右欄で読む |
| 関係の見出しをタップ | 右欄を関係の詳説へ切り替え、地図の関係する産地・地物を強調する |
| 関係を読んでいる間の統計 | 直前に選んだ品目を維持し、「綿花の統計」などの対象名を明記する |
| 横幅のある画面の上段 | 左の「地図＋品目一覧＋関係の見出し」と、右の品目・関係の解説欄の高さを揃える |
| 上段の直下 | 左から「供給元と行き先」「米国からの輸出先」「世界生産と米国シェア」の3列 |

「作物」「畜産」は分類見出しであり、開閉・切替操作を要求しない。各品目へ直接アクセスできる。

### 変更前の案との関係

- 公開済みv7.1（実装PR #39）の統計値、円グラフ、コンパクトな国名・％表示を引き継ぐ。
- 作物・畜産の独立した下部詳説と、それぞれの選択タブは、統合した操作・配置へ置き換える。
- 途中案の「下部に説明と供給を並べ、その下に円グラフ2個」は採用しない。供給も含めた3列へ改める。
- 「分布のつながり」の本文を地図上へ出すポップアップ案は採用しない。右欄切替に統一する。
- 以前提示した `agriculture-detail-layout.html` は途中案であり、本仕様の完成画面見本として使わない。

## 2. 対象とデータの範囲

| 分類 | 常時表示する品目 | 3種類の統計 |
|---|---|---|
| 作物 | とうもろこし、大豆、小麦、綿花、米 | 既存5品目の統計を使用 |
| 作物 | 果樹・野菜 | 説明のみ。複数品目をまとめた既存の分布区分で、共通の3統計は未収録 |
| 畜産 | 肉牛、酪農、養豚、肉用鶏、採卵鶏 | 既存5分類の統計を使用 |

現行の地図下凡例には「果樹・野菜」もあるため、選択肢は11個、3統計を持つ対象は10個である。果樹・野菜を削除したり、とうもろこし等の統計を代わりに表示したりしない。「重なり」は凡例の説明であり、第12の単品統計にはしない。

関係の見出しは既存の3件を維持する。

1. とうもろこし・大豆と豚（`corn-soy-hogs`）
2. 大平原の小麦と牛（`plains-wheat-cattle`）
3. カリフォルニアの米と水（`california-rice-water`）

統計調査・更新や新しい分類の追加は今回の範囲に含めない。

## 3. レイアウト

### 3.1 iPad横・横幅のある画面

適用条件はCSS幅960px以上かつ高さ600px以上。1024×768、1180×820を主な確認対象とする。農業に限って900px基準の旧指定を上書きし、自然環境・産業の配置には適用しない。

| 行 | 左側 | 右側 |
|---|---|---|
| 上段 | 地図 → 作物の全品目 → 畜産の全品目 → 分布のつながりの3見出し | 米国の農業／品目の解説／関係の解説のいずれか1つ |
| 下段 | 全幅を3等分し、供給・行き先 → 輸出先 → 世界生産・米国シェア | 左の全幅行に含める |

- 上段の幅は現行の地図優先比率（約2.05：0.95、右欄最小318px）を起点にし、列間は12〜16px。
- 品目一覧は「作物」「畜産」の2群。横スクロール、隠れた品目、分類タブを設けず、必要な行数へ折り返す。
- 関係欄は「分布のつながりを読む」の下に3つの見出しを並べる。本文や要約をこの欄へ常時展開しない。
- 品目・関係の解説時は、右欄の上端と下端を左列全体に揃える。地図自体の高さを説明量に応じて変えない。
- 右欄の本文は14px以上、行間1.7〜1.85を基準にする。文字数の追加、本文の省略、極端な文字縮小で高さを揃えない。
- 通常の文字サイズでは既存本文を枠内に収める。文字拡大や詳細展開で収まらない場合に限り、右欄の本文領域で縦スクロールを許可する。見出しと「米国の農業」への戻り操作は残す。
- 高さの一致はまずCSSで処理する。必要な場合のみ、左列1か所の`ResizeObserver`で高さを取得し、右欄へ反映する。右欄の変更を再計測する循環を作らない。
- 初期の全国概説は現行の情報・グラフと自然な高さを保つ。選択後の品目・関係表示を高さ一致の対象とする。

### 3.2 統計の3列

統計行の直前に「米の統計」「酪農の統計」等を表示する。関係の解説を開いていても、この見出しで統計の対象を確認できる。

| 項目 | 仕様 |
|---|---|
| 列幅・余白 | 3等分、列間12px、各図の内側余白10〜12px。上端を揃え、高さは内容に応じる |
| 供給・行き先 | 棒を12px程度へ細くし、見出しと棒を同じ行に置く。凡例は色印＋区分＋％をまとめて折り返す |
| 円グラフ | 132pxを基準。円の右に国名と％を並べ、長い国名は自然に折り返す。円の中央は名称・総量・単位の3行 |
| 可読性 | 国名・％・供給の凡例は14px以上。出典・年月・単位は12px以上。SVG中央文字も縮小後の実表示で12px以上を確保 |
| 推移 | 世界生産の列内に米国シェアの10年推移を維持。実表示幅に合わせて目盛りを確保する |
| 補足 | 用途・輸入の補足、数量表、長い定義を各図の閉じた詳細欄へまとめる。本文の単なる削除はしない |
| 常時見える条件 | 年、数量／金額、単位、対象範囲、予備値、換算基準、出典への導線 |

3図の初期状態は数値表・長い補足を閉じる。表を開けば下へ伸びることは許容し、数値表のために隣の図を引き伸ばさない。地図・解説・統計の全てが画面の高さ以内に収まることまでは保証せず、文章を増やさず配置を整え、不要な縦長化を減らす。

酪農の乳換算ボタンは供給の列内に置く。乳脂肪／無脂乳固形分の切替は供給の図だけに作用し、輸出額・FAO世界生産は変えない。乳製品別の輸出額は統計3列の下の全幅に置き、酪農選択時だけ表示する。

### 3.3 iPad縦・スマホ・低い横画面

上記の2列適用条件に満たない場合は、地図 → 品目一覧 → 関係の見出し → 解説 → 統計3項目の順に1列で並べる。解説欄の高さを固定せず、全文を通常のページスクロールで読む。

- 375px・390pxでは円132pxと隣の一覧を維持する。360px未満で窮屈になる場合は一覧を円の下へ移す。
- 11品目と3関係は全て見えるように折り返し、操作対象の高さは44px以上とする。
- 品目・関係を選ぶと解説見出しが画面外の場合だけ、その見出しまでスクロールする。横幅のある画面では自動スクロールしない。
- スクロールは動きを減らす設定に従う。画面回転だけでは選択・乳換算・開いている表を初期化しない。

## 4. 表示状態と操作

右欄の内容と統計の対象を別々に管理する。`stats`と`livestockStats`の従来の2つの記憶値を、そのまま「いま表示中の品目」と扱わない。

```ts
type ProductId = 'corn' | 'soybean' | 'wheat' | 'cotton' | 'rice' | 'specialty'
  | 'beef' | 'dairy' | 'hogs' | 'broilers' | 'layers';
type StatisticsId = Exclude<ProductId, 'specialty'>;
type RelationId = 'corn-soy-hogs' | 'plains-wheat-cattle' | 'california-rice-water';
type ReadingView =
  | { kind: 'overview' }
  | { kind: 'product'; id: ProductId }
  | { kind: 'relation'; id: RelationId }
  | { kind: 'map-context'; id: 'corn-soybean' };
type AgricultureReadingState = {
  view: ReadingView;
  statisticsId: StatisticsId | null;
  resumeProductId: ProductId | null;
  milkBasis: 'fat' | 'skim';
};
```

この型は設計上の責務を示す。既存の地図座標・地域選択・表示レイヤー・旧queryの記憶値は別の責務として保つ。

| 操作・状態 | 右欄 | 下の統計 | 地図 |
|---|---|---|---|
| 選択指定のない初回 | 米国の農業 | 非表示。とうもろこし／肉牛を暗黙に選ばない | 現行の初期表示 |
| 統計のある品目を選択 | 当該品目の詳説 | その品目の3図 | 位置・倍率を保ち、既存図形で対象を強調 |
| 果樹・野菜を選択 | 既存の果樹・野菜の説明 | 3図を隠し「複数品目のため、この区分の共通統計は未収録」と短く表示 | 対象の分布を強調 |
| 品目選択後に関係を選択 | 関係の既存本文・留意点・関連品目へのリンク | 直前の統計対象を維持 | 関係の強調へ切替。位置・倍率は維持 |
| 初期状態から関係を選択 | 関係の詳説 | 非表示 | 関係を強調 |
| 同じ関係を再タップ | 直前の品目の詳説。品目未選択なら全国概説 | 関係を開く前の状態 | 単品の強調へ戻る。未選択なら強調解除 |
| 関係から品目を選択 | 選んだ品目の詳説 | 選んだ品目の3図 | 関係の強調を解除し、品目を強調 |
| 右欄の「米国の農業」を選択 | 全国概説 | 非表示、統計対象を解除 | 個別強調を解除。位置・倍率・表示レイヤーは維持 |
| 他分野へ移動して戻る | 直前の農業表示を復元 | 統計対象と乳換算を復元 | 農業の選択・表示設定を復元 |

単品を選んでも他の品目の分布を消さない。作物・畜産レイヤーの表示チェックは品目を選ぶ操作と分ける。非表示の層に対象がある場合は設定を維持し、右欄で「作物が非表示」等と「必要な層を表示」の操作を示す。関係で既にあるこの動作を単品にも揃える。

関係から別の関係へ切り替えても`resumeProductId`と`statisticsId`は変えない。「米国の農業」へ戻る場合は両方を解除する。

### 4.1 地図上の地域選択との接続

- 作物ポリゴンのクリックは既存の地域判定を使い、対応する品目の詳説と統計を右欄・下段へ表示する。選択地域の既存説明は右欄内の「選択地域：○○」の開閉欄へ残す。
- 畜産の代表点も、種別を特定して同じ入口へ渡す。既存の地域説明は同様に残す。地域情報から統計の対象を特定する方向と、全国の品目から特定の代表地域を勝手に選ぶ方向を混同しない。
- 重なった畜産点の候補選択は既存の判定を使い、候補だけを右欄に一時表示する。候補確定まで統計対象を変えない。
- `corn-soybean`の重なりには既存の説明を使う。単一品目の3統計は作らず、直前の統計を対象名付きで保つ。とうもろこし・大豆への直接リンクを出す。
- 農業の地域・品目・関係の説明は右欄へ集約する。旧`showSelection`による農業の地図上カード、下部詳説へのジャンプ、閉じた関係本文を強制展開する処理は重複表示しないよう整理する。自然環境・産業のカードや選択ロジックは変更しない。

## 5. URL・履歴の仕様

表示状態をURLで復元できるようにし、既存のリンクも受け入れる。新規キー名は次を採用する。

| キー | 値 | 役割 |
|---|---|---|
| `agriReading` | `overview`／`product:<id>`／`relation:<id>`／`map-context:corn-soybean` | 右欄の表示 |
| `agriProduct` | ProductId、未選択時は省略 | 関係から戻る品目。統計はこの値が統計対象10品目に該当すれば同じ対象、specialtyなら非表示 |
| `stats`／`livestockStats` | 既存の値 | 旧リンク互換と各分類の最後の選択値。両方の詳説を同時表示する命令ではない |
| `milkBasis` | `fat`／`skim` | 乳換算を維持 |
| `crop`／`region`／`animal`／`animalRegion`／`relation` | 既存の値 | 地図側の選択。右欄の正規化済み状態から矛盾なく書き戻す |

新規URLの例：

```text
?agriReading=product:rice&agriProduct=rice
?agriReading=relation:california-rice-water&agriProduct=dairy&milkBasis=skim
?agriReading=overview
```

### 復元の優先順位

1. 有効な明示アンカー（`#crop-rice`、`#livestock-dairy`、`#relation-…`）を、対象を読む明確な指示として最優先する。
2. 有効な`agriReading`。`product:<id>`は同じ品目に統計・記憶値を正規化する。`overview`は古い選択値が同居していても概説と統計非表示を優先する。
3. 新キーがない旧URLは、既存の地図選択の優先順位に従う。作物／地域、整合する畜産地域を関係より優先し、その対象の右欄を表示する。
4. 地図選択のない旧URLで、明示された有効な`livestockStats`だけがある場合は畜産、有効な`stats`がある場合は作物を開く。両方ある旧URLは操作順を復元できないため、作物を固定優先にする。
5. 指定がなければ全国概説。旧関数が返すデフォルトのcorn／beefを明示選択と扱わない。

旧`relation`だけのURLは関係表示とし、同居する明示`stats`／`livestockStats`から統計対象を上記の規則で復元する。関係アンカーの場合も同様。旧作物アンカーにはspecialtyも含める。無効な値は破棄し、有効な旧指定、最後は全国概説へ戻す。

`#crop-details`／`#livestock-details`は各分類の品目一覧への旧入口として残し、架空の既定品目を新たに選択しない。出典・背景へのアンカーは通常のページ内リンクとして維持する。

### 書き込みと履歴

- 品目・関係・全国概説の明示選択を1操作につき1回`pushState`する。同一の表示を再指定しただけなら履歴を増やさない。同じ関係の再タップによる復帰は1操作として記録する。
- 乳換算は既存の方針に合わせて`replaceState`し、カメラ操作は既存の頻度・抑制処理を維持する。
- `popstate`／`hashchange`は単一の復元処理を通し、表示と統計をまとめて更新する。復元中の履歴書き込みを抑制する。
- 古い品目・関係アンカーは、新しい選択に合わせて更新または除去し、戻る・再読込で古い対象が勝たないようにする。出典等の無関係なアンカーは保存する。
- `agriReading`等は自然環境・産業へ移っても保管するが、その分野の表示には作用させない。`industry`等の他分野のqueryを削除しない。
- 新しい関係表示は地図用の`crop`／`region`／`animalRegion`を解除し、戻る品目は`agriProduct`に保持する。これにより旧関数の「作物があると関係を無効化する」規則と競合させない。

## 6. データと表示の整合性

- 作物は`cropExplanations`の本文・用途・強調語句を移設する。畜産は`livestockReadings`の本文と製品説明を移設する。説明文を長く書き足さない。
- 関係は既存の`body`、`caveat`、関連品目リンク、出典を右欄で読めるようにする。地図上の近接から調達率や因果の強さを推計しない。
- 供給の2本の棒は共通の総供給を母数とする。未勘定・符号付き調整・公表丸め差を消したり、無理に100%へ正規化したりしない。差がある旨は見える位置に短く示し、正確な値は数量表にも残す。
- 作物輸出の数量、畜産製品輸出の名目米ドル、生産量のトン／俵／乳換算等を混同しない。対象年・換算・期間の違いは各図に残す。
- 米の供給の籾米換算と輸出・世界生産の精米換算、綿花の480ポンド俵と輸出トンを維持する。
- 世界円グラフの「その他」、表示国に含めた米国、FAO公表世界計と原表の集計差、10年推移の系列は変更しない。
- 酪農の2換算は合算せず、生乳・市場出荷・農場内利用を二重計上しない。採卵鶏のふ化用区分、輸出製品の範囲も既存定義を保つ。
- 右欄や3列の見た目を統一するために、データの定義や本文そのものを揃え直す作業は行わない。

表示状態を管理する農業専用コントローラーを拡張し、同じ品目選択関数を凡例・関係内リンク・旧アンカー・地域クリックから呼ぶ。コントローラーの初期化は地図の通信完了を待たずに行う。

| `src/lib/atlas-agriculture-detail-state.ts` | 新しい解説・統計状態、旧URLからの移行、正規化 |
| `src/scripts/atlas-agriculture-details.ts` | 選択・本文と統計の同期・単一の履歴処理 |
| `src/scripts/atlas-explorer.ts`／`src/lib/atlas-state.ts` | 地図の選択と上記を接続。農業の旧カード・自動展開・二重イベントを整理 |
| `src/styles/atlas-explorer.css` | 農業だけの上段の高さ、3列統計、狭幅表示 |

ファイル名のないコンポーネント欄は`src/components/atlas/`内。必要なら農業の表示先・品目選択のみ小さな専用コンポーネントへ切り出す。自然環境・産業を含む共通ファイルの全面書き換えは避ける。

### 静的出力とDOMの扱い

- 統計と本文は引き続きビルド時HTML/SVGとして1回だけ出力する。選択ごとの取得やSVG再描画は不要。
- 既存の本文ノード・統計ノードを右欄と統計行へ移設する方式を基本とし、同一本文やグラフを複製して常駐させない。移設先を変えてもcanonical IDは1個だけにする。
- `#crop-<id>`／`#livestock-<id>`のIDは各品目の本文セクションに保持する。統計側には別IDを使い、旧tabpanelラベルが撤去したタブを参照しないよう整理する。
- 非選択の本文・統計は`hidden`にして、支援技術からも非表示にする。表の開閉状態は品目ごとに保ち、再選択時に再作成しない。
- JavaScriptが無効なら、全国概説、11品目の本文、10品目の統計、3関係を通常のHTMLとして読める構成を保つ。リンクは対応する本文へ移動する。単一表示用の隠蔽は初期化完了後に適用する。
- WebGL失敗時も、代替地図、品目・関係の選択、右欄、統計を利用できる。関係の強調は既存の正確な代替SVGを使う。

### 負荷の上限

新しい地図インスタンス、地理データ、画像、グラフライブラリ、実行時依存、外部APIを追加しない。品目・関係を20回切り替えても、初期の遅延読み込み完了後の通信回数と地図の生成数は増やさない。切替でカメラ移動・地図の再生成を行わない。

HTMLと配信JS/CSSの同条件gzip比較で、追加10KiB以内を目安とする。これを超える場合は重複データ・重複本文・新規依存を先に確認する。前回と比較条件を揃え、サイト全体の成果物合計を実転送量と混同しない。

## 8. 操作・アクセシビリティ

- 品目・関係の名前はリンクまたはボタン全体を操作対象とし、色や記号だけを押させない。分類見出しは非操作要素とする。
- リンクによる選択を基本とし、選択中は`aria-current`等で識別できるようにする。2群を独立したtabpanelとして扱わない。
- 選択表示は右欄で読んでいる品目または関係に付ける。関係表示中の直前品目を「今読んでいる品目」とは表示せず、統計の対象名で区別する。
- 操作後のフォーカスは原則として押した項目に残す。画面内の解説見出しを通知し、本文全体を毎回読み上げない。
- 右欄には「米国の農業」への戻りリンクを1つ置く。関係を同じ見出しで解除した場合は、その見出しのフォーカスを保つ。
- 右欄内でEscを押した場合は関係表示から直前品目へ戻す。品目表示からは全国概説へ戻す。地図のキーボード操作や他分野のEsc処理と重複させない。
- 表・出典リンク・乳換算の操作を、親要素の品目選択イベントとして誤処理しない。修飾キー付きの通常リンク操作も維持する。

自動確認は既存の`npm run check`を使う。`tests/unit/atlas-agriculture-details.test.mjs`、`tests/unit/atlas-state.test.mjs`、`tests/e2e/atlas-agriculture-insights-controller.test.mjs`等を、新しい状態遷移に合わせて更新する。「全国欄が変化しない」「作物と畜産を同時表示する」という旧仕様の期待値は改め、統計の元値・独立した乳換算・他分野の非干渉の検査は残す。CSS文字列の存在をなぞる試験は追加しない。

本番または検証用ブラウザでは、1024／1180pxで11品目と3関係、390pxで代表の米・綿花・酪農・果樹野菜、959／960pxで列数の境界、320pxで長い国名を確認する。供給表・輸出表・世界表を開いた状態は代表品目で確認する。通常ケースと具体的なリスクを解消した後、全画面×全操作の無制限な繰返しは行わない。

CSSビューポートのChrome確認と、Safari・iPad/iPhone実機確認は記録上で区別する。実機未確認なら、その範囲を明記する。

## 10. 実装手順

1. 実装開始時のmainを再取得する。産業・自然環境の更新を取り込み、農業の該当箇所との差分を確認する。
2. 純粋な状態の読み書きと旧URL互換を実装する。品目・関係・統計の対象が分かれるケースを先に検証する。
3. 既存本文・統計の表示先を分け、地図下の選択を共通の入口へ接続する。初期概説、関係の再選択、果樹野菜、酪農を確認する。
4. 農業だけに上段の高さ調整と3列・狭幅レイアウトを適用する。古い下部タブ・地図カード・自動展開処理を整理する。
5. 自動確認、代表画面、元データの表示一致、負荷を確認して実装PRへ記録する。
6. 公開時は対象コミットのCI・Pages配備・`_release.json`を確認し、公開画面の記録を残す。

この設計書の作成では設計用ファイルのみを保存する。実装開始を指示された時点で上記を実行する。
