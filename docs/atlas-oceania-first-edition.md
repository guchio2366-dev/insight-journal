# オセアニア初回4分野：実データ準備

2026-10-01、main `ce37d4154199065ef5164908c736c0549a39829d` を確認。現在の公開版は25国・地域の基礎地図と概要のみ。テーマ別4分野は未実装。この変更はオセアニア専用の出典固定・抽出データを用意する段階で、全域の4分野完成を意味しない。

各assetのmanifestに固定原本URL、利用条件、SHA-256、CRS、単位、処理、欠測診断を記録。気候・作物は元値の切り出しだけを行い、平均・補間はしていない。日付変更線の両側を110–250°Eへ連結し、PNGと数値配列は同じ値から生成した。公開画面のclipには元の国・地域のgeometryを用い、粗いセル中心による診断maskは表示境界に使わない。

次のまとまった実装単位は、次の4つを共通の太平洋地図・選択・比較の枠に載せる初回版。

1. 豪州内陸の乾燥、沿岸・NZの温帯、PNG・島々の熱帯を気候の実分布で読む。
2. 小麦と熱帯作物に豪州・NZの牛／羊を加え、水管理・経営・加工・交通・市場との関係を読む。
3. 豪州の鉱種と輸出港、NZの農林産加工、PNG・メラネシアの資源・港・水産加工を一次資料でつなぐ。実証のない航路・鉱山から港への線は描かない。
4. 全域人口密度と都市中心を組み合わせ、沿岸の集積と離島の交通・公共サービスを読む。小島の未収録を無人と読ませない。

全体・島嶼拡大の双方で、自然条件だけによる説明を避ける。主地図、描画中の全凡例、持ち帰るメッセージ、比較入口を1366×768で確認し、詳しい説明と出典は折り畳む。比較は元分布を保持し、年・単位・専用説明・選択保持・対象名付き戻りを揃える。

主要な残件はGHSL全域人口格子の切り出し、GLW畜産の180度東側原本、小島詳細、豪州外の産業位置と港の一次資料。旧RasterIO/pyprojはPCのDLL制御で動かないため、既存原本を使った許可済み処理経路の確認が必要。現段階で有料データや新契約は必要ない。

公開の最短見込みは10月3日。10月2日に4分野の実画面と比較動作をレビューできる状態を目指す。人口格子・小島詳細の検証が延びる場合は10月4日へ更新する。公開は最終commitのCI、親目視、Pages commitとasset一致の確認後。
