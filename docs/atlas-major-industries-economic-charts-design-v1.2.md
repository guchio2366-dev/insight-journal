## 1. 目的と合意した表示

産業から分野を選ぶと、米国内での規模と変化、輸出先、世界における位置づけを続けて読めるようにする。地図では、比較できる同じ分野の都市圏について経済規模を見分けられるようにする。

| 領域 | 決定事項 |
|---|---|
| 全国推移 | 年次表を主表示から外し、折れ線グラフを常時表示。左に付加価値・出荷額など、右に雇用 |
| 指標 | 公式統計の指標名・値・単位・対象範囲を使用。製造業は出荷額等と意味のある生産数量、サービスは付加価値を中心にする |
| 輸出・世界比較 | 農業v7.1に合わせ、輸出先を左、世界生産等に占める米国シェアを右に置く |
| コンパクト化 | 詳説全幅を使い、余白と数値の重複を減らす。読める文字サイズと必要な注記を保つ |
| 輸送機器の分類 | 航空宇宙、造船、鉄道車両を別の分野として表示する |
| 地図の経済規模 | 同じ分野・同じ比較条件の値に、円の**面積**を比例させる。順位は数値とともに補足表示 |
| 全産業の地図 | これまでどおり同サイズのアイコンを使用する |
| サービスの記号 | 金・情・専・商・観・医・他を明示的に割り当てる |

順位で円を段階的に拡大する案から、実額に面積を比例させる案を採用した。例えば値が4倍なら面積が4倍、直径が2倍になる。雇用を経済規模の代用にはしない。

本書は表示仕様を確定する。新しい統計の全系列・取得可能年・都市圏別の可用性は、実装の最初にデータ台帳で確定する。候補の存在を、その分野の数値を取得・検証できたこととして扱わない。

## 2. 現在地と既存画面との関係

[v1.1実装記録](atlas-major-industries-all-breakdown-implementation-v1.1.md)と[PR #35](https://github.com/guchio2366-dev/insight-journal/pull/35)が現在の基礎となる。全産業のGDP・雇用構成は12区分、サービス業の内訳は7区分として実装済みである。

基準mainでは、第二段に20分野、地図に42件の代表地域、詳説の後に6件のインサイトがある。`IndustryReading.astro`の全国推移は、BEAの名目付加価値・雇用の2017～2024年表を`details`内で表示している。分野に対応する統計がない詳説には表がない。航空宇宙の参照値は3364～3369相当の広い「その他の輸送機器」である。

| 操作・領域 | v1.2の責任 |
|---|---|
| 第一段の産業選択 | 地図、右側の全国構成、分野タブ、詳説を切り替える |
| 第二段の分野選択 | 地図と下部詳説を切り替える。右側の全国構成は第一段の産業全体のまま |
| 右側の全国構成 | GDPと雇用を同じ分類・順序で表示。全産業12区分とサービス7区分の分母を継承 |
| 下部の分野詳説 | 本文に続けて、分野に適した全国推移と国際比較を表示 |
| 地域選択 | 地域説明に、その都市圏の経済指標・年・比較対象内順位を加える |

詳説に造船・鉄道車両を追加しても、右側のBEA構成グラフを取得できない粒度へ分割しない。右側では広い統計区分の正しい名称を使い、分野詳説の航空宇宙にその広い数値を流用しない。

農業v7.1は設計PR #38を参照した後、執筆中に実装PR #39がmainへ統合された。[実装記録](https://github.com/guchio2366-dev/insight-journal/blob/8d2a2af9218ddeb391d8d4d59867f77749e29c8d/docs/atlas-agriculture-compact-charts-implementation-v7.1.md)でも、960pxの切替、132～144pxの円、14pxの国名・割合、最大幅360pxの推移が一致している。実装着手時はこの変更を含む最新mainを使用する。参照した記録では公開後の画面確認が後続工程であり、本書から農業の実機確認済みとは主張しない。

## 3. コンパクトな詳説の配置

### 3.1 詳説全体

本文の後に、全国推移と国際比較をそれぞれ独立した全幅の行として置く。地図右側の狭い全国構成欄には追加しない。

| 読む順序 | CSS幅960px以上 | CSS幅960px未満 |
|---:|---|---|
| 1 | 分野名と既存の説明本文 | 分野名と説明本文 |
| 2 | 左：経済指標の推移、右：雇用の推移 | 経済指標、必要な生産数量、雇用の順 |
| 3 | 左：輸出先、右：世界の構成と米国シェア | 輸出先、世界の構成と米国シェアの順 |
| 4 | 出典・詳しい定義・展開できる数値表 | 同じ順序 |

自動車等の補助的な生産数量は、左の経済指標カード内に小さな別グラフとして置く。雇用カードは上端を揃え、左の高さまで引き伸ばさない。世界シェアの時系列がある場合も、世界カードの中に収める。

二列の間隔は16px、カード内側の余白は12pxを基準とする。詳説の既存外幅・ページ余白を使い、子要素に`min-width: 0`を指定する。カードの固定高さ、内部縦スクロール、項目や注記の切捨ては設けない。DOM順を読書順と一致させ、CSSによる順番の逆転や重複DOMを使わない。

960pxという条件は農業v7.1と揃える。端末名や向きで分岐せず、iPad分割表示・文字拡大で幅が不足すれば一列に戻す。主要産業の外枠内でも各カードが収まることを、1024px幅で実測する。

### 3.2 全国推移の大きさと読み方

| 要素 | 基準 |
|---|---|
| 主折れ線 | `viewBox="0 0 360 140"`相当、最大表示幅360px、高さは縦横比に従う |
| 補助的な数量の折れ線 | 最大幅360px、基準高さ110px。目盛り・年が読める範囲で使用 |
| 見出し | 16px、公式指標に対応する日本語名 |
| 最新値 | HTMLで14px以上。対象年と単位を近くに置く |
| 目盛り・年・出典 | 実描画で12px以上を目安。SVG縮小後のサイズを測る |
| 数値表の開閉操作 | 高さ44px以上を基準 |

横軸は利用可能な直近10年を原則とし、既存の8年系列は補間せず8年で表示する。左右で同じ年範囲を使い、終年の異なる系列には最新年を個別表示する。欠測年は線を途切れさせる。公表が1年だけなら最新値と年を表示し、推移があるような線を描かない。

縦軸に指標と単位を明記し、金額・数量・雇用を別々の軸で描く。単位の違う系列を二重軸に重ねたり、無表示の指数へ変換したりしない。絶対額・数量はゼロ基準を基本とし、負値がある場合はゼロを含む範囲を取る。別の軸範囲が必要なら範囲を明瞭に表示し、切断によって変動を過大に見せない。

開始・終了年と数本の目盛り、最新値を常時見せる。毎年のラベルをすべて線の上に重ねない。正確な全期間の値は「数値を見る」で展開できる表に残す。ホバーやタップをしないと主要な値・期間が読めない作りにしない。

### 3.3 輸出先・世界構成の円

農業v7.1の寸法とラベルの関係を継承する。

| CSS幅 | 円の直径 | 円と一覧 |
|---|---:|---|
| 420px超 | 144px | 円の右に国名・割合。間隔12px |
| 360～420px | 132px | 円の右に国名・割合。間隔10px |
| 360px未満 | 132px | 円の下に一覧。文字サイズを保つ |

国名と割合は同じラベル内に置き、約4pxの間隔で近接させる。割合だけをカード右端へ離さない。国名・割合は14px以上、長い国名は折返し、割合の数値と％は一体として扱う。円中央は「総輸出額／世界総生産等」「値」「単位」の3行とする。

横並びでは見出しの最小高さ72pxを基準に円の上端を揃える。内容が長い場合は自然に伸ばす。円のためにカード全体を正方形にしたり、短いカードの下に空白を足したりしない。世界シェアの推移は最大幅360px・基準360×140で同じカード内に置く。

輸出先は上位5市場＋その他、世界構成は上位5か国・地域＋米国（上位外なら追加）＋その他を基本とする。米国の小さい扇形を水増ししない。国別データがなく、整合する米国値と世界値だけが得られる場合は「米国／その他の世界」の構成として表示し、国別順位を作らない。

表示対象の国・地域と割合は全件見せる。通常は最大7項目だが、秘匿等を別表示する必要がある場合も行を削らず自然に伸ばす。割合は小数1桁、扇形は未丸め値で計算する。丸め後の合計を100%へ強制補正しない。

### 3.4 常時見せる情報

年、単位、名目／実質、対象製品・範囲、推計・予備値・集計値の別、主要な範囲差、原資料の出典リンクは常時表示する。細かなコード対応、長い定義、年次表、国別の正確な元単位値は展開欄へ入れる。

対応するデータがない図は、短い理由を本文の流れに置く。巨大な空カード、0のグラフ、無関係な親区分の数値で空欄を埋めない。コンパクト化のために統計上の重要な違いを隠さない。

## 4. 分野別に使用する指標

以下は**取得・検証する系列の優先順位**であり、全22分野の新しい値が取得済みという一覧ではない。公式の名称・単位を元データに保存し、日本語見出しにも対応関係を残す。桁を読みやすくする換算は可能だが、元単位と換算係数を保持する。指数を金額へ換算しない。

| 分野 | 全国推移の主な金額指標 | 補助数量・範囲の扱い |
|---|---|---|
| 自動車 | 完成車の出荷額。部品を含む集計を使う場合は対象を見出しに明示 | 国内生産台数。部品の点数と足さず、車種・完成車の範囲を合わせる |
| 航空宇宙 | 航空宇宙製品・部品の出荷額 | 航空機の生産・引渡しは公式系列の名称と機種範囲で表示。機体・ロケット・衛星を一つの台数にしない |
| 造船 | 船舶・ボート製造の出荷額 | 隻数・総トン数等は船種と製造／修理の対象を明示。異なるトン数定義を混ぜない |
| 鉄道車両 | 鉄道車両製造の出荷額 | 機関車・客車・貨車を区別。鉄道運行サービスの売上を使わない |
| 半導体・電子機器 | 対応する製造分野の出荷額 | 半導体だけの値は電子機器全体と区別。国内工場の生産能力と米国企業の世界売上を区別 |
| 機械 | 対象製造業の出荷額 | 異種製品の台数合計は設けない |
| 金属 | 対象製造業の出荷額 | 粗鋼等、統一された製品の重量を補助表示。金属製品全体の量と呼ばない |
| 化学 | 対象製造業の出荷額 | 医薬品等の対象を明示。化学製品全体を無理にトン数で合算しない |
| 食品加工 | 対象製造業の出荷額 | 農畜産物の一次生産と加工製品を区別。意味のある個別製品数量のみ |
| その他の製造業 | 定義した残余分野の出荷額 | 含有コードを列挙し、他のタブとの重複を除く |
| 石油・天然ガス | 採掘の付加価値または公式の生産価額 | 原油・ガスを別系列・原単位で表示。採掘と石油精製を区別 |
| その他の鉱業 | 対象鉱業の付加価値または生産価額 | 鉱種別の公式単位。異なる鉱種を一つの量にしない |
| 電力・ガス・水道 | 対象事業の付加価値 | 発電量等は個別に表示。kWhとガス量・水量を合算しない |
| 情報通信 | 付加価値 | 売上高を補助表示する場合は出版・放送・通信・情報サービスの範囲を明示 |
| 金融・保険 | 付加価値 | 預金・融資・運用資産残高を年間の経済規模と混同しない |
| 専門サービス | 対応範囲の付加価値 | 現行の専門・業務支援等の統計範囲と短いタブ名の差を明示 |
| 商業・物流 | 対応範囲の付加価値 | 商品販売額と輸送サービスを区別。輸送量は個別系列 |
| 観光・娯楽 | 観光に対応する公的な付加価値、または「娯楽・宿泊・飲食」の付加価値 | 観光需要に対応する系列と71～72全体を別名で扱う。来訪者数・消費額は補助系列 |
| 医療・教育 | 対応範囲の付加価値 | 民間／政府、福祉を含むかを明示 |
| その他のサービス | 対象分野の付加価値 | 公式分類の範囲を明示 |
| 建設 | 付加価値 | 公式の建設支出額等は別指標。建設支出と生産者の売上・付加価値を区別 |
| 不動産・賃貸 | 付加価値 | 帰属家賃等の包含を明示。資産価格・取引総額を付加価値と混同しない |

雇用は右のカードに置き、主な金額指標と同じ産業範囲・国内範囲を優先する。BEAの国内雇用、Censusの製造事業所雇用、BLSの対象雇用は定義が異なる。年平均か特定時点か、人数か雇用数か、自営業・政府の包含を記録し、異なる定義を一本の線につながない。

### 4.1 航空宇宙・造船・鉄道車両の追加

| タブID | 表示名 | 公式分類の出発点 |
|---|---|---|
| `aerospace` | 航空宇宙 | NAICS 3364：Aerospace Product and Parts Manufacturing |
| `shipbuilding` | 造船 | NAICS 3366：Ship and Boat Building |
| `railway` | 鉄道車両 | NAICS 3365：Railroad Rolling Stock Manufacturing |

分類の出典は[Censusの2022 NAICS Manual](https://www.census.gov/naics/reference_files_tools/2022_NAICS_Manual.pdf)。系列取得時には各調査の採用分類年と下位コードを確認する。3364の対象を民間航空機だけと表示せず、3366ではボートや修理の包含を確認する。

第二段は20から22分野となる。航空宇宙の次に造船・鉄道車両を置き、既存のID・リンクは保つ。新分野ごとに本文、出典付きの地域例、データ対応を用意する。地域例が未確認の場合は既存の空状態を使い、別分野の都市を複製して埋めない。統計コードの残余を再点検し、「その他の製造業」との重複を取り除く。

## 5. 公式統計とデータの確定条件

### 5.1 取得候補と確認済みの制約

| 用途 | 公的な取得候補 | 設計時点で確認したこと・実装時の確認事項 |
|---|---|---|
| 全国の付加価値・既存雇用 | BEA GDP by Industry、NIPA | 現行データを継承。下位分野への正確な対応・公表年・改訂版を系列ごとに確定 |
| 製造業の出荷額・事業所雇用 | Census Economic Census、旧ASM、AIES | [ASMはAIESへ移行済み](https://www.census.gov/programs-surveys/asm.html)。調査変更・分類改定・ベンチマークを確認し、接続できない年を線で結ばない |
| 詳細分野の雇用 | BLS QCEW等 | [QCEW](https://www.bls.gov/cew/overview.htm)は対象雇用に除外範囲がある。MSAの公表は2025年第2四半期から総計のみとなり、最新の分野別都市圏値を当然に取得できると扱わない |
| 都市圏の付加価値 | BEAの公表済み都市圏値、郡GDPからの集計 | [BEAは都市圏等の集計地域での公表を終了](https://www.bea.gov/help/faq/1481)。既存公表系列と郡からの独自集計を区別する |
| 観光 | BEA Travel and Tourism Satellite Account等 | [BEAは定期作成終了を告知](https://www.bea.gov/data/special-topics/travel-and-tourism)。同ページの最新掲載は2018～2023年。更新済みのように年を延ばさない |
| 財の輸出先 | Census International Tradeの公的貿易統計 | [輸出の定義](https://www.census.gov/foreign-trade/reference/definitions/index.html)に従い、国内産品輸出・再輸出・総輸出を区別。製品コードと産業コードの対応を保存 |
| サービスの輸出先 | BEA International Services | [公表拡充の説明](https://www.bea.gov/news/blog/2025-09-08/statistics-services-trade-expanded-147-more-countries-and-areas)では、サービス全体と詳細種類で国別の収録範囲が異なる。国内の産業分類と貿易のサービス分類を一対一とみなさない |
| 数量・世界比較 | 分野別の政府統計、国際機関が公表する比較可能な統計 | 国別の対象・年・単位・分母を照合して採用。調査先・系列ID・実値は未確定 |

公式サイトが業界団体の数字を転載している場合は原出典まで記録し、政府が作成する統計と同一扱いにしない。OICAやSIA等の団体統計を、合意した公式統計の条件を満たすものとして黙って採用しない。適合する公的系列がなければ、その比較を未整備として記録する。

観光の全国推移では、TTSAの取得できる期間を「観光の付加価値」として表示できる。より新しい71～72の付加価値を添える場合は「娯楽・宿泊・飲食」と明記した別系列にする。住民による飲食等を含む値に「観光GDP」とラベルを付けない。

### 5.2 輸出先と世界シェア

輸出先の分母は、同年・同じ製品／サービス範囲の米国輸出総額とする。財は国内生産との関係を読むため国内産品輸出を優先し、総輸出しか対応できない場合は再輸出を含むことを明示する。サービスは相手国別の該当サービス輸出額を使用し、海外現地法人の販売額を混ぜない。

世界シェアは図の名称に分母を含める。「世界の自動車生産台数」「世界の当該産業の付加価値」等とし、米国の国内生産と米国企業の世界売上を区別する。同じ国内概念・分類・年・価格評価・換算基準が揃う値だけで計算する。

OECD加盟国だけ等、世界を網羅しない値の合計を「世界」と表示しない。生産や付加価値の世界シェアが取得できない場合に、世界輸出シェアで置き換えない。貿易のシェアを補足する場合は別名・別分母として扱う。輸出額を付加価値で割って「輸出依存度」とはしない。

その他は、同じ公表総量から表示項目を差し引いて算出できる場合に限る。国別秘匿・未配分を含む残余は名称と注記に反映する。母集団が不完全な国別表を100%に正規化して完全な分布に見せない。総量との不一致や負の残余を検出した場合は、原因を確定するまで円を表示しない。

### 5.3 データ台帳

`docs/atlas-industry-statistics-data.md`を実装時に追加し、22分野×全国金額・数量・雇用・輸出先・世界比較・地域経済規模の可否を一覧化する。状態は「取得候補／取得済み・未照合／検証済み／対応統計なし／秘匿等で比較不可」を区別する。

各系列に、提供機関、統計名、表・系列ID、原資料URL、取得日、公表・改訂日、年、元指標名、単位、分類と版、対象地理、価格・通貨、国内／企業本拠地、対象事業者、推計等のフラグ、欠測理由、変換・集計式、元資料の保存先を記録する。公開画面は検証済みの系列だけを使う。

原資料と加工後の値を分けて保持し、再現可能な取得・変換処理を用意する。ブラウザ閲覧時に外部APIや認証情報へ依存させず、静的データをビルド時に取り込む。

## 6. 地図：同じ分野の経済規模を面積で示す

### 6.1 比例表示を有効にする条件

初期対象は第二段で一つの分野を選び、比較可能な経済系列が確定した場合とする。第一段の「全分野」でも、親産業の同じ合計を都市圏ごとに用意できればその専用系列を使用できる。金融の値と情報通信の値を混ぜたまま、サービス業の都市順位を作らない。

| 条件 | 必須の揃え方 |
|---|---|
| 分野 | 同じ産業定義・コード集合 |
| 経済指標 | 同じ付加価値、出荷額、生産価額等。金額と雇用・数量を混ぜない |
| 年・単位 | 同じ対象年、名目／実質、通貨・換算、暦年／年度 |
| 地理 | 同じ都市圏定義・境界の版。市域・郡・州・都市圏を混在させない |
| 対象範囲 | 同じ国内生産、事業所、民間／政府等の範囲 |
| 数値状態 | 公表値または検証済み集計。欠測・秘匿・非該当を0へ変換しない |
| 比較集合 | 2地域以上の検証済み値。同一都市圏の代表地点が複数あっても重複計上しない |

都市圏の経済値を市中心の代表座標へ置く場合は、ラベルを「○○都市圏」とし、市域の数字ではないことが読めるようにする。市の総GDP、州の産業GDP、企業本社の全社売上を、その市の特定分野の規模として代入しない。

既存の代表地域には都市・州・広域が混在するため、地域説明のレコードと経済比較の地理レコードを分ける。`geographyId`と境界版で対応づけ、42件の地域例へ全国値を機械的に付けない。

### 6.2 BEAの公表済み系列と郡からの集計

同じ年・定義で使える公表済み都市圏データがあれば、最終公表年を明示して使用する。新しい郡GDPを都市圏へ集計する場合は、[BEA FAQが案内する方法・技術資料](https://www.bea.gov/help/faq/1481)を確認し、対応する郡と都市圏境界の版を保存する。

集計は加算可能な名目値を使用し、連鎖方式の実質値を単純加算しない。構成郡の欠測・秘匿や境界変更がある場合は、完全な都市圏合計とみなさない。採用可能な集計は「公的統計から集計」と表示し、BEAが直接公表した都市圏値とは区別する。

この工程で比較できる粒度が見つからない分野は、同サイズの地域例表示を続ける。「比較可能な都市圏別の出荷額は未整備」等、具体的な理由を地図の説明に短く置く。雇用・事業所数・主観的順位で経済規模を代用しない。

### 6.3 面積、順位、凡例

比較集合を`C`、各地域の値を`v`、集合内の最大値を`Vmax`とし、塗りの円の半径を`r = 32 × sqrt(v / Vmax)` CSS pxとする。全データに共通の係数を使い、最大直径は64pxとなる。値の4倍に対する面積4倍を検証する。

`Vmax`と順位は比較集合全体から決め、画面内に見える点だけから再計算しない。パン・ズームによって円の画面上の大きさや順位を変えない。分野・対象年・比較集合が変わるときだけ、凡例を伴って係数を更新する。

最小半径の加算、下限クランプ、対数・順位変換は行わない。中心の記号は14pxを基準に一定とし、塗りの円と独立した要素で表示する。小さい円では文字を隣接ラベルへ逃がし、面積を水増ししない。操作領域は透明な44×44px以上を確保し、データ円とは区別する。

真の0は数値として扱い、塗り円を描かず「0」を表示する。欠測には経済規模を表さない別形状の参照記号と「数値なし」を使う。負値を含む比較集合は面積比例を無効にし、絶対値へ変換しない。全値が0の場合も比例表示を無効にする。

地図に代表的な値の円を2～3個置き、指標・単位・年を付ける。凡例は「円の面積は金融・保険の付加価値を示す」等とする。指標が異なる分野をまたいで円の大きさを比較できる表現にはしない。

地域カードには「都市圏名／指標名／値・単位／年／比較対象N都市圏中の順位／出典」を表示する。順位は未丸め値による降順、同値は同順位（1位・1位・3位）とする。初期の比較集合は、同一分野で登録した代表都市圏のうち条件を満たす集合であり、全国全都市圏を網羅する保証はない。「全米第○位」とは書かない。

### 6.4 重なりと既存の地域選択

現在の`groupIndustryMarkers`は近接するラベルをまとめ、円内に地域例の件数を表示する。経済規模表示では、別都市圏の円を一つの件数円や合算円へ置き換えない。面積円は地理座標に残し、大きい円を先、小さい円を後に描いて小さい値を選べるようにする。

ラベルや操作領域が重なる場合は候補一覧で選択できるようにし、候補数は円と別のバッジへ出す。重なりによる見かけの濃さを量の表現に使わない。同じ都市圏に複数の地域説明がある場合は経済円を一つにし、その下に説明の候補を置く。画面端ではラベルだけ位置調整し、量を表す円の中心を別の都市へずらさない。

全産業では既存の同サイズ表示と近接候補選択を継承する。地図初期化失敗時の投影・地域一覧・地域カードにも同じ値と凡例を使い、WebGLの成功を数値への到達条件にしない。
