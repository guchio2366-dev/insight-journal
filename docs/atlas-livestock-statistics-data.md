## 米国の数量収支

WASDE p.32の脚注4で、牛肉・豚肉は枝肉重量、鶏肉は可調理重量と確認。頭数を肉量へ足さない。p.33の卵は百万ダース、乳は十億ポンド。全て2025年列であり、2026・2027年予測を混ぜない。

- 供給：国内生産＋輸入＋期首在庫。酪農だけは国内生産の代わりに市場出荷を使う。
- 行き先：国内利用＋輸出＋期末在庫。卵のふ化用1,163.8百万ダースは別区分。
- 生乳生産231.7 − 農場内利用1.0 ＝ 市場出荷230.7十億lb。
- 酪農は乳脂肪換算の総供給251.1、無脂乳固形分換算246.6。2つの換算値は合計しない。
- 国内利用は消失量に基づき、実際に食べた量とは断定しない。

両方の棒は同じ総供給を100%とする。丸めで内訳合計が上回る場合は、2本共通の描画領域をわずかに広げ、100%の位置を線で示す。各棒を別々に100%へ引き伸ばさない。

内訳合計−公表総供給：豚肉の行き先+1百万lb、卵+0.1百万ダース、乳脂肪の供給+0.1／行き先−0.1十億lb、無脂乳固形分の供給+0.1十億lb。許容差は式の各項について公表最小単位の半分を足した値。原表の差を保存し、架空の用途は追加しない。

各商品の正確な10桁コード・原名称・世界向け額・除外コードを `product-codebook.json` に保存する。牛・豚は生体を含まず、内臓・調製品を含む。酪農は乳糖・カゼイン・乳を含む調製品等の派生品も含む。

鶏：020711、020712、020713、020714、160232で始まる明細と1601000010。七面鳥・あひる・その他家禽、生体は含めない。

卵：0407210000、0407900000、0408110000、0408190000、0408910000、0408990000、3502110000、3502190000。ふ化用040711/040719、他鳥種の生鮮殻付き卵040729、卵と特定できないその他アルブミン350290を除外。

**加工卵・卵白製品のコードは鳥種を区別しない。** 鶏だけの額へ推定配分せず、その制約を図の常時表示注記に記載する。設計で想定した他鳥種の完全分離は、これらの公開コードでは実施できない。

乳製品内訳はチーズ／粉乳／ホエー・乳アルブミン／バター・乳脂肪／その他の排他的な区分。合計は上の同じ総輸出額に一致する。国内小売販売構成ではない。

評価額はCensusのF.A.S.輸出価額（輸出港等までの国内運賃等を含み、その先の国際輸送費を除く）。カナダ向けは相互データ交換の調整に従う。総輸出には再輸出を含む。農家売上・小売売上と差引計算しない。

## 抽出と再現

保存先は `data-source/atlas/livestock/`。FAO・GATSの出典JSONに取得日、公表更新日、URL、原配布ファイルのSHA-256、抽出後のSHA-256、列・照会条件を記録する。原表抜粋は公開配信の `public/` に置かない。

GATSの共通指定：FAS U.S. Trade、Exports、BICO (HS-10)、Value／Dollars、Annual、2025–2025、January–December、All、Rank、Calculationなし。取得した各レポートの表見出し「2025」「January - December」を確認した。

1. 5商品群、World Total＋All Partners、Product/Partner、In Detail＝Partner。世界行と直下の相手先だけを保持し、後続の重複した国別表や構成地域を足さない。
2. 同じ5商品群、World Total、Product/Partner、In Detail＝Product。全HS10明細の世界向け額と親総額を取得。
3. 家禽・卵の2商品群、All Partners、Partner/Product、In Detail＝Product。整数順位の相手先親行に属するHS10明細だけを保持。旧国集計(*)とその構成国(!)の二重計上を避ける。

5群の全相手先合計＝採用総額を1ドル単位で検算した。鶏・卵は明細コードを選別した後にも、世界向けコード別合計と全相手先合計の一致を確認した。

再生成は標準Pythonだけで実行できる。

```sh
python scripts/prepare-atlas-livestock-statistics.py
node --test tests/unit/atlas-agriculture-details.test.mjs
```

通常ビルドではPythonや取得用ライブラリも不要。原表を更新する際はコード範囲・単位・共通年・世界集計差・全相手先との一致を再確認してから、出典ハッシュを更新する。
