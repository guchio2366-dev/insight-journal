# 主要産業 v1.2：統計台帳・実装記録

取得日：2026-09-14。設計：`atlas-major-industries-economic-charts-design-v1.2.md`。
実装基点：`e9597ce4644f3d8d64601f989d1e584fac142a07`。農業の輸出額ドーナツと同じく、コンパクトな図と隣接する国名・割合を採用する。

## 実装の判断

- 下部の全国推移を常時見える折れ線に変更。960 CSS px以上は経済指標と雇用を横並び、それ未満は縦並び。SVGは最大360×140、数表は折りたたむ。
- 製造業は出荷額、その他は名目付加価値。自動車は生産台数を補助図にする。異なる単位を同じ軸に載せない。
- ドーナツは144px、360〜420px幅では132px、360px未満は国名一覧を下に置く。割合は原値から計算し、上位5か国＋その他。世界生産では米国が上位5か国外でも残す。
- 全産業の上部GDP・雇用は従来の12区分（サービス7内訳を含む）。第二段タブでは上部構成・カメラを動かさない。
- 航空宇宙・造船・鉄道車両を独立。国内分類と輸出品目は一致しないため、各図に対象範囲を表示する。
- 地図の円は半径ではなく**面積**を付加価値に比例させる。`r=32√(value/max)` CSS px。比較母集団全体で係数を固定し、パン・ズーム・画面内の地域数では変えない。小値を最小半径へ切り上げない。
- 同じ分野・名目指標・2024年・2023年7月都市圏定義の2地域以上で比較できる場合のみ有効。全産業・親分類・比較不足は同サイズの地域例。
- 欠測・秘匿をゼロにせず、経済比較中は四角い参照記号。フォートワースとダラスは同一都市圏として重複除去。順位は登録された比較対象内、全米順位ではない。
- サービス記号は金・情・専・商・観・医・他。複数分野の集合は「複」、件数を別バッジにする。経済円は異なる都市圏を合成しない。地域一覧から全対象を選べる。

## 原資料と再現

- Census ASM: https://www2.census.gov/programs-surveys/asm/data/2022/AM2231GS1.zip
- Census AIES: https://www2.census.gov/programs-surveys/aies/data/2023/AIES31BASIC01.zip
- UN Comtrade: 公開プレビュー、年2024・報告国842・輸出X・全輸送C00/0・相手国別。各リクエストURL、原ファイル名とSHA256は`detail-statistics.json`の`sources`。取得件数が上限500未満、相手国重複なし、相手国合計と世界総数が一致することを生成時に検査。再輸出を含む米国報告総輸出額（原単位USD）。国グループの重複計上を除く。
- BTS: https://www.bts.gov/sites/bts.dot.gov/files/2022-09/table_01_23_092922.xlsx 、表1-23。原提供は**Wards Intelligence**。政府独自調査ではなく、BTSが公表した民間原資料の統計であることを図中にも明記。
- BTS世界総数2021が2020と同値のため、その年の世界分母は未採用。国内生産台数は2012–2021、世界構成は照合できた2020、世界比率の推移は2011–2020。これは最新の世界自動車生産を示す図ではない。
- BEA郡別名目GDP: https://apps.bea.gov/regional/zip/CAGDP2.zip 、`CAGDP2__ALL_AREAS_2001_2024.csv`。原単位は1,000米ドル。
- 都市圏の郡構成: https://www2.census.gov/programs-surveys/metro-micro/geographies/reference-files/2023/delineation-files/list1_2023.xlsx 、OMB July 2023。公式都市圏名・構成郡FIPS・使用行・原資料SHA256を`regional-economy.json`に保持。郡の各セルが数値で、全構成郡がそろう場合のみ合算。

再生成は各`sources`のファイルを同名でキャッシュディレクトリへ取得し、Python＋openpyxl環境で次を実行する。APIの利用制限を守って順番に取得する。原本のハッシュを保存済みのものと照合し、改定があった場合は別のデータ更新としてレビューする。

```sh
python scripts/prepare-industry-detail.py --cache /path/to/downloads
```

サイト実行時の追加統計API呼び出しはない。詳細データは静的HTMLへ描画し、ブラウザー側には小さい地域経済データだけを含める。

## 地図の現在の比較対象

|分野|今回数値比較できる登録地域|非比較の例|
|---|---|---|
|金融|ダラス・フォートワース、サンアントニオ|ニューヨーク：構成郡に秘匿値|
|観光等|ラスベガス、サンアントニオ|州単位など異なる地理範囲の例は除く|
|医療・教育|ヒューストン、サンアントニオ|他の未集計地域|
|電力等|オースティン、サンアントニオ|他の未集計地域|

7都市圏の元データを保持するが、各分野の既存地域例に存在する対象だけ表示する。比較するために無関係な都市を追加していない。製造業の都市別出荷額は今回未収録のため固定記号。新しい造船・鉄道地域例は、VEDPのNewport News Shipbuilding資料とNY州知事室のHornell Alstom資料を出典にする。

## 検証と残件

- 数値・描画単体検証：出荷額のNAICS分離、欠測の断線、国別合計と分母、米国の表示保持、面積比例、都市圏重複除去と秘匿除外。
- 操作検証：実際のビルドHTMLとコントローラーを使用。第二段切替、履歴復元、農業・自然との往復、WebGL失敗時、サービス記号、比較凡例、3製造分野の図と閉じた数表。
- 実ブラウザーの寸法・視覚検証は公開反映後に実施する。ローカルビルドの検証と区別する。
- 継続する統計整備：同じ定義のサービス輸出先、製造業各分野の世界生産・付加価値、製造都市の出荷額。未取得分は短い注記とし、別の分母・推定値で埋めない。
