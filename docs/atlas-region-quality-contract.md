# 地域展開の品質基準 — 米国との操作・表示の一致

2026-10-05のカナダ修正依頼が競合する旧仕様に優先する。画面の骨格を似せるだけでは合格にしない。

## 基準と証拠

| 対象 | 必須条件 | 検証 |
|---|---|---|
| 配置 | 同じ画面寸法で同じ分野の地図幅・高さを米国に揃える。ニュース、選択、右解説へ同じ順で到達 | 1536×864、1280×720、1024×768で矩形を測定。横溢れなし |
| 初期範囲 | 読者の問いに関係する居住・農業地域を大きくする。国土全域の収録と初期カメラを混同しない | 北端・南端、海岸・対象地域、復帰ボタンを実画面で確認 |
| 気候・降水量 | 共通分類は米国の色・階級・単位・凡例を参照。別の配色を複製しない | 共通定義との自動比較、実ブラウザーの画面対比 |
| 流域 | 州境・統計区分で集水域を代用しない。上流・支流・出口と越境部分を説明 | 原典トポロジー、独立した河谷の地点、親子流域、描画と説明の一致 |
| 地形 | 名称の尺度に対応した実際の輪郭だけを選択強調。地形区分を地形名と偽らない | 全項目を選択し、輪郭と右の説明を確認。背景は中立 |
| 産業 | 米国と同じ5業態→分野→地図と解説・統計。独自の上部比較操作を増やさない | 全業態・全分野、州選択、URL再読込、欠損、合計・分母 |
| 表示 | 主題に関係しない地点注記・重複ボタンを除き、ラベル衝突・切れを解消 | 初期、選択、拡大、小さめのPC、出典末尾 |
| 根拠 | 年・単位・母集団・分類対応・利用条件・加工方法を残す | 原表抽出CSVとSHA256、欠損をゼロ化しない |

## 公開のゲート

`npm test`、`npm run build`、`npm run test:e2e`、`npm run test:browser:canada`、`npm run verify:release` を通す。PRとmainのCIに実Chromiumの検証を追加し、失敗時は公開ジョブへ進まない。画面証拠と測定値はActions artifact `canada-us-map-acceptance` に残す。

ブラウザー検証は生成済みの本番ファイルをHTTPリクエストへ返し、実Chromium・実MapLibre/WebGLで実行する。地図ライブラリをモックしない。ライブラリを意図的に遮断したSVG代替表示は別の検証として記録する。Happy DOMの試験結果を通常の実画面確認に読み替えない。

## 他地域へ適用するとき

同じ検証関数に対象地域のURLと項目を追加する。色・階級は既存の共通定義を参照し、データ源・対象年・地域の違いは明示する。同じ数の品目や州に無理に合わせない。今回のカナダの合格を、未検証のメキシコ・アジア・アフリカ等の合格として報告しない。

## 今回変更した旧仕様

カナダ産業の2023〜2025年・州内GDP割合・比較州選択・保存操作を主画面から外した。この旧UIを要求したE2Eは、5業態と分野選択、州別GDP、全国の付加価値・雇用構成、旧URLからの移行、人口ページへの安全な復帰に更新した。旧統計原本と旧自然環境比較URLの検証は残す。

河川流域は25統計地域から主要6水系＋サスカチュワン支流域へ変更した。旧25地域の原本整合性テストは保存し、新しい図がそれを表示に使わないことを検証する。

ローカルでのブラウザー確認は `npx playwright install chromium` の後に実行します。日本語フォント（Noto Sans CJK JP等）を用意します。CIもChromiumとNoto CJKをインストールし、画像を文字欠けの状態で比較しないようにします。
