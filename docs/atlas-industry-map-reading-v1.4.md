# 主要産業 v1.4：地図と説明・構成比・インサイトの配置

更新日：2026-09-14。実装基点：`1bb645f`。

## 読む順序

| 位置 | 内容 |
| --- | --- |
| 上段左 | 地図、記号の凡例、その直下に小さな「地域と産業のつながり」 |
| 上段右 | 選択した業態・分野の説明、その下に当該業態の全国構成比 |
| 上段の直下 | 選択した分野の付加価値・出荷額・生産台数・雇用の推移。続いて輸出先などの比較図 |

前版で下部に残った「製造業を読む」などの業態総論も右へ移す。製品選択時に構成比を消していた動作をやめ、説明と構成比を同時に読む。構成比には「製造業を100%」等の分母を明記し、自動車など単一分野の統計と混同させない。

右欄は説明の見出し、段落間、構成比のヘッダーと行間をまとめる。本文14px、構成比の項目名・数値12pxを保ち、全文・全区分を表示する。説明の見出しは本文と同じ段落にまとめる。地図の高さに近づけるが、今回は多少の超過を認め、固定高さ・内部スクロール・行数制限で隠さない。

インサイトは既存6件の本文・出典を再利用する。地図のすぐ下に2列の短い見出しを並べ、ネイティブの開閉欄で本文と地域名、関連分野へのリンクを読む。内容追加の調査より配置を優先する。展開はユーザー操作に従い、関連分野のリンクは現在の地図の位置・倍率を保つ。

## 実装と検証の条件

- Astroによる静的HTMLと既存のSVGを再利用。新しい図表・地図ライブラリーや通信は追加しない。
- 右欄の説明は全27状態を一度ずつ出力し、既存の業態・分野のURLと履歴復元で切り替える。構成比は5業態分を一度ずつ出力する。
- インサイト欄も一度だけ出力し、農業・自然環境・人口への切替では隠す。既存のインサイトIDと比較リンクを保つ。
- 幅960px以上かつ高さ600px以上では地図と右欄を2列にする。その他は地図→インサイト→説明と構成比→推移の1列。下部の最大3列グラフは前版を維持する。
- 数値表の開閉、地域選択、戻る・進む、他分野との往復、地図の代替表示を保つ。
- 業態総論が下部に重複しないこと、製品選択中も構成比が見えること、インサイトが地図列内にあることを実際のビルドを使って検証する。公開後に960px以上と320px幅の配置・はみ出しを確認する。

実装時検証：`npm run check` 成功（ユニット97件、E2E38件、ビルド、配信情報の整合性検証）。公開後の表示結果は実装PRへ記録する。

## 経済規模の円が限られる理由

描画は実装済みで、同じ産業・指標・年・地理範囲の比較対象が2都市圏以上ある時に面積比例となる。現在のデータは2024年の郡別名目GDPを2023年7月定義の7都市圏へ集計したもの。構成郡に秘匿・欠測があれば、その都市圏の値を採用しない。

比較できる登録地域がそろうのは金融、観光等、医療・教育、電力等の4分野。製造業の全国出荷額は収録済みだが地域別出荷額は未収録。地域例には都市圏以外の州・盆地もあり、そのまま同じ円の尺度に混ぜられない。情報通信などは同じ条件の比較対象が2都市圏に満たず、建設・不動産も地域例や秘匿が制約となる。

次のデータ整備では、製造業の代表地域と公的統計の地理範囲・製品範囲を対応づけ、同年・同単位の地域値を追加する。州の値を都市の値として描いたり、雇用で経済規模を代用したりしない。今回の配置変更で統計値や経済円の採用条件は変更しない。
