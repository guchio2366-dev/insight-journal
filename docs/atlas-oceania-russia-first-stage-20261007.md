# Oceania / Russia 共通指針への第一段

旧PC診断の対象は `ad4a8ad`。クラウドの引継ぎ時mainは `5125278`
（Canada PR #201取込済み）で、両地域の対象コード・表示assetは旧診断から不変だった。
この変更は地域専用コードと地域専用のテスト・レビューCIに限る。
別地域の実装と共有のValidate / Pages workflowは維持する。

## 初期状態と選択

- 両地域の4分野を、国・学習地域・テーマを未選択の全域と分野の概要から開始する。
  サーバーHTMLとブラウザ初期化後で同じ概要文を使う。
- Oceania産業は、既存の豪州347鉱山と港・加工・サービスの代表地点を同時に表示する。
  丸とひし形、各既存色の凡例、各資料の年・出典・収録範囲を保持する。
  生産量・埋蔵量・施設全数・GDP比には読み替えない。
- 地図や選択欄で場所を選んでも、表示中の分布・比較分布と表示範囲を保つ。
  選択枠だけを変更し、再読込でも保持する。
  「選択国」「選択地域」の範囲操作を明示的に選んだ場合に拡大する。
- 選択した場所に対応する既存テーマが表示中の分布と合わない場合は、
  別品目への自動切替や不適切な地域の理由説明を避け、分野概要と選択場所を示す。
- Oceaniaの国輪郭に重複する国名ホバーポップアップは付けず、選択用の日本語名を保持する。

## 地図と凡例

4分野の通常地図は地域内で同じ列配分・縦横比（1.55）を使う。
産業だけに残っていた620px固定高さ、コンパクトPCでの分野別寸法差、
非表示の重複凡例が確保していた高さを取り除く。
右側の可視凡例、詳しい説明、帰属表示、欠測説明は残す。

## 検証

- 既存のOceania / Russiaの単体テストで、原本assetのハッシュ、年・単位、
  欠測と有効0、日付変更線、係争区分、比較の表示窓を確認する。
- 地域E2Eで、直接URLの全域・概要、両系統の産業点、農畜産比較の単位と画像、
  場所の選択・再読込・明示的な拡大、Russiaのキーボード選択を確認する。
- `tests/browser/atlas-oceania-russia-first-stage.mjs` は実際のビルドをローカルHTTPで配信し、
  sandbox有効の既存Chromeで1536 / 1280 / 1024pxの初期状態・操作・寸法を確認する。
  当該head、配信情報、測定値、実スクリーンショットを記録する。
  USの4分野も参考画像として記録するが、地域間のデータ網羅性や投影の一致とは扱わない。
- 地域専用workflow `atlas-oceania-russia-pc-review.yml` がPR headをcheckoutして上記を実行する。
  新規の画面資料はそのworkflowのartifactに保存する。

クラウドのローカルChromiumはSUID sandbox helperの設定不備で起動できなかった。
サンドボックス無効化、権限や証明書の変更、既知403資料の再取得は行わない。
ローカルの画面目視を実施したものとして扱わず、CIの新規画面資料で確認する。

2026-10-07の新規レビューrun `37600153468`（head `868c745`）では、
sandbox有効の実ChromeによるPC3幅の操作・寸法確認と画像保存が成功した。
当該の新規artifact取得も配信先で `Forbidden` となったため、画像の目視は未実施。
既知の403資料への再試行や、別経路・権限変更による取得は行わない。
画面確認が完了するまで、マージ・公開は保留する。

## 次段に残す項目

農畜産の同じ地図への全品目重ね描画は未実装。既存の2020年原本は、
作物の収穫面積ha／5分セルと家畜密度頭／km²で量が異なる。
既存の数量色画像を単純に透過合成すると、色・有効0・欠測が混ざる。
現在の比較機能では同じ表示範囲に実画像2枚とそれぞれの凡例・単位を同時表示できるが、
これは全品目を1枚に重ねた表示とは区別する。
次段では原本値を保持した品目別表現・輪郭強調・選択時透過を実装し、凡例との対応を検証する。

林業、都市雨温図とその気候解説、水資源・年降水量・等雨量線・流域、
500m標高線と線間塗り、民族・宗教等の文化分布、農業の貿易・世界生産シェア・推移統計は未整備。
実装には対象年・単位・分母・欠測・位置・再利用条件の確認された実データが必要。
主要国の選定、少量・少額品目を除外する対象と閾値、ライセンス不明資料の採用は決めていない。
空のグラフ、架空値、資料の欠測を0や不存在に置き換えた図は追加していない。
