# 地図と一緒に読むための共通編集・UI指針

更新：2026-09-16  
対象：Insight Journal の農業・自然環境・主要産業・人口タブ  
基準例：農業タブ「とうもろこし」の改稿と本文内リンク・河川表示（PR #71・#72）

## 目的と適用範囲

読者が一読して、説明されている現象を地図上の場所・分布と結び付け、その理由と意味を理解できることを目指す。各ページで読者に何を持ち帰ってほしいかを先に決め、文章、強調、地図、ボタン、統計をその理解のために組み立てる。

以下は、とうもろこしの改修でユーザーが評価し、他タブにも共有するよう求めた共通方針である。文章の長さや段落数、ボタンの数を全タブで固定する指示ではない。現時点の適用例はとうもろこしであり、他の全品目・全タブへの適用が完了したわけではない。

## 1. 持ち帰る要点を一文で示す

本文冒頭には、そのページ全体の理解をまとめるキーセンテンスを置く。項目ごとにも必要に応じて短い見出しとキーセンテンスを設ける。

とうもろこしの例：
> 中西部の肥沃な土地と暖かく湿潤な夏が大規模生産を支え、収穫物は飼料・燃料・輸出へつながる。

「夏の気候」「立地条件」だけでは内容が分からない。副見出しにも「暖かく湿潤な夏・西ほど乾燥」のように、特徴を数語で書く。

## 2. 条件と現実の地理を、理由でつなぐ

地名や条件を列挙するだけで終わらせず、「何が必要か」「その場所に何があるか」「だから何が可能か」をつなぐ。

例：
> 中央低地には起伏の小さい農地が広がる。斜面や段差が少ないため、大型のトラクターや収穫機で広い畑を連続して作業でき、大規模な生産に適している。

農畜産物では、産地、気候・水・土壌などの生産条件、現実の地域との合致、その場所で生産される理由、用途を過不足なく扱う。市場、加工、輸送、技術などが分布を支える場合も、その関係を説明する。自然条件だけで立地の全てを説明しない。

順序や段落数は題材に合わせて決める。とうもろこしでは「産地と土地 → 夏の気候と水 → 用途と畜産 → 内陸から輸出港へ」とした。

## 3. 用語を定義しながら、知識を増やす

専門用語・固有名詞は、初出の近くで短く説明する。専門語を避けて曖昧な言葉だけにするのではなく、用語と意味を一緒に学べるようにする。

- コーンベルト：とうもろこしと大豆の栽培が集まる地帯。
- プレーリー土：草原由来の黒く肥沃な土壌の地域呼称。
- センターピボット：長い散水管が支点の周りを回る灌漑方式。
- エタノール：糖を発酵させてつくるアルコール。燃料用途ではガソリンに混ぜて使う。

高校地理などで学ぶ用語も、現象を理解する手掛かりとして積極的に取り入れる。ただし、用語の定義・分類は公的資料、学会、教育資料などで確認する。地域呼称と現行の分類名、植生名と土壌名を混同しない。地図で示していない土壌分布を、作物の輪郭と同じ範囲だと扱わない。

## 4. 強調によって、文章の構造を見せる

単語を無差別に太字にするのではなく、項目の結論、重要な関係、説明の切り替わりを強調する。

冒頭で「用途は飼料とエタノール」と構造化したなら、その後も別段落にして次のような太字の小見出しを置く。

- **飼料｜家畜のエネルギー源**
- **エタノール｜自動車の燃料**
- **その他｜食品・工業原料**

見出しと太字を拾うだけでも大筋が分かり、通常の本文を読めば理由と定義が補える状態にする。重複する「主な用途」などの説明は整理する。

## 5. 地名は地図と結び付ける

本文で重要な地名・河川・地域を述べる場合は、読者が地図上で場所を特定できるよう、名称表示または対応する強調・比較への導線を用意する。本文中でも位置・性質を短く補足する。

とうもろこしでは、農業地図にミシシッピ川の名前を表示し、選択中だけ他の河川より少し濃い青で流路を示した。自然環境への比較では中央低地や帯水層などを強調し、とうもろこしの分布も残す。

- 強調の強さは本文との対応が分かる程度とし、元の分布・地名・記号を隠さない。
- 選択に連動する強調は、他の品目・話題へ切り替えたら解除する。
- 既存の実データを優先する。概略の代表点や範囲を、正確な境界・個別施設・数量として見せない。
- 対応する形状がない場合は位置説明などで補い、強調できているとは記載しない。

## 6. 読んだ場所から直接、確かめられるようにする

「下のボタンで確認」と書いても、ボタンが画面外なら理解と操作が途切れる。案内文は、関連する段落の直後に置く押しやすいリンク・ボタンへ置き換える。

ボタン名は「詳しく」だけでなく、何を見られるかが分かる言葉にする。

- 地形と産地を重ねる
- 500mm線と産地の東西差を見る
- 地下水と円形の畑の写真を見る
- 作物と養豚の重なりを見る
- 用途ごとの割合を見る
- 川を産地から輸出港へたどる

別タブでは、元の品目・話題の分布と比較対象を一緒に確認でき、元の解説へ戻れることを重視する。同じページ内の統計や関係解説へは、不要な画面切り替えを挟まず直接案内する。実装済みの導線を活用し、同じボタンを本文と末尾にむやみに重複させない。

## 7. 基本的な傾向を明確にし、必要な留保だけ残す

一般的な傾向を説明する本文では、「ただし」「必ずしも」「すべてが〜ではない」を繰り返さない。読者がまず理解すべき関係を明確に述べる。

一方、意味を変えてしまう留保は削除しない。例えば、年降水量の目安と栽培の可否、地図の省略と実際の不在、地理的な近接と因果関係、異なる統計の対象年・単位の違いは区別が必要である。短い説明を適切な場所に置き、詳細な加工条件や出典は折りたたみ等にまとめる。注意書きの削減を、断定の強化や出典の省略と取り違えない。

## 8. 写真・統計も、理解したい関係に合わせる

写真は「その現象を何で理解してほしいか」で選ぶ。円形の畑と灌漑の関係には、装置の地上写真よりも上空から円形の区画が見える画像が適する。場所、撮影時点、出典、画像の意味を簡潔に添える。

統計には必要に応じて、何が大きいか・何を比較する図かを示すキーセンテンスを添える。本文の用途区分とグラフの区分・分母が対応しているかを確認する。

## タブごとの適用の考え方

以下は共通指針を適用する際の観点であり、個別ページの結論を先に決めるものではない。

| タブ | 説明の中心 | 地図・統計につなぐ対象 |
| --- | --- | --- |
| 農業 | どこで生産され、必要な条件がどうそろい、何に使われるか | 産地、地形、土壌・水・気候、飼料・加工、輸送、用途 |
| 自然環境 | どんな特徴があり、なぜその場所で生じ、何に影響するか | 山地、風・海流、降水、河川・帯水層、都市の雨温図 |
| 主要産業 | どこに集積し、資源・市場・人材・交通などがどう関わるか | 産業地域、拠点、原料・物流・市場、雇用・付加価値 |
| 人口 | どこにどのような分布があり、その背景に何があるか | 都市圏、移動、雇用、歴史、人口規模・構成 |

## 実装の参照先と引き継ぎ時の確認

参照PR：[とうもろこし改稿 #71](https://github.com/guchio2366-dev/insight-journal/pull/71)、[本文内導線・川名 #72](https://github.com/guchio2366-dev/insight-journal/pull/72)。

- `src/data/atlas/corn-reading.ts`：要点、項目、小見出し、用途別段落、本文内アクション。
- `src/components/atlas/AgricultureProductReading.astro`：本文とアクションの描画。
- `src/data/atlas/agriculture-insights.ts`：比較先・品目に対応する説明。
- `src/scripts/atlas-agriculture-insights.ts`：分布と比較対象の強調、川名、復帰導線。
- `tests/e2e/atlas-agriculture-insights-controller.test.mjs`：本文リンクと強調解除の確認例。

各タブへの適用時は最新の実装を確認し、既存の選択・戻る・描画の仕組みを使う。新しいライブラリや地理データを追加すること自体が目的ではない。

完成確認では、①要点が先に分かる、②用語がその場で理解できる、③理由がつながる、④本文の地名を地図で追える、⑤その段落から比較へ進める、⑥戻る・選択解除が機能する、⑦地図と文章を同時に読める、を確認する。画面確認の端末・表示方式は実際に確認した範囲を報告する。代替地図での確認を、iPad実機や通常の操作地図での確認と同一視しない。
