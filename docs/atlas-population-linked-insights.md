# 人口から読む４つの関連ストーリー

採用済みの４案だけを実装。入口はキーセンテンス、見られるもの、遷移先の３要素。表示中の人口テーマに応じて１〜２件を出す。移動先の本文は短い１段落、方法と出典は折りたたむ。

| 入口 | 移動先 | 地図で追う対象 |
| --- | --- | --- |
| 人種・民族／投票傾向：南部の黒人定住史と民主党支持 | 人口・2024年選挙結果 | アラバマ州ダラス郡、ミシシッピ州コアホマ郡。人種・民族分布との切替 |
| 人種・民族／デトロイトの人口解説：南部からの移住 | 主要産業・製造業・自動車 | デトロイト、ウェイン郡と既存の産業集積 |
| 人口分布：砂漠都市の水源 | 自然環境・水資源・河川 | ラスベガス、ミード湖、コロラド川、上流のロッキー山脈 |
| 宗教／投票傾向：末日聖徒の支持と判断 | 人口・2024年選挙結果・ユタ州 | ソルトレイク郡とユタ郡。宗教分布との切替 |

## 読み方

- 人種地図は既存の「特徴的な集積」の分類を使う。黒人だけを抽出した分布図には変えない。宗教地図も既存の最大宗教団体に基づく分類を維持する。
- 南部の説明は定住の歴史と政党支持・政治参加の変化を区別する。郡の色から個人の投票を推定しない。
- デトロイトの産業地図は現在に近い時点の集積であり、移住当時の工場・雇用の復元ではない。
- 南ネバダの水供給の約９割というSNWAの地域集計を使用。コロラド川の線幅に数量の意味は持たせない。上流の点は山地の代表位置。
- 末日聖徒の共和党寄りの割合はPewの成人調査。政策や候補者の評価を通じて判断が分かれうる理由を説明し、個人の動機を測定した結果とはしない。
- ２郡の宗教所属率（51.39％、82.86％）はUSRC 2020の教会報告による子どもを含む全人口比。投票率・有権者比ではない。選挙結果との母集団の違いを補足に明記。
- ソルトレイク郡の2024年民主党得票273,658、共和党221,555。ユタ郡は民主党84,937、共和党203,476。既存MITデータと照合。

根拠URLは `src/data/atlas/population-insights.ts` に集約し、各本文から開ける。

## 移動・復帰

同じAtlasインスタンスのURLと表示を切り替え、新しいWebGL地図は作らない。`popStory` が解説、`popStoryLayer` が比較側、`popStoryReturn` が人口画面の復帰状態。復帰パラメータは許可リストで検証し、同一オリジンの人口ページだけに戻す。

初回は各話題の地域へ移動。比較ボタンではカメラを保ち、郡の輪郭と地名を残す。元の解説へ戻る操作ではテーマ、都市・郡の選択、カメラ、同一セッションのスクロールを復元する。直接URL・再読込・ブラウザ履歴にも対応。関連しないテーマを選ぶとストーリーを解除する。

代替図では既存画像の地理的範囲と投影を使って同じ地域を拡大し、SVGの輪郭・地名を重ねる。通常の表示に戻ると変形を解除する。データが欠けた場合には輪郭・流路が表示できない旨を明示する。
