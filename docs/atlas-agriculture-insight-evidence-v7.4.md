# 農業「地図で確かめる」v7.4

## 目的と変更
地図に移動するだけで終わらず、「結論→強調した対象→産地との比較」で読めるようにする。

- とうもろこし・大豆の広域流域リンク、南部稲作のミシシッピ流域リンク、酪農のサンホアキン流域リンクを削除。産地と上流の水源を比較できるカリフォルニアの作物向け流域は維持。
- 穀物輸送では、既存のミシシッピ川・オハイオ川の線を白縁付きの青い太線にする。物流量や全区間の可航性は符号化しない。
- 全ての残存インサイトに短い結論と具体的な見方を追加。内陸降水は作物別の結論も用意。
- 内陸降水では500mm線、綿花とカリフォルニアの比較では500・1,000mm線を強調。前者は乾湿・水確保の目安、後者は比較の目盛りであり、一律の栽培限界ではない。
- センターピボットは米国中西部の実写を地下水灌漑の飛び先に追加。USGS提供の17KBサムネイルを遅延読み込みし、原寸画像は利用者の操作でのみ開く。写真は取水源を特定する証拠ではなく、散水方式の実例として扱う。

## 実装契約
既存MapLibre一台と既存SVGオーバーレイを使用。線幅は画面上で固定し、作物の茶色の破線と対象の実線を区別。SVGはクリックを奪わない。WebGL停止時も同じ緯度経度を既存Webメルカトルの代替図へ投影する。

対象の等雨量線は新たに推定せず、既存PRISM `precipitation.geojson.gz` の `kind=isohyet`、`value=500/1000` を使用。水資源本体と強調側で取得・解凍済みデータを共有し、再取得を避ける。写真は固定寸法を予約し、スマートフォンでも横にはみ出さない。

URLは既存の `agriInsight` に結び付け、手動で雨量帯を選んだらインサイトの指定強調を解除。産地比較と戻るリンクは維持する。削除済みリンクを含む古いURLも、有効な `agriReturn` があれば産地表示・復帰を維持。

## 出典・解釈
- 河川：既存Natural Earth。穀物輸送の説明：USDA AMS https://www.ams.usda.gov/sites/default/files/media/ReliableWaterwaySystem042025.pdf
- 降水線：既存PRISM 1991–2020年平年値、mm/年、米国本土。20インチ（約508mm）という教育上の目安はPenn State教材 https://courses.ems.psu.edu/geog3/node/1093 を参照し、本サイトの500mm線と完全に同一の境界とは扱わない。生育期・蒸発散・土壌・灌漑によって条件が変わる。
- 小麦と東西の乾湿：Columbia https://lamont.columbia.edu/news/100th-meridian-where-great-plains-begin-may-be-shifting
- カリフォルニア：既存California DWR出典。流域≠灌漑給水区域。
- 写真：USGS / Peter C. Van Metre、2013年、Public Domain。素材と取得情報は同ディレクトリの `sources.json` に記録。

## 検証
降水リンクの対象線・産地同時表示、解凍データ共有、手動選択での解除、河川強調、写真の出し分け、削除対象リンク不在をコントローラーテストで確認する。既存の高速往復と状態復元テストも維持。公開後にクラウドブラウザーで実画面を確認する。iPad実機の確認とは区別する。

公開画面の確認で全国の500mm線が西部山地を過度に目立たせたため、対象インサイトの比較範囲内に強調表示をクリップする。背景の全国降水図は維持し、線を新たに生成・連結せず、範囲外の強調だけを隠す。
