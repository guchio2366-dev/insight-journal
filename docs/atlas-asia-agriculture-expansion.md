# アジア農林業の次段階：実装計画とデータ確認

確認日：2026-09-25。対象は東アジア、東南アジア、南・中央アジアの30か国・地域。西アジア・ロシアは除外する。本書は気候・都市・米の初期実装に続く計画であり、ここに挙げた機能は未実装。追加のデータ生成や公開は行っていない。

## 1. 北米と同じ深さをどう捉えるか

現行コードの北米は米国本土48州が中心である。カナダ・メキシコの基図とは区別する。

| 現行北米で確認した内容 | アジアへ持ち込む価値 | そのまま移植しない点 |
| --- | --- | --- |
| 作物6群：とうもろこし、大豆、小麦、綿花、米、果樹・野菜 | 作物別分布、地域説明、統計への接続 | 地域ごとの重要作物を選ぶ。USDA CDLの衛星分類とMapSPAMの推計を同じ測定方法と呼ばない |
| 畜産5用途：肉牛、酪農、養豚、肉用鶏、採卵鶏。代表地域15点 | 飼料・水・集荷・加工の関係を読む | GLW4は動物種の分布であり、肉牛/乳牛や肉用鶏/採卵鶏の分布へ分割できない |
| 作物・畜産ごとの生産、世界との比較、輸出、国内供給等の統計 | 生産地の見た目だけで終わらず規模と用途を知る | 米の籾/精米、肉の枝肉重量、乳換算、暦年/年度の違いを保存。未整備の供給勘定を足し引きで作らない |
| 森林分布＋南部・北西部・北東部の3事例、NC州の木材用途統計 | 森林の成立、管理、木材用途を結ぶ | 森林分布から木材生産量・人工林・伐採範囲を推定しない |
| 全11農畜産品目の解説と、気候・水・地形・加工へ移動して元の選択へ戻る操作 | 選択した場所を保って条件と結果を比べる | 本文だけの一般論や未完成の移動先へのボタンを増やさない |

確認元：`north-america-agriculture.ts`、`livestock.ts`、`statistics.ts`、`livestock-statistics.ts`、`forestry.ts`、`agriculture-insights.ts`、`agriculture-relations.ts` と農林業の実装文書。古い実装文書の未確認事項を現在の不具合と断定せず、コードの範囲確認として使用した。

**完成の単位は「作物/畜種を選び、分布・地域の説明・定義付き統計・比較と復帰を一巡できること」。項目数の一致ではない。**

取得方法の判断：匿名で使える公開HTTP配布を選び、元ファイルの一部または必要作物だけをビルド時に処理する。新規アカウント、課金設定、契約は不要。公開サイトは引き続き静的アセットを読む。

利用条件：MapSPAMは今回使ったCGIAR配布物のCC BY-SA 4.0を個別に継承する。GLW4/FAOSTATは個別条件とFAO統計データ規約を確認し、出典・加工表示、第三者例外、非推奨表明等を守る。WorldCoverは指定の帰属表示を入れる。サービスや提供者の推薦を示唆しない。

### 数値処理上の判断

- MapSPAMは従来どおりha/格子から始める。全作物を「最大の作物」1分類に潰さず、重なりを切り替えて読めるようにする。
- 作物のindexは座標ラベルから解決する。例：`chic`は14、`teas`は34。隣り合うbeans/cocoa等と取り違えないよう、名称配列とスナップショットを照合する。
- GLW4の単位は頭・羽/km²。密度の画素値をそのまま合計して頭数にしない。色を国別頭数の順位と読ませない。高緯度の見かけの面積拡大にも注記する。
- GLW4カタログに旧来の寸法/型の記載が混在していたため、実TIFを優先する。今回確認した羊TIFのnodataは約 `-3.402823466e+38`。欠測を0にせず、変数ごとにメタデータから読む。
- WorldCoverの2020/2021は分類アルゴリズムが異なり、差分を森林減少量として使わない。最初は2021固定の樹木被覆を表示する。
- 地図の輪郭・格子と統計の地域区分は一致しない。描画用に切った格子の総和を正確な国別統計として出さない。

| 順位 | 東アジア | 東南アジア | 南・中央アジア |
| --- | --- | --- | --- |
| 1 | 米と小麦：南北で分布・生育期を比べる | 米：大陸の平野と島嶼、灌漑/天水 | 米と小麦：季節、水の確保、南北差 |
| 2 | とうもろこし・大豆：飼料や加工との接点 | とうもろこし・キャッサバ：食料/飼料/加工 | 綿花：乾燥地域の水と繊維への接点 |
| 3 | 綿花：中国内の産地と水 | 油ヤシ：作付けと加工、森林被覆との違い | 豆類・雑穀：ひよこ豆、レンズ豆、トウジンビエ等 |
| 4 | 茶：山地の気候と生産条件 | ゴム・コーヒー：高温域/高地の違い | 茶：インド、スリランカ、バングラデシュ、ネパール |
| 5 | 豚・鶏：飼料の地図と見比べる | 鶏・豚：飼料・都市・加工を読む | 牛・水牛：飼養と乳/肉の用途を区別 |

同一テーマ内で、選択できる作物/種を分ける。例：油ヤシとゴムを一つの面に混ぜない。地域によって扱わない作物があっても、理由を持って選定した構成とする。

### 国別の確認状況と穴

- 東アジア：今回の小麦は6か国・地域すべてに1ha以上の格子があり、モンゴルも2,137格子あった。米だけでは農業が空白に見える問題を先に補える。
- 東アジア：茶は中国・日本・台湾・韓国で分布を確認。北朝鮮・モンゴルには今回の閾値を超える茶の格子なし。図の空白だけで「生産なし」と確定しない。
- 日本のとうもろこしは今回のMapSPAM表示閾値で5格子。子実用と青刈り飼料等の品目対応を調べるまでは、日本の飼料生産の全体図として扱わない。
- 東南アジア：米・とうもろこし・キャッサバは大陸/島嶼の多くで有効。油ヤシ・ゴムはインドネシア/マレーシア/タイ等、コーヒーはアラビカ/ロブスタの2項目を別々に確認。東ティモールにはアラビカの表示可能な格子がある。
- シンガポールは確認した米＋追加14作物に1ha以上の表示格子なし。農業全体の不存在とはせず、国の公的統計/都市農業の事例で補完する。農業地図の閲覧自体を不可にしない。
- 南・中央アジア：小麦はスリランカ・モルディブ以外の11か国で表示格子を確認。綿花はインド・パキスタン・中央アジア諸国を含む複数国に分布がある。
- モルディブは今回の既存海岸線マスクと5分格子では中心が陸地内に入らない。格子拡大や最近傍で他国の値を埋めず、国別統計/解説に切り替える。
- ブルネイ、台湾、小島の多い国は細い海岸・島で格子の脱落があり得る。北朝鮮、アフガニスタン等を含む全30か国について、原統計の年・推計flagを調べる。現時点でGLW4・FAOSTATの国別欠測が確認済みとは扱わない。
- 国名の文字列だけで結合しない。FAOの国/地域コード、China集計とmainland、台湾等の領域が資料ごとに違うため、重複集計を防ぐ対応表を作る。

上記の格子数は**取得・描画の確認指標**であり、生産規模、正確な面積、国別ランキングの値ではない。追加14作物は公開アセットに保存せずメモリ内で確認したため、実装時には元ファイルを改めて固定・保存する。

**次に実装する最小単位は「小麦を追加して米と切り替える＋米/小麦の国別統計1例」**。東アジアで設定切替を確認後、同じデータ生成方式で残り2地域へ展開する。GLW4とWorldCoverの取得確認は別担当で並行できる。地図共通部・URLの所有者はroot、データ/解説は地域またはソース別に担当を固定する。

地域固有の分布データは共有部と別のファイルへ出す。北米の既存データやコントローラーを大きく変更することを前提にしない。統合は一度に1変更群で行い、他地域の進行中ブランチと現行mainの両方を確認する。

## 5. 最低限の受け入れ基準

### 各テーマの公開条件

- [ ] 年・版・取得元・利用条件・加工内容・単位・欠測をmanifestで固定した。
- [ ] 地図の表示値と選択時の照会値が同じ元データに基づく。値を選べるか、選択できない場合は理由を示す。
- [ ] 少なくとも1つの地域内の違いを、出典付きの解説と場所の対応で読める。
- [ ] 当該品目の統計か、同じテーマを説明する検証済み地域資料がある。統計待ちの分布試作を「北米相当の完成」と数えない。
- [ ] 比較先が実装済みで、行き来後に品目・国・カメラを失わない。公開リンクの再読込/戻るを確認。
- [ ] PC/スマートフォンで凡例と単位が読める。失敗時には空白ではなくデータ取得失敗を示し、再試行か静的表示を提供する。
- [ ] 既存の北米、米、気候・都市の操作に影響しないことを差分に応じて確認した。

### 地域全体の完成条件

- [ ] 各地域の7テーマを「データ確認/分布実装/統計・本文/比較/画面確認/公開」に分けて管理した。
- [ ] 30か国・地域について、各データの「表示可能/統計のみ/本ソース欠測/格子で表示不可/未検証」を区別した。
- [ ] 作物・畜産・森林それぞれに選択と比較の完成例があり、地域固有の主要テーマを外していない。
- [ ] 複数国の統計比較で同年・同定義がそろわなければ、個別年を示すか比較を出さない。国別値を埋めて全列をそろえない。

## 6. 今は約束しない範囲

畜舎/工場/農場の正確な位置、全国共通の肉牛・乳牛分離、全種の放牧経路、毎年の森林伐採、米の全県統計、国をまたぐ完全な需給勘定・貿易相手別図は、今回確認したデータでは確約できない。国別の公的資料があるテーマから独立して追加する。課金API、新規契約、登録必須の配布経路を採用しない。
