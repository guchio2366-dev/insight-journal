# アジア4分野の読解・比較改善（2026-10-01）

基準版は main `960f39bed4ffcad841b7f4cf3b9e957af7bfa4aa`。東アジア、東南アジア、南・中央アジアと個別focus、中東の既存4分野を対象とする。共通CSS、北米、他地域、ルートは変更しない。新たな統計資料やライブラリを追加しない。

## 読者に見える変更

- アジア3地域では要点と分野比較を右欄の上部へ置き、詳説・数値・全出典を開閉する。対象を切り替えると、都市・気候区分・作物・産業・居住域の要点も対応する。
- 比較先に元の分布の色区分の輪郭を残し、元の色面も同じ位置で確認できる。元と比較先の全凡例、年、単位、欠測の意味をまとめ、対象名付きの戻りから選択と地図位置を復元する。色面同士を混ぜて第三の尺度にしない。
- 人口の事例を無条件に隠していた処理を除き、既存の都市と産業・水系をつなぐ導線を利用できるようにする。
- 中央アジアには専用の4分野の要点と、フェルガナの綿花、北カザフスタンの小麦、ウズベキスタンの加工業、タシケントの事例を設ける。focusの事例選択にはそのfocusの対象国を使う。国別値を中央アジア全体の値へ読み替えない。
- 中東は専用SVGの元分布と比較先を左右に見比べ、両凡例と比較専用説明を読める。元の選択をURLに保存し、対象名付きの入口から戻る。

自然条件と地理的な分布をつなぎつつ、灌漑・品種・加工・交通・市場・制度も読む。分布の重なりから個人の属性や政治的意見を推定しない。

## 根拠と境界

既存の格子・概略面・行政区域・施設点・都市範囲を使う。輪郭は資料の表示区分であり、圃場や居住地の精密な境界を新たに推定したものではない。元の表示をOFFにした場合の意味も引き継ぐ。参照年と解像度は各主題の凡例・詳説で区別する。

中央アジアの読解の一次資料は [FAO（2013年、2012年調査）](https://www.fao.org/4/i3289e/i3289e.pdf)、[USDA FAS・KZ2025-0004（2025-04-18）](https://apps.fas.usda.gov/newgainapi/api/Report/DownloadReportByFileName?fileName=Grain+and+Feed+Annual_Astana%28Nur-Sultan%29_Kazakhstan+-+Republic+of_KZ2025-0004)、[世界銀行（2020年）](https://documents1.worldbank.org/curated/en/688501593501612264/pdf/South-Caucasus-and-Central-Asia-The-Belt-and-Road-Initiative-Uzbekistan-Country-Case-Study.pdf)。歴史的な説明と現況の推計統計を分け、将来の推計を実績として使わない。個別事例の正確な出典は `asia-place-readings.ts` に保持する。

## 検証と残件の扱い

要点切替、focus対象、比較URL・復帰、実グリッド・流域への接続を限定テストで確認する。通常地図の実画面は北米USと同じ1366×768で確認し、比較・復帰・詳説の末尾も別に確認する。最終の公開判定は当該commitのCI、親担当の実画像確認、公開commitとPages・配信assetの一致を必要とする。

地域全体が選択された画面と、対象国の首都を初期選択する国別画面は分ける。国別気候の首都初期選択、各比較の全状態、低いPC画面の全品目確認は、今回の実画面・検証結果に含めた範囲だけを受入済みとする。米国の全細分類統計を複製した完成とは扱わない。
