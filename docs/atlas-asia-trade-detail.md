# アジアの商品貿易（2026年9月27日）

## 対象と完成範囲

東アジア・東南アジア・南中央アジアの30か国・地域を対象に、2023年の商品輸出・輸入を加えた。国別の全商品総額と97の商品章（HS2桁）、全商品の輸出先、各国の輸出上位3章の輸出先を選べる。国の輪郭を金額で塗る図であり、国内の生産分布や輸送経路の図ではない。従来の国内製造業・発電施設・国別構成の表示は別主題として維持する。

原本で値が得られたのは25か国・区分。AFG/BGD/NPL/PRK/TKMの5対象は今回の2023年公開取得が空で、0や別年の値へ置き換えない。これは各国の統計すべてが非公開という判定ではない。TWNの位置には国連のOther Asia, nes（490）を明示して参照し、台湾だけの厳密値とは呼ばない。CHNは中国本土156、INDは1975年以降の699を用いる。旧356は1974年までのインド（シッキムを除く）であり採用しない。

農林業の22主題には25のHS4桁品目を対応付け、生産統計と分けて輸出入表を設けた。例として、油ヤシ果実とパーム油、茶生葉と加工茶、種を含む綿花と綿繊維、牛の頭数と牛の類の肉・乳製品を区別する。鶏の地図に対応する0207は他の家きんを含む生鮮・冷蔵・冷凍の肉等で、加熱調製品を含む全鶏肉輸出と呼ばない。森林は丸太と製材を分ける。

## 原資料と再現

- [UN Comtrade](https://comtradeplus.un.org/)の公開preview APIを利用した。2023年・商品C・年次A・全運送形態・全通関区分に固定し、Worldを分母とする。取得日は2026年9月27日。
- [APIの説明](https://uncomtrade.org/docs/un-comtrade-api/)に基づく無認証previewを使い、135クエリの各件数が500未満であることを検査した。抽出は合計17,236行で、[利用条件](https://uncomtrade.org/docs/policy-on-use-and-re-dissemination/)の無料可視化・分析と100,000行以下の抽出の範囲内である。CC BYの資料とは表示しない。
- `public/assets/atlas/asia-trade-v1/provenance.json`に全135原本のURL・件数・SHA-256、報告国対応、参照ファイルのハッシュを保存した。生成器は取得一覧そのもののSHA-256も固定している。
- 再生成は `python scripts/atlas-asia-trade.py --cache <固定原本のあるディレクトリ>`。通信・補間・通貨換算・相手国報告への置換を行わず、圧縮時刻を0に固定する。3地域の配信gzipは合計151,880バイトで、選んだ地域だけを必要時に取得する。
- 原分類はHS2022/H6またはHS2017/H5を保持する。日本語名は商品の範囲が分かる短い要約であり、厳密な関税分類の法律上の解釈に用いるための名称ではない。

## 数値の検査と読み方

金額は原本のprimaryValueを使う当年米ドル。通常は輸出FOB・輸入CIFで国別の例外がある。輸出には再輸出、輸入には再輸入が含まれ、国内付加価値・国内生産額ではない。重量の0には推定等の扱いが混在するため、重量や自給率は作らない。

全採用国で、輸出・輸入それぞれのHS2桁章の合計がTOTALと一致することを検査した。相手先もWorld・グループを順位から除き、残った個別相手先（未特定区分を含む）の合計がWorldに一致することを確認した。許容差は1米ドルまたは100万分の1の大きい方。4桁品目を2桁章へ重ねて加算しない。返却された0と、返却されていない値を区別する。小額は百万米ドルへの丸めで0と見えないよう「0.01未満」とする。

輸出相手先は全商品と上位3章だけで、ほかの章には未収録と明記する。輸入相手先は未収録。米国の区分842にはプエルトリコと米領バージン諸島が含まれる。相手先を実際の輸送経路・経由地・最終消費地とは呼ばない。

## 操作と検証

`topic=trade-exports|trade-imports`、`detail=t-<有効なHS2桁章>`をURLに保存する。国変更と輸出入切替で商品章を維持し、国内の産業・農林業・人口との比較から戻ると、主題・商品章・国・地点・カメラを復元する。農林業からの貿易比較も作物と地点へ戻る。

取得失敗後は利用者が再試行でき、20秒で通信を中止する。別分野へ切り替えた後の遅い応答は別の表示を上書きしない。WebGL再生成時には取得済みのデータを使う。人口密度の遅い取得失敗が同じ人口分野の社会統計へ切り替えた後にエラーを表示する点も修正し、回帰テストを加えた。

自動検証は固定値（日本・インドの全商品等）、全商品の加算関係、現行報告コード、未掲載と0、URL不正値、必要時取得、gzip/HTTP展開済みJSONの両方、失敗後の再試行、遅い応答、比較復帰、地図の再生成を対象とする。初期HTMLに貿易の全数値・相手先一覧を埋め込まない。

実施結果：`npm run check` は単体243件（242成功・既存1スキップ）、画面検証117件成功、ビルド・配信情報照合とも成功した。実ブラウザーでは日本HS85の輸出101,716.86／輸入115,091.13百万米ドル、マレーシアHS85の輸出119,041.96百万米ドル、インドHS27の輸出89,330.99百万米ドルと20.71%を確認した。390×844の表示で横幅はclient/scrollとも375px。バングラデシュの未掲載、油ヤシからHS15への比較と元の品目・座標への復帰、URL再読込も確認した。
