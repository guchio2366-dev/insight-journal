# 地域別の地図入口（2026-09-25 更新）

## 現在の構成

入口 `/atlas/` に大項目と地域リンクをまとめ、1回の選択で地域の地図を開く。

- 南北アメリカ：北米／中南米。
- アジア：東アジア／東南アジア／南・中央アジア。
- アジアの各ページに共通の3地域リンクを置く。地域は独立URLで、国の選択は `?place=ISO3` に保存し、再読込・戻る操作に対応する。
- 西アジア・イランは中東、ロシアは別枠とし、アジアの選択対象から除外する。周辺の陸地は位置関係を読むため灰色で描く。
- 北米の既存URLと米国のテーマ地図は維持。共通の地域・国ナビゲーションを追加し、カナダ・メキシコは独立した基礎地図へつなぐ。
- 中南米はメキシコを除く中米・カリブ・南米。メキシコは北米側だけに置く。
- 旧 `/atlas/asia/?region=…&place=…` は対応する地域ページへ置換移動。対象内の国選択を維持し、未指定・対象外は東アジアへ移動する。JavaScriptなしでも3地域へのリンクを表示する。
- 新しい6地域ページをサイトマップへ追加。旧アジアURLは互換用のためnoindex。

## 実装とデータ

- `regional-atlas.ts` が地域分類とリンクを管理し、`AtlasRegionNavigation.astro` が入口と各ページの分類を共通化する。
- `RegionalAtlasPage.astro` が1ページに1つの静的SVGを生成。対象国の境界から初期表示範囲を計算し、隣接陸地を灰色で描く。地図データ自体はブラウザへJavaScriptとして配信しない。
- 経度を地域の標準緯線の余弦で縮める等距円筒図法。東アジア35度、東南アジア10度、南・中央アジア27度、中南米南緯12度、カナダ58度、メキシコ24度。面積比較用ではない。
- 基本データ：Natural Earth Admin 0 Countries 1:110m、Git blob `1e6ab74c7042f97013be69ceec798be8e1aff27d`、177地物。
- 補完：同1:50m、Git blob `9d99f26dc470fcdbd08b062c813005acbdf73ccb`。SGP・MDV・ATG・BRB・DMA・GRD・KNA・LCA・VCTの9地物を追加。いずれも `nvkelso/natural-earth-vector/geojson` の固定原本で、public domain。
- 属性のみ簡略化し、座標は原本のまま。186地物を `regional-countries.json` に格納。小島・属領などの完全網羅は目的とせず、省略を画面に明記する。
- 地図の選択対象は国一覧と同じ。小国は一覧から拡大でき、タッチ・キーボードでも操作できる。タブは通常のリンクなのでJavaScriptなしでも移動できる。
- スマホは地図・選択欄・国一覧の順に縦置き。地図は画面幅に合わせ、国の選択で拡大し、全体ボタンで復帰する。
- 新ページは国・地域の基礎地図。テーマ別分布データはこの変更に含めない。

## 検証

# 初版：アジア地図の基礎地図

## 目的

北米アトラスと並行して、アジアの地域・国・地域の位置関係を読める独立した入口を作る。地域別のテーマ地図を追加するための共通の地理的土台であり、この段階では自然環境・農林業・産業・人口の分布値を表示しない。

## 変更範囲

- `src/pages/atlas/asia/index.astro`：東・東南・南・中央・西・北アジアの切り替え、国・地域の選択、URL状態。
- `src/data/atlas/asia-countries.json`：地図用の輪郭データ。
- 北米のページ、コンポーネント、データは変更しない。共通の地図一覧にはアジアのカードを追加し、サイトマップにも掲載する。
- 公開URLは `/insight-journal/atlas/asia/`。内容を基礎地図と明示し、通常の公開ページとして扱う。

## 地理データ

- 出典：Natural Earth、Admin 0 Countries、1:110m、public domain。
- 原本：`nvkelso/natural-earth-vector` の `geojson/ne_110m_admin_0_countries.geojson`。既存の南アジア地図と同じ原本を利用。
- 元データのGit blob：`1e6ab74c7042f97013be69ceec798be8e1aff27d`。固定した原本からの抽出結果が本ファイルと一致することを確認。
- 加工：原本の `CONTINENT=Asia` の地物とロシアの地物を抽出し、輪郭の座標は変更せず、属性を `code`・`name`・`region`・`subregion` に絞った。48地物。
- 表示範囲：東経20度～180度、南緯12度～北緯82度。SVGの表示枠で外側を隠す。ロシアは北アジアとして色分けする。
- この縮尺では小島や小規模な国・地域が原本に含まれない場合がある。境界・名称は出典の表現であり、政治的な地位や主権の判断ではない。

## 操作と確認

- 地域を選ぶと、対象外の輪郭を薄くし、右の一覧を絞り、対象範囲が地図の枠に収まるよう拡大する。
- 地図または一覧から選ぶと国・地域を強調し、その輪郭に表示範囲を合わせる。「アジア全体」で全体表示へ戻る。
- `region` と `place` のクエリで選択状態を共有し、戻る・進む操作でも復元する。
- 地図と同じ対象をボタン一覧から操作できる。狭い画面でも地図全体が収まり、地域・国の選択で拡大できる。
- 次の段階で実データと出典を決めてからテーマ別レイヤーを追加する。概略境界だけから農業・人口などの分布を推定しない。

## 公開前の画面確認（2026-09-25）

- ローカルの実ブラウザーで、通常のPC幅と390px幅の表示を確認。ページの横方向のはみ出しなし。
- 東アジア選択、日本選択と拡大、再読み込み後のURL復元、「戻る」で地域選択へ戻る操作を確認。
- 地図一覧に北米とアジアの両方の入口が存在することを確認。
- 投影は経度・緯度の等間隔表示で、位置関係の確認に使う。高緯度ほど形状や面積の歪みが大きくなるため、面積を比較する統計地図には使わない。
