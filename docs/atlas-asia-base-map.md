# アジア地図：基礎地図（第1段階）

## 目的

北米アトラスと並行して、アジアの地域・国・地域の位置関係を読める独立した入口を作る。地域別のテーマ地図を追加するための共通の地理的土台であり、この段階では自然環境・農林業・産業・人口の分布値を表示しない。

## 変更範囲

- `src/pages/atlas/asia/index.astro`：東・東南・南・中央・西・北アジアの切り替え、国・地域の選択、URL状態。
- `src/data/atlas/asia-countries.json`：地図用の輪郭データ。
- 北米のページ、コンポーネント、データは変更しない。共通の地図一覧へのリンク追加は、並行作業との統合時に行う。
- ページは `noindex` とし、公開コンテンツとしての完成前に検索結果へ入れない。

## 地理データ

- 出典：Natural Earth、Admin 0 Countries、1:110m、public domain。
- 原本：`nvkelso/natural-earth-vector` の `geojson/ne_110m_admin_0_countries.geojson`。既存の南アジア地図と同じ原本を利用。
- 加工：原本の `CONTINENT=Asia` の地物とロシアの地物を抽出し、輪郭の座標は変更せず、属性を `code`・`name`・`region`・`subregion` に絞った。48地物。
- 表示範囲：東経20度～180度、南緯12度～北緯82度。SVGの表示枠で外側を隠す。ロシアは北アジアとして色分けする。
- この縮尺では小島や小規模な国・地域が原本に含まれない場合がある。境界・名称は出典の表現であり、政治的な地位や主権の判断ではない。

## 操作と確認

- 地域を選ぶと、対象外の輪郭を薄くし、右の一覧を絞る。
- 地図または一覧から選ぶと国・地域を強調する。
- `region` と `place` のクエリで選択状態を共有し、戻る・進む操作でも復元する。
- 地図と同じ対象をボタン一覧から操作できる。狭い画面では地図を横スクロールできる。
- 次の段階で実データと出典を決めてからテーマ別レイヤーを追加する。概略境界だけから農業・人口などの分布を推定しない。
