## 実装と統計上の境界

- `atlas-oceania-agro-trade.ts` の地域専用renderer/controllerが既存三列へ追記する。①②のノード・数量・出典を置換しない。国・品目・肉／乳切替、非同期取得、再試行の完了に追随する。未選択の全分布と国未選択では追記しない。
- 林業はオセアニア専用の静的routeで共通 `RegionalForestryPage` をそのまま構成し、既存の豪州／NZ／PNG事例を選んだ時だけ三列の国別参照と林産物選択を有効にする。①②の同定義原表欠測は維持する。事例解除で元の統計ノード・見出し・状態へ戻す。地図のカメラ・画像・事例位置は変更しない。
- 共通routeと静的routeが同じオセアニアURLを持つため、Astroは優先する静的routeを一度だけ生成し、動的route側に競合警告を出す。これは本ブランチで共通ファイルを編集しないための地域限定構成。統合担当が共通部品を触る場合の小さい差し替えは `oceania-agro-shared-integration-proposal-20261016.patch`。地域componentを条件付きで呼び、専用routeを除く提案であり、**本ブランチには適用していない**。`git apply --check` は成功。
- 国別総輸出と、同国からオセアニア域内／域外への数量小計を区別する。地域内取引を域外へ含めない。豪州・NZのほか太平洋の国・領土、地図未収録のTokelauも地理的オセアニアとして区別。宗主国では分類しない。WITSの `Naoero` は相手リンクの `NRU` を確認しナウルとして域内に含める（`partner-aliases.json`）。`Bunkers` 等は帰属未判定。これらは1報告国の行小計で、地域全体の合計ではない。
- 全相手を数量順に表示し、上位5相手を主欄、全行を開閉欄へ置く。金額列は数量の代替に使用しない。全公表相手の行を保持し、差を架空の「その他」へ入れない。例：NZ丸太の全相手20,239,880m³とWorld20,239,900m³の差は−20m³。域内2,936m³、域外20,236,944m³。
- kg÷1,000＝tだけを行い、数量は小数3桁まで表示する。小さい正の比率は「0.01%未満」であり0%へ丸めない。欠測はnull、World数量がない場合は全輸出数量比を出さない。数量欠測相手がある時の「最多」は数量判明相手中と限定する。
- 通関上の仕向け先は最終消費地ではない。総輸出には再輸出を含み得る。国内用途、在庫、飼料・加工、実消費や国産品の仕向けは逆算しない。ABARES 2022/23–2024/25平均輸出率をFAO2024生産へ掛けない。
- 公式表のWebコネクタによるテキスト保存（各行末の空白のみ除去）であり、原HTMLを取得したとは記載しない。SHA-256は保存テキストを識別する。FAOSTAT資料のCC BY表示をWITSへ転用しない。地域専用の新規データは農林業操作時に遅延importし、他分野への初期取得を増やさない。
