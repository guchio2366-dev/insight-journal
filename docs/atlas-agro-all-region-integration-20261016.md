# 農林業・選択品目三列の全地域統合

基準mainは軽量化公開済み `3fbb4c957c21685bddbf8148a95a2a03ba210553`。統合ブランチは `codex/agro-statistics-all-regions-20261016`。13地域の担当成果を統合し、共通部品・全域受入検証・既存Pages公開は統合担当が行う。日本専用、品目未選択時の仕様、地図品目の追加、別公開先は対象外。

## 既存仕様と分担

選択時の列順は公開済み仕様の①生産量・世界シェア、②国内／域内利用・輸出、③輸出先数量・構成比。米国大豆の期首在庫・生産・輸入／国内加工等・輸出・期末在庫を参照する。現行の未選択renderer、地図、ニュース、URL操作を保持する。三列の見た目を新たに設計する作業ではない。

地域担当は地域固有の原表・抽出・対応定義・検証・パッチを所有する。統合担当は `AgroStatistics.astro`、`atlas-agro-statistics.ts`、共通renderer・数量検証・共通CSS・受入テストを所有する。既存の地域独立部品は意味を保って接続する。地域成果の元形式が異なる場合は統合側の薄いadapterで接続し、原値を表示の都合で再分類しない。

## 共通数量契約

型と純粋検証は `src/lib/atlas-agro-quantity-contract.ts`。原表を持たない合成数値を公開データへ登録しない。既存 `AgroData`、WASDE、東アジア数量原票を破棄する置換契約ではなく、地域成果を接続する時の比較可能性と充足度の共通検査である。

- 一意なrecord、地域、既存series ID、実際の国／地域scope。全対象membersと観測済みmembersを分ける。国別参考を地域全体のrecordにしない。
- 数量は値／null、原値文字列、原記号、reported／estimated／derived／missing、basis ID、出典IDを保持。0、欠測、丸め0.00、抑制記号を区別する。
- basisは暦年／販売年度／会計年度／複数年平均、期間、加工・換算を含む品目定義、単位、原表版を保持。生産とWorldの版もそろえる。籾と精米、丸大豆と油・粕、頭数と肉・乳、丸太と製材・パルプ、樹皮基準を自動接合しない。
- 供給と仕向けは輸入・在庫を含めて照合。期首／期末または符号付き在庫変動、原符号の調整を保持する。国内利用の内数にはparentを付け、飼料・加工の小計／内数を再加算しない。丸め許容は原表の掲載精度に根拠を持たせる。
- `apparent-stock-unadjusted` はP＋I−Xの在庫未調整見掛量を明示する独立指標。実消費、国産分の仕向け、食用率にはしない。P−Xを国内利用と呼ばない。輸出／生産が100%を超えても切り詰めず、輸入・再輸出と国産品の追跡不能を説明する。
- 相手表は同期間・同製品・同単位の輸出分母と相手数量を保持し、complete／partial／missingを区別する。地域は域内相手を除外し、国別は外国・別関税領域の対象定義を保持。World行を相手へ二重計上しない。上位国だけの表から架空の「その他」を作らない。公表されたその他は原区分として保持する。
- 同定義ではない年・金額・加工品の参考は別掲し、その存在だけで主三列の数量充足を完了にしない。
- 出典は公的資料のURL・名称・保存ファイル・SHA256・表／ページ／行のlocatorを保持。公式抽出ならoriginalと区別する。既存の取得失敗と新しい取得の日時・対象・操作・結果を混ぜない。独立した許可済み代替資料を使う場合も定義照合と取得証跡を保存する。

## 不足記録と完了基準

`src/data/atlas/agro-quantity-coverage.json` は既存の不足監査から13地域の状態を記録する。初期状態は全地域 `awaiting-regional-result`。担当パッチを受け取っただけでは数量の完了へ変えない。全13地域の最終成果は部分実装で、統合候補のコード検証と原表の全域充足判定を分ける。

1. 地域ごとに既存選択品目・国／地域scope・林業加工段階をinventory化し、全対象と成果recordを照合する。新しい品目は増やさない。対象外・別範囲参考も対応理由を記録する。
2. 各recordを原表・値・単位・期間・版・World分母・相手合計へ照合する。出典ファイルとhashを検査し、地域内取引の扱い・coverage・欠測を確認する。
3. 共通assessmentは `invalid`（整合性／出典違反）、`partial`（未充足）、`qualified`（見掛量等の限定付き）、`complete`（三列の数量条件を満たす）を別に返す。限定付き数量は限定を画面に出し、実消費や国産追跡まで完成したと報告しない。
4. 既存不足の各項目へ、解消record・原表とテスト、または具体的な残件と取得結果をひも付ける。不足を隠して完了にしない。13地域のinventoryが未確定、invalid、未解消の必須数量がある間は全域完了の公開判定を通さない。解消不能時は親へ具体的な不足と影響を報告し、独立可能な作業を続ける。
5. 未選択→品目→別品目／国→解除、林業加工段階、URL再読込と戻る、非同期の遅い応答、失敗時再試行、日本専用除外を検証する。産業修正と軽量化の回帰も保持する。
6. クラウドの安全なChromeで1896×996と1280×665 CSS px・両方DPR1.5を記録し、地図下三列、文字・図・単位・期間・出典、主要操作を確認する。自動検証、取得した実画像、実際に目視した範囲を区別する。ユーザーPCへ接続しない。
7. 全域の受入条件・回帰・実画面検証後にPR作成、CI、マージ、既存Pages公開を行う。公開SHA、Pages結果、公開後主要操作と画像範囲を確認する。実装済み・テスト済み・公開済みを分けて報告する。

## 準備段階の検証

共通契約の合成fixtureテスト11件が成功。原値の代用となる公開数値は追加していない。地域の統計補完、ブラウザー受入、PR、公開はまだ未完了。

追補：全域充足ゲート3件、既存WASDEのadapter2件を加えた16テストが成功。既存22行を原値・原表hash・丸め0.00・符号付き未勘定・籾／精米・綿繊維の境界を保持して共通契約へ対応した。22行とも同販売年度の相手表がないため `partial` で、完了へ格上げしない。全地域の新しい原表をこの22行の検査だけで照合済みとは扱わない。担当の原表hash・抽出・数量照合テストは別に実行する。`node scripts/verify-agro-quantity-coverage.mjs` は通常実行では未充足を非0終了とし、準備用 `--report-only` の成功を公開受入成功とは扱わない。

`scripts/audit-agro-selected-inventory.mjs` は本番buildの共通設定と米国・メキシコのnative選択から棚卸しを再現する。初回は南・中央の重複を整理して2,359件のscope×topic設定を検出したが、非品目文脈・地域独立パネル・実際の既存品目分類は担当資料との照合待ち。これは2,359件の数値充足や新規実装義務を確定した記録ではなく、既存の選択を取り落とさないためのinventoryである。

Playwright公式CDNのchromium/1194/chromium-linux.zipへの通常HTTPS取得は403（curl exit 22）で停止した。fallback配信先や取得再試行は行っていない。既設 `/usr/bin/chromium` は通常の制限実行内では起動できなかったが、自動承認レビューを通った通常実行環境では起動に成功した。Chromium 151.0.7922.173 の `chrome://sandbox` でNamespace・PID/Network namespace・Seccomp-BPFが有効、adequately sandboxedと確認した。OS設定・helperの所有権・sandbox無効化flagは変更していない。各地域の実行時にも同じ検査を行い、ユーザーPCへ接続しない。

`scripts/run-agro-regional-reviews.mjs` は13地域の担当検証を最大2並列で同じ固定buildに対して実行する。通常はbuildのSHAとHEADの一致・入力の無変更を要求する。未コミット候補は `AGRO_REVIEW_ALLOW_WORKTREE=1` を明示し、buildが正直に `local` と名乗る場合だけ実行する。入力hashと実行browserのsandbox状態を保存し、実際の画像目視と自動成功は別に記録する。このモードは公開受入を通すものではない。

## 統合された共通接続

- 南アジアの数量moduleを共通controllerへ接続し、遅延応答の世代検査を保持。
- 東アジアの既存数量・別販売年度の参考を、原表の期間と製品範囲を保持して共通表示へ接続。
- アフリカ専用の林業3段階componentを既存の地域林業pageへ接続。
- 欧州は選択時の独立panelを導入し、未選択overviewと森林の既存blockのhashを引き続き固定。
- 中央アジア4本とオセアニア林業は担当の専用routeを維持し、不要な共有page置換を加えない。
- ロシア最終差分には新しい年選択UIを含めず、2024主図と2020/21の別期間参考を分離。

全13担当の原本差分と統合候補の比較では、地域のapplication/dataファイルは最終SHAと一致した。担当ファイルへの統合側変更は、同じsandbox・入力同一性・共通出力先を記録する検証scriptの追補のみ。共有接続の変更は上記の別ファイルで行っている。

不足原表の重複を除いた依頼は `docs/atlas-agro-source-request-minimum-20261016.md` に集約する。原表の不足が残る間はマージ・Pages公開を行わない。
