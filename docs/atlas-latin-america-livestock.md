# 中南米の家畜分布 — GLW4 2020

## 採用データ

- [CGIAR Climate Action Data Hub の GLW4 2020](https://cgiar-climate-data-hub.github.io/catalog/glw4-2020/)
- [FAO の原データカタログ](https://data.fao.org/catalog/dataset/9d1e149b-d63f-4213-978b-317a8eb42d02)
- Food and Agriculture Organization of the United Nations (2024), *GLW 4: Gridded Livestock Density (Global - 2020 - 10 km)*.
- 基準年は **2020年**。別製品の GLW4 2015 とは混在させない。CGIARでの公開・変換日は2026年6月23日、取得日は2026年9月25日。
- ライセンス: **CC-BY-4.0**。原著作・提供元と、Insight Journalでの抽出・表示加工を出典記録に明示。
- 牛（cattle）、豚（pig）、鶏（chicken）の3層。牛の肉用・乳用、鶏の採卵・肉用などは分離できない。

値は地方単位の統計などを空間配分した**モデル推計の密度**。原単位は `head/km2`。日本語では牛・豚は「頭/km²」、鶏は「羽/km²」と表示する。農場の実測位置、セル内頭数、生産量、年間と畜頭数ではない。地図から正確な飼養頭数を断定しない。

## 地図・照会ファイル

出力先: `public/assets/atlas/latin-america-livestock-v1/`

| ファイル | 内容 |
|---|---|
| `manifest.json` | 3層の凡例・範囲・画像・照会格子・出典・出力SHA-256 |
| `cattle.png` / `pig.png` / `chicken.png` | Web Mercatorで作成した透過画像。1200px幅 |
| `cattle-grid.json` / `pig-grid.json` / `chicken-grid.json` | 元の5分格子の数値。`positiveCells` と `validRuns` |
| `provenance.json` | 入力URL・SHA-256、境界ファイルSHA-256、加工条件と検証値 |

表示範囲は西経93～33度、南緯56～北緯28度。現行サイトの中南米国境データで格子中心を判定し、メキシコを除外する。格子は南北1008×東西720、左上原点、行を先に進める配列。照会時は `row=floor((28-lat)/(1/12))`、`col=floor((lon+93)/(1/12))`、`index=row*720+col`。

`validRuns` に含まれないセルは欠測または範囲外。含まれ、`positiveCells` にないセルは値0。正値は小数4桁へ丸めるため、極小値は0.0000に丸められる。0と欠測を同じ説明にしない。統計的な推計値0は、現地に動物が一切いないという調査結果ではない。

密度の色は3種共通で、下限 **1 / 10 / 50 / 200 / 1000**。1未満は透明だが照会値を保持する。画像は経緯度格子をWeb Mercatorへ最近傍で再配置し、補間で架空の密度を作らない。南北のセル面積が変わるため、着色面積を頭数と解釈しない。

国別の `countries[].value` は密度×球面セル面積の合計による**表示範囲内の概算頭数**。密度を単純に合計していない。球半径6371.0088km、緯線間の球面面積で重み付けする。`meanDensity` は有効セル面積による加重平均。`validCells: 0` の国は `value: null`。国境はNatural Earthに基づくため、海岸・小島の省略があり、公式国別飼養頭数と一致する集計ではない。

## 再生成

Pythonに numpy、Pillow、numcodecs 0.16.5、shapely 2.1.2 を用意する。

```text
python scripts/atlas-latin-america-livestock.py --dependencies <追加依存ライブラリのディレクトリ>
```

任意の `--cache <ディレクトリ>` を指定できる。既定の原データキャッシュはリポジトリの親フォルダの `latin-livestock-cache`。キャッシュは公開配信物ではない。

Zarr v3の連結メタデータを読み、必要な1080×1080 Bloscチャンクを各種4個ずつ取得する。原データ全域やCOGのダウンロードは行わない。スクリプト内にメタデータと12チャンクのSHA-256を固定し、内容の変更を検出したら停止する。上流更新を採用する場合は単にハッシュを更新せず、年・単位・収録範囲と再生成結果を再確認する。

## 検証

- メタデータの基準年、EPSG:4326、解像度、浮動小数型、単位、軸順、チャンク寸法を照合。
- 各チャンクの展開バイト数と全有効値の非負を確認。欠測のNaNを0へ置換しない。
- 国境マスクと元格子から照会値を生成。画像には同じ元格子と色閾値を使用。
- 有効セル数: 牛227,578、豚226,839、鶏226,664。正値セル数: 牛214,740、豚214,621、鶏190,672。
- ブラジリア付近のサンプル密度: 牛6.0989、豚20.7671、鶏1058.9940（各種/km²、2020年）。場所は格子を検証するための参照点で、観測所や畜舎ではない。
- 画像と照会格子のSHA-256・サイズをmanifestに保存。全取得物のSHA-256とサンプル点5か所をprovenanceに記録。
- 固定ハッシュを有効にしてキャッシュから再生成し、画像・照会格子のハッシュ一致を確認。各種6画素についてWeb Mercatorの逆変換位置・格子照会値・凡例色が一致することを検証。牛の画像も目視確認済み。

各PNGは約59～104KB、各照会JSONは約3.2～3.5MB。UIは選択した種だけを読み込み、全3種の照会格子を初期表示で一括取得しない。
