# ロシア主要産業・三分野版（2026-10-14）

最新main `63e998cc`（#351）からのロシア専用ブランチ。カナダ三分野版の「産業名 → 集積と理由 → 地図下の統計」という順序を採用。共有UI、他地域、農林業・自然・人口の分布資料、公開先は変更しない。

## 採用対応

研究で挙げた主案12テーマ（肥料3系列）、追加の天然ダイヤ・ヘリウム・小麦接続をすべて掲載。既存のトラック製造と本社管理も保持し、19産業・48案内点とした。精製・精錬は資源と製造に、濃縮設備／役務は製造とサービスに重複表示するが、統計を加算しない。

## 地図・状態の設計

- 3分類の初期表示は概要。産業ボタンを主軸に、右側で具体的な分布・立地理由・工程を表示し、統計は地図の下に置く。
- 元座標は既存GHSL都市重心とNatural Earth v5.1.2の都市座標。地点ごとに出典名・元の都市名・工程・地域案内か否かを表示。新規NE座標の小さなスナップショットを保存。
- 州都チタ・マガダン・クラスノヤルスク等は地域の案内点で、遠隔鉱山の敷地ではない。近接点は最初の出典座標にまとめ、全地点は一覧と近接点ボタンから選べる。
- ラベルは分類と画面幅だけで配置。産業・地点・単独表示の選択は強調だけを変更し、配置をやり直さない。短い実線は位置案内であり、輸送や取引ではない。
- 小画面の地図は760pxの可読幅を地図内で横スクロール。ページ全体は横にはみ出さず、右欄は下へ回る。ニュース欄は小画面では本体の後ろへ回す（このルートのみ）。
- `sector / industry / site / only` の直接URL、戻る・進む、キーボードのタブ移動、Enter／Space、旧 `industryLocation` を扱う。無関係なクエリとハッシュは保存する。
- 境界・係争地は既存の固定版を再使用。USDAのロシア集計領域や港湾協会の範囲は背景図と別に明記。

## 欠測と判断の限界

ゼレノゴルスク濃縮工場は所在を確認したが採用座標資料に未収録。3工場を地図に表示し、4工場の能力を本文に掲載する。全てを地図に載せたとは表現しない。ウスチルガ・プリモルスク等も全国港湾表の量と地図の全地点網羅を区別する。

制裁後の貿易は、日本・米国・中国が報告した2024年輸入（HS＝国際的な品目分類）とEIAの船舶・市場資料等に基づく推計を区別。相手国側の輸入額はロシアの直接報告による輸出額や生産者売上ではない。2025年品目別の相手国側統計は未取得。肥料団体は2022年以降の輸出を専門家推計としているため直接報告扱いしない。

広い鉱業・化学・金属のGDPを個別製品へ転用しない。企業連結値、設備能力、実生産、輸出、港湾での取扱いも別指標。産業の正確な地域別数量がない所で、点の数や面積から生産比率を作らない。

USGS個別PDFとGeoNamesダウンロードは取得制限を回避せず、公開のUSGS国別HTMLと既存GHSL／公開NE資料を使用した。

## 検証

ロシア専用の単体テストで採用品目、元座標一致、同名別都市（ナホトカ）の排除、全分類の760／960／1280pxでのラベル・点の非重複、URL復元を確認する。ビルド後のDOM操作テストで全産業・全地点、出典、統計、キーボード・履歴を確認する。

`verify-russia-industry-review.mjs` は既存のPRブラウザCIから実行され、1920／1440／1024／390pxで全産業・全地点、ラベルの実寸重複と文字切れ、選択前後の位置、直接URL・履歴・単独表示を測定して画像とJSONを保存する。共通のOceania/Russia UX検証はロシア産業分岐だけ新画面の契約へ更新。

ローカルChromiumはSUID helperがroot所有でないため起動不可。サンドボックスを無効化したり権限を変更したりせず、実ブラウザ画像は既存PR CIで取得する。最終的な実行結果はPRとレビュー報告を参照。
