# オセアニア基礎地図

## 読者ができること

`/atlas/oceania/` で、オーストラリア大陸から太平洋の島々までの位置関係を読む。25の国・地域を、地図または44px以上の一覧ボタンから選択して拡大する。オーストラリア・ニュージーランド、メラネシア、ミクロネシア、ポリネシアの4区分に切り替えられる。

これは国・地域の位置を読む基礎地図。自然環境・農林業・産業・人口の詳細レイヤーは含まない。地図一覧は別の世界地図入口の変更で統合し、本変更は専用ページとサイトマップを担当する。

## 描画と操作の設計

- ページ内のSVG地図は1枚。輪郭はAstroのビルド時に描画し、外部タイルや新たな実行時依存を追加しない。JavaScriptなしでも地図・名称・出典を読むことができる。
- WGS84の経緯度を使用。太平洋側へ経度を連続化し、東経110度〜250度、南緯58度〜北緯25度で切り出す。南緯20度を標準緯線とする等距円筒図法。面積比較用ではない。
- フィジー、ニュージーランドのチャタム諸島、キリバスを180度経線で切り離さない。破線の180度経線は日付変更線を表さない。
- 陸地は地域ごとの色、周辺は灰色、選択は茶色と輪郭で区別する。色だけに依存せず、地域名・国名・選択状態を表示する。細い境界線は拡大時も太さを保つ。
- 小島の中空の丸は位置を補う記号で、面積の符号ではない。選択時は輪郭を拡大し、記号を消す。一覧からすべての対象を選択できる。
- `region` と `place` をURLに保持。再読込・戻る・進むで復元。未知の国・地域は全体表示へ戻し、矛盾する地域指定より有効な国の所属を優先する。無関係なクエリ・ハッシュは維持する。
- PCは地図と一覧を並べ、850px以下では地図・選択内容・一覧の順にする。地図へ戻るボタンを設け、スマートフォンのページスクロールを妨げない。地図には独自のパン・ホイールズーム・位置情報許可を追加しない。
