# 中南米の実地域に重なる民族・宗教分布

main起点 `755ec125daf9272e21328ff4c1ecab32756ce917`、Draft PR318。最新の明示承認に基づき確信案・必要案を実装・検証し、他地域との公開順を親threadで調整する。国別割合を横帯に置いた旧実装は撤回し、現在の地図は実際の行政区集計と、明記した地理的概略を使用する。

## 地図の読み方

民族132地域（数値122・概略10）、宗教116地域（数値102・概略14）を各タブの一枚に同時表示。国境34地域・投影・カメラは既存の中南米共通構成を使用。メキシコ・カナダ・米国を追加しない。

- メスチソ、先住民関連、白人・欧州系関連、pardo、アフリカ系、インド系・アジア系、Mixed、Ladinoを分離する。pardo／LadinoをMestizoに置換しない。
- 宗教はカトリックの広がりと、福音派・プロテスタント関連、所属なし、ヒンドゥー教、イスラム教、ニカラグアMoravaの複数分布を重ねる。宗教を民族から推定しない。
- 色の範囲は地図に採用した行政区・調査地域の集計単位。地理的概略は点線枠で示し、割合はnullとする。概略の県形は地理記述に寄せた独自の近似で、各県の割合・多数派・個人の居住位置を意味しない。
- 民族は10%以上、宗教は5%以上の確認済み値を表示。最高割合の民族分類、または宗教のカトリック（20%以上）を面にし、同地域の他の主要分類を色付き斜線・点で残す。最多分類だけの地図へ切り替えない。
- 面の淡色／濃色は50%未満／以上。重なる斜線・点の薄／中／濃は20%未満／20–34%／35%以上。概略の色には割合の程度を付けない。線や点の位置は集計域内の構成の併存記号であり、領土や居住の細部ではない。
- 灰色は表示値なし（未収録または表示閾値未満）。0人、不在、所属なしと解釈しない。未回答・不明をNoneへ足さず、残差分類を作らず、複数回答を100%に正規化しない。

選択・強調は右説明欄と枠線を更新する。他の分類の色・不透明度・行政区形・カメラは維持する。分類と地域はキーボード、直接URL、再読込、戻るで選択を復元する。原分類・原人数・年齢・資料年は右欄と地図下に保存し、旧全国表／統計行URLも参考資料として残す。都市人数2018、密度2020、農畜産・林業の共通外枠は変更しない。

## 概略と残る限界

Berglee2012のMiddle America／Mixed Mestizo Regionを参照し、中米mainland内陸・太平洋側、コロンビア／ベネズエラ内陸高地、Paraguayのメスチソの概略を独自に描く。Boliviaのアンデス高地、Argentina Southern Coneの欧州系移住に関する地域記述も概略とする。古い全国割合は採用しない。教科書の地図をトレース・転載しない。

数値地域資料が未採用の中米・南米では、植民地化以降のカトリックの地理的な広がりを点線の概略で示す。現在の県別信仰割合や各県の多数派は未知。Argentina2019原典のPatagonia／NEAの比較的多いEvangélica、PatagoniaのSin religiónは一般的な地域の州形に寄せた概略として重ねる。6調査地域の厳密な自治体範囲が未確定のため、公表率を州別値へ移転しない。AMBAのSin religiónは境界未確定で描画しない。

グアテマラ・エルサルバドル・ホンジュラスの従来の歴史的カトリック概略は、Pew2013–14成人調査が述べるCatholic／Protestant／Unaffiliatedの併存を示す国単位の概略へ更新。ウルグアイは所属なしが比較的多いという国の背景にCatholic／Protestantも重ねる。4国とも割合はnull。国を背景範囲として示し、県別割合・多数派・精密な居住範囲は主張しない。全国参考率は別表に保ち、県や濃淡・面積に再配分しない。Protestantは歴史的教会・ペンテコステ派等を含み福音派だけではない。Pew方法論の対象年齢・調査期間・除外を台帳へ記録。ホンジュラスは成人98%を代表する調査で、除外されたBay Islands県を概略面から外す。5県の一部小都市等の除外境界は未確定で、全国の全域を完全に観測した図とはしない。原典は統計事実の独自整理として使い、原図・文章は転載しない。

エクアドルのメスチソ県別面は未取得。採用済み暫定2022原典PDFp13／16はIndígena／AfroANMのみで、メスチソを残差から生成しない。既存Berglee文献の都市居住という一般記述にも都市範囲ポリゴンや県別率がない。追加原典の通常取得結果も `major-pattern-followup-20261011.json` に残し、初期説明とメスチソ選択欄で未取得と明記する。先住民・Afro24県の値と境界は変更しない。

未採用・未検証は、ペルーUcayali内4郡の境界対応、Argentina6調査地域の厳密な範囲／AMBA、Suriname地区宗教、他の小島等の下位表。資料のない部分を集団の不在としない。歴史的概略と異なる年齢・年・質問の集計を2026年の統一比較としない。
