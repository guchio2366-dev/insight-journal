# 中南米・民族／宗教の分布初版

起点は公開済み `755ec125daf9272e21328ff4c1ecab32756ce917`。今回の差分はDraft PRで確認し、マージ・公開しない。

## 何を伝えるか

民族・文化タブは、中米のマヤ／ガリフナ、ペルーのケチュア語／アイマラ語地域、チリ中南部のマプチェの歴史的地域、太平洋岸・Palenque／Bahiaのアフロ系文化という7テーマを同時に位置づける。民族自己認識、言語、歴史的地域、文化の事例は互換な分類ではなく、各説明で属性を明示する。既存34国の基図を保ち、メキシコは今回追加しない。

宗教タブは、文献の地域記述をもとに6つの特色を同時に示す。中米のカトリックと福音派などの併存、南ペルーのキリスト教と山・大地の信仰が重なる巡礼文化、キューバ西部のサンテリア、ハイチのヴードゥー、サルバドール／レコンカヴォのカンドンブレ、ウルグアイの世俗化の歴史。アフリカ由来の3宗教は別宗教として区別する。国や国内の居住域を宗教別に塗らない。Pewの18国・地域の全国回答割合は地図下の補助表に置き、地図上の国別比較棒にはしない。

## 表示と操作

初期右欄は概説→解説。分布選択時は全分布を残して強調し、説明だけ切り替える。右欄の「この分布だけを表示」を選んだ場合に限り他分布を隠す。全体に戻す、直接URL、再読込、戻るを支える。国比較の操作は追加しない。選択はSVGカメラを変えず、既存の明示的な拡大・縮小・全体表示を使う。

詳細表は地図下。公開済み都市人数、チリ・パナマ・グアテマラ・コロンビアの国勢調査値と原典・利用条件は維持する。グアテマラ／コロンビアの旧統計行URLも読み取れる。

## 空間的な方法

国境は既存Natural Earth基図。投影は既存Web Mercator、`latinMapLayout`を共用する。面積の比較には使わない。

民族の淡色点線帯は、原典に出る地名・地域の代表位置を結んだ独自の模式表示。幅は可読性のための画面上の幅で、資料の境界・居住密度・人口・面積を示さない。短線を離して配置し、連続した排他的領域にしない。地名代表位置は丸めた案内位置で、施設の正確位置ではない。全国数値から形状を生成しない。灰色の基図に特定集団の意味を与えない。

宗教の点線帯も、文献が記す文化の地域への模式案内である。中米は資料の3国の例、南ペルーはクスコ諸谷とティティカカ湖流域、キューバ西部はハバナ／マタンサス、ハイチは中央高原北部の巡礼地、バイーアはサルバドール／イタパリカ／カショエイラの例に限定する。施設の正確な位置・巡礼経路・住民の連続居住境界ではない。帯の幅や色の濃さから信者の割合・密度・強弱を読まない。ウルグアイの点は全国の歴史的背景への案内で、無神論者の居住地ではない。未掲載を0や無宗教に置換しない。全国割合の原表は地図下にその他も含めて置き、合計を100%へ正規化しない。

## 不足

民族の全域の精密境界、民族数・人口密度、現在の所属割合を網羅した図ではない。先住民以外の多様な自己認識を背景色で一括分類していない。宗教の地域記述は刊行・観察年代が異なり、2026年の構成比や全宗教の網羅図ではない。Pew2013–14年の全国調査とチリ2024統計は地図下で分けて確かめられる。未記載の人々・集団・文化が存在しないという意味ではない。

PC主確認は1920×1080 CSS、100%、DPR1、scroll(0,0)。実Chrome、SHA、地図・news・reader寸法、文字の重なり、選択・単独表示・履歴・カメラ維持を記録する。1440pxと390pxは補助で、PC主確認と区別する。
