# アジアの農業と月降水量を読む事例

確認日：2026-10-04。対象は東アジア、東南アジア、南・中央アジアと、その中の中央アジアfocus。既存の五つの作物事例を強化し、新潟の米の事例を一つ追加した。

## 比較の目的と時間の範囲

作物の分布から、同じ地点の月降水量へ移り、年間合計では隠れる季節の配分を確かめる。入口の月は出典が扱う生育期や雨季・乾季から選び、単に全事例を既定の7月へ送らない。比較後は元の作物・国・着目地点・カメラ・事例へ戻る。

- 作物の分布：IFPRI MapSPAM 2020 v2r2の推計収穫面積。米は灌漑・天水の合計で、同じ田を複数回収穫すればその回数も数える。小麦は冬小麦・春小麦の内訳を表示しない。
- 月降水量：GPCC 1991～2020年の月別平年値。雨と雪の水当量であり、個々の試験年、2026年の天候、雨だけの観測ではない。
- 既存の年降水量：CHELSA 1981～2010年。GPCCと期間・処理が違うため、月平年値の和との違いを異常と決めない。
- 既存の流域流量：BasinATLASが扱う1971～2000年のモデルによる長期平均。地点の降水量や現在の配水・取水量とは異なる。

月降水量だけから、作物の水不足、灌漑の必要量・実施状況、地下水位、収量、塩分濃度を求めない。出典が説明する過去の仕組みと、地図で直接比べられる値を分ける。

## 月を選ぶ一次資料

|事例|入口の月|出典が扱う範囲|比較で確かめること|
|---|---|---|---|
|華北平原の冬小麦|4月 `m-04`|FAOの二地点・六作期（1991/92、1992/93、1994/95、1997/98、1998/99、1999/2000）。10～5月の生育期。|生育期の春と夏の降水の配分。試験の灌漑量を平年値から再計算しない。|
|新潟平野の米|7月 `m-07`|新潟県の2023年7月11日の水稲資料。県内調査ほ場の5月田植えと7月の生育・水管理。|田植え後の夏と冬の降水の配分。2023年の天候や調査ほ場の位置を平年図へ転用しない。|
|メコンデルタの米|3月 `m-03`|FAO・世銀による2016年の事業評価とMRCの下流域の季節区分（12～5月乾季、6～11月雨季）。|乾季と雨季の降水。淡水流入・潮汐・塩水侵入は雨量と別の情報として読む。|
|インド・パンジャーブの小麦・米|6月 `m-06`|FAOのBox 6。2008年の6月10日以降への水稲移植対策と2009年の冬小麦の土壌水分に応じた灌漑時期の説明。|水稲の移植時期と冬小麦の季節での雨の配分。過去の措置を現行法と説明しない。|
|フェルガナ盆地の綿花|7月 `m-07`|FAO 2013年報告のウズベキスタン章。主な降雨期10～4月と、20世紀の灌漑拡大・生産計画の歴史。|夏と冬・春の降水。地点の雨と上流を含む集水域を異なる範囲で比べ、気候だけで分布を説明しない。|
|カザフスタン北部の小麦|7月 `m-07`|USDA FASの2025年4月18日報告。北部の春作物は通常5月中旬～6月初めに播種し、短い生育期に合う品種を選ぶ。|播種後の夏と冬の降水。報告中の2025年の予測を実績や現在の条件として扱わない。|

## 地点と復帰の検証

`tests/unit/atlas-asia-place-readings.test.mjs`は六事例すべてで、作物の配信格子に正の収穫面積があり、同じ地点を含む実流域の対象国が事例の国を含み、月降水量の原格子に全12か月の有効値があることを検証する。パンジャーブから米へ移る比較先にも正の米格子がある。流域と国の重なりは、公式の国別流域区分や正確な国別面積として解釈しない。

新潟は市中心点 `[139.03,37.92]` に正の米格子がない。検討した海側の `[138.95,37.8]` には米があるが、対応するGPCC格子中心 `[138.875,37.875]` は陸域マスク外で全12か月欠損だった。このため、米と月降水量を同時に確認できる内陸の説明用地点 `[139.05,37.7]` を明示して採用した。米の2020年格子は2321.4ha、GPCC原格子中心は `[139.125,37.625]`、7月平年値は218.41mmで全12か月が原典と一致する。地点と降水量格子中心は対象国を含む実流域 `b-4060043180`（沿岸の小流域群）に入り、この広い区分を信濃川単独の流域とは呼ばない。地点は特定の田や調査ほ場の台帳ではない。海側の欠損格子は欠損のまま保持し、画面操作時に内陸へ自動代替しない。メコンの既存地点 `[105.8,10]` は米格子10505.1ha、実際のメコン集水域 `b-4060017020` に含まれる。近傍の `[105.9,10.3]` はこの簡略化したデータでは別の沿岸区分に入るため、近傍の地点から流域IDを代用しない。

六つの季節比較について、入口の具体的な月、URL再読込、月変更後の元事例への復帰で、作物・国・地点・カメラ・事例が保持されることを検証する。`PlaceBridge.question`は季節の比較を問い、入口の月が現在表示されているとは述べない。MRCの補助出典は`PlaceReading.additionalSources`に保持する。

作物事例に関する変更対象は`src/data/atlas/asia-place-readings.ts`、上記テスト、この文書。共有UI・状態正規化・GPCCデータの生成は各担当の実装・検証範囲とする。
