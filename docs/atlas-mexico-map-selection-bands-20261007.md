# メキシコの地図表示・選択の修正

基準は main の PR200（`ad4a8ad357e245291b64c989a9166ba4b7202774`）。既存のメキシコ実装を継承し、カナダや原典データは変更していない。

- 産業の地図枠を他のメキシコ分野と同じ縦横比にする。通常の分野切替から入る産業は全国・州未選択とし、明示した州選択と比較元・戻りの情報は保持する。
- 作物選択中は畜産マーカーを薄くする。全作物・畜産、州別棒グラフ、明示的な項目絞り込みは保持する。
- 流域は地図の区域・名前から選ぶ。地図下の3水系ボタンを撤去し、右側の初期表示に3水系の概要を置く。選択区域は保存済みの流域と国土境界から事前に切り出し、複雑な SVG のクリップによる応答遅延を避ける。
- 標高は保存済み ETOPO 原格子から500mごとの面を生成し、同じ格子の等高線と数値凡例を表示する。標高では州・線を選択しない。他のタブの州選択は保持する。
- 牛肉だけに、保存済み FAOSTAT の2024年世界比較の確認用表示を加える。米国の既存コンポーネントを使い、メキシコを強調する。全品目への展開は確認後とする。

産業ラベルは画面上で14pxを維持し、実際の日本語文字枠と長い説明の幅を使って配置する。SVG の文字サイズ変更が描画へ反映されてから測定し、拡大・縮小・全体ボタンの領域を避け、初回の狭い画面でも全10件を保持する。農業のカメラ位置は URL と同じ精度に正規化し、ドラッグ後の再読込による小さな位置ずれを防ぐ。

## 標高の生成と検証

入力は ETOPO 2022 surface のメキシコ周辺格子。1分解像度、EPSG:4326、1980×1200、Float32 little-endian、単位 m、鉛直基準 EGM2008、NoData -99999。保存済み格子の SHA256 は `47e9c1792e653c05e94058b2b7311a18a7db38c094d47fb0f8a5acfef45c9743`。巨大な原本の再取得は行っていない。

`prepare-mexico-elevation.py --bands-only --grid <保存済み格子JSON>` で生成する。ContourPy の面と線を同じ格子から求め、面を国土境界で切る。独立した簡略化は行わない。0m未満、0–500mから4500–5000mまで、5000m以上の12階級。元の等高線5490件を保持する。2022年版であり、全地点の観測年が2022年という意味ではない。

生成した gzip GeoJSON は3,732,614 bytes、SHA256 `0ea85b43c326d5a9d6acedf49e067f6cacb67788adfd3e044339448b3e3fb616`。別途、原格子の1742点を面と照合し、階級違い・二重割当・未割当はいずれも0。11等高線の139,585個の固有頂点は、全て隣接する2階級の境界に一致した。国土境界との差は面積比約0.000022%。NoData は0mとして扱わない。

## 表示の意味と残る確認

3水系は全国158の国内流域区分への代表的な入口。国外の上流域を除く。レルマ―チャパラ―サンティアゴには RH12G の閉鎖流域を含めない。本流・流向・河口は未確認のため、線の頂点順や端点から推定表示しない。元の流域 GeoJSON と地図画像は保持する。

牛肉の確認用表示は FAOSTAT QCL、生産量（5510）、品目867、2024年、t。メキシコ2,253,615.34t、世界69,749,016.37t、世界比約3.231%。定義は骨付き・生鮮または冷蔵の牛肉。頭数や水牛肉とは区別する。既存の SIAP 2025年全国・州別統計も保持し、期間・定義の違いを明記する。メキシコの未取得の時系列は表示しない。

地下水の既存10階級・固結／非固結・産出区分／存在可能性・1996年作成／2008年改訂の意味は保持する。未取得の DMA 地図、より細かい人口データ、原典確認が必要な河川情報を補ったことにはしない。

## 検証方法

既存の単体・E2E・配信検査と、既存のブラウザキャプチャを使う。ローカル実行は `execution: 'local'` と実際の40桁コミットを指定し、CI の環境変数を偽装しない。画像とメタデータにはレビュー対象のコミット・画面寸法・操作結果を残す。PC とモバイルで選択、ズーム、切替、比較、戻り、履歴、再読込、凡例、画像ロード、横方向のはみ出しを確認する。画像の確認前にマージ・公開は行わない。
