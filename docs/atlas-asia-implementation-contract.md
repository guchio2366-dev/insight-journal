# アジア詳細地図：初期実装の契約

## 対象と作業境界

東アジア、東南アジア、南・中央アジアの既存ページを詳細化する。中東（イランを含む）とロシアは選択対象にしない。北米のデータ、URL処理、AtlasExplorer、欧州ページを変更せず、アジア用の地域設定・画面・状態処理を追加する。

## 読み方と描画

空間的な分布の違いを、気候の分類ラスタ、都市の雨温図、作物の分布と解説で読む。1ページにMapLibreを1つ置き、Web Mercatorに投影したデータを描く。気候の分類値は連続値として補間しない。周辺国は位置関係を示す灰色の背景にする。面積の大小を比較する地図には使わない。

国の選択→地図と対象都市→選択地点の説明→比較という順。地域と国を上部、地図を左、説明を右に配置し、モバイルでは地図を先に置く。凡例・出典・数値はタップとキーボードでも読める。気候の色は分類専用、選択状態は輪郭で示す。

## 状態と失敗時の動作

- 現行の `place=JPN` 等を維持。地域別に有効な国・都市と座標範囲を検証する。
- 分野、都市、国、カメラ、比較元をURLに保持。再読み込み・戻る・進むで復元する。
- 気候だけでも起動できる。未実装分野のデータは取得しない。
- データと描画ライブラリの失敗を分離し、静的な国境図と都市の図表・数値・出典を残す。
- 地域切替は各地域のURLへ移動し、無効な国・都市を持ち越さない。

## モバイル

390px幅を主要確認対象、横向きと768px・1280pxでも確認する。主要ボタンは44px以上。1本指の縦スクロールを妨げず、地図操作は2本指と拡大縮小ボタンを用意。ホイールズームは初期無効。地点は地図だけでなく一覧から選べる。地図と説明の間に長い設定群を置かない。動きを減らす設定を尊重する。

## データと検証

固定版入力・利用条件・加工手順・ハッシュ・格子定義・欠測を記録する。観測所の平年値と格子の気候分類は区別する。作物分布は空間配分モデルによる推計であることを示す。

URLの有効値、地域変更、比較と復帰、表示色と格子照会、12か月のデータ、欠測の扱いを検査。既存CIとは別に実ブラウザで描画・選択・小国・スクロール・失敗時の表示を確認する。初回転送量と表示時間を測り、3地域へ展開する前に実測結果を記録する。

## 公開

対象ブランチの変更範囲を確認し、最新mainの他地域の変更を取り込む。共通部分を含む変更は順に統合し、CI・実ブラウザ・配信結果・公開URLを確認する。契約、購入、課金設定は扱わない。
