# 人種・民族：最多区分から特徴的な集積へ

2026-09-23。白人（非ヒスパニック）が最多の郡で地図が単調になるため、既存の ACS 2020–2024 B03002 推計値から特徴的な集積を表示する。参考画像の境界をデータとして使用しない。

## 表示ルール

- 重複しない8区分・全年齢の総人口を分母にする。ヒスパニック以外は非ヒスパニック。
- 白人以外の7区分で、割合20%以上、または割合5%以上かつ全米の同一区分の1.5倍以上を対象とする。境界値を含む。
- 対象が複数なら、その中の最大割合を郡の地色にする。同率は凡例順。
- 対象なしは薄灰色。これは主に白人が最多の地域であり、白人だけの地域、少数集団が不在の地域を意味しない。
- 欠測・不正値・人口0は別の濃灰色。対象なしと混同しない。
- 編集上の表示基準であり、公的な地域区分・推計誤差を加味した有意差ではない。丸め前の点推計で判定する。
- 全米基準は50州とDC。初期地図・代替画像は米国本土を表示する。

地図と代替画像は同じ `ethnicityFill` を使う。選択郡の表には該当しない集団も含め全8区分と全米割合を表示する。色だけに依存せず、該当する行には文字を添える。

## 検証対象

境界値・欠測・同率・白人が最多の実在郡・複数集団の都市・合算・履歴復元・他レイヤー切替・WebGLなし・読み込み競合をテストする。既存の地図、カメラ、ニュース枠、記事を維持する。共有地図の読み物選択だけでデータ再取得や再着色を行わない。
