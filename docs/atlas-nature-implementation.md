# 自然環境タブ 実装・検証記録

対象設計：`atlas-natural-environment-design-v1.0.md`および軽量化差分`atlas-natural-environment-lightweight-release-design-v1.0.md`。基準main：`0d758c93fb2dc1b3dbf9428f7fe1390d51bfb617`。2026-09-13。

## 継承と修正

先行試行のローカルチェックポイントには自然環境の実装とUSGS/NOAA等の取得結果が残っていた。農業・畜産の最新mainは統合済みだったが、描画が旧気候WebPと全国固定の等高線を参照し、更新データ・ズーム別等高線・河川選択・出典原稿が未接続だった。独立作業コピーでこれらを接続した。これを過去の停止すべての原因と断定するものではない。

地図はMapLibre 1インスタンス、カメラは共有。自然環境内部を気候区分・水資源・地形・標高（等高線）の順に切り替える。雨温図は気候のみ。季節・土壌の独立操作は追加しない。海流は模式線と名称・暖寒・方向を共通表示する。

## データと実装判断

- 気候：koppen.earthのAbout表示がBeck et al. (2023)、DOI `10.1038/s41597-023-02549-6`を明記。1991–2020年を採用。配信スナップショットの版をV3と同定しない。分類色をIDへ正確に復号し、最近傍でWeb Mercatorへ投影。描画と地点取得は同じ3200×1940格子。米国陸域以外を対象外にする。色凡例は収録23区分を保持。
- 都市：NOAA NCEI 1991–2020の同一観測所CSVの`MLY-TAVG-NORMAL`と`MLY-PRCP-NORMAL`を使う。CSVは華氏・インチの実数値。整数倍率を重ねて適用しない。各観測所CSV、SHA-256、月別変換確認表を`data/sources/nature-v1/`へ保存。月ごとの品質・寄与年数も公開JSONへ保存する。公表30年平年値が全月30年の観測値を持つという意味ではない。
- ワシントンD.C.：Reagan National観測所の正確な座標は採用した沿岸気候格子で欠測。分類はnullと注記し、近隣値や市中心の分類を補わない。雨温図の12か月は完全に収録されている。他11都市の分類は同じ描画格子との一致を確認した。
- 帯水層：USGS Ground Water Atlas由来のEsri配布を利用。主要帯水層の地表露出・浅部範囲であり、地下の全範囲・残水量・水質ではない。ハイプレーンズとセントラルバレーを含む4系統。
- 地形・水系：既存Natural Earthを継承。地形の輪郭は地誌的概略域。小さな貯水池は代表点であり、実水面を膨らませたものではない。
- 等高線：USGS 3DEP ImageServerから共通500m格子（EPSG:5070、CONUSの鉛直基準NAVD88）で抽出。ContourPyで生成し、地理座標へ変換した全国500m間隔だけを公開する。全国比較用の簡略化であり、線間隔を鉛直精度と呼ばない。拡大しても線間隔は変えない。
- 等高線の公開量：全国版はgzip約1.47MB、展開後約8.50MB。初めて標高表示を開いた時だけ取得・展開・地図ソースへ設定し、パン、ズーム、タブ往復では繰り返さない。地域別100m・250mの62ファイル、合計24,093,925バイトは`data/derived/nature-v1/contours-detail/`へ同じGit Blob SHAで保全し、公開成果物から除外する。
- 最高峰：エルバート約4,400mはUSFSの14,433ft表記の概数、ミッチェル約2,037mはNC State Parksの6,684ftから換算。山脈名に付した説明であり、地図上のラベル位置を測量済み山頂座標としない。間引いたDEMの最高値や山脈平均標高とも区別する。

## 非同期・URL・操作

遅延読込はリクエストをキャッシュし、失敗はキャッシュから除いて再試行できる。世代番号で古い応答の画面への反映を防ぐ。読み込み中・失敗時は選択した表示の代替図を明示し、別タブへ移動可能。等高線は全国ファイル一件だけを読み、同一セッション中は取得・展開・地図ソース設定を一度に抑える。

`nature/`を正規経路とし、`land/`を地形、`climate/`を気候に正規化。`env`・`city`・`natureFeature`と既存の農業・畜産選択、カメラ、fit/customを保持する。不正な地名文字列は登録済みのIDへ制限。タブ・都市選択で自動パンしない。画面外の選択は明示したボタンで移動する。

選択カードは地図上の対象、地形ポリゴン、地名、操作部と重ならない候補へ置き、狭い画面や配置不能時は地図下へ移す。右欄は全体概説を保持する。農業から選択作物の補助輪郭を継承する。

## 自動・データ検証

`npm run check`で単体試験、Astroビルド、静的成果物試験、公開境界検証を実施。自然環境の追加試験は、原データ変換、固定都市、分類と欠測、公開資産ハッシュ、全国gzip復号、URL互換、キャッシュ再試行、詳細62ファイルの保全、実コントローラーによる12都市切替・カメラ保持・遅延応答競合・等高線の単一取得を対象にする。コントローラー試験のMapLibreは描画境界のモックであり、GPU検証とは区別する。圧縮GeoJSONも展開して公開境界を検査する。

Pythonによる別検算：全都市の元CSVの月・観測所を照合、144組の単位変換・品質列を照合、公開PNGの全分類IDに対する色を照合、12観測座標の地点取得結果と欠測を照合。

## 再生成

Pythonのnumpy/Pillow/rasterio/pyproj/shapely/contourpyを使う準備処理：`python scripts/prepare-atlas-nature.py`。通常のサイトビルドは原資料をダウンロードしない。取得した原資料を`ATLAS_NATURE_TMP`（既定`/tmp/atlas-nature-v1`）で再利用する。新規に取得し直す際は出典の日付・ハッシュと派生資産を確認してから採用する。NOAA原表はリポジトリにも保存。模式海流・貯水池の公開GeoJSONは編集済みの出典付き資料として保持する。

地図代替図の再生成にはNoto Sans CJK JPのOTFが必要。`ATLAS_NATURE_FONT`でパスを指定できる（フォント自体は配信物に含めない）。
