# 農林業・林業 初版実装

2026-09-16。設計書 `atlas-forestry-design-v1.0.md` に基づく地域資料型の初版。

## 表示と学習内容

- 上位表示名は農林業。既存URL・内部IDはagricultureのまま維持。
- 作物・畜産に加え、林業「森林資源と木材生産」を直接選択できる。
- 森林の成立条件、地域別の管理、製材・合板・パルプの用途を説明。初出の用語を定義し、キーセンテンスと本文内比較リンクを配置。
- 森林選択時は農畜産の地図記号・統計を隠す。表示設定・カメラを保持し、農畜産選択時に復帰。
- 農畜産の概況の販売収入に林業の金額は加算しない。

## 出典・実データ

### 森林分布

USGS/MRLC NLCD 2021、連続48州。公式WMS `NLCD_2021_Land_Cover_L48` をEPSG:3857、1800×1084で取得。公式凡例の分類41（落葉樹林）、42（常緑樹林）、43（混交林）の色と完全一致する画素のみ抽出した。未知色0、抽出画素213,769。概略表示であり面積集計には使わない。湿地の樹木（90）は含めず、商業林・人工林・伐採区域の地図とはしない。

- [公式入口](https://www.mrlc.gov/)
- 加工スクリプト：`scripts/build-forestry-assets.py`
- 原資料URL・SHA256・範囲・分類・ライセンス・生成物：`public/assets/atlas/forestry/v1/manifest.json`
- 森林マスクは約160KB。国全体の生産量の濃淡・順位は作っていない。
- 州境は既存Natural Earthの実形状。南部のNC、太平洋岸北西部のWA・OR、北東部のME・NH・VTを解説事例とし、地域全体や生産域の網羅的定義として扱わない。

### 木材の生産・用途

[USFS TPO North Carolina 2022（2024年公表）](https://www.ncagr.gov/divisions/nc-forest-service/2022-timber-product-output-and-use-north-carolina/open)。生産788,881千立方フィート、用途比率42.9 / 31.5 / 14.0 / 7.0 / 4.3 / 0.3%、合計100%。州内生産の体積比であり全国値・金額比ではない。州間の木材移動を国際輸出入と呼ぶ図は作らない。

全国同年・同定義の木材生産量を取得・検証したものではないため、設計の地域資料型を採用した。世界シェア・輸出先図は初版の対象外。木材加工の専用項目が存在しないため、主要産業への曖昧なリンクは未作成。

## 状態と地図

- `agriReading=forestry:timber` または `#forestry-timber` で直接表示。`forestRegion` はsouth / northwest / northeast。
- `forestCompare`・`forestReturn` で自然環境の降水量・地形へ比較。選択州・森林分布を表示し、林業へ戻るボタンを置く。復帰先は同一サイトの農林業に限定し、許可した状態のみ復元する。
- 既存の単一MapLibreを利用。森林は同じメルカトル座標へSVG画像として重ねる。地図の移動時は座標を更新、代替図ではobject-fit後の実画像枠へ投影する。
- 森林データは選択時だけ取得し、ページ内の往復では取得済みの画像・形状を再利用。失敗は明示し、再取得ボタンで回復可能。
- 広い画面は既存の地図・右側解説の高さ調整を利用。狭い画面は縦積み、統計は1列。

## 検証

- 通常／WebGLなしの林業選択・直接URL・比較・復帰。
- 20回の品目切替で森林データを再取得せず、地図インスタンスは1個を維持。
- 読込失敗・再試行、農畜産グラフの復帰、非表示にした畜産設定の維持。
- URLの許可リスト、地理データの州コードと分類、用途構成の合計。
- 既存テストとビルド・公開成果物検証を実行。実機iPadでの確認とは区別する。

クラウドブラウザはローカルURLへの接続が制限されたため、公開ページでの画面確認はデプロイ後に行う。
