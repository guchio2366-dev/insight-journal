## 1. 最新の合意と適用範囲

目的は、米国の産業構造を把握し、各産業がどこに集まり、なぜそこにあるかを地図と説明から理解することである。農業と同じく、左に大きな地図、右に統計２枠、下に詳説とインサイトを置く。

本書は、主要産業についての分岐前の検討案・生成画像より優先する。自然環境・農業の承認済み仕様は各設計書が引き続き担当する。

| 論点 | 本書で採用する最新方針 | 過去案の扱い |
|---|---|---|
| 分野の選択 | A案の二段タブ。第一段は業態、第二段はその内部の分野 | 説明カードを入口にするB案は不採用 |
| 複数産業の比較 | タブを切り替えて比較。関係を説明するインサイトを別枠で常設 | C案・AC複合案・比較用チェックボックスは不採用 |
| 右の２グラフ | 第一段の業態に応じて内容を変更 | 「常に全産業で固定」は撤回 |
| 金融・情報通信などの選択 | 地図と下の詳説に反映。右欄はサービス業の構成を維持 | 細分野ごとに右欄まで切り替えない |
| 全米全体の統計 | 第一段の「全産業」でGDP比・雇用構成を表示 | 非農業だけを100%として全産業と呼ばない |
| 農畜産 | 全産業の構成に含め、地図・詳説は既存農業タブへ接続 | 主要産業ページ内に農業機能を複製しない |
| インサイト | 比較先・見る地域・共通点や相違の理由まで説明 | 「見比べてみよう」という問いだけで終えない |

生成画像は配置・余白・階層を確認する参考である。画像中の都市位置、産業分布、グラフの長さ、説明文、検索・お気に入り等の付随機能を実装仕様や根拠として取り込まない。旧画像の右欄は最新方針と異なる。

| 最上部 | 既存の自然環境・農業・主要産業の分野ナビゲーション | ページ分野の変更 |
| 第一段 | 全産業／製造業／資源・エネルギー／サービス業／建設・不動産 | 業態の変更 |
| 第二段 | 選択業態の「全分野」と細分野 | 分野の変更 |
| 左約７割 | 選択範囲に対応する産業集積地図、凡例、地域選択 | 業態・分野・地域の変更 |
| 右上 | 全産業または選択業態の付加価値構成 | 第一段の変更のみ |

| 下部１ | 全体・業態・個別分野の詳説 | 第一段・第二段の変更 |
| 下部２ | 産業を見比べるインサイト | 関連する論点を上位表示。別枠は常設 |
| 末尾 | 数値表、分類、出典、対象年、表示方法 | データ更新 |

| サービス業 | 金融・保険 | 金融・保険の集積 | 上と同一 | 金融・保険の規模、役割、立地、変化 |

第二段の変更、都市の選択、地図のパン・ズームによって右欄の数値、分母、並び順、強調色を変えない。右グラフを新たな分野選択操作にはしない。

### 3.2 初期値と戻り方

- 初回は `sector=all`。全産業に架空の「全分野」行を重ねない。
- 第一段を変更したときは、その業態の `subsector=all` へ移る。前の業態の細分野と地域選択は解除する。地図カメラは保持する。
- 第二段を変更すると、対象の地図と詳説を同時に更新し、前の地域カードを閉じる。自動スクロール・自動パンは行わない。
- 「全分野」で業態全体へ、「全産業」で全体構成へ戻れる。現在の選択は二段タブと見出しで常に分かる。
- 詳説への移動は「この分野の詳説へ」、画面外の地域への移動は「地図で位置を見る」という明示ボタンで行う。

## 4. 業態・分野の分類

ナビゲーションは学習の入口、統計分類は合計の整合性を保つ区分である。両者はIDで対応させるが、航空宇宙などの学習上の細分野を、取得できないGDP内訳へ無理に分解しない。

### 4.1 全産業の統計区分

次の６区分を、付加価値・雇用の共通の親区分とする。NAICSは概念対応であり、実装ではBEAの表名・系列名・行IDとの対応表を作成する。

| ID | 表示名 | 集計範囲 | 注意 |
|---|---|---|---|
| agriculture | 農林水産 | 民間のNAICS 11相当 | 農畜産を含む。林業・漁業も含む数字を「農畜産だけ」と表示しない |
| manufacturing | 製造業 | 民間の31–33相当 | 食品加工、石油精製、化学を含む |
| resources | 資源・エネルギー | 民間の21・22相当 | 鉱業と公益事業。石油精製・化学製造は製造業に置く |
| services | サービス業 | 民間の42、44–45、48–49、51–52、54–56、61–62、71–72、81相当 | この閲覧区分では不動産・賃貸を別掲。政府部門も含めない |
| construction-real-estate | 建設・不動産 | 民間の23・53相当 | 賃貸・リースを含む。サービス業との二重計上を防ぐ |
| government | 政府 | BEAの政府部門 | 政府消費・投資額とは異なる。公立学校・公的医療等を民間サービスへ重複計上しない |

全産業グラフは６区分すべてを載せる。農林水産は既存農業タブへの案内、政府は全産業の詳説内の説明に接続し、第一段タブは増やさない。グラフの近くに「農林水産は農畜産を含む」「サービス業は不動産を別掲」を短く記す。

統計原表に上記の区分に収まらない項目・調整がある場合、無理な再配分で100%に合わせない。対応表を直し、なお残る公表上の調整は数値表に明示する。

### 4.2 サービス業

| 第二段の表示 | ID | 統計上の範囲 | 説明で明示する内容 |
|---|---|---|---|
| 全分野 | all | サービス業全体 | 複数の立地類型を短く整理 |
| 情報通信 | information | 51相当 | 出版・ソフトウェア出版・映像・通信・情報処理等。一般的な「IT企業すべて」と同義ではない |
| 金融・保険 | finance | 52相当 | 銀行・証券・保険等。本社と営業・事務機能を区別 |
| 専門サービス | professional | 54–56相当 | 右グラフの正式名は「専門・業務支援」。法務・会計・研究開発・企業管理・事務支援等を含む |
| 商業・物流 | trade-logistics | 42、44–45、48–49相当 | 卸売・小売・輸送・倉庫。本社、店舗、配送拠点を区別 |
| 観光・娯楽 | tourism | 71–72相当 | 娯楽・宿泊・飲食。住民向け飲食も含むため統計全体を観光需要とは呼ばない |
| 医療・教育 | health-education | 民間61–62相当 | 福祉を含む。公立部門は全産業の政府側に計上 |
| その他のサービス | other-services | 81相当等の明示した残余 | 修理・個人向けサービス等。原系列の一覧を添える |

「全分野」を除く７項目を右の２グラフに共通表示する。最初から７色を割り当てず、棒は中立色で統一する。「その他」は残余の具体名を数値表で確認できるようにする。

受託ソフトウェア開発・システム設計は、統計上、情報通信と異なる専門サービス側の系列に入る場合がある。企業の知名度だけで分類しない。関連性はインサイトでつなぎ、同じ系列を両区分に足さない。NAICS改定によるコード変更は採用年の対応表で処理する。

### 4.3 製造業・資源・建設

| 第一段 | 第二段の初期実装対象 |
|---|---|
| 製造業 | 全分野、自動車、航空宇宙、半導体・電子機器、機械、金属、化学、食品加工、その他の製造業 |
| 資源・エネルギー | 全分野、石油・天然ガス、その他の鉱業、電力・ガス・水道 |
| 建設・不動産 | 全分野、建設、不動産・賃貸 |

製造業の右グラフは原統計の共通粒度で、原則「食品・飲料等」「木材・紙」「石油・化学・プラスチック」「金属」「機械」「電子・電気機器」「輸送機器」「その他の製造業」の８区分へ集約する。３桁の元分類を重複なく分割し、残余には繊維・衣服・皮革・印刷・非金属鉱物・家具等の実際に含めた系列を列記する。

例えば航空宇宙の地図を選んでも、右欄はこの製造業８区分のままでよい。航空宇宙だけのGDPが得られなければ、下の詳説で雇用など取得できる指標を使い、広い「その他輸送機器」のGDPを航空宇宙のGDPと呼ばない。

資源の右欄は、両指標で一致して取得できる「鉱業／公益事業」を最低限の共通粒度とする。石油・天然ガス等の分解が両方で可能なら同じ分類で追加する。建設・不動産は23／53相当の２区分である。

## 5. 右欄の統計設計

### 5.1 見出し・分母・指標

| 選択 | 右上 | 右下 |
|---|---|---|
| 全産業 | 「全米のGDP構成」／各業態の名目付加価値÷全米GDP | 「全米の雇用構成」／各業態の雇用÷採用雇用統計の全産業計 |
| サービス業等 | 「サービス業の付加価値構成」／各分野÷サービス業計。見出し下にサービス業の全米GDP比と金額 | 「サービス業の雇用構成」／各分野÷サービス業計。見出し下に全米雇用比と規模 |

棒は横棒グラフ、ゼロ始点、割合を棒の末尾に常時表示。金額・雇用数は全件数値表に置く。上と下は同じ分類・同じ並びにする。並びは初回採用年の付加価値順で固定し、雇用側だけ独立に並べ替えない。目盛りは両グラフに共通の上限を採用し、例えば片方だけ最大値を100%幅に正規化しない。

割合は内部では丸めず計算、表示は原則小数１位。表示上の合計99.9%・100.1%は丸めと分かる短い注記を置く。売上高・販売現金収入・輸出額を付加価値へ代入しない。実質連鎖ドルの非加法性があるため、構成比は名目値で計算する。

### 5.2 データ源と取得時の判断

| 用途 | 第一候補 | 採用前の確認 |
|---|---|---|
| 全米・業態別付加価値 | [BEA GDP by Industry](https://www.bea.gov/data/gdp/gdp-industry)、年次の名目Value Added | 表ID、系列、期間、単位、改定日、全産業合計との一致 |
| 全米・業態別雇用 | BEA NIPA Table 6.4D「Full-Time and Part-Time Employees by Industry」 | 年平均のフルタイム・パートタイム雇用。自営業を含む就業者数やFTEと区別。私企業・政府の分類をGDP側と対応 |
| 地域別産業集積 | [BLS QCEW](https://www.bls.gov/cew/overview.htm)の年次・民間・産業別雇用 | 対象年、地理単位、NAICS版、秘匿、所有部門、カバレッジ |
| 細分野の補助指標 | BLS、Census、BEA、EIA等の公的統計 | 指標の意味・対象範囲を下の詳説に明記 |

BEAが民間の雇用比と付加価値比にこれらの表を用いていることは、[BEAの方法説明](https://www.bea.gov/news/2021/activities-us-multinational-enterprises-2019)で確認した。雇用概念は[BEA NIPA Handbook第10章・付録A](https://www.bea.gov/resources/methodologies/nipa-handbook/pdf/chapter-10.pdf)を併せて確認する。

本設計では公表元・指標・集計方針を確認済みであり、最新年の全行データを取得・照合済みとはしていない。実装の最初に実データを取得して表ID・単位・行対応を確定する。年を見かけだけ2026年へ更新しない。

年次の全国２指標で必要行が揃う直近の共通暦年を採用する。2025年が揃えば2025年、揃わなければ両方を同じ取得可能年へ戻す。地図は別の年でもよいが、地図と統計それぞれに対象年を明示する。

NIPAの雇用では、居住者の人数と国内生産に対応する雇用を混同しない。兼業・自営業の扱いを原表の定義で確定し、「就業者数」「働く人の全数」と安易に言い換えない。ラベルは「雇用」、注記は「フルタイム・パートタイム、年平均。自営業は含まない」を基本とする。

BEA雇用の取得や細分が不十分でも、QCEWを一部の分子だけに継ぎ足さない。全国２グラフを共通の粗い分類へ集約することは可能。全国雇用全体をQCEWへ変更する場合は農業等の対象範囲が変わるため、具体的な差分を提示して合意を得る。

### 5.3 読み違いを防ぐ説明

- 農林水産のGDPは、既存農業タブの農畜産物販売収入とは異なる。販売収入からGDP比を算出しない。
- 不動産の付加価値には住宅サービスなどが含まれる。土地・住宅の取引額や不動産会社の売上高と同一視しない。帰属家賃の扱いは採用系列の定義とともに説明する。
- 政府の付加価値は政府支出総額ではない。
- 付加価値比と雇用比の差だけで、個人の能力・給与・産業の優劣を結論づけない。自営業、労働時間、資本・住宅サービス等の違いがあるため、本画面では生産性ランキングを作らない。
- 全国統計は原則50州＋D.C.、地図初期表示は連続48州＋D.C.。カードに「統計：全米／地図：米国本土」と明示し、周辺国の白地を産業不在と読ませない。

## 6. 産業集積の地図

### 6.1 表現

MapLibreの既存１インスタンスを使い、地形・河川・湖・州境を共通の土台として継承する。産業の描画は代表点と短い地域名を基本とし、地図全体を巨大な色面で塗り分けない。

全産業・全分野では、同じ都市圏の複数産業を一つの選択対象へまとめ、「デトロイト周辺｜自動車・機械」のように短く表示する。タップで収録産業の一覧を開き、分野を選べる。何もない白地は未収録を含み、産業ゼロではない。

細分野では、同じ種類の控えめな記号で主要集積を表示する。初期版では記号の大小を雇用数へ対応させず、凡例に「主要集積の代表点。事業所位置・規模ではない」と示す。全国統計が規模を、地図が立地を担当する。工場等の実所在地を出す場合だけ、別の形の記号と出典で区別する。

密集時はラベル衝突を避けて地理的に近い候補をまとめる。元の点座標を動かして都市の位置を変えない。ラベルの退避は短い引出線を付ける。候補の全件一覧を地図下の「地域一覧から選ぶ」でも利用できるようにする。

資源地域は都市に置き換えず、資料で確認できる盆地・鉱区などの概略域または代表点を使う。郡統計しかない範囲から厳密な資源境界を描かない。建設・不動産、医療、小売は広く分布することを説明し、表示した都市以外に存在しないような表現を避ける。

### 6.2 根拠と集積地域の選定

規模と特化度を分ける。地域内の分野雇用比を全国の同分野雇用比で割るLQを参照する。[BLSの定義](https://www.bls.gov/cew/about-data/location-quotients-explained.htm)に従い、分子・分母で年・地理・所有部門・産業範囲を揃える。LQが高いだけの小規模地域を、最大の集積と呼ばない。

初期の収録候補は、同じ統計母集団での雇用規模上位地域と、規模も確認した高特化地域の和集合から選ぶ。候補表に雇用数、LQ、全国比、選定理由、出典を残し、地理的な偏りを減らすためだけに根拠のない点を追加しない。概観は12～18地域、業態全体は8～14地域、細分野は4～8地域程度を目安とし、収録数ありきでデータを作らない。

全国比較の点密度を抑える表示上のまとめと、データ上の欠測・秘匿を別に扱う。秘匿値は0にせずnull、未表示の理由は数値表で確認可能にする。小規模業種の秘匿を逆算で推定しない。

### 6.3 都市圏統計の変更への対応

BLSは2025年第２四半期から、QCEWの都市圏（MSA）の公表を総計へ限定した。詳細産業については郡別データとCounty–MSA–CSA対応表から集約できるとしている。[BLS公表変更の告知](https://www.bls.gov/cew/notices/2025/change-in-the-presentation-of-metropolitan-statistical-area-data-in-qcew.htm)

したがって「最新QCEWのMSA×詳細産業がそのまま取得できる」と仮定しない。取得順序を次で固定する。

1. 変更前の年次MSA×産業データ（2024年を第一候補）の実在・必要行・境界年を確認する。
2. 不足時は、同一年の郡別データを公式の境界対応表で集約する。郡の重複、州またぎ、欠測・秘匿を検査する。
3. 郡の一部が秘匿なら、その和を都市圏の完全な総数や完全なLQとして表示しない。公開可能な広い業種、郡・州単位の証拠、当該地域の公的資料へ切り替える。
4. 比較対象の地理単位が揃わない場合は一つのランキングに混ぜず、代表地域として説明する。

QCEWは自営業など一部の雇用を対象外とする。地図上のQCEWの数値と全国欄のBEA雇用を、同一母集団の地域内訳として加算しない。

### 6.4 地域カード

地域名、選択分野、地域で担う機能、立地理由２～３文、使用統計の年と範囲、詳説へのリンクを表示する。本社・研究開発・生産・物流・営業・事務機能を区別する。地図の位置や倍率をカードの都合で変更しない。

カードは対象記号・地名・操作ボタンを避けて配置し、置けない場合は既存の地図直下スロットへ移す。狭い画面では直下を基本とする。地域選択は分野の全国詳説を置き換えず、地域固有の説明をカードで補う。

## 7. 下の詳説とインサイト

### 7.1 詳説の共通形式

| 読む順 | 内容 | 標準分量の目安 |
|---|---|---|
| 冒頭 | どのような産業で、米国のどこが特徴的か | ３～５文 |
| 何をする産業か | 製品・サービス・機能と規模。個別分野のGDP・雇用等はここに置く | 150～250字＋主要指標２～３個 |
| どこに集まり、なぜか | 資源・市場・輸送・人材・大学・取引先・歴史を地域に即して説明 | 250～400字＋地域例 |
| 何が変わっているか | 取得可能な年次推移、立地・技術・需要・政策の変化 | 200～350字、必要なら小さな時系列図 |
| 企業の具体例 | その地域で担う機能と確認日を添える | ２～４例を追加展開 |

選択していない全分野の長文を一度に縦へ並べない。基本文は常時読め、追加の表・企業例・方法はdetailsで開く。見出しと文章は静的HTMLにも存在し、JavaScript失敗時は目次から読める。

### 7.2 インサイトの形式

見出しは「産業を見比べるインサイト」。詳説とは独立したsectionとし、PCでは主要３件を２列程度、iPhoneは１列にする。初期版は全体で６件程度の根拠ある論点を目標に、選択業態に関係するものを先に出す。残りは「ほかの関係を見る」で読める。

各項目に、(a)関係を述べる見出し、(b)見る地域、(c)観察できる共通点・相違、(d)説明できる理由と限界、(e)根拠、(f)比較する２分野へのリンクを入れる。200～350字程度を目安とする。単なる課題文や、因果関係の根拠がない断定で埋めない。

以下は原稿調査の候補であり、地域別の本文と因果説明の確定には出典確認を要する。

| 比較候補 | 読者に確かめてもらう関係 |
|---|---|
| 金融・保険 × 情報通信 | 大都市での共存、顧客・資金・専門人材の関係。共存だけから直接の因果を断定しない |
| 自動車 × 金属・機械 | 完成品工場と部品・加工・技術人材の立地関係 |
| 石油・天然ガス × 化学 | 採掘・原料・精製・化学工場・港湾の違いと接続 |
| 商業・物流 × 製造業 | 港湾・内陸輸送拠点と市場・工場への接続 |
| 食品加工 × 農畜産 | 原料産地、加工、保管、輸送、市場の関係。既存農業タブとつなぐ |
| 医療・教育 × 専門サービス | 大学・研究・医療の関係と、人口に広く対応する日常サービスとの違い |

比較リンクは対象のsector/subsectorへ切り替え、地図のカメラを保持する。元のインサイトが分かる見出しと「もう一方を見る」を残す。通常は自動スクロールせず、必要なら「地図へ戻る」を明示する。履歴の戻るで元の選択へ戻れる。

## 8. 端末別の配置・アクセシビリティ

- PC・iPad横：幅900px以上かつ高さ600px以上を既存の出発点とする。地図約68～72%、右欄約28～32%、右欄の実用最小幅は約300px。1024px幅では文字を小さくしすぎるより地図比率を約66%へ調整する。
- 第一段と第二段は地図の外側、地図と右欄の上に置く。１行へ無理に縮小せず、iPadは必要時２行折り返し。地図・右グラフの上端は揃える。
- iPhone縦：第一段 → 第二段 → 地図 → 地域カード → 付加価値 → 雇用 → 詳説 → インサイト。タブは44px以上のタップ領域を確保し、横スクロール可能な各１行を基本とする。次項目があることを端で示し、選択タブを行内に表示する。
- サイドバーや画面を覆う比較パネルは設けない。地図の上に多段の操作群を重ねない。
- 本文はPC16px、モバイル16pxを基本、チャート項目名は原則13～14px以上。既存農業の密なグラフ用9px指定を新設産業欄へそのまま継承しない。
- iPad横は地図と右の２グラフを同時に読めることを優先。７～８行のグラフを収めるために注釈・全数値表を下へ移す。高さ不足時は自然な縦スクロールを許容し、文字を極端に縮小したり図を切ったりしない。
- 色だけで選択を示さず、下線・太字・形を併用する。通常文字4.5:1、図形・フォーカス等3:1を基準に確認する。
- タブは単一選択として実装。ロービングtabindexと矢印、Home/End、Enter/Spaceで操作できる。URL付きリンクを拡張する場合も、読み込み失敗時の通常遷移を残す。
- グラフはSVGまたはHTML/CSSで、図タイトル・説明・常時表示値・数値表を用意する。地図の同じ選択は地域一覧からも可能にする。
- 375×667、390×844、768×1024、820×1180、1024×768、1180×820、1440×900、iPhone横の844×390で確認する。画面全体の横はみ出しを認めず、タブ行の意図した横スクロールとは区別する。

## 9. 状態・URLの契約

正規経路は `/insight-journal/atlas/north-america/industry/`。既存のbase-pathヘルパーを用いる。

| パラメーター | 値・意味 | 初期値 |
|---|---|---|
| sector | all / manufacturing / resources / services / construction-real-estate | all |
| subsector | 選択sectorに属する登録済み分野ID | all |
| industryRegion | 選択範囲に存在する登録済み地域ID | 未選択 |
| industryInsight | 存在するインサイトID。比較リンクの復帰に利用 | 未選択 |
| lng, lat, z, view | 既存と共通のカメラ・fit/custom | 既存仕様を継承 |

例：`industry/?sector=services&subsector=finance`。右欄はsectorからのみ計算し、subsectorや地域の値を参照しない。

不明なsectorはall、不正・不一致のsubsectorはそのsectorのall、不正な地域IDは未選択へ正規化する。文字列をHTMLへ直接挿入しない。比較チェック用の配列状態は作らない。

第一段・第二段・地域の明示選択はpushState、連続するカメラ操作は既存ルールに従いreplaceStateで記録する。再読込・戻る・進むでタブ、右欄、地図、詳説が一致する。URL復元の処理中に追加の履歴を発生させない。

農業のcrop/region/stats/agriLayers/animal/animalRegion、自然環境のenv/city/natureFeatureと共存させる。非表示分野の選択は保持し、各分野へ戻ったときに復元する。既存のregionを産業地域へ流用しない。第一段の変更と、農業・自然環境・主要産業という最上位分野の変更を別イベントにする。

### 10.2 性能と非同期

１ページ１MapLibre、既存のworker・pixel ratio上限を継承。初回は全産業の軽量地域データを表示し、細分野の追加データは初選択時に読んでキャッシュする。全国グラフ・基本原稿は静的HTMLで先に読める。

産業追加分の目標予算は、初回の圧縮JSON/GeoJSON合計300KB以下、追加JSの圧縮分50KB以下、分野切替１回の追加データ200KB以下とする。既存MapLibre・地形資産は別計測。原CSV一式をブラウザへ送らず、派生データだけを配信する。

産業→自然環境→農業を素早く切り替えても遅い応答が現画面を上書きしないよう、世代番号・キャンセル・現在選択の確認を使う。失敗した取得を成功キャッシュとして固定しない。地図の取得失敗でも右グラフと詳説は残し、再試行可能にする。

### 10.3 代替表示

WebGL非対応時も、同じ出典・座標・投影から作った産業代替図と地域一覧を表示する。通常の地形画像と透明なSVG/HTMLの記号層を重ねる方式を基本とし、SVGをimgとして読み込んだ内部から外部画像を参照する方式は使わない。畜産で発生した表示遮断を再発させないためである。

代替表示の業態・分野・凡例・地域選択も同じstateへ連動させる。背景だけの地図を、産業表示の成功として扱わない。資産には内容ハッシュまたは版付きURLを使い、旧キャッシュが残っても確実に更新されるようにする。

JavaScriptが使えない場合は全産業の代替図、全国数値表、分野別の本文目次を読める。切替の操作が動かないことと、内容が読めないことを同一にしない。

## 12. 実装時に相談が必要な変更
