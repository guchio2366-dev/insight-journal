# 農林業統計：全地域で重複を除いた最小取得セット（2026-10-16）

13地域の担当成果はすべて部分実装。以下は、各地域の残件記録をまとめた**不足原表の取得依頼案**であり、これらを取得・照合済みとする記録ではない。統合可能なコードの作業は継続し、全域の必須不足が残る間はマージ・Pages公開へ進めない。

対象は既存の品目を選んだ時の①生産・世界シェア、②国内／域内利用・輸出、③輸出先数量。日本専用、品目未選択時の新仕様、年度選択UIの追加は含めない。食料カロリー・カロリー自給率は今回の取得依頼から外す。

追補：親が通常の公式UIで取得成功した配布URL・更新日と、保存済みデータで進めた残件を [3区分の再確認](atlas-agro-residual-triage-20261016.md) に記録した。このcheckoutでは原ZIPは未受領で、QCL通常GETはCONNECT 403。SUAの現行domainはSCL。廃止済みForestry Trade Flowsを2024年相手数量へ転用しない。

## まず共通で取得する4つの原表群

「4ファイルで全完成」という意味ではない。原表群ごとに、可能なら全対象をまとめた公式CSV/ZIPとmetadataを一度提供すれば、13地域が同じ原本を再利用できる。既に保存済みの原本が同じ版で完全なら再取得は不要。

|群|通常の公式exportから必要な内容|期間・範囲と注意|
|---|---|---|
|A 生産・公表World（FAOSTAT QCL）|既存作物・肉・生乳・卵の国別生産と公表地域／World。国・品目・要素・年・単位・Value原桁・Flag・Note・公開版。欠測国も識別できる原行とコード辞書|2023と2024を同じ取得版で。2023需給へ接続する生産／Worldは2023にそろえる。2024の不足分母だけが欲しい場合も、既存国値と版が異なれば国値とWorldを一緒に照合する。Worldを国合計や丸め比率から再構成しない|
|B 供給・用途・在庫（FAOSTAT FBS/SUA）|同年の生産、輸入、輸出、国内供給／国内利用、期首・期末または在庫変動、食用、飼料、加工、種子、損失、その他、残差・調整、観光客消費。原料換算・加工段階・符号・内数関係・単位・原旗のmetadata|共通利用可能年2023を第一候補とする。SUAの原品目とFBSの製品群は同一と仮定せず、採用する品目範囲が合う原表を選ぶ。欠測を0にしない。国内供給は実際に人が食べた量や国産由来の消費ではない|
|C 全相手数量（FAOSTAT TM／公的通関原表）|対象Reporterすべて×Worldおよび全Partner×輸出入方向。品目コード・分類版・数量・数量単位・netWeightの有無・原記号・期間・再輸出区分を保持。地域の域内外判定に使える報告国／関税領域コード辞書|Bと接続する年・商品範囲をそろえる。上位国だけや金額だけでは不可。Worldと全相手の丸め差、帰属不明、Free Zones、Other Asia, nes、Bunkers等を保持。部分表から地域外の「その他」を作らない|
|D 林産物の数量・相手（FAOSTAT FO/JFSQと対応する公的貿易表）|丸太・産業用丸太・製材・各パルプ製品を別に、全国／公表地域／Worldの生産・輸入・輸出、原品目・要素コード・単位・旗・版。全相手数量は対応する森林貿易の原表を別exportし、分類対応を付ける|2024を第一候補とし、他列と接続するなら同年へ。丸太の燃料材包含・樹皮基準、製材の全樹種／針葉樹、木材／非木材／溶解／製紙用パルプの範囲と乾燥・含水基準を明記。m³とt、原料投入と製品生産を合算しない|

公式の通常入口は、担当記録にある [FAOSTAT](https://www.fao.org/faostat/en/) のQCL／FBS・SUA／TM／FO、または既に利用できる公的通関画面。利用者PCへ接続する必要はなく、取得済みのCSV/XLSX/ZIPを受け渡せばよい。新規契約、API認証情報の発行・共有、制限の回避は求めない。拒否された当環境のURLを再試行する依頼ではない。

コード集合は既存地図・統計scopeに合わせる。例えば地理的SEA11国と年別ASEAN、欧州45対象とEU27／FAO欧州、アフリカ55対象と公表Africa、中南米の編集34対象を分ける。日本専用のUIを保留しても、Worldや域内境界・外国相手に関係する日本の原行を削除しない。

Aの代表的な不足は未繰綿World、羊肉・山羊肉の対応行、デーツ・オリーブ・水牛乳、キャッサバ・油ヤシ果実・ゴム・さとうきび、カカオ・ココナツなど。必要コードは各地域の既存generator・原表定義から照合し、通称から推測しない。アフリカの公表地域不足は既存 `data-source/atlas/africa/statistics/qcl-2024-missing-required-rows.csv` も再利用する。

## 共通原表だけでは閉じない例外

1. **現行の販売年度需給に対応する全相手数量。** 米国5作物はGATS等の月別World＋全相手。小麦2024-06〜2025-05、とうもろこし・丸大豆2024-09〜2025-08、米・綿繊維2024-08〜2025-07。米の精米換算、綿繊維、小麦製品換算の定義を添える。他国のWASDE／AAFC／GAINには各国自身の期首・期末と商品範囲が必要で、米国の期間を流用しない。カナダCGCの施設カバレッジとAAFC全国の差も確認する。
2. **畜産・乳の換算。** 同年のWorld・国内利用・数量相手を、枝肉／製品重量、鶏全体／ブロイラー、生乳／乳製品／乳成分、卵重量／ダースで区別する。米国ERSの年次肉貿易表と換算コード表、乳の公式成分別表などが必要。金額円を数量円へ換算しない。
3. **森林の実投入・在庫・使途。** FOのP/I/Xだけなら在庫未調整見掛量まで。実際の用途には国別木材需給・工業投入等の別表が必要。欧州のEurostat/Luke等、カナダの物量表、NZ MPI、チリINFOR、カザフ農産物資源用途、ロシアの同年需給などは、既存の異年・工場限定・部分製品参考と混ぜない。
4. **PNGカカオ。** 公表通関行の数量桁と欠測Worldは、Cocoa Board等の独立した公式年次表・原重量・旗で確認が必要。独断の1/100・1/1,000修正をしない。
5. **分類が複合の選択。** MapSPAMの温帯果樹、メキシコの果樹／野菜／その他などは単一のFAO品目と同一ではない。既存の分類・構成品目定義を照合する課題であり、統計ファイルが来ても勝手に代表1品目へ置き換えない。

ロシアは既存のQCL国・Worldとも公式値Aのみという方針を保持する。非A行を古い公的値で自動置換せず、2020/21 USDA参考を2024主図に接合しない。年を変えるUIも追加しない。

## 提供物に添える最小metadata

- 取得元の公的URL、取得日、原公開版／改訂日、抽出したReporter・Partner・品目・要素・期間・単位。
- 原数値文字列、品質旗、脚注・欠測／秘匿／公表0の記号、加工・換算・樹皮・含水基準。
- 地域の全対象集合と観測済み集合。CSVのWorld行や合計行を詳細行に重ねて加算しない。
- 原ファイルを保持し、SHA-256は受領側で計算する。web reader抜粋を公式ZIP／PDFのバイナリhashと呼ばない。
