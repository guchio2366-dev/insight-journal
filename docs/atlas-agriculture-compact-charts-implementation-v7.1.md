## 実装した表示

- 詳説上段に説明と供給元・行き先、下段に全幅の比較行を置いた。CSS幅960px以上では輸出先が左、世界生産が右。狭幅は所定の順序で1列になる。

- 作物輸出のSVGを共通の144座標・中央3行へ揃えた。国名・％は14px、米国数量と出典の古い10px固定指定を解消した。
