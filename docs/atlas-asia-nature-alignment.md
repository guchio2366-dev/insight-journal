# アジアの表示範囲と自然環境の共通構成

2026-09-28。北米ハンドブックと、main `7d151861` の自然環境画面を参照しました。北米・欧州の描画や資料は変更していません。

## 表示範囲

南・中央アジア全体のページに加えて、`south-asia` と `central-asia` に自然環境・農林業・主要産業・人口の4分野を用意しました。個別ページは初期表示範囲と導入文を変更し、南・中央アジアの検証済み資料を共有します。範囲を切り替えても閲覧中の分野・主題を維持し、カメラ・選択地点は新しい初期表示へ戻します。

国の一覧は比較用に南・中央アジア全体を残しています。国別統計を表示枠内の集計や中央アジアだけの値へ読み替えていません。この範囲はページ下部にも記載しています。個別ページのURL、正規URL、サイトマップ、比較からの復帰に対応しました。

## 自然環境

現在の北米と同じ「気候区分・水資源・地形・標高（等高線）」にそろえました。水資源は「河川・地下水・降水量・河川の流域」という意味の分類を、北米と同じ3ボタン（河川・地下水／降水量／河川の流域）で示します。降水量250mm間隔、等高線500m間隔の資料は維持しています。旧 `topic=precipitation` URLも有効です。

気候コードは背景・枠・影を外し、文字の周囲だけを白く縁取ります。都市の常設名は `asia-focus.ts` の編集上の主要都市リストに限定します。全観測地点の点は残し、ホバー・キーボードフォーカスで名前、タップで雨温図を表示します。選択した都市は名前も表示します。

水資源では標高画像・等高線・標高値の読み込みを行いません。河川と湖に、既存BasinATLASの集水域を重ねます。流域のボタン、河川の一覧、地図の色面から選択できます。川の形状はNatural Earth、集水域はBasinATLASの実際につながる出口（NEXT_SINK）で結合した既存資料です。

主な河川のボタンは明示した出口IDに対応します。例えばガンジス川とブラマプトラ川は同じ集水域に属します。デルタで出口が別になる小区域まで一つの流域にまとめることはしません。塗りは対象国の範囲、面積は資料に含まれる流域全体であり、境界を灌漑区域・現在の水量・洪水範囲とは扱いません。

「地形」では、既存資料の山地・高原・平野の着目点を選べます。背景は標高であり、地形名の表示位置は地形区域の境界を表しません。
