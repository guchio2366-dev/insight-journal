# Oceania / Russia 農畜産同時表示

第一段PR #206は `74f4161` でマージされ、2026-10-07 22:09:46 JSTにPages公開が成功した。
この段階は、その公開済み状態から農畜産の同時表示を実装する。
まずRussiaの代表画面を親担当に返して方向を確認し、その後Oceaniaへ展開する。
共通コード・他地域・既存Validate / Pages workflowには変更を加えない。

## Russiaの代表表示

- 初期は小麦・牛を同じ全域の地図に表示し、右側は保存資料に基づく南西部・西シベリア南部・東部の具体的な全体概要にする。
- 小麦は元画像の数量色、牛は独立した青い点の濃さで、元の数量階級を示す。
  ha／元5分セルと頭／km²を別々に表示し、量を足したり比較順位を作ったりしない。
- 小麦を選ぶと、牛を薄くし、小麦の正の収穫面積の元セル輪郭を強調する。
  牛を選ぶと、牛の元画像の数量色を表示し、小麦の輪郭を残す。
- 学習地域の選択、再読込、全体への復帰で、選んだ品目と他分布を維持する。
  明示的な地域範囲操作以外では表示窓を変えない。
- 輪郭はモデル格子の正の値の境界で、行政境界・農場境界ではない。

凡例は地図下に2品目を並べ、小麦と牛それぞれの有効0・未収録を説明する。
右側の詳説を初期から開き、本文・資料範囲の高さ制限を外して末尾まで通常のページ操作で読めるようにする。
学習地域ラベルは高さ28pxの軽い表示にし、操作領域44pxとキーボード操作を維持する。

## 原本と派生画像

保存済みMapSPAM 2020 v2r2の小麦とGLW4 2020の牛を使う。
元のFloat32格子、PNG、出典、年、単位、CC BY 4.0の帰属を維持する。
`prepare-oceania-russia-farming-overlay.py` は保存済み格子から表示専用画像だけを生成する。
新規データを取得しない。元5分セルの位置を変えず、補間・集計・国計は行わない。

牛の点画像は、元セルを表示上4×4ピクセルにし、正の値だけを階級別の濃さで示す。
低密度を含む全正値を残し、有効0は透明にする。未収録は独立した元セルマスクで薄い灰色の逆向き斜線を描く。
元の密度階級の境界値を使う。輪郭は正の作物セルの外周に限る。
未収録をゼロに変えず、輪郭の外を生産ゼロと判断しない注記を保持する。
全域では元セルが画面ピクセルより小さいため、品目選択で元の数量色を読めるようにする。

## 検証と範囲

独立したPNGデコードで、元格子の全セルと密度階級・有効0・未収録の表示を照合する。
地域E2Eで、初期同時表示、品目強調、別分布の維持、地域選択、再読込、単位・出典を確認する。
正常な既存地域専用CIで、sandbox有効の実ChromeによるPC3幅の画面と操作を確認する。
親担当の代表画面確認前にOceaniaへ展開・公開はしない。

Russiaの保存済み品目は小麦・牛の2品目、Oceaniaは作物3種・家畜2種に限られる。
上位10品目の網羅性・順位の根拠は未整備で、この表示を上位10として扱わない。
雨温図、新データの広域取得、林業、貿易・世界シェア・推移統計はこの段階に加えない。
