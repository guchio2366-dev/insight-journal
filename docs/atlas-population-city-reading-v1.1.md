# 人口タブ：都市と地図を見比べる改修

2026-09-14。州・地域の選択欄を削除し、気候タブの12都市を選んで右側で解説を読む構成に変更。

## 読み方と実装

- 右側は「短い総論 → 全国の構成を示す円グラフ → 選択都市の産業・職種 → 地図を見る視点」。都市を変えても全国の割合は変わらない。
- 人口分布、人種・民族、宗教、投票傾向の4画面で同じ12都市を選べる。座標・名称とラベル配置は既存の気候タブから共用。`popCity`で選択を保存し、4画面間と履歴移動で復元。選択だけではカメラを動かさない。
- デスクトップは左の地図をスクロール中も見られる配置。狭い画面は地図の下に解説を置き、都市選択時に解説を表示して、地図へ戻るリンクを提供。地図上の名前が見えない場合にも12都市の一覧から選べる。
- 州・郡のプルダウンは廃止。地図をクリックした場合の数値確認は地図下に残し、未選択時は表示しない。
- 人種・民族にはドイツ系、イギリス系、アフリカ系、ヒスパニックの歴史を地域名とともに掲載。英系・独系の祖先分類は現行8区分とは異なる。白人区分を英系・独系の分布と呼ばない。
- 円グラフは軽量SVGと常時表示の数値凡例。人口はNCHS郡分類の人口加重、人種・民族は重複のない8区分、投票は2024年全国得票の3区分。全国値にはアラスカ・ハワイを含む。
- 宗教は確認済み値94.9%を実際の角度で示す。100%との差5.1%は「未表示分（差分・丸めを含む）」とし、未取得の2分類に割り当てたり、確認済み値を100%に引き伸ばしたりしない。

## 宗教が止まっている理由

画面と原表受け入れ処理は実装済み。Pewの州別集計をまとめて取得・再掲載する方法・条件が未確認で、州別行は0件。今回、新しい州別推計は追加していない。

[Pewの利用条件](https://www.pewresearch.org/about/terms-and-conditions/)は適切な表示を伴う利用を認める一方、主要部分の再掲載や無許可の自動収集に制約を設けている。すべての転載が禁止、必ず有料、とは判断していない。許諾の問い合わせは送信していない。既に承認された全国値と欠測表示の公開は継続。

## 軽さと確認

追加の統計API呼出し、地図インスタンス、大きな図表ライブラリーはない。既存の圧縮地理データと遅延読み込み・最大2都市圏キャッシュを継続。人口コントローラー単体を依存モジュール込みで束ねた参考容量はgzip 14,713 bytes（都市解説・共用ラベル配置を含む。共通地図本体・HTML・CSSを除く）。

確認対象は、12都市と気候カタログの一致、URL復元、全国値・カメラの保持、遅延データ競合、未取得宗教の円グラフ、代替図の座標、既存の自然環境・農業・産業への影響。ブラウザーのローカル接続は環境側で拒否されるため、公開後に既存の画面検証ページで確認する。
