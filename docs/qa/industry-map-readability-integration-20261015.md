# 13地域の産業地図：分野別表示と可読性の統合

基準は main `6f3d4a27c17bf205220d0eb44563975af2bcbdad`。資源・エネルギー、製造業、サービス業の表示集合を分け、現在の分野に属する地点・注記・線・凡例を使う。資料に意味のある共有所属は保持する。原座標、元データ、規模・単位・年・出典を表示の都合で作り替えない。

地図外の品目操作はプルダウン又は折りたたみ一覧。産業名を先、場所を補足とする短い注記を使い、同じ分野で品目・拠点を選んでも注記割当とカメラを動かさない。全項目の詳細と出典は右欄・下段・一覧で読む。

## 統合で調整した動作

- アフリカは3つの独立SVG地図枠をタブに接続。一般分野の国別形状と産業専用形状を分け、人口・農林業等の既存表示へ干渉させない。
- 南アジアは地域担当の工程別モデルと短距離ラベル配置を共有MapLibreコントローラーへ接続。東アジアも3タブと分野内プルダウンに接続。
- 東南アジアの加工7拠点と中南米の加工8拠点も、元の宣言にある資源・製造への共有参照を保持。LNG液化、製錬、精製などは実工程と凡例で区別する。東南アジアの参照数は資源12・製造16・サービス9、中南米は資源27・製造45・サービス13。共有参照数は一意な施設数や数量の合計ではない。
- 東南アジア・アフリカ・メキシコは注記の産業名を先に表示。アフリカ・中南米は品目選択時も部門の注記と位置を維持し、限定表示でも残る注記の位置を保持。
- 米国は3主タブと1つの品目プルダウン。既存の建設・不動産は補助図に保持し、資料・旧URLを削除しない。中央アジア・西アジアの品目一覧は折りたたみへ接続。

日本の他分野、品目未選択の農林業統計、選挙サイトは対象外。既存世界7品目と農林業の公開成果を保持する。

## 検証の読み方

ローカルでは本番ビルド、配信情報検証、全単体1,435件（成功1,432、既存skip3、失敗0）、地域操作の検証を実行した。共有所属の最終調整は対象29件で再確認し、最終ソースの全体E2EはPR CIで検証する。農林業の保護検証は専用読解・品目切替ルーチンの元実装を照合し、既存の分野遷移テストも維持する。

実ブラウザー検証は既存 `Review regional industry additions` の13地域smokeで行う。主再現1896×996、補助1280×665 CSS px・DPR1.5、縦390×844を別contextで実行する。主再現の寸法はユーザー画像の寸法であり、元PCのCSS viewport実測とは扱わない。Chromeの `chrome://sandbox` を確認し、3分野の初期・選択画面、URL復元、カメラ・注記位置、出典、横はみ出しを記録する。

ローカルChromeはSUID helperの所有者不整合で起動できない。権限やsandboxを変更せず、代替Firefoxの通常取得もHTTP403で停止した。自動テスト・静的SVGの結果と、実ブラウザー画像の取得・目視所見は区別する。CIの最新結果、実画像レビュー、公開SHAと公開後操作は統合PRに記録する。
