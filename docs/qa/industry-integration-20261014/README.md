## ブラウザー証跡の扱い

欧州、東アジア、オセアニア、中央アジアの旧ローカルブラウザー検証と、既存の欧州一般・アフリカ一般レビューは、コードと記録からサンドボックスを無効にした実行と確認した。旧結果を受入検証に数えない。統合では無効化フラグ／オプションを削除し、`chromiumSandbox:true` と通常のrunner Chromeで再検証する。欧州の狭幅、東アジア21品目、オセアニア18項目、中央アジア11品目の検証を既存CIに接続した。既存CIで呼ばれる欧州一般・アフリカ一般レビューの無効化も除き、同じ通常Chromeで再検証する。未使用の保存用旧スクリプトや画像を今回の受入に数えない。

統合担当のローカルChromiumもSUID helperの所有者・設定不備で起動できない。設定や権限を変更しない。世界版CIの通常のartifactダウンロードは配信先403で拒否された。自動チェックの成功を画像の目視確認済みと扱わず、最終headの画像を確認できない場合はその不足を記録する。保存済み旧欧州画像の参照は、安全な新実行の受入確認とは別に扱う。

## プログラム検証と受入条件

全14成果を含む `f73e987b` のローカル全体検証は、単体1,400成功・3既存skip、E2E632成功・11既存ブラウザーskip、build・release成功、失敗0。ブラウザーskipを実画面確認済みと扱わない。13地域のPC・狭幅での主要操作26ケースと、世界7分野および追加された詳細操作は通常ChromeのCIで確認する。後続の東南アジア狭幅の修正を含む最終headの全体CI・詳細ブラウザーCIが受入条件で、各runの対象headと結果をPR362のチェックで照合する。

既存検査が期待していた米国との画素寸法一致は、今回の米国PC地図拡大に合わせ、欧州自身の従来の可読幅・地域地図の高さ、左右配置と各地域の操作を検査する形に変更した。新しい品目・専用ページについては、その実際の有効な選択肢と出典開閉を操作する。

世界版ではTSMCのJASM計画55,000枚/月（2022年、12インチ）、Gasscoの2025年欧州向け114.9 billion scm、worldsteelの2024年鋼材見掛消費（中国856.6・インド147.9百万t）を一次資料と抜取り照合した。全原表の再収集を意味しない。東アジアの公開記事URLの例外は国家能源集団の実際の公開ページを確認し、完全なそのURLだけを対象とする。別の文脈でのID検知を保持する専用テストがある。

## 公開時の確認

全範囲の受入後に統合PRをmainへマージし、既存pages.ymlの公開結果、Pages deployment、`_release.json`のSHAを照合する。公開後は同じSHAを固定して主要操作を再確認する。世界版7分野については既存の産業レビューworkflow_dispatchに、公開サイトでの全工程・地点・供給線・4画面寸法の検証を追加した。新しい公開先や有料サービスは追加しない。

統合で判明したOceaniaの中間PC幅（地図731.074×471.875）でのラベル未収容による初期化停止は、全18名称を保つコンパクト配置へのフォールバックで修正。実寸の回帰テストを追加した。欧州21分類、西アジアと中央アジアの専用ページに既存検査を追従させ、共通農林業の旧ハッシュ検査は承認された産業接続の差分だけを除いて保持している。

通常Chromeの再検証で、Oceaniaの札が既存案内点を覆うクリック妨害を発見し、8案内点の領域を避ける配置へ修正した。全18札と地点座標を保ち、PC・狭幅の回帰検査が成功。中央アジアではドラッグ後のクリック抑止を明示的なリセット・分類切替で解除する。東南アジアでは狭幅の設備能力・年を札内で折り返し、表示集合を減らさず文字切れを修正する。中央アジアの他分野から産業へ移る操作は、旧コントローラー内での切替を解除して専用ページへ通常遷移する。390px幅で約249px高だった東南アジア産業地図には、狭幅で札と凡例を収容できる高さを確保する。これらの実画面操作は最終CIで受け入れる。

公開後の13地域の選択・出典表示・同一地図寸法・再読込・狭幅検証は `scripts/verify-industry-pages-smoke.mjs` で行う。ビルドへの同じ検証も既存産業レビューCIの独立ジョブで先行実行する。
