# 東南アジア農林業概説：地域統計の採用前調査（2026-10-08）

この文書は初期概説の指標候補を比較するための資料であり、新しい地域自給率や貿易先の値を採用する決定ではない。品目選択後の説明と初期概説は別に扱う。漁業の調査・タブは別担当とする。

## 範囲と年

- [ASEAN公式の加盟国一覧](https://asean.org/member-states/)では東ティモールの加盟日は2025年10月26日で、現在は11加盟国。2024年以前を「当時のASEAN11」とは呼べない。
- [ASEANstatsの商品貿易データ](https://data.aseanstats.org/trade-annually)はASEANを報告主体として選べ、HS2〜8桁、相手国、輸出・輸入の選択肢を持つ。ページ表示の最終更新は2026年7月1日。東ティモールの完全系列は2021年以降を追加し、2020年以前は含めないと明記する。2025年分は同日現在の入手分に限る。利用条件はCC BY 4.0。抽出時に報告主体・相手・HS・取引方向・対象年・東ティモールの扱いを記録する。
- 保存済み[FAOSTAT国別農林業](../../public/assets/atlas/asia-farming-v1/manifest.json)は地理的な東南アジア11か国の2015–2024年。保存済み[UN Comtrade貿易](../../public/assets/atlas/asia-trade-v1/manifest.json)は同じ11か国の2023年輸出入額。どちらも「その年のASEAN加盟国」の系列とは別物。
- 保存済み[世界分母照合済みのFAOSTAT系列](../../public/assets/atlas/southeast-asia-v1/world-shares.json)は米・トウモロコシ・大豆（生産量）と丸太材・製材・森林面積。2024年の11か国合計は米10、トウモロコシ9、大豆8か国の報告値だけなので、作物3品目を完全な地域の世界比とは呼べない。林業3系列は11か国すべてに値がある。

## 中央：特徴的品目の輸出入相手

ASEANstatsの公式「ASEAN」報告主体・相手国・HS・輸出／輸入を組み合わせた取得を第一候補とする。2023年の保存済みComtradeでHS15油脂類、HS1511パーム油、HS1006米などは候補として比較できるが、地域単位の品目別相手国は保存されていない。現行のインドネシアHS15の円図を地域全体の図へ読み替えてはならない。

域内・域外を分けて表示する。地域の対外相手国円図なら、加盟国間の貿易を除いた**域外輸出**または**域外輸入**の単一方向にする。域内も示す場合は独立区分にし、ASEAN内の輸出と輸入を足して「総貿易量」にしない。国別輸出を単純合算すると、域内取引と再輸出が含まれ、同一商品の複数回の越境が計上され得る。[ASEANstatsも域内・域外貿易を区別して報告](https://www.aseanstats.org/wp-content/uploads/2024/05/ASB-202405-03.pdf)する。候補品目の確定には公式データの抽出値と欠測・再輸出の検査が必要。

## 右：カロリーベースの食料自給率

ASEAN全体について定義・年次・方法が確認できる**公式カロリーベース自給率系列は未発見**。[FAOのFood Balances公表](https://www.fao.org/statistics/highlights-archive/highlights-detail/food-balance-sheets-2010-2023/en)は2010–2023年、178か国、449品目の需給勘定で、食料供給エネルギーを含むが、この値は自給率ではない。[FAOの食料需給表ハンドブック](https://www.fao.org/4/x9892e/X9892e02.htm)は生産・輸入・輸出・在庫増減から国内利用を考え、飼料・種子・加工・損失・人の食用を区別する。[FAOが示す品目別SSR](https://www.fao.org/4/x9892e/X9892e04.htm)は生産／（生産＋輸入－輸出）であり、そのまま地域全体のカロリー自給率にはならない。

独自算定案を検討するなら、全11か国・全対象年の需給勘定、品目から加工品への変換係数、食用エネルギー換算、輸入原料・再輸出・域内移動の控除、在庫・飼料・非食用の処理と、分子「域内原産で人の食用に供されたkcal」／分母「域内で人の食用に供された総kcal」の定義を固定する。国別自給率の単純平均、生産重量／食料供給重量、貿易**額**／食料供給量は使えない。方法が合意されるまで右の推移図は作らない。代替ならFAOの「一人一日当たり食料供給kcal」推移を別名で検討できるが、これも自給率ではない。

## 左の2候補

1. **世界生産での位置（品目別）**：ユーザーの問いに最も近く、既存FAOSTATの同年・同単位のWorld分母を再利用できる。ただし現状の作物3品目は国欠測があるため「報告国の下限値」と明記する必要がある。油ヤシなど上位作物の世界分母は保存されていない。
2. **地域の米生産を担う国**：既存の2024年FAOSTAT国別系列で、メコン・紅河デルタとジャワの地図上の位置に結びつけやすい。現在の米は10/11か国に値がある。輸出量や国内向け量への読み替えを避ける。

左をどちらにするか、中央の品目と輸出／輸入・域内／域外の選択、右を独自方法で算定するか別指標にするかは未決のまま保持する。
