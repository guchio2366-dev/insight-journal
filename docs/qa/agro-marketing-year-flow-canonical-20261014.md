# 同一販売年度の生産・国内利用・輸出原表

`scripts/prepare-agro-marketing-year-flow.py` は保存済み `scripts/data/wasde0926.txt` のWASDE-675（2026-09-11公表）だけをオフラインで解析する。原物SHA-256は `de4baa0dc24769b2d8cc153bac488049d905b5c8aa1fec9696e2d4e13036e285`。各国の2024/25生産・輸入・国内利用・輸出・期首／期末在庫と、同じ提供元・版・年度・商品基準の公表World生産を保持する。国合計からWorldを再構築せず、2025/26推計・2026/27予測は採用しない。

生成先は `src/data/atlas/agro-marketing-year-flow.json`、接続APIは `agroMarketingYearFlow(countryCode,seriesId)`。小麦p18、とうもろこしp22、丸大豆p28の20国品目行に、米国だけの精米換算米と綿繊維を加えた22件・10国・5系列。元行の文字列、各セルの原桁、公表World元行、量の丸め差、出典ページ・ハッシュを保持する。RUSは既存品質方針の確認を別途要するため除外し、EU・地域行を国へ割り当てない。対象に元行がない場合はundefinedで、0を作らない。

販売年度は国ごとに期間が異なり得る。元TXTには脚注全文・開始終了日の定義がないため日付はnullとし、共通暦年と呼ばない。小麦の生産は原穀で、用途・輸出は原表の小麦基準数量を保持する。小麦粉・製品を含む換算範囲は原脚注の追確認が必要であり、未製粉小麦だけのHS1001相手数量とは自動一致させない。Domestic Totalは食用・飼料・種子・加工等の合計で、掲載されたFeed／Crushはその内数。期首在庫・輸入があるため、国内利用と輸出を当年国内生産そのものの直接分割とは扱わない。

米国米のprimaryはp24の公表Milled Basis・百万t、`rice-milled-production`。生産7.05、World542.30、国内利用5.30、輸出2.87、期首1.27、輸入1.56、期末1.71。このモジュールで籾・ブッシェルを精米へ換算していない。一般QCLの `rice-production` は籾なのでaliasにせず、米国の既存米選択だけ明示して接続する。

米国綿花のprimaryは `cotton-lint-production`、百万480ポンド俵。国別数量はp17の2024/25先頭列、World119.53はp26。両表の米国生産14.41・国内利用1.70・輸出11.90・期首3.15・期末4.00・未勘定−0.04の一致を照合する。輸入はp17の数値0.00を掲載精度の丸め値として保持し、実量が厳密に0とは判定しない。p26の輸入セル `3/` は脚注記号として保存し、0へ推定変換しない。未勘定−0.04は符号付き独立項目で、正の用途帯や食用等へ押し込まない。QCL328の種子付き未繰綿とは異なるためaliasにしない。

同年度・同商品基準の全相手国輸出数量は全22件で未収録、`exportDestinations=null`。したがって生産／World→国内利用・輸出までを補えるが、輸出先まで完全に結ぶ候補は0件。2025暦年GATSや異なる乳換算・枝肉／製品重量・金額の輸出先を接合せず、再輸出・輸入原料の最終仕向けもこの需給表から推定しない。
