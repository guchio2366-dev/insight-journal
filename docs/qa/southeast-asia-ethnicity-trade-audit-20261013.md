# 東南アジア：民族と米の供給・仕向け原表の照合

## 民族分布

- 保存済み [GeoEPR 2021 / EPR-ED 2021 のマニフェスト](../../public/assets/atlas/asia-settlements-v1/manifest.json)は2020年に有効な政治的集団の居住域を採用。東南アジアの民族区分はビルマ、タイ・ラーオ、クメール、キン、マレー、ジャワ・スンダ、ダヤク、パプア、モロ、シャンの10区分と重複域。集団の割合・人口密度や全住民の民族分類ではない。元の境界は [ETH Zurich GeoEPR 2021](https://icr.ethz.ch/data/epr/geoepr/GeoEPR-2021.geojson)。
- [フィリピン統計庁の2020年国勢調査](https://psa.gov.ph/content/ethnicity-philippines-2020-census-population-and-housing)は17地方の上位民族を示す。保存済みの7値（イロコス58.3％、カラバルソン74.4％、ビコール78.8％、西ビサヤ67.6％、中ビサヤ61.4％、東ビサヤ64.2％、バンサモロ26.4％）を原文と照合した。分母は各地方の世帯人口。バンサモロのマギンダナオ26.4％を地方全体の単一集団とみなさない。地図上の札を4件から7件へ増やし、右欄では7件すべてを維持した。
- このリポジトリには2020年国勢調査の地方境界とPSA値を対応づけたポリゴンがない。[フィリピン公式Geoportal](https://geoportal.gov.ph/)と[国連人道データの行政境界カタログ](https://data.humdata.org/dataset/cod-ab-phl)を確認したが、手元の形状と2020年国勢調査の17地方定義・コードの一致を検証していない。したがって行政区の塗り分けは加えず、地点札を地方を探す目印と明記する。現行のGeoEPR境界をPSA統計の境界へ読み替えない。

## 米の供給・仕向け

- 保存済み [FAOSTAT国別原表](../../public/assets/atlas/asia-farming-v1/manifest.json)は2015～2024年、地理的東南アジア11か国。既存の2024年籾米生産表示は10/11か国に値があり、作物生産重量（t）。輸出・国内仕向けではない。
- 保存済み [UN Comtrade貿易マニフェスト](../../public/assets/atlas/asia-trade-v1/manifest.json)と[照会条件・照合ハッシュ](../../public/assets/atlas/asia-trade-v1/provenance.json)は2023年、HS2017、current USD、各国報告。米HS1006について輸出は10/11、輸入は11/11か国に対世界額がある。11か国表として輸出・輸入を別列に掲載した。東ティモールの輸出欄は欠測として保持した。
- 米HS1006の相手国別表、国内向け数量、在庫・飼料・加工別の仕向けは保存済み原表にない。タイとベトナムの輸出額やインドネシアとフィリピンの輸入額を結ぶ矢印は、その二国間取引の証拠にならない。国別額の合算も域内取引や再輸出を含むため、地域純供給や自給率と呼ばない。
- [UN Comtradeの公的入口](https://comtradeplus.un.org/)と既存のAPI照会URLを確認したが、追加の米相手国別照会はこの環境からHTTP 403で取得できなかった。403の迂回や認証変更は行わない。[ASEANstats年次貿易](https://data.aseanstats.org/trade-annually)も報告主体・相手国・HS品目・年の指定が可能だが、未取得値を表示に補わない。元資料を取得できる環境では、2023年HS1006、輸出方向、各報告国、相手国、域内・域外、再輸出の扱いを固定して照合する。
