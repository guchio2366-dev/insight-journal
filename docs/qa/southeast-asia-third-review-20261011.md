# 東南アジア第3次表示確認・資料範囲

## 産業・実画面

13産業群の選択を右欄の最初の主操作とし、国別統計・比較・資料は開閉欄に移した。30地点の一覧と地域供給網も開閉欄に置き、選択地点の短い解説を先に見せる。PC画像検査はMapLibre canvas、フォールバック非表示、地点マーカー描画を待ってから撮影し、ゴム・タイヤは再読込後も確認する。農畜産初期図、作物・家畜選択、メコン選択後も他の水系を残す画面、標高・民族・宗教の画面を追加した。

## 地形の紫の輪郭

[NOAA ETOPO 2022](https://doi.org/10.25921/fd45-gt74)の既存60秒角標高格子を地図用Web Mercator格子に平均化した値から、`scripts/prepare-southeast-landform-extents.py`で再現できる抽出を行う。7つの着目地形ごとに公表名を探すための窓を定め、その**窓内の標高条件**に該当する格子の輪郭を作った。低地は0–50m、高原は200m以上、山地は500m以上、島は連続する0m以上の陸域。窓の矩形を地形境界として描かず、条件に一致する領域だけを紫の線で表示する。3格子程度の孤立片を除去している。海岸の粗い格子、窓の端、標高だけでは名付けられない地質境界は制約である。この面は正式な地形区分や洪水想定域ではない。

## 民族・宗教の補完

[フィリピン統計庁の2020年民族集計](https://psa.gov.ph/content/ethnicity-philippines-2020-census-population-and-housing)から、地域別の民族回答7例を採用した。地図の丸数字は地方の世帯人口に占める割合であり、丸の位置は地方を探すための目印。居住域の境界やその地点の人口比ではない。GeoEPRの政治的集団の面とは別の出典・分類と記した。BARMMにはマギンダナオ26.4％のほかタウスグ23.3％とマラナオ22.7％もあり、最多分類だけで地域を塗らない。

宗教は[ベトナム2019年国勢調査公表](https://vietnam.un.org/en/28931-results-population-and-housing-census-0142019)、[フィリピン2020年国勢調査](https://psa.gov.ph/content/religious-affiliation-philippines-2020-census-population-and-housing)、[東ティモール2022年国勢調査](https://timor-leste.unfpa.org/sites/default/files/pub-pdf/final-main-report_tlphc-census_2022.pdf)の国全体の回答を、国の代表位置の円と右欄の内訳で表示する。ベトナムは全人口、フィリピンは世帯人口、東ティモールは3歳以上。年と分類も異なる。ベトナムの残差は「宗教なし」だけを意味せず、民間信仰や儀礼の有無も示さない。GeoEPR/EPR-EDの居住域と合算しない。

上記以外の国については検証済みの同一定義の細地域割合をこの便で追加していない。未掲載を0％や特定集団の不在として表さない。
