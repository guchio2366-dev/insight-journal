## 設計からの実装上の調整

実行環境が起動しないため、既存の分類PNGをブラウザのCanvasで最近傍サンプリングし、選択区分の透明マスク・境界を生成する。ビルド時にGeoJSONを作る方式は採っていない。幅最大1600pxの描画用派生画像とし、分類の算定・栽培適性の判定には使わない。元の赤チャンネルの分類IDを既存凡例と照合し、NODATAを除外する。

地図の上に一つのSVGを重ね、既存のMapLibre投影、または既存代替図のWebメルカトル投影を使う。別の地図インスタンス、新しい依存パッケージ、PRISM/WBDの再取得は不要。代替図では本土全体表示を維持する。
