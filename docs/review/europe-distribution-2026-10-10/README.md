# 欧州の農業分布：主要国と地域例の根拠

基点は `ab2bf51581f6874fb141b5e858892c7a2faf9f2e`。このDraftは既存の品目別格子を残し、乳牛・肉用繁殖母牛、ワイン用ブドウ畑、オリーブ樹園について、資料が明示する**主要国**と一部の**地域例**を重ねます。世界シェア・貿易・自給率統計には触れません。

## 今回、地図で確かめられること

色面は従来のFAO GLW4（牛・豚・鶏・羊の推計密度）とSPAM 2020（収録済みの作物集合区分）のままです。四角い国名札は資料が挙げる主要国を示し、果樹・園芸の「葡」はワイン用ブドウ畑、「オ」はオリーブ樹園です。**割合・面積・細かな地域例は右の説明へ移し、果樹の初期画面には丸印や品目名の大きい吹き出しを重ねません**。品目色は地図内の凡例に残し、選択は地図下の品目一覧からできます。国の中の札位置は対象国を識別するためのもので、その地点や国土全域に生産があるという意味ではありません。畜産の丸印は資料が値・特徴を記述した地域の目印です。いずれも農場座標や統計地域の境界ではありません。値のない国をゼロと見なしません。

### 原表取得の実行記録

実際に失敗したのは次の**一つのURLだけ**です。Python `urllib.request.urlopen` で通常の読み取りを実行しました。

```text
GET https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/ef_lsk_bovine?lang=en&time=2023
query: lang=en, time=2023
result: URLError: <urlopen error Tunnel connection failed: 403 Forbidden>
```

これは接続トンネルの失敗で、Eurostat APIからのHTTP本文・ステータスは受け取れていません。`vit_t1` と `ef_lus_orcholives` のAPI、および `ef_lsk_bovine` の別クエリは**未試行**で、同じ403と扱いません。失敗URLを繰り返し呼ばず、接続設定の変更もしていません。上記の公表記事は通常の閲覧で内容を確認できました。

## 独立した残件：地下水

[PANGAEAのIHME欧州図](https://doi.pangaea.de/10.1594/PANGAEA.855274)はCC BY 3.0の2008年の図モザイクで、地下水の帯水層・水理地質の定性的な資料です。地下水残量、年間使用可能量、安全な揚水量ではありません。先に用意されたC4 Berlinの投影済み画像のmanifestでは範囲はおよそ東経2.11–15.37度、北緯48.76–55.96度で、欧州全域ではありません。原図には分類コード帯がなくRGBと線・文字が混在するため、色だけを自動分類しません。

Libraryの画像、manifest、凡例を正規の転送手順で準備しましたが、三つとも `download failed` でした。指定された一度の再試行も同じ結果で、実行環境には画像・凡例のローカルファイルがありません。manifestの文字情報は読めましたが、原画像と凡例を開けず、基図との位置合わせも確認できません。地下水レイヤーは追加していません。今回の再修正では転送を再試行していません。
