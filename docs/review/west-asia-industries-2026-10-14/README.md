## 表示・操作の契約

- レンダラーは地域専用 SVG、HTML の産業名、固定された地理パス。外部タイル・有料APIを追加しない。
- 地図内のラベル配置は分類・画面寸法・手動カメラのみから決める。産業・国・地点の選択によって位置を動かさない。
- 初期右欄は地名・分布と集積理由。統計は地図下の3列と定義・出典付き表。
- 同一年・単位・製品段階の全国値だけを国の色に使う。企業・都市・空港・港の値を全国へ配分しない。未取得は地色で0ではない。
- 地点は概略位置。本社は菱形、加工・製造は四角、採取・サービス等は丸。点の数や大きさは数量ではない。
- 引出線は産業名への案内で、取引・物流・パイプラインの実経路ではない。実際の取引線は今回追加しない。
- URLに分類・産業・地点・国・明示した単独表示・手動カメラを保持。再読込・戻る/進む・分類のキーボード操作・地図の移動/拡大/復帰を検証。
- モバイルでは地図、産業ボタン、解説、統計の順。ホバーだけに依存せず一覧からも地点を選べる。

## 統計・出典の限界

各行に年・単位・対象と一次出典。2026年資料内の2024/2025年実績と、2026年の現在稼働を区別。能力・計画・会社の全世界売上を国内生産としない。農業一次生産を衣類・化学肥料など加工製品に合算しない。

USGSのアクセスできる公式国別本文・表、OPEC ASB、IGU、各国当局と企業の公表を使う。Maaden 2025年報全文403のため、検索索引の販売670万tは主要表から除く。バーレーンiGAの17.6%は公式検索索引で確認した速報と明記。白物家電とホウ素の世界分母方法、狭い情報サービス世界シェア、未収録国の細分値は未取得として残し、架空の数量・工場・ゼロを作らない。これらは画面に表示した根拠の限界で、採用品目の未実装ではない。

## 検証の実行

```sh
npm test
ASTRO_TELEMETRY_DISABLED=1 npm run build
node --test --test-concurrency=4 tests/e2e/atlas-west-asia*.test.mjs
npm run verify:release
REVIEW_CHROME_PATH=/usr/bin/google-chrome node scripts/verify-west-asia-industry.mjs
```

実画面の自動検証は 1920×1080、1440×1000、1024×768、390×844、DPR1。3分類の全初期画面と全産業の選択・地点・単独表示・解除、ラベルの不重複/枠内、欠測、履歴、再読込、キーボードカメラを確認。スクリーンショットとJSONは `/tmp/atlas-canada-qa/west-asia/industries-20261014`。既存CIのカナダQAアーティファクト収集範囲に入る。

ローカル環境のChromiumはSUIDサンドボックス設定不備で起動不可。サンドボックス解除・権限変更は行わない。Firefoxの通常インストーラーも配布元403（Domain forbidden）で失敗し、回避はしない。通常サンドボックスのChromeを持つ既存CIで実画面検証する。
