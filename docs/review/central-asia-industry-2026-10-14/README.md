# 中央アジア主要産業：11品目の実装と検証

対象はカザフスタン、ウズベキスタン、トルクメニスタン、キルギス、タジキスタンの5か国。南アジアと別URL・別表示を維持する。main `63e998cc16e671230b3c1a9d0a95803e1d6d0545` を基点とする独立ブランチで、中央アジアの主要産業だけを変更する。マージ・公開は行わない。

承認済み11品目は石油、天然ガス、ウラン、銅、金、水力発電、紡績・織布・衣料加工、製粉・小麦粉、輸送・物流サービス、観光・旅行サービス、クロム鉱石・フェロクロム。三分類の品目数をそろえるための追加はない。銅とフェロクロムの同じ加工地点を資源・製造に重ねて表示し、同じ統計を合算しない。

## 要件との対応

| 要件 | 実装・確認 |
| --- | --- |
| 11品目をすべて残す | 独立した品目定義・選択ボタン・地図位置・品目固有の統計。全品目を実ブラウザーで選択する。 |
| カナダの三分類を参考にする | 地図と右の概説を先に置き、地図下に「規模と稼ぎ方」「地域の集積・供給先」「世界での位置」の3列。狭い画面では縦に並べる。 |
| 地図は産業名が主役 | 固定サイズの産業名、補助の地名・工程・地域数量。記号の大きさに生産量を対応させない。 |
| 選択で位置を動かさない | 配置の入力は分類・画面寸法・カメラ範囲。産業・地点の選択と「この産業だけ」は既存の位置で強調・表示を変更する。全ラベルの座標と地図範囲を比較する。 |
| 工程と地理の範囲を明記 | 採掘、選鉱、製錬、紡績・織布・衣料、製粉、サービスを区別。企業売上をGDPにせず、州の数量を都市・工場へ配分しない。 |
| 数字の年・単位・分母・出典 | 各統計に範囲、定義、速報・推計等、一次リンク、必要な分母と計算式を保持する。未確認はnullであり0ではない。 |
| 本物の地理と確認済みの工程 | 既存Natural Earth国境をSVGで描く。確認した37案内地点。新しい取引・輸送ルートや工場数を推定しない。 |
| 建設中と実績を混ぜない | ログンは「一部稼働・建設中」を破線の記号と本文で表示。完成後の能力や輸出計画を現状に加えない。 |
| 他地域の改修をしない | 共通ページの分岐は `focusId==='central-asia' && initialField==='industry'` だけ。南アジアは既存の独立描画を実画面で確認する。 |

全数値・位置・出典の対照表は[出典台帳](../../../data-source/atlas/central-asia/industry/README.md)、実装の契約は[src/data/atlas/central-asia-industry.ts](../../../src/data/atlas/central-asia-industry.ts)。

## 地理・数量の注意点

国境形状と地点は44°Nを標準緯線にする正距円筒図法で同じ変換を使う。5か国の形状全体から初期範囲を求める。表示点は操業・集積地域の案内位置で、敷地境界や生産量の重心ではない。ボズシャコル・アクトガイには企業の尾鉱施設座標開示を使い、操業実績は2025年資料で別に確認する。

州別の繊維生産・旅行代理店売上は州等全体の値として表示する。接近した同産業の案内点をまとめる場合も、年・単位・出典が一致する地域値だけを合計する。タシケントの衣料1–8月と盆地の繊維1–7月を加算しない。引出線は案内点と産業名の対応で、実際の輸送線ではない。

カザフスタンのtU（ウラン金属含有量）とNavoiyuranのU₃O₈（酸化物重量）は別単位。輸送サービスには管路・旅客等を含み、旅行サービスには業務・親族訪問等を含む。商品の需給式はサービスへ適用しない。丸紅・伊藤忠への契約売上は日本の最終燃料消費量ではない。

## 確認方法

```sh
npm test
ASTRO_TELEMETRY_DISABLED=1 XDG_CONFIG_HOME=/tmp/central-asia-config npm run build
npm run test:e2e
npm run verify:release
CENTRAL_REVIEW_OUTPUT=/tmp/central-asia-review node scripts/verify-central-asia-industry.mjs
```

`verify-central-asia-industry.mjs` はproduction buildをlocalhostで配信し、1920×1080、1440×1000、1024×900、390×844（DPR 1）で3分類と全11品目を確認する。分類・品目・地点選択、同一加工地点の分類切替、選択解除、限定表示、URL再読込・履歴、国の強調、キーボード操作、パン・ズーム・全景、実タッチでの選択・2本指拡大・1本指のページスクロール、ラベルの枠内配置・重なり、統計3列、南アジアの既存描画を検証する。`review.json` に実際の寸法・座標・結果・検証したコードSHAを記録する。

実行環境のChromiumのSUID補助プログラムは起動時に所有者エラーとなる。検証はPlaywright標準のChromium sandbox無効設定を使い、既存の実行環境サンドボックス内でローカルビルドだけを閲覧する。OS権限・ファイル所有者・セキュリティ設定は変更しない。この設定と検証対象はJSONにも記録する。

## 正直に残す不足

ガスの最新の品目単独GDP・輸出金額、製粉単独の付加価値・雇用、ウズベキスタンの地域別製粉数量、2025年フェロクロム製品別値、繊維製品・輸送サービスの同一定義の世界シェアは未確認。石油・ガスの世界比較は確認できたEI 2025年版の2024年値を使い、2026年版の全文数値は未検証と表示する。カザフスタン輸送サービスの確認済み値は2024年。

これらは未実装品目ではなく、統計上の未確認範囲。地図の地点がない地域も生産ゼロを意味しない。一次資料の国・企業・州の範囲を5か国の地域合計へ勝手に広げない。
