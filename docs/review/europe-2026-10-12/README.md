## 実装した部分

- 海岸線・国境はNatural Earth公式維持リポジトリの実1:10m形状へ更新。元3,182頂点から103,907頂点。表示枠での切り出しのみで、平滑化・細分化による見かけの細部は作っていない。出典commit・SHA256・公有条件は [取得記録](../../../data-source/atlas/europe/detailed-coast-2026-10-12.json)。SVGでは同じ国形状を`defs/use`で再利用し、操作地図の詳細形状はgzipを別取得する。旧格子の数値・国マスクは生成時の原形状を保持する。
- 農畜産3ジャンル、元16品目・数量格子・全集中域・地図下統計を保持。概略図は約4,000km²未満の小断片を省略（品目が全て消える場合は最大部分を残す）、新しい海岸で海側を切り落とす。断片を橋渡し・拡張しない。選択時は元の全集中域の輪郭を保持した表示用面を強調。ラベルは保持面内の実正値格子に固定し、局所7×7格子合計で持続した集中を選ぶ。小麦・トウモロコシ・ジャガイモは出典の実値を確認した東側の窓内に置く。北イタリア等を重要でないとする順位判断ではない。
- 国名／品目の札とアイルランドの「〇非」を撤去。「非」は2020年の北部・西部NUTS2における乳牛以外の牛395,751頭で、肉牛出荷量ではない。南部の乳牛1,124,842頭とともに右の説明へ正式名称で残す。牛・豚・鶏・羊に加え、酪農・生乳の別選択を提供。ただし酪農の分布面は原資料待ちと明示し、総牛数を乳牛面へ変換しない。
- 地図内の全体／拡大／縮小／描画方式ボタン群と気候のクリック説明札を撤去。都市名の下線、カーソル、hover/focusで操作性を示す。全都市のラベル配置を選択によって並べ替えず、リスボンも常設。北側を多く切り、PCの上部を圧縮する。共通の雨温図尺度と月別数値表を保持。
- 林業・雨量・標高の座標クリック円を除去し、右の数値照会は保持。樹木被覆にカウカス、運営会社で確認したラウマのパルプ加工拠点とコトカの木材製品輸出港を追加。代表点は工場境界・木材調達範囲・取扱量ではない。
- 河川初期図をライン／ドナウ／セーヌ／テムズ／ドン／ヴォルガ／ウラルの7名称へ整理。残る15名称の資料・解説は保存。小名称と線クリックを保持し、背景は既存ETOPO標高格子から生成した連続陰影。航空写真ではない。新しい解像度や海岸欠測の標高を補っていない。河道は引き続きNatural Earthの収録区間で、完全接続と呼ばない。
- 流域初期図の細かな識別色を、実MAIN_BASに対応する5水系の保存面へ統合。ドナウ／ドン／ヴォルガは各9区画、ライン／セーヌは各1区画。NEXT_DOWNが同じ保存組内へ接続することを確認。元の131区画、数値格子、選択輪郭は保持。国マスク・表示枠で切れた面であり、7自然流域の完成ではない。
- 地形名を山地・平原・海域・風の異なる小書式にし、退避を52px以内に制限。選択優先の再配置と長い引出線を抑える。等高線図にも主要山地・平原名を表示。500m色段階・等高線、250mm雨量線と青13段階は保持。
- 人口の地点を小さな十字へ変更。密度色面・首都・説明・統計は保持。宗教の31全国割合カードは撤去し、全国割合は右側に保持。**全国最大分類の既存色面は実居住分布の完成として数えない。**
- 使用言語の区分と、母語／家庭内使用／会話能力／公用語の区別を追加。チェコ2021年の原母語人数・第二言語・未回答を補足表に収録。民族へ転用せず、全国人数から国内の面を作っていない。全欧州の実使用分布は未収録。

共有変更は地域林業の再利用記録2ファイルにある欧州manifestのhash/bytes参照だけ。産業の3区分改編、他地域UI、公開・マージは行わない。
