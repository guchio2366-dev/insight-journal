## 宗派の広域図の追加（引継ぎ継続）

Pewの直接取得失敗を宗派全体の停止条件にせず、独立して取得できた[SMRE自身の標準化推計](https://www.smre-data.ch/en/content/download/159)（01/2018版・Appendix A、PDF57–63ページ）を使用した。[45か国・8分類の保存値](../../../src/data/atlas/europe/smre-religion-2010.json)は2010期＝原観測2006–2015年で、現在の分布図とは表示しない。SMREデータベースはODbL 1.0、SMRE内容はDBCL 1.0で、個別の元資料の条件は別に残る。[SMRE利用条件](https://www.smre-data.ch/en/content/privacy-policy-impressum)を凡例・国別詳細へ付けた。

初期図は45か国の最大分類を比較する色面で、カトリック、プロテスタント、正教会、イスラム教、宗教的帰属なし等を1枚で読む。最大分類が35%未満のドイツは分散。国の色は国内の均一性や宗派の領土を意味せず、全国値から国内の色帯を作っていない。国クリック／一覧選択で8分類の少数派も読める。資料品質は原表Appendix Aの評価を併記する（他付録の異なる品質値から上書きしていない）。

原表のISL・SRBは8分類合計98.5%、MKDは101.2%。公表値を保持し、不一致を国別詳細に明示して構成帯を表示しない。その他には未回答・不明も含まれ、無所属へ移していない。Pew2020の40か国・7分類、5対象の全国回答構成、7地域の公式抜粋は切替／国選択後に残し、分母・年・質問が違う資料を混ぜない。主題の初期図を局所例や大量の注釈で代替していない。

民族は追加原表の通常取得を確認したが、セルビア宗教自治体表・クロアチア自治体workbookはCONNECT403、ドイツ結果ページはweb readerの403。拒否後は停止し、原表を保有しているとは扱っていない。セルビアの公式発表・再利用条件は読めたが、民族自治体の全値は得られなかった。GeoEPRの公式コードブックは政治的集団の部分集合であることを示し、再配布条件も未確認のため完全民族図へ採用していない。原図／地域名付きの出典ある概略からも実装でき、全域共通GISを入力の必須条件にしていない。[取得証拠と利用できた資料](../../../data-source/atlas/europe/acquisition-handoff-2026-10-11.json)と[必要な最小入力](source-files-needed.md)を更新した。

追加部の [1920宗派図](culture-followup/religion-confessions-45-1920x1080.png) を目視し、地図・操作・全凡例が1080px内に収まるよう調整した。[操作記録](culture-followup/checks.json) はコミット前の作業差分を明示して保存。通常／簡易地図の45か国色面、8分類、既存地域値、Pewとの往復、無断自動ズームなしが成功。単体1128成功・3スキップ。欧州統合検査19件は18件成功後、宗教の説明を旧語句で期待した1件を正しい無所属分類へ更新し、その1件も再実行成功。最終headのCI結果はPRに記録する。

## 実装範囲と資料境界

- 農畜産の3ジャンルで既存の16品目の集中域を同時表示し、品目の件数切り詰めを外した。代表色面と、重なりで隠れる別品目の輪郭を分けた。ブドウ・オリーブと乳用・肉用を分離する元格子は未収録なので、その形状は作らない。
- 降水量の13帯を連続する青系に統一し、同じ250 mm等雨量線から段階色を再生成した。欠測を塗り足していない。
- 地形26名称を1920×1080の初期画面内に配置し、密集部分は引出線で地図上の位置につないだ。局地風の固定矢印は描かない。河川名と収録線は選択できる。線はNatural Earthの収録区間だけを強調し、完全な本流とは呼ばない。
- ドナウ川・ヴォルガ川はBasinATLASの `MAIN_BAS` で接続するレベル4の各9区画を一緒に輪郭表示した。公開格子は対象国と地図枠で切れているため、川の全流域とは呼ばない。
- 民族はONS 2021のイングランド・ウェールズ331行政区で、宗教はPew 2020の国別推計とONSの同行政区で出典・分母を分けた。両者の欠測を0にしていない。Pewの分類から宗派を推測していない。
- EEA ECRINSの公式データ取得口はこの環境からHTTP 403となった。[HydroATLAS](https://www.hydrosheds.org/hydroatlas) の BasinATLAS と RiverATLAS は集合データベースとして CC BY 4.0 であり、全流域と本流の検証候補になる。元のレベル4区画のハッシュと `MAIN_BAS`・`NEXT_DOWN` は [selected-inputs.json](../../../data-source/atlas/europe/drainage/selected-inputs.json) に記録済みだが、元の形状ファイルはこの作業環境に残っていない。公式 Figshare のダウンロードと API への通常の接続も HTTP 403 となった。全流域には国境で切っていない同一 `MAIN_BAS` の全区画、本流には RiverATLAS の `MAIN_RIV`・`ORD_CLAS`・`NEXT_DOWN` と独立した河口・河川名の照合が必要。今の図はどちらも満たさず、全流域・源流から河口までの本流とは表示しない。取得先と検証手順は [connected-basin-review.json](../../../data-source/atlas/europe/drainage/connected-basin-review.json) に記録した。別製品の HydroRIVERS を RiverATLAS として扱わない。
- [Copernicus CORINE Land Cover 2018](https://land.copernicus.eu/en/products/corine-land-cover/clc2018) は、ぶどう園（221）とオリーブ園（223）の別区分があり、公開図の候補になる。ただし土地被覆図であり生産量・収穫面積・品種分布ではない。25 ha の最小作図単位と2017–2018年の対象期間を明記する必要がある。公式 REST 配信先への通常の接続は HTTP 403 となり、元図形を確認・収録できていない。乳用・肉用の地域分布も現在の家畜総数格子から推定しない。
- 生乳の地域統計は Eurostat `agr_r_milkpr` の NUTS 2 表が候補。統計値の再利用条件と GISCO の境界形状の利用条件は別に確認する。地域を点で示すなら、統計地域の中心という意味、元表の年・単位・欠測を一緒に示す。家畜頭数を生乳量に置き換えない。
- 宗派の広域説明には [Pew の東・中欧調査（2017）](https://www.pewresearch.org/religion/2017/05/10/religious-affiliation/) と [西欧調査（2018）](https://www.pewresearch.org/religion/2018/05/29/religious-identity/) が候補だが、成人調査の対象・設問を現在の全年齢国勢調査の地方面に合成しない。セルビア2022の自治体実数は [統計局の原表](https://www.stat.gov.rs/en-us/vesti/20230616-st/?a=0&s=1104) と [再利用条件](https://www.stat.gov.rs/en-us/copyright/) を確認する。既存の7地域例を初期地図へ一括表示すると、中欧・バルカンで国別構成帯と重なり読めなかったため採用していない。広域の説明帯と局所の実数を別層にする必要がある。
- [MapSPAM 2020 v2.2](https://www.mapspam.info/data/) の独立したブドウ・オリーブ格子の有無は品目表で未確認で、[利用条件](https://www.mapspam.info/terms/) は CC BY-NC 3.0。既存の温帯果樹格子を品目別へ推測配分せず、新格子も収録していない。
- 農畜産の食品群別自給率帯、林業の輸出入先、地下水図、欧州全域の宗教細地域と民族分布は、対応する原表・定義・利用条件が揃うまで未表示とした。既存の出典付き集計は維持した。
