## 現状の区別と修正

現行中央アジアは既に `site.sectors.includes(state.sector)` で地点・注記を切り替えている。全分野の全地点を同時表示する問題ではない。一方、資源20地点のうち銅・クロムの加工5地点を製造にも重ねる例外、全分野共通の凡例、数量・年・範囲が入った付箋、長い引出線があった。844px横向きの旧製造地図では注記が一部収まらなかった。

今回、加工5地点は製造だけへ移した。資源15／製造14／サービス8の地図に分け、37位置レコードを1回ずつ表示する。国境・座標・資料・63指標・51出典・11品目の定義と数量は保持する。アルマリクは製錬の案内位置とし、近接する鉱山・選鉱の説明を残す。

- 地図内の産業選択ボタンを、透明背景の短い注記へ変更。選択は地図外の産業ボタン、案内点、地点一覧で行う。
- 数量・年・地域範囲は右の地点詳細と地図下の統計へ残す。異なる期間の量を注記で加算しない。
- 近接する同じ産業を集約。国・分野をまたがず、サービスでは機能・工程を分ける。歴史都市の文化観光とタシケントの旅行手配は別注記にする。
- 集約注記は実在する案内点のうち中心に近い点へ対応させ、架空の中心点は作らない。引出線は1集約につき最大1本・40 CSS px以内。近い注記には線を描かない。
- 選択・解除・限定表示によって注記の位置と地図範囲を変えない。分野別の凡例と、銅・クロムの工程に合う産業名・概説を表示する。

## 共通担当への受け渡し

共通UIは `resources / manufacturing / services` を1つずつ選択し、`data-central-sector` のボタンと同じ選択状態へ接続する。現在の地域コントローラーはこの属性、選択肢列 `data-central-choices`、地域root内のtablistを利用するため、共通コントロールへ置換する場合は属性・イベントの橋渡しが必要。

地域側では選択分野だけの地点・注記・対応線・凡例を構築する。背後の5か国の地理は再利用する。共通側で全分野の地点を併記したり、除去した数量付き付箋を再挿入しない。産業選択肢は地図外に置く。加工拠点の重複を復活させる旧 `data-central-overlap` 操作は今回のデータでは常に非表示。

モバイルのニュース欄と共通操作列が地図より先に並ぶ現行構成は変更していない。縦・横とも地図全体が初期viewportへ収まること、共通UI統合後の操作列の密度と画面全体の可読性は、共通担当で確認が必要。地図要素自体の確認とページ全体の確認を区別する。

## 追加確認に基づく統合上の注意

加工地点が複数分野に登場することは、工程理解に役立つ場合にはユーザーが許容している。選択分野の地点・注記だけを描くことと、全地点の単一分類を強制することは別の仕様。今回の中央アジア差分では加工5地点を製造だけへ移し、排他性を検査しているが、この制約はユーザー要求以上の地域側判断であり、全地域共通の必須仕様として採用しない。

工程上意味のある共有地点を統合担当が残す場合は、地域単体の単一分類条件とブラウザー検査の「資源に加工なし」「重複操作なし」の条件を調整する。注記は地点の実工程から銅採掘／銅製錬・クロム鉱／フェロクロムを分け、凡例も実際に表示する工程へ合わせる必要がある。現在のパッチを地域側でさらに変更せず、確認済み差分とこの注意を一緒に引き継ぐ。

成功したローカル実画面検査はChromium内蔵sandboxを無効にした起動であり、「ブラウザーの安全設定を維持した起動に成功」とは扱わない。内蔵sandbox有効のまま起動する代替方法は、この環境では未確認。
