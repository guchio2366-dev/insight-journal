## 実装した範囲

- `/atlas/japan/{agriculture,nature,industry,population}/` と日本側の独立した状態・controller。
- 東アジアの明示的な日本選択と「日本の全国図」リンクを同じ入口へ接続。現在の分野を引き継ぎ、元の分野・選択・主題・カメラを `return` に保存。日本内で分野を切り替えても元の東アジアへ戻れる。都市クリックや `place=JPN` だけでは移動しない。
- 既存のニュース欄を日本の記事に絞って左に固定。右は概説→解説→収録範囲、地図下は統計。初期状態は県を選択しない。
- 日本だけの Natural Earth 1:10m 基図、薄い県境、緯線。沖縄を実際の位置に置き、離島の移動や別縮尺の挿入図は使わない。基図が収録していない微小な島は明記。
- 主要産業：6産業・7地点の立地事例。産業名が主、都市・工業地域名が補助。別モードで47都道府県×25業種の2024年製造品出荷額等、原表の秘匿等の状態、製造業計の2025年6月1日従業者を表示。拠点記号の大きさを数量に使わない。
- 自然環境：札幌・東京・那覇の観測所と既存の雨温図部品。共通軸コードには変更なし。3観測所の平年値を比較できる。
- 農林業：全国の小麦需給・自給率、米生産量、森林面積・丸太生産等。全国値を県別の色に配分しない。
- 人口：既存GHSL 2020の5km集約値を元の画素端で切り出し、日本の詳細海岸線でマスク。内陸値の一致を全セル検証。都市域は東京・大阪・名古屋の既存資料を接続し、市域・県人口と区別。都市選択で自動ズームしない。

## 地理・資料の整合

`scripts/prepare-japan-atlas.py` はチェックイン済み資料だけから生成します（shapely / numpy / Pillow が必要）。原統計の数値・時点・状態を変更しません。県ポリゴンを全国の詳細国形状と交差させ、海岸線より外に数量が出ないようにします。簡略化の違いによる未割当部分に値は補いません。

日本用人口画像と数値グリッドは同じ配列から生成。既存5km集約グリッドの画素境界で切り出し、詳細国形状の画素中心マスクを適用します。高解像度化・補間はありません。0と欠測は区別して照会し、透明な陸地を海・無人地と読み替えない説明を付けています。

入力SHA256・生成ファイルのSHA256・収録範囲は `public/assets/atlas/japan-v1/manifest.json` に保存。METIの製造業計は原値合計 `381,654,010 百万円`、47県です。

## 未完成の範囲と見込み

4分野すべての全国主題図が完成したわけではありません。自然環境の全国気候区分・標高・河川と湖、農畜産・林業の県別国内原表、人口の県別人口・年齢構成、サービス業・資源・エネルギーの全国産業図は追加が必要です。

既存Beck/ETOPO画像は粗い国形状でマスクされており、詳細海岸線だけ置き換えても失われた島・沿岸画素を復元できません。Beck 1km原資料、ETOPO原資料、全国河川・湖、県別原表を取得し、同じ日本の海岸線・投影・欠測処理で作り直す必要があります。このcheckoutには該当する日本向け原資料がないため、気候や農業の精細な全国分布として再表示していません。MapSPAM/GLW4の5分角資料も精細な県内分布として扱いません。

残る4分野の整備・地理照合・PC検証は、原資料の取得と公開条件を確認したうえで **追加2〜4作業日が暫定見込み**。原表の粒度・河川データの加工量によって変わります。雨温図の全地域共通軸修正は別担当の変更を後で接続する前提です。
