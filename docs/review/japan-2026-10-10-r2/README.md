# 日本全国図：PC修正版

Draft PR #306 の初便を修正。最新mainの基点 `ab2bf515` は維持し、マージ・公開は行いません。

- ラベルの下送りを廃止し、地点近傍の候補を組み合わせて重なりを回避。引出線は最大64px、PCの文字サイズは維持。表示枠外・極端に狭い範囲では無理な線を作らず、選択可能な実地点と統計を残します。
- 地図は実際の文書内の位置から画面の残り高さを計算。右解説も画面内に収まる高さで独立スクロール。地図下の統計はページスクロールで読みます。
- 通常PCの1440×900 / 1024×768を検証対象に変更し、固定450px条件を廃止。地図が残り高さを満たすこと、右解説が収まること、7地点のラベル数・重なり・線の長さを確認する条件を追加。
- 東アジアの実MapLibreカメラを全分野で記録。東京選択の前後に有効なlng/lat/zoomがあることと、同一であることを検証。URLのzだけを確認する旧条件を置換。
- ブラウザは `chromiumSandbox:true` の標準起動だけを許可。追加起動引数なし。起動不能なら `unverified` と記録して停止し、無効化設定による再試行はしません。GitHub Actionsも同じスクリプトと標準Chromeを使用します。
