## 今回確認したこと

- 農畜産の元格子は再取得していません。条件を満たす558形状を保持してから表示用の輪郭を簡略化し、計529形状（従来96）、小麦25形状（従来5）です。フランス・ドイツの小麦域も初期画面に含まれます。
- 左ニュース枠を維持し、地図と解説の下にニュース枠を除いた幅で統計を置きました。地図右の文面は概説（分布の事実）と解説（理由）に分けています。
- 国名の選択は既存の国の概要への移動です。年・国の任意比較操作を画面から除きました。
- 地形、人口、水系・降水の初期表示範囲を調整しました。表示枠外はドラッグで見られます。
- 農畜産の下段統計に、FAO公表の2023年欧州地域の世界生産シェアと供給熱量9群、UN Comtradeの2021年対象報告地域の域外貿易相手先を掲載しました。年・集合・金額分母を各図に明記しています。自給率の同年・同群対応表は未確認のため数値を作っていません。
- 林業にはEurostat 2024年の4か国・産業用丸太と製材の供給と見かけ消費を掲載しました。在庫調整済みの消費量や最終用途とは呼んでいません。既存のFAOSTAT国別丸太・製材比較は補助表示です。
- 産業の10分野は地点と複合産業名を初期地図に表示。地形では名称・概略範囲を主にし、標高数値は500m等高線へ切り替えて読みます。降水量のmm表示は線上の検証済み点へ結ぶ目印を付けました。

## 次の統合で必要な資料と判定

一次資料を確認できた数値だけを収録しました。次は未収録の系列と形状が必要です。

- 農業：2023年の食品群別自給率は同年・同群・同じ地域集合に対応する原表が必要です。重量の比率を国内由来カロリー比と呼び替えません。
- 林業：欧州域外の輸出入相手先と世界シェアの推移は、加工段階と地域集合を揃えた原表が必要です。既存の丸太・製材国別比較は補助表示として保持。
- 地下水：BGR/PANGAEAの2008年Draftを現行図に位置合わせできるか検証。WHYMAPの権利未確定資料は採用しない。
- 宗教：4か国の地域表と各表の母集団・未回答を確認。全国値を地方へ複写しない。
- 流域：現在のBasinATLAS level 4区画を川全流域と呼び替えず、全流域・本流・河口の検証済み形状を追加する。
