# 世界の産業工程・7分野パイロット

対象ページ：`/insight-journal/atlas/industry/world/`。既存の `/atlas/industry/` の見出し直下から入る。国代表点の既存比較と、拠点・地域を区別した世界版を併存させた。

対象は半導体・太陽電池・蓄電池、天然ガス・原油／石油、銅・鉄鋼。レアアース、独立した日本ページは追加しない。

## 地図とバリューフロー

- PCは短い工程図と大きな地図を左右に併置。工程ボタンで対応地点を強調し、場所一覧を絞り込む。
- 半導体は「設計＋材料・装置→前工程→後工程・検査」。設計から材料を製造する誤った直列関係を避けた。
- エネルギーは産地・処理・受入／需要、金属は原料・加工・利用という読み方を共通操作の中で分ける。
- 地図内に選択地点の規模・単位・年・指標を固定表示。詳細カードに対象範囲と出典を示す。
- ラベルは全地点からビルド時に一度配置。工程・地点・供給線の選択でラベル位置、地図の範囲、点の大きさを変えない。
- 地図上の供給線は根拠がある接続・実績・販売公表に限定し、証拠の性質と年を併記。一度に1本だけ表示する。太さは数量を表さない。
- 工程図の矢印は一般的な流れであり取引線ではない。位置とラベルの細い引出線にも別の凡例を付けた。

## データの範囲

出典確認日：2026-10-14。古い計画能力は公表時点を表示し、現在の実稼働能力とはみなさない。会社の世界シェアや全社数量を工場へ割り振っていない。資料で拠点別数量が確認できない場合は、その範囲を明示する。

指定の過去3スレッド（東アジア・米国・欧州）の取得を試みたが、Personal Contextはこの会話で利用不可だった。既存 `industry-feature.ts`、東アジア拠点調査等を確認し、公開一次資料を各担当が再検証した。元の図表、写真、ロゴ、PVOUTラスタは転載していない。

## 検証方法

```sh
npm ci --no-audit --no-fund
npm test
npm run build
npm run test:e2e
npm run verify:release
REVIEW_CHROME_PATH=/path/to/google-chrome node scripts/verify-world-industry.mjs
```

ブラウザー検証は Chromium のサンドボックスを有効にしたまま実行する。1440×900、1280×800、390×844、844×390で7分野・全工程・全地点・全供給線、選択前後のラベル位置、URL復元、キーボード、横溢れを検証し、代表画面とJSONを `review-artifacts/world-industry/` に保存する。

既存の `industry-regional-review.yml` の同じジョブへ専用スクリプトを追加した。新たな公開先・デプロイ・有料サービスは追加していない。mainへのマージと公開は行わない。

## 実行結果

- データ整合性と固定ラベルの非重複テスト：通過。
- 単体テスト全体：1350件成功、3件既存スキップ、失敗なし。
- 静的ビルド：成功。
- 専用DOM操作テスト：3件成功。全7分野の工程・地点・供給線切替とURL復元を確認。
- 実ブラウザー：ローカル環境ではSUID sandbox helperの所有者・設定不備で起動拒否。安全設定は変更していない。別の通常ブラウザー取得も配信ドメインの403 `Domain forbidden`で拒否されたため停止。ローカル実画面確認・スクリーンショットは未完了。PRの既存レビューCIで同じスクリプトを実行する。
