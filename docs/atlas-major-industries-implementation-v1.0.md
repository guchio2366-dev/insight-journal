# 主要産業：実装・検証記録 v1.0

更新日：2026-09-13。実装開始時のmainは `95f9da1e29947542a3794665b200cea464676b22`。作業ツリーの全260ファイルをGitHubのmainと照合し、自然環境の全国等高線と既存農畜産機能を保持した。同時編集・外部サービス追加は行っていない。

## 実装

- `/atlas/north-america/industry/`。第一段５入口、第二段20分野。第一段だけが右の全国２グラフを変更する。
- 全産業の６区分は農林水産（畜産を含む）、製造業、資源・エネルギー、サービス業、建設・不動産、政府。サービス７区分、製造業８区分、資源２区分、建設・不動産２区分。２指標とも同じ分類・順序・0–100%軸。
- 全国値はBEAの2024年。名目GDP 29,298.0十億ドル、国内産業の年平均雇用163,223千雇用。雇用表6.4Dの国内行２を分母とし、国外調整後の行１を使わない。
- 原表2017–2024年を取得記録JSONとして保存。年次への切替をBEA画面上で確認して取得した。金額、雇用数、割合、名目推移の表を静的HTMLに生成する。
- 42件の地域・分野レコードと代表点。近接する点をまとめ、候補一覧と地図下の全地域一覧で選べる。説明カードは対象を避け、収まらなければ地図下へ置く。
- 全体・各業態・各分野の基本説明。独立した６件のインサイトは理由・限界・出典・２つの比較先を持つ。食品加工から農業へ移り、産業の選択へ戻れる。
- １ページ１MapLibre。sector/subsector/industryRegion/industryInsightをURLで復元。農業・畜産・自然環境の状態を併存させる。タブや地域・比較リンクからカメラを変更しない。
- WebGL不可でも、既存地形画像と同じメルカトル範囲にHTML記号を重ねて操作できる。JavaScript無効のindustry直開きではSVG代表点・地域本文・全分野本文を表示。

## データの範囲と設計からの具体化

地域の共通QCEW CSVは取得できなかったため、公的機関・連銀等の地域資料で裏づけられる代表例を採用した。州・都市圏・資源地域の単位、1990–2019年の歴史分析から2026年確認資料までの対象時期が異なる。カードに単位と対象年を明記し、同一年の全国雇用順位・特化度・頭数として比較しない。地域雇用、特化度、全国比はnullであり、0や推定値へ置き換えていない。

「その他のサービス」NAICS81は全国統計と詳説を実装済み。地域例は未登録として明示しており、裏づけのない主要都市を追加していない。地図は米国本土、全国値は全米。公営の医療・教育は政府へ分類する。資料のIT・観光等の産業群を独自のNAICS集計へ数値転用しない。

閲覧用「その他の製造業」は木材・紙等も含む入口、統計の残余は木材・紙を除く。本文と分類表で範囲を説明する。航空宇宙の補助系列は「その他の輸送機器」であり、船舶等も含むことを表題に明記。取得できない航空宇宙単独GDPを作成していない。

地域データは軽いためHTMLへ一括埋込みし、分野切替時の追加取得を不要にした。原CSVをブラウザへ送らない。産業コントローラー単体のminify後10,220 bytes、gzip 3,877 bytes（分類・状態codec込みの上限計測）。予算50KB以内。データのSHA-256・丸め許容差・対象年は `public/assets/atlas/industry-v1/manifest.json`。再計測は `node scripts/record-industry-assets.mjs`。

## 自動検証

`npm run check`：単体63件、完成サイト・実コントローラー12件、ビルド、公開情報・release検証を通過。

- BEAの全８年・２指標・全親区分について、子合計を元データの丸め精度から定める許容差内で照合。割合の計算、対象年、行重複、指標間の分類・並びを検証。
- 実ページ・実コントローラーを動かし、金融→情報通信の右欄HTMLが完全に不変であること、製造業への親切替、地域直開き、食品→農業→自然環境→産業、履歴復元、キーボード操作、インサイトリンクを検証。
- MapLibreの描画境界のみをモックし、カメラ変更回数と地図インスタンスの保持を検証。WebGL例外を注入して、代替図の記号・候補・地域一覧・説明が残ることを検証。
- 既存農業・畜産・自然環境とコンテンツ公開境界の試験を維持。industryを未完成とする旧静的試験だけを新しい公開状態に更新。

これらはGPU描画やSafari実機操作を検証したものではない。CSSビューポート確認結果は以下の公開版確認を参照。
