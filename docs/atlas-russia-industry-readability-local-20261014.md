# ロシア主要産業地図：可読性のローカル修正

基準は公開main `6f3d4a27c17bf205220d0eb44563975af2bcbdad`。旧作業ブランチ `codex/russia-industry-complete-20261014`（79fa4079）は保全し、クリーンなmainから `local/russia-industry-readability-20261014` で作業。commit・push・PR・マージ・デプロイは行わない。

## 現状の切り分け

旧版の描画処理は分野ごとに地点・産業をフィルターしていた。主因は他分野を一括で描くことではなく、資源12・製造13の操作用カード（114×46px）と引出線が地図を覆うことだった。精製・濃縮などの意図的な分野重複はカタログに残している。

## 修正

- 資源・エネルギー／製造／サービスにそれぞれ独立した地図、SVG識別子、注記、凡例を用意。選択中の1地図だけを表示する。
- 地図内の産業選択カードと引出線を廃止。産業選択は地図外の単一selectへ移した。地理的な案内点の選択、キーボード、URL・履歴、単独表示は維持。
- ノリリスクの併産金属、チェレポヴェツの鉄鋼・肥料など、同じ集積を短い非操作注記にまとめる。注記は白い縁取り文字だけとし、大きな付箋を描かない。
- 各注記は案内点の近傍30px以内に限定。局所的に空かない注記は省略し、遠方へ引出線を伸ばさない。注記数は資源・製造で10〜12、サービスで最大10。選択状態を配置計算へ渡さず、既存注記は産業・地点選択で移動しない。
- 省略するのは注記だけ。全49案内点・19産業の立地根拠、工程、規模、統計の定義、出典、座標を保持。地図外の一覧、右側の詳細、統計から参照できる。高密度域のトラック製造などは常時注記が省略されるが、地点・産業選択・詳細は残る。
- 資源・製造の注記の予約面積は、760/960/1280pxの検証で旧カード面積の40%未満。サービスは大分類3枚から各港・濃縮都市の短い注記へ変わるため、この削減率をサービスには適用しない。

## 共通UI・統合担当への接続事項

共通ファイルは変更していない。

- 分野タブの既存フック `data-ru-sector`、URLの `sector / industry / site / only`、右側詳細・統計のフックは維持。
- 産業選択は `select[data-ru-product-select]`。旧 `data-ru-products / data-ru-product` のボタン群は廃止した。
- 地図は3個になるため、共通検証は `[data-ru-scene]:not([hidden]) [data-ru-map]` またはvisibleなsceneに限定して読む。`tests/browser/atlas-oceania-russia-ux-refresh.mjs` のロシア産業分岐にある単一SVG前提は統合側で修正が必要。ここでは変更しない。
- `scripts/verify-industry-pages-smoke.mjs` のロシア定義も、旧ボタン群と単一canvasを前提にしている。active sceneへの限定とnative select操作への対応を統合側で行う。ここでは変更しない。
- `data-ru-label` は操作ボタンではなくSVGの注記g。IDは代表地点。`transform`・`data-box` が固定配置、`data-ru-label-industries` が対応する産業。選択は地図外selectか案内点で行う。
- ロシア専用の `scripts/verify-russia-industry-review.mjs` は上記契約に追従し、実ブラウザの1920/1440/1024/390px確認用として残す。CI/workflowの変更・実行はしていない。

## 検証と目視の限界

専用単体テストは、座標、同名都市除外、分野ごとの注記所属・重なり・面積・近傍性、固定配置、URLを検証する。ビルド後テストは、独立3地図・1分野だけの表示、選択肢が地図内にないこと、全19産業と49地点の詳細、凡例・履歴・キーボード、ゼレノゴルスクを検証する。

ローカルChromiumは、SUID helperがroot所有でない設定エラーで起動不可。サンドボックスを無効化・変更していない。**実ブラウザの画面可読性は未確認**で、テスト成功を目視済みとは扱わない。

別途、保存済みの国土・実地点・旧/新の配置関数から760/960pxの静的SVG参考画像を生成。三分野を目視し、「石炭」と背景の「西シベリア」が重なった箇所を修正した。これはHTML/CSS全体や390px端末のブラウザスクリーンショットではない。実ブラウザの各分野・選択時・小画面の目視を統合側に引き継ぐ。

差分パッチ、検証ログ、静的SVG/PNG見本、目視方法のJSONはローカルの引継ぎディレクトリにまとめる。最終応答の保存先を参照。
