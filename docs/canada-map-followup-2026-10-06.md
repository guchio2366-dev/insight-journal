# カナダ実画面レビュー対応（2026-10-06）

今回のユーザー指定は、旧版の都市比較・年選択・数量円を基本画面に置く仕様より優先する。

- 気候区分を地図の基準とし、水資源・人口は共通のメルカトル座標・南部範囲・枠寸法を使う。旧URLのaffine座標は描画時に読み替える。投影が変わる画像は最近傍で再投影し、区分色を保持する。
- 国土輪郭は気候区分の境界から結合。0.01度の簡略化と0.003平方度未満の小島・穴の省略を行う概観用地図。統計集計には使用しない。取得元と利用条件は気候区分の台帳を引き継ぐ。
- 右欄は雨温図、都市の気候区分と特徴、農畜産の適性、確認した実際の生産の順。適性の解釈と実績、観測地点と州・地域の範囲を区別する。
- 人口の上部の都市・比較・年・指標選択を削除。都市を地図で選び、凡例から集団を読む。地図操作は全体・拡大・縮小、ドラッグと矢印キー。人口密度を初期表示する。
- 人種・民族は白人を背景の灰色とし、米国と同じ集積閾値（20%以上、または5%以上かつ全国比1.5倍以上）に該当する集団のうち最大割合の色を使う。色点は該当する全区分。分類そのものはカナダの公式14区分を保持する。
- 宗教は各都市圏の最大分類を色分け。無宗教を含む本人回答で、米国の宗教団体報告とは異なる。欠測・秘匿がある場合は一意の最多を推測せず、同率も区別する。
- 41都市圏の外側と教派別のデータは「本サイトでは未収録」と明記する。原典自体にデータがないとは断定しない。全域の小地域データ取得・結合や教派追加は今回の表示修正とは別の残課題。
