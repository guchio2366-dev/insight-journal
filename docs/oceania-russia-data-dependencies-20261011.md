# Oceania・Russia：分布資料の残件（2026-10-11）

この表は、現在の保存済み資料で表示できる範囲と、次の分布を作るために必要な入力を区別する。掲載できない欄は空図や推計値で埋めない。

| 項目 | 現在表示できる範囲 | 次段に必要な資料と判定 |
| --- | --- | --- |
| 農作物 | Russia の小麦、Oceania の小麦・ココナツ・カカオの保存済み MapSPAM 2020 格子。既存の羊・牛格子を重ねる。 | 他作物には対象作物ごとの固定版 MapSPAM 2020 v2r2 収穫面積格子と国別 coverage・欠測・ライセンスの照合が必要。公式の一括アーカイブは今回 CONNECT 403 となり、再取得していない。少品目を除く閾値は未決。 |
| 林業 | 保存済みの西部 Russia、PNG 西部など限られた範囲の参考図。 | 両地域の全対象国を同じ定義で覆う樹木被覆または森林分類の原格子、年、解像度、利用条件が必要。保存済み部分を地域全体の森林分布として外挿しない。 |
| 流域・河川の流向 | Natural Earth 1:50m v5.1.2 の名称付き河川線を Russia 5例、Oceania 3例表示。 | 流域の同時表示には流域境界ポリゴンと河川との対応表が必要。流向・河口には有向の水系線と出口の根拠が必要。現在の線座標の並びから推定しない。 |
| 地下水・利用可能水量 | 該当する数量分布は未整備。 | 地下水の得やすさ、涵養量、年利用余地、残量をそれぞれ定義し、対象期間・単位・地域区画を揃えた資料が必要。降水量から地下水量を換算しない。 |
| 民族・宗教 | GHSL 2020 人口密度と UCDB 2020 人口を用いた都市位置のみ。 | 各国の比較可能な細地域区画と、自己認識に基づく項目別人数、分母、調査年、非回答・欠測、再利用条件が必要。国全体の構成比を細地域や都市の分布に割り当てない。 |
| 産業の数量 | Russia の代表地点10例と Oceania の豪州鉱山347点・代表地点6例は、位置や鉱種の説明用。 | 生産量・産業割合などを地点に載せるには、施設または比較可能な行政単位に結び付く数量、年、単位、欠測、許諾が必要。主要国の統計対象と閾値は未決。 |

既存の産業代表点は固定サイズで、産業の件数や生産量を表さない。出典は各地点の選択時の右説明と資料一覧に表示する。
