## 実装

- `AgroStatistics.astro` と共通renderer/controllerで、既存の国・重要品目に限り、供給・仕向け／相手国／世界生産の三列を地図下へ追加。既存の地図・ニュース欄は保持。PCはニュース幅を除き、狭い画面は一列。国・品目選択に同期し、畜産の肉・生乳など補足系列を切り替えられる。概説での統計品目は既存品目に限定し、地図へ新しい品目を増やさない。
- 保存済みQCL・FO・RLを同一原表版・品目・要素・年・単位で照合。199国・地域、2,627系列、18,755行。日本・米国も既存原値を順位比較に含め、対象ページの改修可否から分離する。World・地域集計・中国合計を国別collectionから除外。Decimalで重複値、単位、原フラグ、原表版の不一致を検出し生成を停止。
- 右列の世界比は国／同年World。国合計でWorldを再構成しない。推移は欠測・欠落年で線を切る。順位は同じ定義の有効値がある**収録国・地域中**の順位。同値順位を共有し、上位5対象＋選択国の表示位置を順位と混同しない。日本・米国を含むが、品目別の保存範囲は不完全であり、全世界の網羅順位とは呼ばない。
- 左列はFOの丸太・製材で同年・同単位の国内生産＋輸入を横帯にする。在庫を含まない分母と明記。輸出は独立公表量。国内用途・在庫・損耗が欠けるため、残りを国内消費・加工・食用へ押し込まない。輸出先での用途は既存の根拠付き本文を維持し、相手数量から推定しない。丸太（燃料材を含む）と製材・パルプを合算しない。
- 相手国数量・分母が未収録なら円を作らない。東・西アジア、欧州、インド米の既存確認済み相手表は、年・数量／金額・加工段階・地域外／国別参考の区別を保つ。
- データは32品目別gzipへ分割し、表示品目だけ遅延取得。最大34,790 bytes。牛肉＋生乳＋manifestは65,250 bytes。原値全体は監査用に残す。取得失敗時は再試行可能で、古い要求が別国や日本の選択へ復帰しない。
