# アジアの降水量・流域・地下水

自然環境の既存3主題に「年降水量」「流域」「地下水と涵養」を追加します。東アジア6、東南アジア11、南・中央アジア13の計30か国・地域を対象とし、ロシア・中東などの周辺国は灰色の位置参照に保ちます。流域は国境で途切れるとは限らないため、対象国の陸地を塗り、国境を越える集水域は輪郭を表示します。

## 資料と意味

- **年降水量**は [CHELSA BIO12 v2.1](https://www.chelsa-climate.org/datasets/chelsa_bioclim) の1981–2010年の推計平年値です。雨・雪などの水換算量をmm/年で示します。30秒角（約1km）の原本をWeb Mercator座標上で約4km間隔の格子に平均化し、整数mmへ丸めます。地表の4km間隔や1mm精度とは主張しません。色とクリック値は同じ格子から生成します。既存の都市雨温図・気候区分の1991–2020年とは期間と資料が異なります。原本はCC0 1.0です。
- **流域**は [BasinATLAS v1.0](https://www.hydrosheds.org/hydroatlas) のレベル6小流域を、実際につながる出口 `NEXT_SINK` ごとに結合します。`MAIN_BAS` が含む内陸水系への仮想接続は採用しません。面積は原資料 `SUB_AREA` の合計で、画面外を含む接続した集水域全体です。沿岸の小流域群 `COAST=1` は一つの川ではないため、代表流量を割り当てません。範囲は主に約500m相当の地形資料に由来し、緯度60度以北の上流では粗くなります。表示輪郭は0.008度で簡略化します。データセット全体の利用条件はCC BY 4.0です。
- **出口の流量**は [BasinATLAS属性カタログ](https://data.hydrosheds.org/file/technical-documentation/BasinATLAS_Catalog_v10.pdf) p.2 の `dis_m3_pyr/pmn/pmx` です。WaterGAP 2.2（2014年版）が推計した1971–2000年の自然化流量をm³/sで示します。人による取水・貯水施設などの影響を除いたモデル値です。最少・最多月は長期平均した12か月間の比較で、災害時の極値ではありません。原モデルの0.5度格子を細かい水系に配分したもので、流域輪郭と同じ空間精度を意味しません。この属性もCC BY 4.0です。他の約280属性を一括で画面に掲載していません。
- **地下水**は [WHYMAPサービスのレイヤー11](https://services.bgr.de/arcgis/rest/services/grundwasser/whymap_gwr/MapServer/11) から取得した、2008年世界図（縮尺1:25,000,000）の区分です。878個の原ポリゴンを2026-09-27に取得し、公式凡例の11区分を保持しています。取得年は観測年ではありません。青は主要な地下水盆地、緑は複雑な水文地質構造、茶は局地的・浅い帯水層です。各群の涵養区分を別々に示します。涵養は地下水への補給であり、貯水総量・水質・現在の水位・安全な取水量ではありません。表示輪郭は0.006度で簡略化します。BGRの[提供条件](https://www.bgr.bund.de/whymap/EN/Maps_Data/maps_data_node_en.html)に従って `Datenquelle: WHYMAP, (C) BGR Hannover & UNESCO Paris` を掲載します。

## 加工と再現

生成器は `scripts/atlas-asia-water.py`、配信データは `public/assets/atlas/asia-water-v1/` です。既存の人口地図と同じNatural Earth 1:10mの詳細な国境・海岸線を使います。河川の補助名称はNatural Earth 1:50m v5.1.2の線との重なりから得ており、BasinATLASの公式流域名ではありません。

原本と配信ファイルのSHA-256、期間、尺度、加工方法、利用条件はmanifestに記録しています。CHELSAは2025年配信のCOGを固定し、内部のscale=1・offset=0を確認しています。以前の配信版に使われる0.1倍を重ねて適用しません。BasinATLASは[公式Figshare記録](https://doi.org/10.6084/m9.figshare.9890531)のレベル6を取得してZIP内部CRCとSHA-256を確認しました。WHYMAPは取得件数878がサービスの件数照会と一致し、途中打切りがありません。

```text
python scripts/atlas-asia-water.py --cache <原本保存先> --rivers <Natural Earth河川GeoJSON>
```

NumPy、Rasterio、Shapely、PyShp、Pillowが必要です。原本はリポジトリに含めず、固定した入力ハッシュに一致しなければ生成を止めます。gzip配信はmtime=0で再現可能にします。

流域は複数地域にまたがるため、地域間の件数を足して世界の独立した流域数にはできません。全配信データは約11MBで、主題を開いたときに地域ごとのファイルだけ取得します。降水量の数値格子は地点を選んだときに取得します。初期HTMLには全区域のID索引や形状を埋め込みません。

## 選択と解説

地点・国・区域・主題・地図位置をURLに保持し、農林業・人口との比較後に同じ選択へ戻れます。区域一覧は国で絞り、最大100件を表示しますが、地図には全区域があります。流域一覧は全流域面積の大きい順です。区域を国の一覧から選んだ場合は、その国と区域が実際に重なる位置へ地点を設定します。

新潟、東京、タリム盆地、メコン川、シンガポール、西ガーツ山脈、インダス川、アムダリヤ川の8つの着目点に、場所固有の解説とJMA・MRC・MSS・UNESCO・ICIMOD・FAO等の根拠を付けます。資料から比較できる事実と、季節風など一次資料で説明される仕組みを区別します。着目点だけで流域・地下水の区域を代用していません。

## 検証する点と限界

- 元DBFから独立に照合した接続流域の面積は、メコン川774,339.2km²（89小流域）、インダス川857,634.5km²（97小流域）です。隣接した閉鎖水系・沿岸区分を除いたこの資料上の区分であり、他資料の「流域面積」と同じ定義とは限りません。
- 地図とクリック値の同一性を、独立にPNGを復号して検査します。東京付近・タリム盆地・シンガポール・西ガーツ・アムダリヤで多雨／乾燥の分布を確認し、海・欠測を0に置き換えません。
- 直接URL、他分野からの復帰、遅い取得応答、取得失敗の再試行、描画の再作成を制御テストで検査します。範囲の点判定は穴を除外します。
- 流域図と国境図の重なりは、流域に属する国の公式区分ではありません。例えばインダス区分とネパールの境界に約3.2km²の小さな重なりがあり、資料間の位置・簡略化の違いを含みます。このため国別の公式流域面積や政治的区分としては掲載しません。
- モルディブにはこの縮尺のBasinATLAS流域区分がありません。河川・排水がないという意味にはしません。小島・海岸は格子化や原資料の境界差で欠けます。
- 地下水は広域の概観資料です。北米の詳細資料と同じ縮尺とは主張せず、局地的な井戸・地下水質を推定しません。

この追加だけでアジア全体の北米版との同等性が完了したとはしません。人口の社会属性・行政区域別資料、農林業と主要産業の貿易・場所別の説明、分野を横断した最終監査は別途残ります。
