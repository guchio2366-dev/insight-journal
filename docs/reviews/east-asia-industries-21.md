## 数値と位置の契約

数値は `src/data/atlas/east-asia-industry-evidence.ts` に、指標・値・年・単位・国／企業集合・分母・公表元・一次資料URLを保持。世界売上は領域GDPへ転用しない。設備能力、年間生産、販売、輸入、港湾取扱、金融決済を区別する。サービスに物品の需給式を当てない。

新設の案内点は `east-asia-industry-extensions.ts`。座標は公表された所在地に対応する都市・地域の丸めた案内位置で、測量した工場座標や敷地外形ではない。原図の施設座標を使う既存発電点と区別する。産業色と工程の記号を用い、点の面積は数量を表さない。名称は全表示点から固定の順番・寸法で配置し、選択による優先順位変更をしない。モバイルで全名称が収まらない場合も全品目ボタンと拠点一覧から選べる。

### 未取得・未確認を表示する範囲

- ガリウム・ゲルマニウムだけの領域GDP／雇用は未取得。中国の精製シェアと秋田のガリウム原料の例を別に表示。ゲルマニウムの施設分布は未確認。
- 張家港・東莞の加工は2024年操業資料。現在の全工場の操業状態は未確認と表示。
- 北方稀土の製品売上は磁石用元素だけではない。磁石用希土類の分離精製は2025年、焼結永久磁石は2024年を表示。
- 台湾半導体産業協会の2024年実績を使い、2025年予測を実績にしない。台湾本社企業の世界売上と台湾の領域GDPを区別。
- 同協会の従業者数は原表3・7の掲載数。資料が明示していない国内／海外の雇用地内訳を推定せず、未確認と表示。
- 太陽光モジュールの中国シェア79%はIEA-PVPS公表丸め値。575／722.467の単純比との差を明示し、別系列や設備導入量に接合しない。
- 大豆は暦年2025の輸入通関とUSDA 2024/25年度の圧搾・世界輸入を分ける。造船DWTとGT／CGT、原油処理tと精製能力bbl／日も接合しない。
- 既存の電力点は2021年WRI資料。既存6概観の品目別数量を新21品目の数字で補わない。

## 検証の再現

```sh
npm ci
npm test
ASTRO_TELEMETRY_DISABLED=1 npm run build
npm run test:e2e
npm run verify:release
REVIEW_CHROME_PATH=/usr/bin/chromium node scripts/verify-east-asia-industries.mjs
```

実画面の検証は1920×1080・1896×996・1440×1000・390×844、DPR1、ビルド済みローカルファイル。外部リクエストを遮断し、21品目・3列の統計・地図位置維持・衝突・地図下配置・横溢れ・keyboard拠点選択・日本の工程記述・単独表示・reload・back／forward・分野往復を確認する。画像と結果は既定で `/tmp/east-asia-industries-review` に出力する。

この実行環境では既存ChromiumのSUIDヘルパーがroot所有でなく、非特権名前空間によるsandbox起動も不可だった。機械の権限を変更せず、リポジトリ既存の `atlas-asia-industry-status` と同じ明示的コンテナ設定 `ATLAS_ASIA_BROWSER_UNSANDBOXED=1` を使用。実行環境のファイル権限制限を保ち、外部通信なしで検証し、結果JSONにChromium内sandboxの状態を記録する。sandbox対応環境ではこの設定を付けずに検証する。
