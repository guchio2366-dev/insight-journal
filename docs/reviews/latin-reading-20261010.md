# 中南米：農畜産・人口・民族関連・宗教の読み取り

PR316（`1ea3382cdbff9e018d5b50c5bdcf7aa6e2c3b3f5`）に依存する後続変更。林業の共通枠を維持し、中南米の農畜産・人口の縦幅、分布選択、右側の概説→解説を整える。マージ・公開は行わない。主要産業、カナダの別試作、他地域の固有実装は変更しない。

## 実装

- 農畜産の細縞を廃止。保存済み2020年格子から、表示スコアが最大の品目を1セル1色で表示。色は数量・面積比率ではない。
- 初期図は10作物と牛の同時表示。分布色の実ピクセルまたは品目名を選択すると、その品目の全有効分布の既存輪郭を重ね、他の分布を残す。国境面は選択対象にしない。
- 農畜産・林業の共通地図枠、人口の地図枠を縦に拡張。中南米全体を保持し、南端を切り落とさない。拡大・パン・全体への復帰を追加。
- 人口はUN WUP2018の7都市集積域の実人数を円の面積で表示。市行政界・現在人口・GHSL格子人数として表示しない。密度図は別表示とし、保存済み2020年密度を5階級に再分類。原値は変更しない。国面の選択と右側の比較リンクは廃止。
- 民族関連と宗教は実資料の範囲を保って同時表示。選択による絞り込みは右の説明だけ。チリ代表6州の統計は州都に同サイズの記号を置き、居住域・人数比例記号と区別。パナマ全国2指標は四角の補助統計。
- グアテマラ2018全国6自己認識分類の公表割合と、コロンビア2018先住民自己認識33行政区分の人数を追加。＋記号から右の原表へ接続し、分類・単位・年・分母・利用条件を資料別に保持。分類の選択後も全行・全記号を残す。国別統計の参照位置に既存Natural Earthの国ラベル点を使い、行政区分や民族居住域の図形・代表点を作らない。
- 直接URL・再読込・戻る／進む・通常のサブ項目遷移を回帰チェック。自然環境と主要産業は同一条件の画像hashを前後比較する。
- 既存の自然環境・主要産業の比較から呼ばれる農畜産の合成図・凡例・品目名はPR316の出力を保持。新しい11品目の図は通常の農畜産ワークスペースで使う。比較用のHTML/SVG hashと、産業→農畜産比較の前後画像も回帰チェックする。

## 原典と制約

- MapSPAM2020 v2r2、CC BY-SA4.0／GLW4 2020、CC BY4.0：既存格子の値とhashを保持。加工手順とclick画像のhashは `latin-reading-products-v1/manifest.json`。
- GHSL2020：配信格子は人/km²。元人数と有効面積が保持されていないため、表示セルから人数を算出・合算しない。元42タイルの正規取得は実行環境のHTTPトンネル403。再分類台帳は `latin-reading-density-v1/manifest.json`。
- UN WUP2018 Revision Table III.6（PDF pp.98–99）、CC BY3.0 IGO：都市集積域7都市の2018年年央推計。原表の千人×1,000。都市定義は国により異なり、境界図形は未収録。2025版の正規資料は取得できず、2018年を明記して採用。
- チリINE Censo2024：民族関連の別設問（全年齢、未回答を各分母から除外）、宗教・信条（15歳以上の回答者）。全国と代表6州の原表計数。INEのCC BY-SA4.0を確認し、抽出・日本語加工も同ライセンス。先住民、アフリカ系、言語、宗教を互いに置き換えない。
- パナマINEC2023最終結果：通常居住者4,064,780人。先住民帰属698,114人／17.2%、アフリカ系自己認識1,286,857人／31.7%は別設問。CC BY4.0。PR307のデータ定義を個別に再確認して再利用し、旧PR305/307の全変更は取り込まない。

- グアテマラ副大統領府「Datos generales」：Censo2018を出典とする全国6区分の公表割合（56.0、41.7、1.8、0.2、0.1、0.2%）。ページのCC BY-SA4.0を確認。分母表記は総人口だが、対象年齢と未回答処理は概要に明記なし。その不足を表示し、2023推計人口を掛けて人数を作らない。
- コロンビアDANE資料PDF 25ページ（index24）のCNPV2018列：32県＋Bogotá D.C.、先住民自己認識の人数。33行合計1,905,617人が全国計数と一致。各区分の総人口分母は未収録なので総人口割合を作らない。DANE利用条件第2項の指定出典表示で利用・変換・分析可。PDFを一律CCと称さず、指定文 `Fuente: Departamento Administrativo Nacional de Estadística: www.dane.gov.co` を掲示。採用値と定義は `data-source/atlas/latin-reading/culture-supplement-2018.json`。

**文化資料の整備は部分実装。** チリ・パナマ・グアテマラ・コロンビアだけで中南米全域が完成したとは扱わない。宗教はチリの資料範囲のみ。ブラジルのIBGE原配布は403、転載条件は未確認。ペルーは原表または利用条件の確認が未完了。UNdataの正規利用条件（出典表示で複製・再配布可）は確認できたが、国別フィルタの実データ取得は不可。国の割合から架空の民族・宗教居住域は描かない。中米・カリブの同定義都市人数は未取得。WUP2018-F12-Cities_Over_300K.xls のHTTPトンネル403と、国連データブックレットの403／Internal Errorを上記JSONに正確なURLとともに残し、同じ拒否を反復しない。
