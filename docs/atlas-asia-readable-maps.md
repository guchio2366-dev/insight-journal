# アジア地図の読みやすさの修正

## 今回の表示契約

既存の東アジア・東南アジア・南／中央アジアを対象とする。西アジアのデータ、ページ、生成処理は変更しない。北米の分野タブ、地図と右解説、地図直下の品目名という順序を使う。

一つの MapLibre 地図を維持し、表示の切替で作り直さない。都市を選ぶと解説だけを切り替え、現在のカメラを URL に保存する。手動の拡大縮小と全景ボタンは残す。選択地点のマーカーには国名を表示する。南アジアはスリランカからパキスタン北端、中央アジアはアフガニスタン南端からカザフスタン北端を初期範囲とする。

水資源は海岸線・国境・主要都市を位置の手掛かりにする。河川・地下水では河川と主要地下水盆地を重ね、涵養量の細分類を概要図に重ねない。流域では主な河川の流域を表示し、それ以外の細かな流域境界を常設しない。区域や涵養量の詳細は選択後の解説と出典に残す。

農畜産物は既存の MapSPAM / GLW4 格子から、各品目の地域内での相対的な集中度を共通格子で比較し、一つの格子に一品目を割り当てる。表示の重なりは作らない。異なる品目の生産量・頭数を比較した分類とは説明しない。概略図は代表的なまとまりを示し、元の品目別分布へ移れるようにする。品目名は地図直下と地図上の両方に置く。

人口の入口は「人口分布／人種・民族／宗教」の三つにする。人口分布は人口密度のみを扱い、年齢・国籍・選挙等の選択を常設しない。民族・宗教の概略図については行政区別統計を居住境界に見せかけず、空間資料の種類、対象年、収録されない集団、混在を明記する。全国的に分散する集団と、地域の居住域が記録された集団を区別する。

## 検証

都市の選択前後でカメラが一致すること、直接 URL と履歴の復元、水の背景に小流域線が現れないこと、農畜産物の面が重ならないこと、家畜のラベルが存在すること、人口の三つの入口、390px と PC の実画面を確認する。画面の代替表示・資料の失敗時も名称と出典を残す。

## 居住域の資料と限界

GeoEPR 2021の地域分布から、2020年に有効な記録を抜粋しました。州別統計や、全国の境界をそのまま居住域とする記録は使いません。個別集団の定義とIDは配信用の一覧に保存しています。異なる掲載集団の重なる面は別色にし、どちらかの多数派地域とは扱いません。

宗教図は、EPR-ED 2021の集団全体の宗教構成を、確認した居住域に結びつけた限定的な概略図です。結合した集団内で8割以上と記録された事例だけを採用していますが、その場所の全住民に占める信者割合ではありません。この違いを地図の横の常設文に示します。全面的な民族・宗教分布図ではなく、漢族・日本人や朝鮮半島を含む未掲載範囲が残ります。EDのパプア系集団など、宗教の分類に疑義がある記録を自動採用していません。最新版の人口調査と誤認させないため、2020年対象・資料2021年版を明記します。

生成は `scripts/atlas-asia-settlements.py --source-dir <ETHの2資料を保存した場所>` で再現できます。取得元とSHA-256は `asia-settlements-v1/manifest.json` に記録します。公開資料の引用指定に従ってGeoEPR、EPR-EDと各論文を画面で示し、確認できない利用ライセンス名を付け加えていません。

## 検証結果

単体検査は273件成功、既存の1件はスキップしました。全体の静的画面・操作検査123件と配信情報検査が成功し、最終調整後にもアジア20ページを対象にした静的検査3件を再確認しました。農畜産物の3地域の面には重複がありません。民族・宗教の6図も幾何検査で重複部分を分離し、各名称の位置が対応する面内にあることを確認しました。

実ブラウザーでは、都市選択前後の中心・倍率の一致、河川／地下水と流域の静かな背景、南・中央の初期範囲、作物と家畜の名称を確認しました。1280×720では品目一覧の下端が700px以内に収まり、390px幅ではページの横方向へのはみ出しがありません。民族・宗教の切替中に古い面を重ねないことと、取得が遅れて別画面へ移った場合の動作も検査しています。
