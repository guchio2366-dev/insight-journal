# アジア農林業の分布と国別統計

2026-09-26に追加しました。既存の米の分布を維持し、東アジア11、東南アジア12、南・中央アジア14の主題を追加しました。34枚は作物・家畜の数値図、3枚は森林の参考画像です。

## 出典と数値の意味

- 作物はIFPRI MapSPAM 2020 v2r2、Harvard Dataverse V6.0の固定ファイル13827040です。元ZIPのMD5は`dd9ac5def086fcae26d28423b2b31f8b`です。すべての生産体系を合計した収穫面積を使っています。5分角の元格子のhaを、最近傍でWeb Mercatorへ再標本化しています。同じ表示配列から画像と地点の数値を生成し、0と欠測を区別しています。土地面積、農場の境界、生産重量ではありません。
- 家畜はFAO GLW4 2020をCGIAR Climate Data Hubが変換した固定Zarrから取得しました。牛、水牛、羊、山羊、豚、鶏の5分角の推計密度です。動物種を肉用・乳用・採卵用に勝手に分割しません。頭/km²や羽/km²をそのまま合算して頭数にはしません。
- 森林はJRC GFC2020 v3のWMS参考画像を無加工で保存しました。提供元のRGB画像を数値解析に使わず、地点分類や森林面積も計算しません。v3の既知の問題、特に東カリマンタンでの森林と樹木作物の混同を説明します。国別の面積と木材生産は別の統計です。
- 国別統計はFAOSTATの作物・畜産、林産物、土地利用の一括資料から2015–2024年を抽出しています。品目、集計要素、単位、年、資料のフラグ、注記を保存しています。CHNは本土のM49:156であり、China集計159ではありません。台湾はM49:158です。未掲載値を0で埋めません。
- 茶は生葉、綿花は種を含む綿、油ヤシは果実、キャッサバは生鮮、サトウキビは原料の重量です。コーヒーの国別値は種類の合計、Milletの値はトウジンビエより広い分類です。鶏の千羽、森林の千ha、木材のm³を区別します。

新しい作物資料は固定Dataverseの利用条件に基づくCC BY 4.0です。既存のCGIAR経由の米の派生資料には従来のCC BY-SA 4.0表示を維持します。GLW4はCC BY 4.0、森林画像はCopernicus/JRCの出典表示付き再利用条件に従います。全入力と出力のSHA-256、固定URL、寸法、処理方法はmanifestに記録します。

## 操作と配信

主題の変更時には、使わなくなった農林業の画像ソース・描画層を削除し、解凍済み数値格子も解放します。保持するのは選択中の1主題だけです。前の主題の取得が遅れて完了しても、保持対象へ戻しません。比較先から戻る際は必要な格子を再取得します。反復切り替え・遅延応答・再取得の検査と、南・中央アジアの小麦→鶏→小麦の実画面確認を実施しました。

主題・国・地点・カメラはURLに保持します。自然環境・人口との比較から元の主題へ戻れます。画像は選んだ主題だけ、数値は地点選択後だけ、国別統計は国を選んだ後だけ読み込みます。国別統計は約101KBのgzipを配信し、配信側ですでに解凍された場合にも対応します。全文JSONも監査用に残します。農林業追加資産の全容量を、最初に全量取得することはありません。

人口図のNatural Earth 1:10m海岸線を新しい農林業図の背景にも利用します。周辺国は灰色で、選択対象ではありません。この国境は統計上の全国値の計算には使いません。小国の表示格子の不足は説明し、国別統計を別に読めるようにします。

数値図34枚の寸法・ハッシュ・欠測、FAOの実際の代表値、30か国・地域の範囲、単位、重複、比較復帰、遅延応答、統計の失敗と再試行を検査しています。北米相当の全分野が完成したという判定ではありません。産業、行政区域別人口、社会テーマ、水の降水・流域は引き続き別に評価します。

## 確認結果

全体の単体テストは211件成功・既存1件省略、静的成果物のE2Eは117件成功しました。その後の表示修正についてアジアの20件と数値検査の1件を再確認し、最終ビルド、アジア全9ページを対象とする2件のE2E、公開前検査が成功しました。公開前検査は、manifestのハッシュ・寸法・有限値を照合した農林業のfloat32資産のみを文書IDの文字列判定から区別します。私的URLや番兵文字列の検査は維持します。

実ブラウザーでは東アジアの小麦（中国、116.4°E/36.8°Nで2,423.5ha/格子）、日本の鶏・森林、東南アジアの油ヤシ（インドネシア）、南・中央アジアのひよこ豆（インド）を確認しました。1440pxの地図と解説の並読、390pxでの横はみ出しなし、44pxの選択欄、主題・国・カメラの比較復帰、URL再読み込み後の復元を確認しました。これは全37主題を実機で一枚ずつ検査したという意味ではありません。
