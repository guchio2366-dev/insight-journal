# アフリカのコーヒー・茶：概略生産帯の根拠

基準は公開済みの `ab2bf51581f6874fb141b5e858892c7a2faf9f2e`。人口・気候・既存7品目の分布データ、色、ラベル位置、地域統計には変更を加えない。コーヒーと茶だけ、産地記述を根拠とする独自の概略帯を追加する。数値格子とは別の表現であり、収穫面積・数量・密度・全国被覆を意味しない。

## 根拠と表現

機関、原典URL、資料年、PDFページまたは節、確認できた地名、再利用範囲は `src/data/atlas/africa-beverage-belts.ts` の `africaBeverageSources` に保持する。閲覧日は2026-10-10。

- コーヒー：USDA FASの2025年エチオピア・ウガンダ・ケニア・タンザニア報告、ICOの2013年コートジボワール・ブルンジ調査報告と2017年カメルーン国別報告、CIRADの2023年キブ湖岸の産地記事。
- 茶：USDA FASの2025年ケニア報告、NAEBのルワンダ産地解説（年記載なし）、FAOのマラウイ2005–2013年資料（刊行2015）、World Bank/IFCの2016年タンザニア報告、Muziraほかの2023年ウガンダ一次研究（CC BY 4.0）。
- マダガスカル東岸のコーヒーはFAOの2000年特別報告が根拠。歴史的産地の概略として明示し、現在の面積・生産順位の根拠には使わない。

各帯には原典ID、国、産地名を対応させる。資料に記載された産地近傍に、丸めた編集上の中心線と表示幅で30本の帯を作成する。原典の地図・図版・表は転載・トレースせず、SPAM未取得格子を補間・捏造しない。帯を当該国の既存地形図の国境でクリップし、未確認の隣国や海へ広げない。線の幅、境界、面積は実測値ではない。小さい独立産地も件数制限で落とさない。

本文の地名などの事実のみを参照する。米国政府報告の第三者図版やFAO・ICO等の原図を素材として再配布しない。CC BY 4.0の研究には著者・年・原典リンクを付す。利用条件の新規受諾、有料取得、認証情報の提出は行っていない。

## 取得制約

シェルからの公式PDF直接保存は通信トンネルの403で拒否された。拒否された取得経路は迂回せず、公式URLの閲覧で確認できた産地記述を記録した。PDF原本のローカル複製・SHAは取得していない。コーヒー・茶のSPAM原格子も未取得なので地点の生産量・面積を表示しない。これは資料で確認できた概略産地を表示できないという意味ではない。

## 検証

`tests/fixtures/africa-agriculture-label-layout.json` は基準mainの1440×1000 / 1024×768画面から取得した旧7品目・マダガスカル国名のSVG座標。限定PC検証は同じ画面サイズで座標の一致、新しい品目名の実際の可視性と重なり、地図内操作との衝突、9品目の初期表示、選択・強調、右側の単一表示、再読込・復帰、6作物/3家畜の切替、5地域、農畜産/林業タブ往復を確認する。

帯の描画は地図内の文字を隠して撮ったPNGの色面ピクセルで検証する。対象以外の人口・気候等を繰り返し撮影しない。代表画像はJPEG10枚と、head・buildのcommitSha・画像SHA・CI run・日本語フォント・原典を記録したmetadataで構成する。公開・mergeは親の実画像確認後に別途判断する。
