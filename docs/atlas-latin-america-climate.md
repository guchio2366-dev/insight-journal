# 中南米の気候データ

2026-09-25取得・検証。地図は実際の分類格子、雨温図は観測所の平年値を用いる。手描きの気候域や推定した月値は含まない。

## 配布内容と接続

- `src/data/atlas/latin-america-climate.ts`: `climateClasses`（原典の30区分の色・名称）、`latinClimateCities`（16観測所）を公開。月配列は1～12月。`LatinClimateCity`の型に準拠する。
- `public/assets/atlas/latin-america-climate-v1/latin-america.png`: 600×971、RGBA、34,058 bytes。
- `latin-america.grid.json`: 同じセルの分類ID、1,205,015 bytes。21区分、174,564有効セル。0は海域・分類なし・対象地域外。
- `manifest.json`: 地理参照、国・地域ごとの有効セル数、出典・ライセンス、入力・出力SHA-256、変換方法。
- `cities-provenance.json`: 全観測所の元ページURL・取得日・キャッシュSHA-256・月値SHA-256・欠測月。
- `legend.json`と`source-legend.txt`: 機械可読凡例と原典の凡例。

画像はEPSG:3857に再投影済み。MapLibreのimage sourceには`manifest.regions['latin-america'].imageCoordinates`をそのまま渡す（左上・右上・右下・左下）。値は`[[-93,28],[-33,28],[-33,-56],[-93,-56]]`。`raster-resampling: nearest`を設定する。

格子は北から南へ、西から東へのrow-major。緯度経度をEPSG:3857に変換し、`bounds3857`と`width`/`height`からセルを求める。IDが0の場合は「分類なし」とし、近傍セルへ置き換えない。地図と凡例の色は原典の30区分の配色を使用する。

## 気候分類の原典と処理

[Beck et al. (2023), Scientific Data 10, 724](https://doi.org/10.1038/s41597-023-02549-6)の[固定版データ](https://doi.org/10.6084/m9.figshare.21789074.v1)を使用する。固定アーカイブは`https://ndownloader.figshare.com/files/45057352`、SHA-256は`d37b8d05b39b96e7cf6e9007b024c7d1ab301d6668409e3e792962a2408fc05d`。アーカイブ内の`1991_2020/koppen_geiger_0p1.tif`だけを抽出した。[配布元の説明とライセンス](https://www.gloh2o.org/koppen/)を確認済み。CC BY 4.0、Beck et al. (2023)の出典表記と本サイトによる抽出・変換の表記を必要とする。

配布元が提供する0.1度の分類格子（南北約11 km）を使っており、画面の解像度を1 kmとは表示しない。各出力画素の中心座標から元セルを選択する。分類番号を連続補間せず、地点の気候を都市の月値から逆算しない。

範囲は西経93～33度、南緯56～北緯28度。既存の`regional-countries.json`から、South America、Central America、Caribbeanの条件に該当する34の国と地域を使用し、MEXを除く。PRIとFLKを含む。国境マスクは画素中心のeven-odd判定。境界の原典はNatural Earth（public domain）であり、領有関係への独自の見解を示すものではない。

全34地域に有効セルがあるが、小島は2～5セル程度しかない場合がある。海岸・島・国境の形は一般化され、一部の陸地セルが0となる。島を拡大したり、海域に近隣の分類を補ったりしない。仏領ギアナは既存の地域データで独立したfeatureになっていないため、このマスクにも独立追加しない。Web Mercatorのセル数を面積・人口・国別統計として扱わない。

## 都市の雨温図

[気象庁ClimatViewの解説](https://www.data.jma.go.jp/tcc/tcc/products/climate/climatview/outline.html)で統計期間1991～2020年とCLIMAT・GHCN由来であることを確認した。各ページの`Normal`の気温・降水量列のみを取得し、同一月が複数年表示される場合に一致することを検証する。`Observation`とSPIは採用しない。16地点×12か月×2要素＝384値がすべて揃っている。気温は℃、降水量はmm。原表の0は0として保持し、欠測を0で埋めない。

都市中心と観測所を混同しない。とくに高山都市や空港は標高と位置の違いが大きいため、地点名・標高・座標を原表に合わせて収録した。旧キト空港とレシフェ空港には平年値がないため採用せず、イソバンバとレシフェ市観測所を明示して使用する。パナマの候補ページは取得時HTTP 500となり採用していない。

[気象庁の利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)に基づき、出典リンクと加工した旨を表示する。推奨表記は「気象庁 ClimatViewの平年値をもとにInsight Journalが図表化」。観測所の平年値は都市・国全体を代表する平均ではなく、分類地図のセルとも別の資料である。

## 再生成と検証

Python 3.11以上、NumPy、Pillowを使用する。大きな入力ZIPと16地点のHTMLキャッシュはリポジトリ外に保存する。

```text
python scripts/atlas-latin-america-climate.py --archive /path/to/koppen_geiger_tif-figshare-v1.zip --city-cache /path/to/latin-climate-source-cache
```

`--download`を指定した場合だけ未取得ソースをネットワークから取得する。通常ビルドは静的配布ファイルを使用し、JMAやFigshareへの接続を必要としない。入力ハッシュが違う場合は停止するため、ソースが更新された場合は内容を再検証してから固定値を更新する。

検証済み項目：ZIP SHA-256/MD5、GeoTIFFのCRS・原点・0.1度解像度・nodata、分類ID範囲、原典30区分の凡例、全34地域のマスク、画像と格子の全画素一致、16観測所の名称・座標・標高、12か月の値と異年表示の整合性。独立した地点照合ではマナウスAf、ブラジリアAw、リマBWh、ブエノスアイレスCfaを確認。メキシコと外洋が0になること、PRI/FLKに有効値が残ることも確認した。PNGを目視で確認し、カリブ・中米・アンデス・アマゾン・南端の位置関係を確認した。
