# 農畜産・林業：同年・同品目の数量フロー監査（2026-10-14）

## 結論と判定範囲

「生産量＋世界生産シェア → 国内／域内見かけ量と輸出量・輸出÷生産 → 全相手国の輸出数量・構成」は、**中国2023年丸大豆の1国品目で、3段の数量比較を検証**した。国内側は在庫調整前の `P+I−X` で、提供元混合の比較である。実際の用途・在庫まで観測した国産原料の追跡フローを全3段検証できた品目は0件。品目名の一次確認前は比較も0件だったが、親が独立した公式WITS原ページを確認し、保存QCL236の品目名と一致する `Soya beans` を確認したため、中国大豆のみ採用した。保存WASDEの前2段や別年・別対象の参考資料を折り畳み表示しても、全3段の完成とは扱わない。

本監査は保存原表・生成物の読取、親から許可された独立した公式定義／Lukeメタデータの確認、および中国大豆の小JSON／pureデータ関数／原表検証テストの作成。UI、地図、日本専用画面、親の統合コードは変更していない。対象は選択済みの具体的な国・品目で、未選択の地域概説は保留。親が並行取得した `data-source/atlas/southeast-asia-independent-publications-20261014/` の結果は、この監査による取得・検証として数えない。SEA残件の詳細は [別監査](atlas-agro-statistics-sea-residual-audit-20261014.md) を維持する。

判定上の制約：国内利用は食用だけではない。`P+I−X` は在庫調整前の見かけ量であり、実際の用途・損耗・在庫増減・国産原料の仕向け割合ではない。`X/P` は輸入／期首在庫由来を含み得る総輸出と当年生産の数量比。欠測を0にしない。相手国数量はその貿易原表のWorld輸出量を分母とし、別版FAO輸出へ付け替えない。国別は全外国相手を含め、同じ地理地域の国も除外しない。地域集計では閉じた対象国集合と域内貿易の除外が別途必要。

## 東アジア：中国丸大豆のみ3段の数量比較を検証

`data-source/atlas/east-asia/statistics-2023/wits/{reporter}-{Export|Import}-{HS}.json` の `rows[].quantity / quantityUnit` は保持されている。既存 `public/assets/atlas/east-asia-v2/food-wood-statistics-2023.json.trade` の金額集約だけを見て「数量未取得」と判断してはいけない。数量単位は穀物・大豆Kg、製材m³。国別構成ではKOR/JPN/CHN、Other Asia, nes（原表区分）、香港・マカオも外国相手として保持する。日本を相手国として表示することと、日本専用画面の実装対象は別。
