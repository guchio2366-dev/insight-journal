# 西アジア・中東アトラス

2026年9月28日。対象は国連M49の西アジア18か国・地域に、編集上のまとまりとしてイランとエジプトを加えた20です。入口は `/atlas/west-asia/`、分野別は `agriculture/`、`nature/`、`industry/`、`population/` です。

## 画面と操作

北米と同じ `AtlasWorkspaceFrame`、ニュース欄、4分野のタブ、デスクトップのニュース／地図／詳説の配置を使います。1200px未満ではニュース300pxを先に表示し、地図と詳説の並びは各分野の北米と同じ画面幅の規則に従います。スマートフォンでは地図の後に詳説が続きます。小国は国の一覧から選べます。

配置の基準は北米の実装です。地域・国の選択はページ上部、パンくずと4分野タブは作業領域の先頭に置きます。自然環境は4タブの直下から地図と雨温図を並べ、水資源の下位項目は追加のタブで選びます。全項目を重ねた大きなプルダウンは使いません。農林業の品目は地図の直下、産業・人口の分類は地図の上、凡例は地図の直下、選択対象の説明は右側、国別の比較表と資料の詳細は下段に置きます。

雨温図は北米と共通の `AtlasClimatePlot` を使い、降水量0〜350mm、気温−10〜40℃の同じ目盛りです。18観測所の全平年値がこの範囲内に入ることを検証します。初期表示はリヤドです。都市名のラベルは座標を動かさず引出線で配置し、狭い画面で重なるものは地図下の一覧からも選べます。都市を選んでも地図を勝手に拡大しません。国の一覧で国を明示的に選んだときだけ、その国の範囲へ移ります。分野移動・再読込・戻る操作でも表示範囲を保ちます。

地図はWebメルカトル座標のSVGに、原資料から作成した分布画像と地理形状を重ねます。WebGLや実行時の外部地図APIを必要としません。一つの地図に主題を切り替え、拡大・縮小・ドラッグ・矢印キー・地域全体への復帰を提供します。画面が変わっても国・観測所・都市・選択地点・表示範囲・比較年をURLから復元します。観測所は別分野でも保持し、雨温図が非表示の間はその旨を表示します。

国別統計の比較と格子の分布は区別します。人口・農業等の格子を合計して国別統計を作る処理はありません。欠測は0に置き換えません。利用者が指定した年が未収録の場合も、その年を保持して未収録と表示します。主題切替時に収録値が全地域でない年の場合は、収録年へ切り替えたことを知らせます。

## 再作成

通常のサイトビルドは保存済みの成果を使い、これらの原資料をダウンロードしません。資料を更新する場合は、原資料の版を確認してから `scripts/atlas-west-asia.py` の各段階を順番に実行します。

共通引数は `--cache`、`--global-cache`（ETOPO、GHS-POP、MapSPAM、Natural Earth水系）、`--climate`（固定ZIP）、`--geography`（Natural Earth v5.1.2の10m国境GeoJSON）、`--farming`（GLWのメタデータ・圧縮チャンク）、`--fao`（FAOSTATの3ZIP）、`--urban`（GHSL都市ZIP）、`--gpkg`（都市の一般属性GeoPackage）、`--water`（BasinATLAS shapefile一式）です。全て作業者が明示するパスで、キャッシュやPC固有のパスをGitへ含めません。

段階の順序は `rasters → stats → cities → urban → water → extras → finish` です。`cities --discover` はJMAの観測所一覧を調べる専用の操作です。採用観測所は `src/data/atlas/west-asia-stations.json` に固定しています。Pythonにはrasterio、shapely、numpy、Pillow、pyproj、contourpy、pyshp、numcodecsを使います。気候色と観測表の読み取りは既存のアジアの共通処理を再利用します。

## 検証と制約

自動検証は20対象、北米の全30気候色、欠測と0の区別、全配信ファイルのハッシュ、格子の寸法、圧縮済み／配信側で展開済みの両方の読み取り、URLの復元、気候地点、エジプトより上流の流域、固定都市範囲を確認します。画面の検証は共通枠、20の選択肢、分野間リンク、履歴、資料取得失敗からの主題切替、未収録年の維持を含みます。

原資料の縮尺や解像度を超える精度はありません。淡水化施設の一覧・実際の供給量、個別港の現在の稼働状況、油ガスの生産施設・生産量の分布は未収録です。これらを概況地図や別の統計で代用せず、画面内で収録範囲を明記します。観測所を収録できなかった国でも、国の選択・分類格子・別分野の統計は利用できます。

Natural EarthのPSXをPSEに対応させ、CYPとCYNは国の選択をまとめますが、境界のポリゴンは残します。都市の国別選択は地図上の中心点で割り当てた表示上の区分です。統計提供元の対象範囲とは厳密に一致しない場合があり、領有権や現在の実効支配を示しません。
