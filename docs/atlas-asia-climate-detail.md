# アジア気候図の詳細化

## 原本と表示

Beckほか（2023）の固定アーカイブ `45057352` 内の、1991–2020年・30秒角版（赤道付近で約1km）を使用する。旧版の0.1度画像を引き伸ばす処理は行わない。分類IDは離散値のため、表示格子の中心に対応する原本の分類を最近傍で選ぶ。

表示と照会の格子間隔はWeb Mercator上で約2,226m。北米の表示間隔に合わせたもので、原本の1kmと表示間隔を区別する。高緯度では地表距離が小さくなる。境界は従来のNatural Earthの概略形状を用い、小島を拡大したり周辺の分類を補ったりしない。

| 地域 | 格子 | PNG | 圧縮した照会値 |
| --- | --- | ---: | ---: |
| 東アジア | 3,750×2,444 | 491,305 bytes | 266,230 bytes |
| 東南アジア | 2,651×2,179 | 136,065 bytes | 74,364 bytes |
| 南・中央アジア | 2,800×3,586 | 326,872 bytes | 164,285 bytes |

3地域の画像と照会値の合計は約1.46MB。画像と値は同じ配列から作り、値は必要時だけ読み込む。モルディブはマスク内14画素のいずれにも原本の分類値がなく、引き続き欠測とする。都市の観測所平年値は別の資料として利用できる。

## 検証と再生成

- 元アーカイブ・TIFF・凡例・境界・生成スクリプト・公開ファイルのSHA-256をmanifestへ記録。
- 生成後にPNGの全画素と照会用配列の一致を検査。
- 東京、ソウル、ウランバートル、シンガポール、バンコク、ジャカルタ、ニューデリー、アルマトイ、マレを原本へ独立照会。公開値・色との一致、海域、欠測を単体テストで確認。
- gzipと配信側で解凍済みのデータを受け付け、長さの不一致・範囲外の分類値・破損gzipを拒否する。
- 既存v1の原本・アセットと生成手順は保持する。

生成は `scripts/atlas-asia-climate-detail.py --archive <保存済みzip>`。ネットワークは使わない。通常のサイトビルドでは生成を行わず、検証済みの小さな公開アセットだけを利用する。
