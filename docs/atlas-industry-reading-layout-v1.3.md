# 主要産業 v1.3：地図横の製品解説とコンパクトな統計

更新日：2026-09-14

## 目的と合意

製品・サービスを選んだ時に地図と解説を同時に読めるようにし、下部の統計は比較しやすい横並びにする。デフォルトの全国構成比は項目を省かず高さを減らす。

最新の依頼により、v1.2の「分野選択時も右欄に業態の構成比を保つ」動作を変更する。農業の設計 PR #46（`docs/atlas-agriculture-map-reading-design-v7.2.md`、06cf486）の配置・幅条件を参照した。農業の実装には変更を加えない。

## 表示と操作

| 状態 | 地図の右欄 | 地図の下 |
| --- | --- | --- |
| 全産業・業態の全分野 | 付加価値と雇用の構成比 | 業態の概説・統計・出典 |
| 製品・サービスの選択中 | 何をする産業か／どこに集まり、なぜか／変化をどう読むか | 当該分野の統計・出典 |

選択中の説明文は既存の本文を移し、下部との重複をなくす。右欄には業態の構成比へ戻るボタンと下部の統計へのリンクを置く。ブラウザー履歴からの復元にも追随する。Escapeで構成比へ戻り、業態タブにフォーカスする。選択によって地図の位置・倍率を変更しない。

幅960px以上かつ高さ600px以上では、説明欄の上下を地図側の列に合わせる。本文14px・行間1.75を保ち、説明が収まらない場合は本文部分をスクロールできる。狭い画面では地図の下に説明を配置する。分野を選んだ時に説明が画面外なら説明の先頭へ移動し、モーションを減らす設定にも従う。

## 統計の配置

上記の幅・高さ条件で、系列数に応じて1・2・3列を使う。条件を満たさない画面では1列にする。

- 自動車の全国推移：出荷額／生産台数／雇用の3列。
- 自動車の比較指標：輸出先構成／世界生産の構成／米国の世界生産シェア推移の3列。
- その他の分野：利用できる経済指標・雇用などの系列数に合わせる。

生産台数や米国シェアの推移を別のグラフの下へ入れ子にせず、独立した同列のカードとする。折れ線の目盛りは3列時の縮小を考慮する。単位・年・統計範囲・欠年の切れ目・出典リンク・開閉式の数値表を保つ。データ未整備をゼロとして描かない。

## 構成比の集約

業種名は1行に1回だけ表示し、付加価値・雇用の割合を同じ行の2列で比較する。数値と棒の組を使い、両列の分母は全米または選択した業態を100%とする。

全産業の12区分とサービス業の7内訳、製造業の8区分を省略しない。金額・雇用数・定義は1つの開閉式表にまとめる。公表年とBEA出典への導線は常時表示する。

## 検証

- `npm run check`：ユニット84件、E2E30件、静的ビルド、公開成果物の検証が成功。
- 製品選択・業態への復帰・ブラウザー履歴で右欄が切り替わること、本文が重複しないことを検証。
- 自動車の2つの統計行がそれぞれ3カードであり、数値表の開閉状態を保つことを検証。
- 全産業の12区分・サービス内訳7区分・付加価値と雇用の値・原数表を保持することを検証。
- 公開後にPC幅・960px境界・狭幅の実表示、横方向のはみ出し、右欄の高さを確認する。

公式統計の数値や地図の規模表現はv1.2のまま。新しい統計取得・依存ライブラリーは追加しない。
