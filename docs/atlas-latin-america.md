# 中南米アトラス実装引継ぎ

中南米を国名の一覧から、国内の自然条件・農業・工業・人口の関係を地図と解説で読めるページに拡張した。公開ルートは `/atlas/latin-america/`。自然8・農業11・工業8・人口8の計35テーマ、気象庁の16観測地点、12作物と3家畜の分布、人口密度、国別比較を収録している。

この文書はリポジトリ内の実装と保存済みデータを説明する。最終的なテスト結果、実ブラウザでの確認結果、公開状況はレビュー時の実行記録を参照する。

## 対象地域と読み方

対象は既存の地域定義にある中米・カリブ海・南米の34か国・地域。メキシコは引き続き北米に属し、中南米の選択肢・分布データの対象に含めない。周辺国の輪郭は位置関係の説明用に表示する。

地名付きマーカーは解説の代表位置であり、地域の境界、資源鉱床の広がり、生産量の大小を表さない。テーマの `extent` も表示範囲の調整用で、統計上の境界ではない。一方、気候区分・作物・家畜・人口密度の面表示は出典データを変換した格子分布で、手描きの分布帯ではない。国別比較表は国単位の統計として分けている。

| 分野 | 主な内容 | 地図の数値・形状 |
| --- | --- | --- |
| 自然 | アンデス、アマゾン、セラード、パンパ、アタカマ、チリの地中海性気候、カリブ海、パナマの水 | 気候区分格子、主な河川、16観測地点の月別平年値 |
| 農業 | 大豆・二期作とうもろこし、ブラジルとコロンビアのコーヒー、さとうきび、パンパ、チリ果樹、アンデス農業、バナナ、中米コーヒー、植林 | 12作物の年間収穫面積、牛・豚・鶏の密度 |
| 工業 | 銅、リチウム、鉄鉱石、ブラジルの製造業、水力、大西洋の石油、パナマ物流、カリブ観光 | 拠点・地域の代表位置。製造業のGDP比率は国別比較表 |
| 人口 | ブラジル南東部・北東部、アマゾン河川都市、アンデス高地、ラプラタ、中米、カリブ、都市化 | 2020年人口密度。人口と都市人口比率は2023年国別比較表 |

各テーマには日本語の要約、因果関係・用語を説明する複数の節、出典、関連テーマへの導線を持たせた。数値カードには年次・単位・対象範囲を付け、都市・州・国の値を混同しない構成としている。

## データの年次・単位・出典

| 表示 | 保存したデータと処理 | 注意点 |
| --- | --- | --- |
| 気候区分 | Beck et al. (2023)、1991–2020年、Figshare固定版の0.1度格子を最近傍でWeb Mercator画像化 | 元論文の題名に1kmとあるが、採用したファイルは0.1度。現在の天気ではない |
| 月別気温・降水量 | 気象庁ClimatViewの16地点、1991–2020年平年値、各12か月 | 観測所の名称・標高を表示。空港などの値を市中心部の実測値としない。補間値を加えていない |
| 作物 | IFPRI MapSPAM 2020 v2r2、5分格子、灌漑と天水を合計した年間収穫面積、ha | 統計等を空間配分した推計。収穫面積は作付け土地面積・収穫量とは異なり、複数回収穫も反映する |
| 家畜 | FAO GLW4 2020、5分格子、牛・豚は頭/km²、鶏は羽/km² | GLW4の2015年版ではない。農場の実測位置を示すものではない |
| 人口密度 | JRC GHSL GHS-POP R2023A、2020年、等積図法の1km人口格子を10kmに集計し、人/km²へ変換 | 国勢調査等を空間配分した推計。沿岸の一部欠測セルでは有効面積を分母とする |
| 国別比較 | World Bankの2023年値 | 人口、都市人口比率、製造業GDP比率、農林水産業GDP比率、森林面積比率の5指標。欠測は「データなし」 |
| 国境・河川 | Natural Earthと既存の地域定義 | 小島や細かな河川の省略がある。精密な行政境界・流域境界として使用しない |

作物の選択肢は小麦、米、とうもろこし、大豆、さとうきび、コーヒー（アラビカ）、コーヒー（ロブスタ）、バナナ、カカオ、綿花、じゃがいも、温帯果樹。これに牛・豚・鶏と「森林資源と木材生産」を加える。農業テーマの数と選択できる格子レイヤーの数は異なる。

月別グラフはハバナ、キングストン、ベリーズシティ、サンホセ、マナウス、ブラジリア、サンパウロ、レシフェ、リマ、ボゴタ、ブエノスアイレス、サンティアゴ、ラパス、キト、プンタアレナス、モンテビデオ。グラフと併せて数値表を表示する。厳密な観測所名・標高・取得元は[気候データの説明](atlas-latin-america-climate.md)を参照する。

作物・家畜では描画の下限未満を透明にしているが、クリック用格子では有効なゼロと欠測を区別している。国集計は格子中心で対象国を判定した概算で、公式国別値ではない。家畜の概算頭数は密度に球面上の格子面積を掛ける。人口密度の表示画素や密度値を単純合計して人口総数としてはならない。Web Mercator上の見かけの面積も実面積の比較には適さない。

World Bankの都市人口比率は国ごとに都市の定義が異なる。森林面積比率は商業林や植林地だけの比率ではなく、農林水産業GDP比率も農業だけの値ではない。国別表と国内分布図は年次・集計単位が異なるため、同じ測定値として扱わない。

## 操作・URL・失敗時の動作

分野、国・地域、テーマ、観測地点、作物・家畜、気候／河川の切り替えに対応する。関連テーマや「同じ場所で気候・農業を見る」から比較へ進むと、直前の選択と地図位置を保存し、「元の解説と地図へ戻る」で復元する。

URL状態は `field`、`topic`、`place`、`city`、`crop`、`view`、`map`。`map` は経度・緯度・ズームを表す。分野に合わないテーマ、不正な地点・レイヤー・地図値を除外して初期値へ戻す。自然分野で有効な観測地点が指定された場合はテーマより優先する。国の指定が選択テーマ・地点と一致しない場合は国の絞り込みを解除する。

選択の変更はブラウザ履歴に保存し、地図移動は現在の履歴を更新する。「戻る／進む」でも状態を読み直す。比較前の状態は `history.state.latinReturn` に保存するため、共有URLは現在の画面を復元するが、別タブで開いた共有URLに比較元の履歴までは含まれない。

通常はMapLibreで描画し、WebGLが利用できない場合はSVGの簡易地図に切り替える。簡易地図でも一覧、拡大縮小、代表位置、取得できた格子分布・値の参照を利用できる。`?renderer=svg` は簡易地図を直接確認するための指定。JavaScript無効時も基礎地図・解説・出典を残す。

格子データの読み込みは選択したレイヤー単位で行い、連続切り替えで古い応答が新しい選択を上書きしないよう要求番号を確認する。失敗した取得はキャッシュから除き、選び直したときに再試行する。気候・農業データの失敗時は未表示である旨と基礎地図・解説を表示する。人口密度の取得に失敗した場合は代表位置と国別比較の案内を残す。国別統計の失敗も独立した案内を表示する。

## 再生成とレビュー

以下はリポジトリのルートから実行する例。Pythonの依存パッケージと元データの保管先は個別文書・スクリプトを参照する。元データの大きなZIPや取得キャッシュは公開ディレクトリへ置かない。

```sh
python scripts/atlas-latin-america-climate.py --archive ../climate-cache/koppen_geiger_tif-figshare-v1.zip --city-cache ../climate-cache/jma
python scripts/atlas-latin-america-agriculture.py --cache ../latin-agriculture-cache --dependencies /path/to/packages
python scripts/atlas-latin-america-livestock.py --cache ../latin-livestock-cache --dependencies /path/to/packages
python scripts/atlas-latin-america-population.py --cache ../latin-population-source-cache --deps /path/to/packages
node scripts/atlas-latin-america-context.mjs
```

気候と人口は不足する入力の取得を許可する場合だけ `--download` を付ける。人口の `--pin-inputs` は新しい入力を確認して記録し直すときの操作で、通常の再生成には不要。作物・家畜のスクリプトは不足する公開入力を自動取得する。家畜と人口、気候の固定アーカイブには入力ハッシュ検証がある。作物・国別比較・河川については保存した出典ハッシュと再取得後の差分を確認する。World Bankの過去年値にも改訂があり、河川の取得先も可変の参照なので、再取得が常に同じ出力になるとは限らない。

レビュー用の主な確認コマンドは次のとおり。実行結果は別途記録し、未実行の確認を完了扱いにしない。

```sh
node --test tests/unit/atlas-latin-america.test.mjs
npm run build
node --test tests/e2e/atlas-latin-america.test.mjs tests/e2e/atlas-regional-navigation.test.mjs
npm run check
```

対象テストはデータ整合性、URL・選択状態、比較復帰、表示切り替え、地域ナビゲーションなどを扱う。DOM上のE2EテストにはMapLibreの代替実装を使うため、実ブラウザでのWebGL表示や通信失敗の確認とは区別する。レビューでは通常表示と簡易地図、国・分野切り替え、比較からの復帰、共有URL・戻る／進む、連続切り替え、通信失敗後の再試行、モバイルとキーボード操作も確認する。

## 残る範囲と制約

標高ラスタや陰影起伏による地形表示、林業・森林分布のラスタは未実装。植林の地域解説と国別森林面積比率はあるが、森林の種類・伐採・植林地の空間分布を表す地図ではない。工業も拠点の説明と国別統計が中心で、産業の面分布や物流量を連続量の地図としては提供していない。

既存の国境図と格子中心によるマスクには海岸・小島の省略があり、カリブの小島はごく少数の格子しか持たない場合がある。フランス領ギアナなど、既存の地域定義で独立したフィーチャを持たない地域を新しい選択単位として追加していない。ズームしても元格子以上の細かさは得られない。これらを含め、北米との完全な機能同等を宣言する文書ではない。

## 北米との共通レイアウト

`AtlasWorkspaceFrame` と北米の共通スタイルを使い、左にニュース、中央に地図、右に解説を配置する。分野タブは農林業・自然環境・主要産業・人口の順。中南米トップは地理の概況、各分野は `/agriculture/`、`/nature/`、`/industry/`、`/population/` の独立したURLを持つ。旧URLの分野指定も読み込める。

作物と家畜は地図の下のボタンで選択する。選択国とカメラを保ち、解説がある場合は右側を切り替える。解説の「全体像へ戻る」でも国・分布・カメラは保持する。自然環境では雨温図を右欄の先頭へ置き、都市未選択時はサンパウロ、国を指定した場合はその国の掲載都市を案内する。地図の「全体」は選択を保ったまま中南米全景へ戻す。

画面幅に応じたニュース欄、地図の縦横比、列幅、タブ、ヘッダーの寸法は北米と共通。農林業の選択済み解説はデスクトップで地図の高さに揃え、本文を独立してスクロールできる。狭い画面ではニュース・地図・解説の順に積み、本文はページ全体でスクロールする。地名ラベルは重なりを避け、一覧からも全項目を選択できる。
