# 主要産業・全産業12区分 実装記録 v1.1

2026-09-14。設計 v1.1 に基づき、最新main `dacee772f45290362ac5b9387ab089deca594da1` を基準に実装。

## 変更

全産業のGDP・雇用グラフと数表を12区分へ拡張。サービス業の集約行を7分野に置き換え、全項目を常時表示する。分母は全米総額・国内雇用、2024年を維持。サービス業の親合計は別定義に保ち、サービス業タブでは従来どおり親を100%とした7分野を表示する。

サービス内訳に見出しとラベルの字下げを付け、バーの基準位置・0–100%軸を揃える。サービスの共通色を使用。全産業の文字サイズは12px、行間を確保し、ページ全体の縦スクロールで読む。「娯楽・宿泊・飲食」は住民利用も含むことを注記。

## 検証

- `npm run check`：単体テスト、ビルド、操作テスト、配信情報確認を完了。
- 2017–2024年のGDP・雇用を対象に、親子合計が原表丸め許容差内、原表行の重複なしを確認。
- 12区分の順序、全米分母、サービス親分母の保持を回帰テストで確認。
- ビルド済みHTMLの2図各12行・サービス7行・数表12行と合計、サービスから全産業への復帰を確認。
- 既存の金融→情報通信で右欄・カメラを維持する操作と履歴復元のテストを通過。
- ローカルプレビューへのCloud Browser接続は `ERR_BLOCKED_BY_CLIENT`。公開後の画面確認を別途行う。実機iPad Safariは未確認。

統計原表、依存関係、地図資産、農業・自然環境の実装は変更していない。設計PR #31の設計文書をこの実装に同梱する。
