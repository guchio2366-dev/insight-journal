# アフリカ：2020年の作物と家畜のモデル分布

## 実装範囲と受入条件

トウモロコシ・米・小麦・キャッサバの収穫面積と生産量、牛・山羊・羊の密度を加える。既存の林業、自然環境、主要産業、人口社会の画面を保持する。モデル推定を実測圃場や全頭の一斉調査と称さず、代表位置を量の分布として使わない。

分布の期間・単位・全凡例と持ち帰る要点を主地図の近くに置き、長い方法・限界・原典は折り畳む。国別統計の年選択を変えても固定2020年の分布を更新したように見せない。商品と作物指標をURL、履歴、概要往復、比較往復で保持する。比較では元の分布と全凡例を残し、選択した商品名を付けた戻りを設ける。

初回画面は既存USと同じ1366×768で実画像を比べる。本文を過剰に小さくせず、主地図・要点・操作を一画面に収める。候補の単体試験・build・E2E・release照合、Draft PR、Library実画像の親目視を経る。新画像の合格後に親から公開指示を受けるまで、mergeと公開を保留する。

## 作物：SPAM 2020 v2r2

原典はIFPRIの [SPAM 2020 Dataverse](https://doi.org/10.7910/DVN/SWPENT)、確認した固定メタデータはversion6.0、公開日は2026年5月5日。データ固有のTermsのCC BY4.0が再利用・再配布・商用利用を認める対象であることを確認した。MapSPAMの旧データ向け一般利用条件と混同しない。

公式Data Centerの公開mirrorから取得した収穫面積・生産量ZIPを、当該Dataverse固定版のMD5と照合して同一性を確認した。DataverseのGuestbookはemailとinstitutionを要求するため提出していない。原本READMEのmirror版はサイズが同じでも固定メタデータのMD5と異なり、別資料として記録する。

| 原本 | bytes | SHA-256 |
| --- | ---: | --- |
| harvested area ZIP | 68,007,241 | `34895a332ba7ff9d9732a81fe9da7063458d197f3c72ce3a405329c41f94ade2` |
| production ZIP | 75,175,570 | `7bdce0d9f48d50c2596fbc35bfeb1a4d37afa59f421a6b0c2c10fd221277e42d` |

収穫面積はha/元の5分角セル。多期作は収穫ごとに数えるため、物理的な農地面積や土地の被覆率ではない。生産量はt/元セルであり、単位面積当たりの収量ではない。緯度経度格子のセル面積は緯度で異なる。全方式（TA）を使用し、灌漑・雨水別の系列と混ぜない。

統計と土地利用などから生産を配分したモデル。値なしを非生産の0と解釈せず、砂漠の欠測を栽培不能の証拠にしない。表示は元の5分角を再標本化せず切り出し、国境付近のセルを境界内の中心点で選ぶ。セル値を境界内面積へ比例再配分した国別集計ではない。

## 家畜：FAO GLW4 2020

原典は [FAO GLW4 2020 catalogue](https://data.apps.fao.org/catalog/iso/9d1e149b-d63f-4213-978b-317a8eb42d02)。カタログはCC BY4.0を明記し、対象年2020、公開日は2024年7月15日。今回のD-DAファイルは頭/km²の密度であり、過去版の頭/セルという説明と混同しない。元TIFFの実データ型はFloat32。

各地の調査統計をRandom Forestなどで空間配分し、2020年のFAOSTAT総数に整合させた推定密度。入力調査年は国・種別で異なる。モデルの説明変数に人口・植生・標高などを含むため、環境図との重なりから環境の効果を独立に検証できない。密度は農場位置・食肉生産量・放牧だけの分布ではない。

## 共通の加工・読み方

原本はEPSG:4326、4320×2160、5分角。表示範囲は西経27〜東経64度、南緯36〜北緯39度、1092×900の元セルを保つ。この緯度経度表示は等面積ではなく、高緯度のセルを相対的に大きく見せる。家畜の色は密度であり、色の広さを総頭数と読まない。原本NoDataはFloat32の最小有限値で、配信値では-1に変換し、PNGでは透明とする。有効な0は別の淡色で表示する。空間・年・国の穴埋めは行わない。

気候と水は生産を支える条件だが、品種・灌漑・飼料・獣医療・労働・加工・輸送・価格・土地や水の権利も分布を変える。作物比較の国全体の耕地割合は選択した作物の量ではなく、家畜比較の農林水産業付加価値/GDPは畜産だけの価値や頭数ではない。

原本と取得応答の記録は非配信の作業保存先に保持する。配信manifestには原典URL・利用条件・原本SHA・加工方法・単位・期間・欠測・限界を記録し、通常のサイトbuildで原データを再取得しない。今回GeoEPRなどの利用許諾未解決の文化資料を追加しない。
