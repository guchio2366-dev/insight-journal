# Oceania：保存済み農畜産5品目の表示

Russia PR #221（merge `4e77c3b`）の公開確認後、Europe PR #246を含むmain `ec61f3b` から実装した。対象は保存済み2020年の小麦・ココナツ・カカオ・羊・牛。全国上位10品目、林業、国別の生産・貿易・世界シェアと推移は未整備であり、この変更で網羅性を主張しない。

## 表示と操作

- 初期は国・テーマを選ばず、全範囲と保存5品目を表示する。
- 小麦は数量色、ほかの作物は正値の輪郭、羊・牛は別の色・位置の密度階級の点で重ねる。品目選択ではその数量色を表示し、他分布を残す。作物選択時は家畜の点を薄くし、選択作物以外の品目名・記号も32%の濃さにする。分布と名称・記号は消さない。
- 数量の表示色を品目別に変えても、元の階級境界と値を保持する。作物はha／元5分セル、家畜は頭／km²で、足し合わせたり国計へ換算したりしない。
- 地図下は5品目の小型凡例。数量階級・単位・0・欠測は閉じた詳細へ残す。右側は自然条件、栽培・飼養、加工・集荷・市場の地理説明を先に読む。技術説明と範囲は折り畳む。
- 国・地域、分布、追加の範囲・テーマ操作は左上。農業地図内の重複国選択と国名のクリック対象を外す。国選択、品目選択、再読込でも他分布と全範囲を保持する。
- 原本の小島の未収録を農業ゼロにせず、林業等を空の図や推定値で埋めない。既存の自然・産業・人口の表示と他地域のコードは保持する。

## 出典と生成物

`prepare-oceania-russia-farming-overlay.py --region oceania` は保存済みFloat32格子を読み、表示専用のPNGと入力SHA・年・単位・階級・ライセンス・正値/0/欠測数を記録する。元格子・元PNG・元manifestは変更しない。外部データ取得、補間、集計、未決の少量品目の除外を行わない。

数量画像は元セルの階級を直接着色し、有効0は白、欠測は透明のまま背景斜線で示す。家畜の点はすべての正値を元の密度階級で保持し、0は無描画、欠測は別の正確なマスクで示す。羊と牛の点は元セル内の別位置に置く。点の数は個体数ではない。輪郭は正のモデル収穫面積の外縁で、実際の農場境界ではない。

モデル・配布元の2020年、CC BY 4.0、IFPRIの帰属と改変表示、GLW4のFloat32変換履歴を残す。説明資料の年を数量図の年と同一視しない。

## 検証

ローカル単体14件、既存Oceania E2E6件、ビルドが成功。独立PNGデコーダで元格子の全セルと数量色、密度階級、0・欠測を照合し、入力SHA・原階級・境界・年・単位・ライセンスを確認する。Russiaの生成済み表示画像と元格子も同じ検証で保持を確認する。

地域専用workflowはsandbox有効の既存Chromeを使い、1536/1024pxで操作を検証し、今回の修正は1536pxの初期と小麦選択の代表2枚だけを保存する。5品目の選択、国選択、再読込、他分布保持、凡例・操作の位置、名称の重複防止、詳細開閉、本文の非切断を検証する。初回headの1536初期と1024小麦選択は親担当が実画像で確認した。選択連動の修正では、実Chromeの名称・記号の表示値とPNG描画差を記録する。最終headの実画面検証と必須Validate通過後に、承認済みの既存Pages公開へ進む。
