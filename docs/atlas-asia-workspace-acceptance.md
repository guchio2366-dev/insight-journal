# アジア共通画面の受入記録

## この変更で提供する範囲

- 東アジア・東南アジア・南／中央アジアの既存気候・米の地図を、北米と同じニュース／地図／解説の共通フレームへ移す。
- 3地域それぞれに `nature/` と `agriculture/` を提供する。旧地域URLと `?field=agriculture` は選択を保持して正規化する。
- 分野を切り替えても国・都市・選択格子・地図の位置を保持する。比較から元の分野へ戻る。分野リンクを別タブでも開ける。
- 都市を選ぶと、右の解説欄の冒頭に雨温図を表示する。小さい画面では地図と解説を縦に配置する。
- ニュースは各地域の国タグで抽出する。国指定のないアジア全体の記事は3地域に表示し、他のアジア地域・中東・ロシアの国タグだけの記事は混ぜない。
- 記事から地点を開く操作では、分野を保ったまま以前の国・都市・格子・比較を解除する。

## 検証

- アジアの単体テスト31件：元データと公開アセットの一致、欠測、状態の往復、共有URL、比較復帰、履歴、描画障害時の案内、地図の重複生成防止。
- 関連する静的ページ・ニュース・地域ナビゲーションの統合テスト14件。
- 全サイトビルドと公開境界検証。
- ブラウザー：1280pxと390pxで横あふれなし。東京の雨温図→米→ブラウザーの戻るで都市・分野を復元。3地域の切替、デスクトップの3列とモバイルの縦配置を確認。
- 分野パスを古い `field` クエリより優先する。比較の復帰先は保存した分野で検証する。旧地域ページの正規URLは `nature/` とし、サイトマップには分野ページだけを載せる。

## 未完了

この記録は画面と遷移の改善の受入であり、北米と同じデータ粒度の完了を示さない。自然の水系・地形・等高線、複数作物・畜産・林業、産業、人口、各分野の詳細統計と地域別の読み物は引き続き実装対象。提供前の産業・人口タブは表示しない。
