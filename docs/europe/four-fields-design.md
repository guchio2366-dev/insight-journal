# 欧州4分野・追加実装の設計

既存の45対象、24地点の雨温図、国選択とURL復帰を土台にする。
MapLibre 1台と同座標のSVG代替図を維持。欧州専用ファイルを所有する。

|表示|読み取る対象と単位|表現・欠測|確認|
|---|---|---|---|
|人口|GHSL 2020、1km等積格子を5km四方へ集計した人口/km²|青の順序色。人口合計÷有効な元格子の面積。0と欠測を分離|元格子・加工格子の一致、都市近郊の値、海域|
|都市|Natural Earth 5.1.2の都市位置|同じ大きさの点。人口値・順位は推定しない。国別一覧と選択ラベル|座標、国コード、拡大時の読みやすさ|
|地形・等高線|NOAA ETOPO2022 60秒角、標高m（EGM2008）|陸域の段彩、陰影、500m等高線。表示用に間引き。測量用途にしない|アルプス・低地の既知地点、海と負標高の区別|
|水系|Natural Earth 1:50m河川・湖|青の線・面。流量を符号化しない|国境をまたぐ河川、流路の切断、一覧から選択|
|農作物|SPAM2020、5分角格子の収穫面積ha|同じ閾値で作物を切り替え、気候と比較|元格子の値、0・欠測、各作物の定義|
|国別指標|World Bank WDI、共通2023年・国全体|単位別の色と表。出典の欠測維持。ロシア全土・海外領土の扱いを明記|全45対象への結合、範囲、年、単位|
|産業の拠点|出典を付した地域・施設の代表位置|同寸の点、類型と解説。生産範囲の面を創作しない|出典と位置、選択のURL復帰|

各層の主担当は地理可視化スキルによるローカルの設計・批評パス。
国別数値は照合用表を優先し、分野間で統計の分母を混ぜない。
選択はlayer/place/region/city/compare/returnLayer/featureに保存。
モバイルは地図→凡例→解説。ラベルは選択中中心、主要操作44px。
アセットは選択時取得、失敗時はメッセージと出典・代替図を残す。
QAは元データ不変条件、状態往復、通常/代替描画、狭幅、公開後URLで実施。
