# 欧州の共通レイアウト

欧州概況・農林業・自然環境・主要産業・人口に、北米と同じニュース／地図／解説の配置を適用します。ニュース欄は既存の共通部品を使い、欧州に該当する公開記事だけを表示します。記事がない場合は空の状態を表示します。

幅1200〜1599pxではニュース欄を19vw（220〜340px）、地図と解説を1.65対1、両者の間隔を14pxとします。スマートフォンの縦画面ではニュース、地図と凡例、解説の順に積みます。高さ500px以下の横画面ではニュース欄を省き、地図と解説を並べます。欧州に限定したCSSで配置を調整し、北米・アジアのスタイルを変更しません。

自然環境の区分は気候区分、水資源、地形、標高（等高線）の順にします。農林業の農業・畜産・林業と、主要産業の切替は地図枠の内側上部に置きます。人口の区分は人口分布、宗教の分布、民族の分布とし、投票の区分は設けません。国の選択と詳細データの選択は右の解説欄に置きます。

この変更は配置の実装です。地図・統計・解説には既存のデータを使用します。農業の統合分布図、宗教・民族の分布、産業の資源・エネルギーと建設・不動産の個別表示は別途整備が必要です。未整備の区分は準備中と表示し、架空の統計を追加しません。作物・家畜・国別統計など既存の29主題は詳細データの選択欄から利用できます。

欧州の地図は国を基準にしたURLを使用するため、ニュース本文から座標へ移動するボタンは今回表示しません。記事の閲覧と一覧への復帰は共通部品で利用できます。既存の国・主題・観測地点のURL保存と比較機能は継続します。
