# 欧州の共通レイアウト

欧州概況・農林業・自然環境・主要産業・人口に、北米と同じニュース／地図／解説の配置を適用します。ニュース欄は既存の共通部品を使い、欧州に該当する公開記事だけを表示します。記事がない場合は空の状態を表示します。

詳細ページでは、地図と解説を2.1対1、両者の間隔を14pxとします。地図は欧州の南北の広がりを収めるため、幅と高さの比を1.2対1とします。幅1200〜1599pxではニュース欄を220pxに抑えます。スマートフォンの縦画面では地図、短い操作案内、雨温図・解説、凡例の順に読み進めます。高さ500px以下の横画面ではニュース欄を省き、地図と解説を並べます。欧州に限定したCSSで配置を調整し、北米・アジアのスタイルを変更しません。

自然環境の区分は気候区分、水資源、地形、標高（等高線）の順にします。農林業の農業・畜産・林業と、主要産業の切替は地図枠の内側上部に置きます。人口の区分は人口分布、宗教の分布、民族の分布とし、投票の区分は設けません。国の一覧は概況で扱います。詳細ページの右側には国・主題・都市・比較の選択欄を置きません。

気候では右側の先頭を「都市の雨温図」とし、地図の都市名を押すと1地点の雨温図を切り替えます。クリックによる国への自動拡大は行いません。広域表示では主要15都市、狭い画面では8都市と選択中の都市に名前を付け、拡大時には範囲内の観測地点を表示します。月別の数値と観測地点の詳細は折りたたみます。水資源・地形・産業では、主題の要点と地図で選んだ場所の説明を示します。

気候記号の候補は `scripts/europe/prepare-map-labels.py` で生成します。表示画像と同じ分類の画素上に配置候補を限定し、対応する元の分類格子で一致を検証します。都市名は元の観測地点に点と引出線で結び付け、記号と操作ボタンを避けて配置します。通常地図とSVGの簡易地図で同じ表示層を使います。地図の投影は既存のEPSG:3857を維持します。雨温図の気候記号は位置に対応する地図の格子を参照しており、気象庁の月別平年値から新たに算出した分類ではありません。

地図・統計・解説には出典を確認したデータを使用します。農業の初期表示では、SPAMの2020年頃の12作物とFAO GLW4の2020年の4家畜を、それぞれ独立した主な分布面として表示します。作物と畜産の表示は双方をON、品目は未選択とし、重なりと離れた区域を保持します。作物は実線、家畜は破線で区別します。元格子の集中域を平滑化・簡略化した概略図で、圃場・牧場の境界や全生産域ではなく、色や面積から品目間の生産量を比較できません。地図上の品目名または下の一覧から個別の数値付き図に移れます。入力のハッシュと加工条件は `farming-overview-v2/manifest.json` に記録します。ブドウ・オリーブ単独の格子は採用原本に含まれないため、図にあるようには示しません。

宗教・民族は、2021年国勢調査のイングランド・ウェールズ331行政区とクロアチア全国値の限定事例を扱います。各資料の分類・分母・行政区／全国値の粒度を保持し、欧州全域の文化分布や一様な地域比較にはしません。欧州全域の文化分野の網羅と、産業の資源・エネルギー、建設・不動産の個別表示は別途整備が必要です。未整備の区分は準備中と表示し、架空の統計を追加しません。個別の作物・家畜は地図の下の折りたたみ欄からも選べます。従来のデータとURLの解釈は保持し、概況図を含む30主題に樹木被覆・年降水量・流域区画・民族・宗教の5主題を加えた35主題を扱います。公開候補の範囲と未完了の確認は[初版の公開範囲と残作業](four-fields-release.md)に記録します。

欧州の地図は国を基準にしたURLを使用するため、ニュース本文から座標へ移動するボタンは今回表示しません。記事の閲覧と一覧への復帰は共通部品で利用できます。国・主題・観測地点のURL保存は継続します。古い比較URLは最初の1地点を表示します。
