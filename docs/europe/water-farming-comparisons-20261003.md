# 欧州の農林業・水比較と西アジアの年降水量

2026-10-03の候補。基準 main は `32f6105`。北米の「分布を選ぶ→条件と数量を分けて読む→元の選択へ戻る」を、既存の地図と画面構造に接続する。公開判定は最終CIと親担当の同寸法実画像確認を経て行う。

## 今回読めるようにする内容

- 欧州の17農畜産主題から、品目・対象国に応じた月気候、年降水量、地形、流域区画等の代表3入口を示す。米はポー平原またはポルトガルの実格子とBasinATLAS区画へ接続。未収録のミラノ観測をローマの雨温図で代用しない。ヘルシンキの降水12か月欠測は保持し、月別比較の問いを気温の季節差にする。
- 比較先では元品目の集中域の輪郭とその凡例、比較地点の位置と年降水量等の値、短い具体的な問い、対象名付き戻りを示す。輪郭は圃場や灌漑供給区域ではなく、地図の重なりから水量や生産量を算出しない。選択を変えると古い地点の説明と表示範囲を解除する。
- 欧州45対象についてFAOSTATの直接分類22指標を収録。9作物の生産、4種の生体数、6種の肉・乳・卵、丸太・製材・森林面積を区別し、2015〜2024年の公表値と記号・注記を保持。同じ年の国別比較と最大2比較国の推移を読める。販売総額・需給用途・輸出相手国は引き続き未収録。
- 世界比の分母は同年・同品目・同集計要素・同単位の公表World行。欧州の選択国の合計ではない。森林面積、木材体積、頭羽数、重量を足さない。KOS等の原資料との対応がない対象と未掲載年を0に置き換えず、ロシアの全国値は欧州表示枠外を含む全土と明示する。
- 西アジア20対象にGPCCの面的な年降水量を追加し、既存18観測所の点の降水量と別主題にする。灌漑・天水小麦のそれぞれから元分布・両凡例を保持して比べる。年合計は現在の水供給量や栽培限界ではない。

## 固定原典と利用条件

欧州数量は保存済みFAOSTAT QCL・Forestry・Land Useの原ZIPを再利用。原小数・年・M49・項目/要素コード・出典記号・注記を抽出し、推測や別年補完をしない。FAO統計データベース利用条件はCC BY 4.0（個別metadata例外を確認）。資料の公表日と保存原本の再利用日を分けて記録する。ドイツの2024年鶏生体数、フランスの同年鶏卵トン値は採用原ZIPに直接行がなく、産卵鶏数等で補わない。

GPCCはDWD Climatology Version 2025の0.25度・1991〜2020年の月別平年値。12か月が有効な原格子だけ年合計を求め、表示点には最寄り原格子を用いる。固定SHA256と出版社MD5、CC BY 4.0の公式利用条件根拠を既存欧州ledgerと照合する。追加補間、国内平均、利用可能水量を計算しない。

入力と出力のハッシュ・加工・出典・利用条件は各 `farming-statistics-v1` / `west-asia-precipitation-v1` manifestと `data-source` の記録に保持。巨大な原ZIP、私的保存先、実画面証拠を公開リポジトリへ含めない。

## 画面・状態と検証

地図の大きさ、上部の分野・水の操作、ニュース左配置を維持。比較モードでは欧州の地域ナビを1行へまとめ、重複する詳細を開閉にまとめる。文字や地図を縮めて一画面へ押し込まない。数値の全表は既存の下部統計欄に置き、右上に選択国の短い数量と比較への入口を示す。

数量選択は `farmYear` / `farmMeasure` / `farmCompare`、比較地点は許可リストの `europeFocus`。出典地点・対象年を表示し、通常選択・履歴・再読込・比較復帰を一致させる。取得失敗は再試行可能、遅い旧応答は新しい品目へ書き戻さない。

PCの1366×768 / 1180×757を中心に北米同分野と並べ、両凡例、比較の要点、原分布、復帰、月軸、末尾出典を実画面確認する。通常WebGLとSVGを区別する。全数値の独立原CSV照合、原GISと表示格子の地点照合、gzip/配信展開済み両形態、0/欠測、単位、選択同期の試験を行い、最終aggregate checksを別に記録する。
