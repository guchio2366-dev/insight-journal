# 欧州詳細版の実装契約

2026-09-25。基礎地図45対象を維持して主題別表示を段階的に追加する。
初期ベース：96918bef794fb0c97bf4a6d4759fa7338cbcfa4b。

## 今回の順序

1. 公開・再配布条件を確認した気候データと観測地点を固定する。
2. 気候単独起動、国と都市の選択、雨温図、出典、URL・履歴を実装する。
3. 小麦データが利用可能なら、産地と気候を比較して戻れる形に進める。
4. 自然環境の他表示、農林業、産業、人口へ必要条件ごとに展開する。

## 所有するファイル

欧州ページ、EuropeAtlasPage、atlas-europe-*、src/data/atlas/europe/、
public/assets/atlas/europe/、scripts/europe/、docs/europe/、欧州のテスト。
アジア・北米の作業ディレクトリと実装を変更しない。
共通入口・sitemapが必要なときだけ最小差分で統合する。

## 描画と操作

MapLibreは1ページ1台。EPSG:3857で画像・輪郭・選択を一致させる。
静的SVG代替図も同じ投影・アセットを使い、国・都市の一覧から選択できる。
regionとplaceの旧URLを保持し、分野・都市・比較と戻り先を独立した状態とする。
気候単独で起動し、未実装分野の取得を要求しない。
国境をまたぐ主題を保ち、国は輪郭で注目する。

デスクトップは地図と解説の2列。390px縦・844px横では地図を先に置く。
主要操作は44px以上。凡例・雨温図の数値はホバーなしで確認できる。
地図のズームにはボタンを用意し、狭幅のページスクロールを奪わない。
読み込み失敗時には静的地図・説明を残す。位置情報等の端末権限は使わない。

## 根拠と完了判定

生の入力URLとハッシュ、加工コード、出力ハッシュ、期間・解像度を保存する。
観測値と格子分類を区別し、欠測をゼロにしない。
国統計の範囲を地図の表示枠で推定しない。
通常地図と代替表示を分けて確認し、テスト・実ブラウザ・公開URLの証拠を記録する。
部分公開を4分野の完成と呼ばない。
