# 欧州4分野・初版の公開範囲と残作業

更新日：2026-10-02。以下は現在の公開候補の範囲であり、最終候補の全サイト検証・配信・公開URL確認の完了記録ではない。

欧州概況から4分野へ進み、分布の要点を一文で読み、条件の異なる地図を比較して元の選択へ戻れる初版とする。

## 実装範囲

- 欧州概況と自然環境・農林業・産業・人口の階層を維持。45か国・地域、23か国の気候24地点、17気候区分を扱う。
- 主題は従来の概況図を含む30から35へ追加。自然環境6、農林業19、産業4、人口6。主題数はデータ・本文の網羅率を意味しない。
- 自然環境：気候・河川湖沼・地形標高・500m等高線に、年降水量と流域区画を追加。既存の85河川地物・80湖地物を保持。
- 農林業：小麦を含むSPAMの12作物、FAO GLW4の牛・豚・鶏・羊、作物・畜産の概況図、樹木被覆、国別の森林面積比率。
- 産業：4群14代表地点、出典と対象年を付した説明。製造業・鉱工業建設業・サービス業の2023年国別GDP比率。拠点の点は生産額・雇用数を示さず、GDP比率は絶対額ではない。製造業と、それを内包する鉱工業建設業を足し合わせない。
- 人口：2020年の人口密度、132都市位置、2023年の都市人口比率・高齢化・人口増加率。民族・宗教は2021年国勢調査の限定事例を追加し、欧州全域の分布として扱わない。
- 国別10指標、共通2023年の比較表、2020〜2024年の数値表。欠測は他年補完しない。
- 雨温図を初期表示の読む順序の先頭に置き、地図に隣接した凡例で全区分を確認できる構成。主題説明は要点・短い説明・出典を示し、比較先では比較元の地図と具体的な問い、選択名を付した復帰を用意。
- 国・地域・主題・地点・比較元をURLに保存。分野をまたぐ比較では対象地点・地物との対応を確認し、比較元の選択と表示条件へ戻す。通常地図と同投影のSVG代替、選択時の取得を維持。

## データと再現

大きな原本はリポジトリ外の `../europe-source-cache`。必要な範囲抽出と取得記録を保存し、表示用の加工結果を配信する。
`fetch-context.py` → `prepare-context.py` でNatural Earth 5.1.2とWDIを加工。
GHSLとETOPOは各manifestのdownloadUrlから取得。`prepare-physical-population.py population` / `physical`。
SPAMは前回と同じハッシュの原本。`prepare-farming.py` で作物とFAO GLW4を加工。
Python依存はnumpy/Pillow/rasterio/shapely/pyproj/contourpy/numcodecs。
既存資料のmanifestに原本URL・SHA256・加工方法・単位・対象年・出力SHA256を収録。追加資料の取得記録は `data-source/atlas/europe/`、生成処理は `scripts/europe/prepare-{tree-cover,precipitation,drainage,population-cases}.mjs`。追加3地図の配信manifestと、国勢調査事例の取得manifest・`cases.json` に公式利用条件・帰属・加工・対象範囲を記録する。

- 樹木被覆：ESA WorldCover 2021 v200の区分10を、配信元COGの約640m概略格子からカテゴリとして抽出。配信元の概略格子の集約方式は明示されていない。元製品の10mを表示精度とせず、植林地やオリーブ等の樹木作物を含む被覆として読む。その他の有効な被覆と出典欠測を分ける。FAO定義の森林面積・商業林・木材量・林業生産量は求めない。2023年WDI森林面積比率と分ける。CC BY 4.0。
- 年降水量：GPCC/DWD Climatology Version 2025、1991–2020年の0.25度月別平年値。12か月すべてが有効な格子のみ合計し、mm/年で表示する。最も近い原格子を表示用格子へ置き、追加補間・国内平均・水供給量を計算しない。原本の公開MD5と取得SHA256を記録。CC BY 4.0の根拠は製品がリンクするDWD公式利用条件で、DOI登録情報の権利欄による確認ではない。
- 流域区画：実際のBasinATLAS v1.0のレベル4を使う。2019年は製品の公開年で、境界は地形・排水モデル由来。カテゴリ色は区画を識別するもので量の順序はない。個々の名前付き河川の全流域とは限らず、流量・地下水量は示さない。取得したZIP内の原本エントリはCRC32とSHA256を記録・照合し、ZIP全体の取得・MD5確認は行っていない。集約データベースのCC BY 4.0に沿って区画IDだけを使用し、個別に利用条件の異なる環境属性は配信しない。
- 国勢調査事例：イングランド・ウェールズの2021年331行政区のTS021・TS030と、クロアチア2021年の公表された全国行だけ。英国全体やクロアチア国内の地域分布を補完しない。元の大分類・細分類を保持し、重複して足さない。無宗教・未回答・未申告・不明を区別し、表ごとの総人口分母、秘匿処理による合計差も修正せず保持。分類と行政区／全国値の粒度を統一した欧州比較にはしない。ONSはOGL v3.0、クロアチア統計はCroatian Open Licence、全国の表示輪郭はNatural Earthのpublic domain。

GHSLは元1km等積格子の人口合計÷有効面積で5km密度を作る。単純な人口画像の補間はしない。
地形の元CRSはEPSG:9518（水平WGS84、鉛直EGM2008）。水平のみ再投影し、高さは同基準を保持。
標高の照会は表示格子を整数mに丸める。これは1m精度を意味しない。負標高と海域欠測を分ける。
都市は位置情報のみ。異なる定義・年のNatural Earth人口列を大きさや順位に使わない。

## 公開前の検証と現在の状態

国と主題のURL復元、気候比較元の復帰、数値画像の出典ハッシュ、人口と標高の既知地点、0と欠測、全国値の45対象結合。
ブラウザではウクライナのヒマワリ583.9ha、ブラショフの解説と再読込、国別指標の切替を確認。
全サイトcheck、390px縦・844px横・1280px前後、通常地図と簡易地図を確認してから公開する。

追加資料では元データ・加工結果・欠測・凡例・選択値の一致、国勢調査の331行政区の完全結合と元数値・分類・分母の保持を確認する。流域は出典の大陸領域コードによる除外をなくし、レベル4の原本全1,342区画から、表示枠と45対象の陸域に寄与する131区画を生成済み。ロシアの3地点は原本ポリゴンとの独立照合を行い、修正に関する21テストが通過している。表示不足のバチカン・モナコや出典にない場所は欠測として残し、穴埋めしない。

比較元地図のWebGL画像3例はレビュー済み。最終候補を固定した全サイトcheck、必要な画面幅と通常／簡易地図の確認、配信後の公開URL復帰確認は未完了。途中の画像レビューや個別確認を、最終候補のCI・公開成功として扱わない。

## 残る詳細化

この公開で4分野に到達できるが、北米と同等の全必須項目の完了とはしない。
作物・家畜の販売総額、需給・用途別消費、生産量・世界シェア、輸出額・相手国、国内行政地域の経済雇用系列、林業の森林型・伐採・木材生産統計、産業細分類の充足、人口移動・文化背景は後段とする。降水・流域を追加しても地下水と水供給量は未収録。
国別の5テーマ本文は45対象×5の225枠を持つが、準備中の本文枠を中心とした構成を保持している。今回の主題解説・事例と区別し、各国各テーマの編集網羅を完了としない。文化分野の追加も上記の2事例に限り、全45対象の網羅を意味しない。
ブドウ・オリーブ・ライ麦・オーツの専用分布を、SPAMの集合区分で代用していない。
小国では5km人口格子・5分農業格子の分解能が不十分になり得る。国境と都市位置、全国統計を併用する。
国別指標は国全体。ロシア西部だけへの再集計や表示範囲外領土の一律除外を行った値ではない。
