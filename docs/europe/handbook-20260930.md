# 欧州：9月29日改訂ハンドブックへの対応

確認日：2026-09-30。参照した資料は、Notionの[北米サイトの実装・編集ハンドブック](https://app.notion.com/p/3e8340138e73816d8399ec771163165e)と、同ページからリンクされた[画面・選択・遷移仕様](https://app.notion.com/p/3e9340138e73815081bedaaaf0d6e32d)です。基本は9月29日の指定に合わせ、気候欄の配置には、その後のユーザーの直接指示「地図の右側に雨温図。その下に気候区分と特徴的な農畜産物の説明」を優先しています。

## 今回変更した範囲

- 分野ナビを農林業・自然環境・主要産業・人口の4つにそろえました。欧州概況へは上部の地域リンクから移動できます。
- 地図左上に、作物と畜産の独立した表示切替を置きました。初回は双方を表示し、品目は未選択にします。
- 元の収穫面積・家畜密度の格子から、12作物と4家畜の主な分布を独立した面として生成しました。重なりと離れた区域を保持し、選択時は分布全体の輪郭を強調します。
- 通常の品目選択は他の品目やON/OFFを変更しません。非表示の品目は説明だけを選択し、明示した単独表示ではその品目だけを描きます。元のON/OFFへ復帰でき、URL・再読込・履歴でも保持します。
- 重なる地図面では全候補を選べます。地図直下にも全品目の名称と色を置き、概論への入口とEscapeを用意しました。通常地図と簡易地図は同じ面・穴・重なりの判定を使います。
- 気候の初期対象をイギリスの首都ロンドン（HEATHROW観測所）と明示しました。国を指定した場合は収録済みの首都を使い、首都の欠測を別都市で埋めません。有効な都市指定を持つURLを優先します。
- 気候欄の右側は「雨温図 → 気候区分と観測値の説明 → 特徴的な農畜産物」の順に表示します。都市の選択に連動し、説明は折り畳まず通常のページスクロールで読めます。図の上の重複した前置きと選択欄は置いていません。
- 月表、年間の要約、品目統計の収録状況は3列全体の下に置き、雨温図を重複させません。統計はニュースの固定表示に重ならない独立領域です。
- 自然環境の表示を変えても都市・地物の選択を保持します。違う表示の地物は出さず、元の表示に戻ると再表示します。別都市を選ぶと地物選択は解除します。

## データの意味

分布面は圃場・牧場の境界でも、全生産域でもありません。元格子の正値の第80百分位を品目別の基準にし、5×5格子で平滑化、500km²未満の孤立域を省略、輪郭を簡略化し、対象国の陸域で切り抜いた概略図です。異なる品目の面積や色を数量比較に使えません。元格子の値・ゼロ・欠測は変更していません。数量の確認欄は元格子の推計値と明示しています。

出典・手順・入力と出力のハッシュは `public/assets/atlas/europe/farming-overview-v2/manifest.json` に記録しました。生成処理は `scripts/europe/prepare-farming-areas.py` です。牛の肉用・乳用、鶏の肉用・採卵用は元資料で分離されていません。

気候欄の農畜産物の説明と一次資料へのリンクは `src/data/atlas/europe/climate-farming.ts` にまとめました。説明中に例の対象地域を明記し、都市の観測所周辺すべての作付けを示すものとは扱いません。気候区分が未収録のアテネとレイキャビクは、近隣区分で埋めず、その地域の農畜産物の例を別に表示します。

## 残るデータと後段の実装

- 農畜産物の販売総額（米ドル）、需給・用途別消費、生産量・世界シェア、輸出額・相手国は未収録です。地図の面積・密度や国全体のGDP比率で代用せず、統計欄に未収録と表示します。
- オリーブ・ブドウ単独の分布と、未収録首都の観測値は補完していません。気象庁資料の降水欠測は年間0として表示しません。
- 水資源は河川・湖の位置までです。地下水、降水量の等値線、流域の面は未収録と明示します。地形の面選択と等高線そのものの選択は未実装で、現在は代表地点の説明と格子標高の確認です。
- 産業・人口・林業の詳細化、新しい長文インサイトや比較経路は本対応に含めていません。
- 今回はPCを主対象としました。スマートフォン専用の完成確認は後段です。

## 検証

元格子・ラベル・分布面・穴・重複候補の検証、ON/OFF・単独表示・URLの状態検証、生成HTMLの4分野ナビと下部統計の配置を確認しました。PCの通常地図とSVG簡易地図を実際に開き、選択・非表示・単独表示・復帰・再読込、都市と地物の表示切替を確認しています。気候欄では24都市の図・説明・数値表の対応、元データとの一致、欠測と未分類、右側の読む順序と横のはみ出しを確認対象にしています。

変更は欧州専用のファイルに限定しました。他地域のファイルや共通コンポーネントは変更していません。
