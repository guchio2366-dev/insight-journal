# 欧州の国別概要・初回版

対象は既存の欧州表示区分45件（北10・西9・南16・東10）。国・地域を選び、農林業・自然環境・産業・人口・政治の短い要点を白地図の横で読む。各要点は一文、本文は原則1〜2文とし、対象国に結び付く地図・一次資料への入口を示す。225本の長文記事や新たな歴史・文化の網羅を完成条件としない。

農林業・自然・産業・人口は公開済みの地図と2023年WDI国別10指標を再利用する。450値中436値あり、14値は未掲載のまま。モナコの森林比率0%と欠測を区別し、負の人口増加率も保持する。全国指標と局所分布、推計格子と実測地点、都市の位置と人口量は混同しない。ロシアの全国指標はアジア側を含み、フランスの統計範囲は指標の出典に従う。

政治は現任者名や政治評価を含めず、公式制度説明・憲法本文に確認できる統治機関と関係のみを掲載する。確認日は2026-10-02、憲法の版年は出典一覧で別に示す。バチカンの2026-07-31基本法と2024年末の居住者数882人は、それぞれの対象年を示し、欠測の2023年WDIへ代入しない。コソボは既存表示コードであり、地図の区分から国家承認を断定しない。

各国の4分野入口はその国の選択を渡す。特定の地点・主題を示す入口は該当する地点・主題へ直接進み、到着先に「国名の概要へ戻る」を置く。戻り先は元の国・テーマ・選択都市を保持する。国別概要は問いの入口であり、概要からの遷移を異なる統計同士の因果の証明とは扱わない。

PC画面で地図、要点、短い本文、テーマ切替、根拠への入口を同時に読む構造を使用する。全指標、出典、原年、確認日、範囲の詳細は開閉可能にする。専用の欧州コンポーネント・スタイル・コントローラを使い、完成済みの米国・カナダ・メキシコ・アジアと共通概要実装を変更しない。

検証は225項目のデータ契約と実表示、450数値一致、出典・地点・単位・欠測、180の国×分野入口、URL・テーマ・履歴・名前付き戻りを含める。必須全体チェックとCI、親の実画像目視、配備commit・公開HTML/素材一致、公開実操作を通して初回版を閉じる。

この版は全225テーマの長文、全域の地下水、全域同一粒度の宗教・民族、全統計・全歴史の完成を意味しない。それらの未完成範囲を今回の初回版へ混ぜない。
