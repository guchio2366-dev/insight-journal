# 自然環境 第2段階 実装・検証

設計PR #30のv2.2、第2段階に対応。基準mainは `4fa880b80e5b9919ba39e59d33515e13c61140c0`。農業v7と産業内訳の変更を保持した。

## 実装

- 都市選択と雨温図を「米国本土の自然環境」の気候欄に配置。960px以上は地図と概要欄の2列、それ未満は1列。
- 都市の観測値と地域の気候区分ポップアップを独立管理。地域を選んでも都市の図・ハイライトは保持。都市を選ぶとポップアップを閉じる。
- 都市の選択解除、画面外の都市へ戻る操作、1列時の雨温図へのリンクを追加。選択ではカメラ・ページを移動しない。
- URLのcityとnatureFeatureの共存、履歴復元、表示切替後の都市・月別数表の展開状態を保持。
- 元の12都市・144か月のNOAA 1991–2020年平年値、共通軸、出典、観測所情報を再利用。新しいデータ取得や図表ライブラリなし。
- 12個の既存SSR図を再利用し、表示する図は1個。都市のセレクターも1個。

## 公開前の検証

`npm run check` 成功：単体77件、ビルド済みページ・操作ロジック25件、release検証。

追加の重点確認：都市と地域の説明の共存、同じ都市の再選択、Escapeの優先順位、明示解除とフォーカス、画面外での図保持と明示的なカメラ移動、URL復元、他分野でEscapeを押しても都市を記憶、数表の展開保持、DOM個数と分類画像の取得回数。

Happy DOMとMapLibreの描画境界モックによる操作テストは実機・描画検証とは別である。公開後に既存の画面検証ページで390×844、820×1180、1180×820、1280×800を確認する。Safari/iPad実機はこの環境では検証しない。
