# 農業 v7：実装・検証記録

記録日：2026-09-14。設計は [PR #32](https://github.com/guchio2366-dev/insight-journal/pull/32) の v7.0。実装の比較基準は main `942dfb1da0358efa670574ab8f0cdb4fc6af58b9`（自然環境 Stage 1、PR #33 反映後）。

## 実装した動作

- 作物5分類の世界生産を共通ドーナツ図へ変更。公表世界値を分母とし、上位5か国・地域＋米国＋その他、米国数量、10年の推移と数値表を表示する。
- 畜産5分類を作物と同じ詳細配置に統一。地域の説明、米国の供給と行き先、製品輸出先、世界生産と米国シェアを揃えた。数量と輸出額の対象・年・単位は各図に表示する。
- 酪農は乳脂肪／無脂乳固形分換算を切り替える。生乳生産と市場出荷を区別し、製品別輸出額も表示。採卵鶏のふ化用は独立した用途とする。
- 詳細操作を地図初期化から独立させた。作物・畜産の選択と乳換算はURLに保存し、既存アンカー、履歴、キーボード操作、分野の往復に対応する。JavaScript無効時は全文・図・表を順に表示する。
- 地図の作り直しや追加の統計API取得は行わない。固定した公開原表の抜粋から生成するため、通常のビルドは外部統計サービスを必要としない。

主な実装：`AgricultureDetailPanel.astro`、`ProductionShareChart.astro`、`LivestockSupplyUse.astro`、`LivestockExports.astro`、`atlas-agriculture-details.ts`。既存の `atlas-explorer.ts` と `atlas-state.ts` に接続し、自然環境 Stage 1 の変更も保持した。

## データの確定範囲と制約

出典・商品コード・抽出条件・丸め差・再現手順は [畜産統計のデータ記録](atlas-livestock-statistics-data.md) を参照。

| 指標 | 採用範囲 |
|---|---|
| 米国数量 | WASDE-675、2025暦年、p.32–33。肉3分類・卵・乳2換算 |
| 世界生産 | FAOSTAT QCL、5分類に共通する2015–2024年。世界・米国は同じ原表系列 |
| 製品輸出 | GATS、2025年1–12月の総輸出額。全相手先と採用商品コードの合計を照合 |

FAOの公表世界値と国別値の合計には原表上の差があり、理由は未確定である。世界値を置き換えず、その他が集計差を含むことを各図に表示した。加工卵・卵白製品の公開コードは鳥種を分離しないため、鶏のみへの推定配分を行わず、この範囲差も常時表示する。設計で想定した他鳥種の完全分離は未達である。
