# 欧州基礎地図

西欧から東欧・ロシア西部まで45の国・地域を選択できる基礎地図。地域切り替え、国の拡大、URL復元と履歴移動に対応する。地図一覧とサイトマップから到達できる。

## 出典と加工

- Natural Earth Admin 0 Countries 1:110m、public domain。原本Git blob: `1e6ab74c7042f97013be69ceec798be8e1aff27d`。
- 1:50mからマルタ・アンドラ・リヒテンシュタイン・モナコ・サンマリノ・バチカンを補完。原本: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- 1:50m原本のSHA-256: `3e458fc036ad0a66411f2c1e6cac49c5d7bfb81cb1123bc513b22511a2b7fdeb`（2026-09-25取得）。
- 原本のEurope区分を北欧・西欧・南欧・東欧に分類。周辺23地物は灰色で表示。境界と区分は原本の表現であり、現在の実効支配線を示すものではない。
- 西経25度〜東経65度、北緯32度〜73度に輪郭を切り出してから投影する。フランス海外領土やロシア極東の座標が国選択時の拡大範囲へ混ざらない。
- 北緯53度を標準緯線とする等距円筒図法。面積比較用の図ではない。

## 検証

輪郭の切り出し、東欧・小国の収録、URLでの選択、ブラウザの戻る操作、PC・携帯幅の表示を確認する。自然環境・農林業・産業・人口の分布レイヤーは今回の基礎地図には含まない。
