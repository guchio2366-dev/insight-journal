# 欧州地図：基礎地図（第1段階）

## 目的と並行作業の境界

欧州の位置関係を読める独立した地図を追加する。北米・アジアのページ、コンポーネント、データは変更しない。地図一覧へのリンクと共通コンポーネントの整理は、進行中の別作業との統合時に検討する。

## 地理データ

- 出典：Natural Earth、Admin 0 Countries、1:110m、public domain。
- 固定した原本：`nvkelso/natural-earth-vector` の `geojson/ne_110m_admin_0_countries.geojson`、Git blob `1e6ab74c7042f97013be69ceec798be8e1aff27d`。アジア基礎地図と同じ原本。
- 加工：原本で `CONTINENT=Europe` の39地物を選択対象とし、画面に入る周辺23地物を灰色の文脈として追加。輪郭の座標は変更せず、属性を `code`・`name`・`subregion`・`kind` に絞った。
- 地域区分：原本の `SUBREGION` を北欧・西欧・南欧・東欧へ対応。地理的・統計上の区分であり、政治的な所属の判断ではない。
- 表示範囲：西経25度～東経65度、北緯32度～73度。ロシアは表示範囲内の西部を示す。
- 1:110mでは小国・島が欠ける場合がある。境界と名称は出典の表現であり、主権や地位についての見解を示さない。

## 操作

- 地域と国・地域を選ぶと地図を拡大し、対象の輪郭を強調する。
- 同じ選択はボタン一覧でも操作できる。狭い画面では地図を横スクロールできる。
- `region` と `place` のクエリを共有でき、戻る・進む操作で状態を復元する。
- ページは `noindex` とし、地図一覧にはまだリンクしない。

## 次の段階

実データと出典を決めてから自然環境・農林業・産業・人口の分布を追加する。概略の国境からテーマ別の分布を推定しない。
