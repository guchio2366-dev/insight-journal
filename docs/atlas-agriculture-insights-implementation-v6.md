# 農業の関係解説・数量収支 実装記録 v6

基準main：`11b0605e60bdc503b6d5329446b0a5f7764e9692`。内容tree `fce10751a53569ea20ecf0d15d3ff0d0d3e09fe8` と一致するチェックアウトを独立複製した。自然環境と主要産業の公開版を保持。中断前の未公開ローカル差分が失われていたため、保存済みv6設計と原資料から復元した。

## 実装

- 農業の地図直下に「とうもろこし・大豆と豚」「大平原の小麦と牛」「カリフォルニアの米と水」。iPad横は本文まで開き、狭幅は3要点を常時表示して本文を開閉する。
- 比較で既存作物の輪郭・指定した畜産代表点を強調。地図1個・既存投影を共用し、カメラ、全国統計、下部作物タブ、層の設定は保持する。非表示の層は明示操作でのみ表示。
- relationをURLへ保存し、単一地域との同時選択を正規化。直接の地図選択で関係強調を解除。閉じると比較ボタンへフォーカスを返す。詳説リンクは対象作物タブを開く。
- 複数対象の図形全体・地名・記号・操作部をカードの保護領域に含め、余地がなければ地図下に表示。原稿用boundsは配置の安全判定だけに使い、栽培境界を作らない。
- WebGL失敗時も静的HTMLの原稿・統計を読み、正確な既存座標をWebメルカトルへ変換したSVGで代替図の比較ができる。元画像の範囲 -128/22/-64/52、1800×1084と一致。輪郭はビルド時に生成し、閲覧時の再取得・画像解析なし。
- 5作物に同じ母数の供給・行き先の2本の積み上げ棒、全区分の直接ラベル、元値の表、用途と輸入の解説。小さな輸入を水増しせず、在庫を国内消費と混ぜない。
- 温度・水・耕地の9組18箇所を対応する下線で表示。耕地は大型機械での栽培条件として、生育条件と分ける。酪農も生乳生産と加工、山地だけでは説明できないことを明記。

いずれも供給=国内生産+輸入+期首在庫、行き先=排他的国内利用+輸出+期末在庫+原表の符号付き調整。許容差は各項目の公表精度から算出し、差を用途へ配賦しない。5表の採用値では収支差はゼロ。

とうもろこしのその他FSI=6815−5436。蒸留かす等や大豆油・粕を原料投入と重複加算しない。綿花は行き先17.60に未勘定-0.04を別記。2本の棒は同じ尺度で、総供給100%の線からの差を保持する。

設計の米の精米換算候補は、表内の整合を優先してWASDEの**籾米換算**に具体化した。原表の重量を任意の歩留まりで変換しない。玄米と籾米は区別。小麦の貿易には製品の小麦換算も含む。下の輸出先円グラフは2025暦年・米は精米換算であり、収支棒の内訳として接続しない。

輸入品の最終用途別割合はこの需給表では分からないため出さない。米の香り米、小麦粒と製品の輸入はUSDA ERSの各Sector at a Glanceで根拠を確認。とうもろこし・大豆の微量輸入は最終用途を推測せず記述。綿花輸入の0.00は丸め値として扱う。

## 検証

ローカルURLはクラウド検証ブラウザのネットワーク制限により開けず、公開検証ページでCSS寸法を確認した。実機Safari・GPUによる描画は、DOM試験や代替図の画面確認と区別する。

ローカル自動検証：単体67件、完成サイト・実コントローラー15件、ビルド、release検証を通過。地図描画境界だけを置換し、20回比較・URL競合・下部統計維持・層の明示復帰・自然環境との往復・WebGL例外後のSVG切替を試験した。GPU描画の検証ではない。

配信量：農業HTML gzipは既存71,575 bytesから107,740 bytesへ、追加36,165 bytes。地図制御・産業制御・地図CSSのソース全体を圧縮した上限25,382 bytesを加えても追加100KBの目標内。新たな地理取得・地図API・依存パッケージ・常駐サーバーなし。
